# 현재 게임 구현 내용

기준: 2026-10-19 현재 작업 트리의 코드·자료.

## 화면·지도

- 주간 서울 대항전, 재해 모드, 기록 경쟁, 데이터 화면.
- 서울 25개 구 경계·건물·도로·보행로·녹지·하천 표시.
- 구 검색·선택, 소속 구 강조, 지도 이동·회전·확대·축소, 전체화면.
- 같은 위치·선택·확대 상태를 유지하는 3D·2D 전환. 최소 확대 거리 18m.
- 가까운 건물 타일의 지연 로딩, 건물 형상 처리용 Worker, 표시 객체·캐시 상한.
- 지도 자료의 출처·기준일·표시 가정 조회.

## 시설 설치·예산

- `시설 설치하기` 패널에서 시설 선택 → 후보 선택 → 면적 입력 → 설치 확정.
- 지도 설치 6종: 빗물정원, 투수포장, 녹화지붕, 생물저류시설, 식생수로, 침투 트렌치.
- 선택한 시설을 설치할 수 있는 후보만 표시·선택.
- 투수포장의 차도, 인도·보행로, 주차장·기타 지상 후보 필터. 지도 도로 클릭으로 후보 선택.
- 면적 입력·슬라이더, 후보별 면적 상한, 시설별 단가·참고비·사용 가능액 표시.
- 회원별 공동 예산 20억 원과 시설별·사업별 사용액·잔액 계산. 같은 사업의 예산을 공동 차감.
- 재해 설계는 여러 구의 배치를 하나의 예산으로 합산하고 해당 설계의 잔액 표시.
- 서버에서 후보·허용 시설·면적·예산·동일 위치 중복 검사.
- 공개 기존 시설의 확인된 건물·부지와 같은 공간·층위에 대한 신규 설치 차단.
- 공개 기존 시설 표시 켜기·끄기, 시설 종류·원문 제원·출처 조회, 확인된 건물·부지와 종류별 3D 기호 표시.
- 설치 당시의 후보 형상·시설 제원·원가·정책·출처 해시 보존.
- 사용자 시설 6종의 종류별 3D 기호·2D 도형, 선택 상태·본인 시설 구분. 치수 근거가 없는 형태는 표시 기호로 취급.

## 주간 서울 대항전

- 가입 시 소속 구 선택, 미선택 회원의 소속 구 1회 지정.
- 로그인한 회원이 소속 구에 시설 설치. 다른 구는 이동·조회.
- 서로 다른 회원은 같은 후보에 설치 가능. 같은 회원의 동일 위치 중복 설치 차단.
- 설치 확정 후 다음 월요일 00:00 KST까지 변경·철거 제한.
- 시즌 종료 시 설치의 활성 배정 해제·예산 복원, 설치·비용·계산 기록 보존.
- 설치 이후 실제 관측 강우를 적용한 시설별 누적 기여 계산.
- 같은 위치의 회원별 시설·면적·누적 기여·계산 완료 시각 조회.
- 이번 주·지난주 구별 순위, 개인 상위 100명, 내 순위, 지난주 우승 구 표시.
- 같은 점수 공동 순위, 음수 기여 보존, 미계산·일부 미평가·집계 완료 상태 구분.
- 종료 주의 평가 구간이 모두 계산된 경우 양수 최고 기여 구를 우승으로 확정.

## 재해 실험

- 2010-09-21, 2011-07-27, 2022-08-08 집중호우 사건 선택.
- 서울 25개 구별 관측 강우를 공통 지도에서 재생.
- 재생·일시정지, 초 단위 시간 이동, 1~3,600배속, 첫 비·강우 최대 시각 이동.
- 비회원의 시설 배치·설치 취소·자동 계산·현재 재생 시각까지 누적 효과 조회.
- 설치 당시 재생 시각을 시설별로 기록하고 설치 전 효과는 제외.
- 여러 구의 배치를 유지하며 구별 계산·진행 상태·실패·재시도 표시.
- 상단 타임라인에 전체 구의 설치 시각·시설 아이콘 표시. 가까운 표식 묶음 펼치기, 표식 선택 시 해당 시각·위치로 이동.
- 로그인 회원의 사건별 설계 저장본 생성·재접속 복원. 전체 취소의 빈 설계도 저장.
- 저장 요청 재시도의 중복 방지, 다른 창에서 변경한 저장본과의 충돌 검사.
- 같은 화면에 남아 있는 비회원 설계의 회원 저장본 가져오기.
- 현재 공개 형상에 과거 강우를 적용하는 실험으로 표시.

## 재해 제출·기록 경쟁

- 로그인 후 최신 설계 저장본을 확정하여 제출.
- 모든 구의 확정 배치를 설치 시각과 무관하게 사건 평가 시작부터 종료까지 별도 계산.
- 제출 당시 저장본·설치 시각·원가·입력을 고정하고 이후 실험 편집과 분리.
- 제출별 대기·계산 중·성공·실패 상태, 최종 평가체적 차이, 재현 자료 다운로드.
- 사건·평가 규칙별 순위, 회원별 최고 기록, 공동 순위, 설치비·제출 시각 표시.
- 설치 시각 실험의 진행 효과와 전체 기간 제출 결과를 별도 표시.

## 관측·계산·물 표시

- 기상청 직접 조회를 통한 현재 구별 강우·기상 상태 표시. 관측 시각·지연·결측·만료 구분.
- EPA SWMM 5.2.4를 이용한 시설 없는 기준안과 설치안 비교.
- 유출·시설 배수·최종 저류·초기 저류를 반영한 평가체적 차이를 m³로 계산.
- 주간·재해의 현재 경쟁 지표는 독립 표면 평가체적 차이. 계산 실패·누락을 0점으로 대체하지 않음.
- 선행 관측 기간의 계산 상태를 평가 시작으로 이어가고 선행 기간의 기여는 평가 점수에서 제외.
- 실제 결과가 있는 경우 시설 전후 유출 비교·물수지·시설 상태·원가 근거 조회.
- PostgreSQL 작업 큐, 요청 중복 방지, 작업 점유 만료·재시도·실행 시간 제한.
- 계산 입력·엔진·정책·원본·결과 해시와 재현 묶음 보존.
- ANUGA 지표 계산과 SWMM 관망의 물 교환, 수심·유속 원 프레임 저장·조회·지도 표시 경로.
- 공개 현재 지표 계산·연장·재생·게시 워커. 현재 등록된 서울 운영 지표 모형은 0개.
- 주간에서 과거 침수흔적 사건 선택·비교, 재해에서 선택 사건의 침수흔적 표시.
- 과거 침수흔적은 보라색, 하천은 청록색, 계산 침수는 수심·속력 색상으로 구분.
- 계산 수심의 상대 두께와 확보된 유향·유속 표시. 반사·굴절·잔물결·빗방울 재질 적용.
- 재해 재생 시각·배속·정지에 물 표현 연결. 물결 재질과 침수흔적을 계산 수심·시설 효과로 사용하지 않음.

## 도시·교통 표현

- 주간 현재 시각·재해 재생 시각에 따른 태양 위치·하늘·그림자·수면 밝기.
- 야간 창문·가로등·차량 전후등 점등.
- OSM 도로·보행로를 따른 차량·보행자 이동, 일방통행·우측 차선·보도 반영.
- 시간대별 생활인구에 따른 표시 객체 수 배분. 주간은 유효한 현재 장소 인구·도로 속도를 우선 사용하고 참고 인구로 복귀.
- 재해 시간 이동·배속·정지에 교통 위치·표시 인구·조명 연결.
- 공개 경계가 있는 지상 주차장 523곳의 주차 칸·정차 차량 표시. 가까운 80곳·3D 정차 차량 400대 상한.
- 주차장 내부 통로를 일반 차량 통과 경로에서 제외. 지상 설치 시설과 겹치는 주차 칸 제외, 투수포장 위 주차 유지.
- 표시 침수와 접촉한 차량의 감속·정차·비상등, 보행자의 건조 구간 회피·고립 신호, 정차 차량 노출 기호.
- 교통·주차·조명·침수 반응은 표시 객체의 연출로 구분하며 실제 피해·교통 관측·점수에 합산하지 않음.
- 화면 숨김·동작 줄이기 설정에 따른 연속 애니메이션 중단.

## 계정·접근 제어

- 플레이어 가입·로그인·로그아웃, 기업·기관·정부 회원 가입 신청.
- 단일 관리자의 조직 회원 승인·반려·정지와 이력 기록.
- Argon2id 비밀번호 저장, DB 세션·로그인 시 세션 교체, 상태 변경 요청의 CSRF 검사.
- 관리자·조직 회원의 TOTP 다중 인증.
- 회원 소유 설계·계산·제출 접근 검사, 비회원 계산의 세션별 소유권 분리.
- 비회원 계산의 세션별·네트워크별·전체 호출 한도와 동시 작업 제한.
- 공통 오류 응답으로 내부 오류·스택·비밀값 노출 차단.
