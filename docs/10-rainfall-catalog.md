## 관측소 대표성

[기상청 성동 421 공개 지점 상세](https://data.kma.go.kr/tmeta/stn/selectStnDetail.do?pgmNo=82&isSelectStn=Y&stdStnNo=421)의 현재 게시 좌표는 WGS84 경도 127.03885, 위도 37.54721, 해발고도 34.73m. 페이지의 GPS 측정일은 2005-10-25. 성수 실험 구역 중심 127.05400, 37.54425까지 WGS84 지오데식 거리 약 1.38km. 출처 페이지 해시·조회일·유효성 한계는 `data/derived/kma-station-421.json` 보존.

2026-10-16 추가 승인 후 지상관측 지점정보 API에서 2024-06-22 00:01, 2024-07-02 00:01, 2024-07-18 05:00 KST를 각각 조회해 같은 좌표·해발고도를 확인했다. 요청 조건·원본 해시는 `data/manifests/kma-station-421-*.json`, 시점별 좌표는 `data/derived/kma-station-421-*.json`에 보존. 특정 시점의 API 조회 결과이며 관측소 전체 이전 이력이나 현장 실측 검증을 뜻하지 않는다. 기존 모델 원문의 `UNVERIFIED` 값과 원문 해시는 보존하고 추가 확인 근거를 별도 제공한다. 같은 창의 두 관측소 총강우 차이는 성동−서울 = −5.7mm이며, 60분 최대 강우는 성동 쪽이 1.3mm 크다. 총량이 적다는 이유로 모든 시간대 강우가 약하다고 판단할 수 없다. 두 관측소 차이를 현장 오차율이나 공간 보정계수로 사용하지 않는다. 비교 결과는 `data/derived/rainfall-comparison.json`.

## 해석 제약

- 6월 22일과 7월 2일은 강우 이후 관측 구간이 짧아 장기 배수·저류 회복 평가 불가
- 7월 18일은 창 시작 2~3분 후 강우가 있어 충분한 선행 상태 초기화 자료로 사용할 수 없음
- 자정 누적 초기화를 추정하지 않으므로 00:00~00:01 등 창 밖 강우 미포함
- 증발 0·초기 포화도·침투계수·유출 경계·유입 동선 가정 유지. 토양/관망 보정·독립 유출 검증은 별도 필요
- 일시 저류를 영구 저감으로 오인하지 않도록 최종 잔여저류를 평가체적에 포함
- 강우별 순위 분리. 다른 강우의 점수끼리 절대적인 설계 우열 판정 금지

## 구현·재현

`data/models/catalog.json`의 네 모델은 정확한 원문 SHA-256으로 식별. 서버·워커 동일 목록 사용, 런타임 임의 URL/경로 불허. 기존 `seongsu-lab.json` 바이트 유지. 모델 간 배치 복사는 새 설계이며 기존 버전의 모델 교체 차단. 공개 리그의 강우 해시 불변.

실제 PostgreSQL→워커→SWMM 5.2.4로 G1 빗물정원 40m², 22,400,000원 배치의 세 강우 계산 성공. 모든 물수지 오차 절대값 0.02% 미만. 각 재현 ZIP의 18개 파일 해시와 기준안·배치안·민감도·분 시계열 재계산 일치. 이 검증은 소프트웨어 재현성과 수치 수지 검사이며 현장 정확성 검증이 아니다.

```bash
simulation/.venv/bin/python scripts/fetch_kma.py --station 421 --start 202406220001 --end 202406222359
simulation/.venv/bin/python scripts/fetch_kma.py --station 421 --start 202407020001 --end 202407022359
simulation/.venv/bin/python scripts/fetch_kma.py --station 421 --start 202407180500 --end 202407182359
simulation/.venv/bin/python scripts/prepare_rainfall_catalog.py
simulation/.venv/bin/python scripts/verify_model.py
```

카탈로그 재생성에는 기존 서울 108 원본도 필요. 원본 해시가 달라지면 새 자료 버전으로 검토 후 등록. 기존 배포 모델 덮어쓰기 금지.
