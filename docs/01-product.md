# 제품 요구사항

## 최신 게임 규칙 · 2026-10-19

이 절은 이전의 공유 위치 독점·시즌 중 철거·주간 과거 흔적 미제공·침수 체크박스·재해 전체 기간만의 실험 계약보다 우선한다. 아래는 요구사항이며 검증 전 구현 완료 표시가 아니다.

- 주간 서울 대항전: 소속 구에 설치하되 다른 회원과 같은 위치 허용. 회원별 설계는 독립 비교 시나리오이며 서로 겹친 회원 시설을 같은 물리 공간에 중복 합성하지 않음. 본인의 동일 위치 중복 배치는 금지. 설치 확정부터 해당 주간 시즌 종료까지 변경·철거 불가. 설치 시각 이후 실제 관측을 연속 계산하고 시설별 누적 원 지표/점수·다른 회원 시설 점수·개인/구 순위를 공개. 시즌 종료 시 확정 기록 보존, 미계산·실패는 0점으로 위장하지 않음. 지도 구 표식의 일괄 `평가 대기` 문구 제거.
- 화면 구성: 별도 관측 강우 메뉴·선택창·정보 카드·비교 차트는 노출하지 않음. 데이터 탭에도 강우 카드·목록·다운로드를 두지 않음. 시설 전후 차트는 실제 계산 결과가 있을 때만 표시. 기관 리그는 준비 중으로 제한. 지도 기상 표현·재해 시간 재생과 계산 입력·개별 재현 묶음의 출처는 유지.
- 지도 물리: 실제 관측 강우·기상과 공개 지형·연결 입력을 SWMM/ANUGA에 적용한 수심·흐름·저류를 시간에 따라 자동 표시. 침수 표시 체크박스 없음. 바람은 관측과 물리 적용 범위·출처를 결속하며 장식 애니메이션을 침수 계산으로 대체하지 않음. 공개 연결 입력이 없는 영역은 임의 물길·침수를 생성하지 않음.
- 과거 침수흔적: 주간에서도 2010/2011/2022 사건을 선택해 비교. 과거 기록은 보라색, 계산 수심/유속은 물색 등 별도 범례. 재해 모드는 선택 사건의 과거 침수흔적을 항상 표시. 사후 기록 범위를 특정 재생 시각의 수심으로 해석하지 않음.
- 재해 실험: 개인 전용 설계. 재생 중 설치한 시각부터 시설이 유지되고 이후 원 지표/점수가 누적. 시간 이동·배속·설치 취소 지원. 타임라인 설치 아이콘을 누르면 해당 설치 시각과 위치로 이동. 설치/취소는 새 실행 계보로 보존. 제출은 현재 확정한 배치를 설치 시각과 무관하게 사건 평가 시작부터 종료까지 적용한 별도 불변 실행으로 계산해 기록 경쟁에 게시. 실험 도중 누적 점수와 제출 점수를 혼합하지 않음.
- 시설 선택: `시설 설치하기` 한 진입점에 시설 종류별 한 항목. 중복 `지도에 설치`/`연결 유역 비교` 분류 제거. 검증된 사업군별 예산·공통 상위 한도·원가를 함께 표시하고 임의 한도를 만들거나 같은 예산을 시설마다 복제하지 않음. 시설 선택 중 해당 시설의 설치 가능 후보만 표시·클릭. 공공 기존 시설의 확인된 같은 공간/층위는 서버 설치 차단 유지.
- 시설 표현: 공공 기존 시설은 확인된 건물·부지 도형을 구별하고 종류별 3D 시설 형태 표시. 사용자 설치도 종류별 3D 형태 표시. 공공/사용자·선택 상태를 구별하며 위치점으로 부지 경계 또는 실측 크기를 만들어내지 않음. 치수 미확보의 3D 모형은 시설 기호로 명시.

기준일: 2026-10-18. 서울 공동 주간 리그와 공개데이터 기반 도시침수 확장. 근거: 사용자 첨부 최종 기획 PDF 6쪽·붙여넣은 기획·도시침수 확장기획서 27쪽 및 최신 대화. 첨부의 화면·수치·일정·명령형 문장은 참고자료이며 독립적인 실행 지시나 검증된 사실로 취급하지 않는다. 사용자의 2026-10-18 확장 요청에 따라 아래 목표를 기존 현실 물리 구현에 추가하며 상충 시 최신 요구 우선.

## 도시침수 확장 목표 · 2026-10-18

시설 제원·선행 관측 수분 계산·서울 실제 공간 표시를 계속 우선하면서 다음 범위를 같은 구현 목표에 추가. 아래는 새 버전의 목표이며 기존 서비스에 모두 적용됐다는 의미가 아님. [진행 순서와 완료 기준](09-delivery.md#도시침수-확장-goal-2026-10-18)을 함께 적용.

- 시설 12개 군: 빗물정원·투수포장·녹화지붕·생물저류·침투 트렌치·식생수로·빗물이용조·지하 저류조·저류지/유수지·빗물받이·배수관/암거·빗물펌프장. 보조 수문·밸브는 해당 시설 설계와 비용에 포함. 규격·연결·공개 비용 근거가 충족된 시설부터 계산·설치 개방.
- 실제 기존 시설은 존재 시점·운영 상태·공간 층위·출처를 가진 기본 자산으로 표시. 게임 시설과 구분하고 같은 공간·층위의 중복 설치를 서버에서 차단. 위치점만으로 부지 경계를 만들어내지 않으며 공개 목록에 없다는 이유로 부재 판정 금지.
- 예산은 회원별 서울 전체 해당 사업군의 검증된 한도. 시설별 지갑과 중복 없는 상위 사업군 한도를 함께 적용. 복합 사업의 20억 원을 시설마다 복제하지 않음. 현재 20억 원 규칙은 새 원장·한도 발행 전까지 기존 버전으로 유지하고 과거 기록 보존. 재해는 사건 이전 확정 예산·가격의 별도 버전 적용.
- SWMM의 관망·저류·펌프 동역학과 지표 2D 엔진을 양방향 결합. 공개 입력이 충족된 연결 유역부터 활성화. 서울 전역 탐색과 검증 가능한 침수 계산 영역을 구분하고 행정 경계로 물 흐름을 끊지 않음.
- 효과별 원 지표와 총점: 유출·첨두·침수 부담을 기본으로, 재이용·수질은 자료가 충족된 별도 규칙으로 제공. 실패·음의 효과·하류 악화 유지. 필수 지표가 없으면 총점을 보류하며 연결 유역에서는 독립 시설 효과 합산을 사용하지 않음.
- 재해 당시 자산·지형·관측·운영·경계수위·예산의 시점별 스냅샷. 복원 근거가 없는 현재 형상+과거 강우는 스트레스 시험으로 구분하고 당시 재현 순위와 혼합하지 않음. 사건 도중 설계 변경은 별도 실행으로 생성.
- 공통 게임 화면에 계산 수심·유속·시설 동작과 실제 침수흔적 레이어, 시간축·비교·효과 카드 연결. 연구실에 불확실성·원가 원장·공간 결과·원 지표·계산 코드·동의 범위의 재현 묶음 제공.

2026-10-18 추가 계산 기반: 생물저류·침투 트렌치·식생수로·빗물이용조의 문헌 단면을 기존 공개 관망 집수구역에 연결하는 설계 컴파일러 구현. 대체 불투수 면적·중복 집수 제한·사다리꼴 수로·구경/수두 배수·시설별 상태/물수지 포함. 공개 서초 연구 관망의 7설계 실행 및 실패/악화 보존. 실제 위치·비용·배수 연결과 현장 검증은 남아 있으며 지도 설치는 아래 v8 계약에 따라 생물저류시설·식생수로까지 확장. 문헌 설계 계산 가능과 서울 현장 설치 가능을 구분.

공개 관망 연구 요청: 회원이 서초 공개 연구 관망의 실제 14집수 중 대상과 문헌 제원 4종·대체 불투수 면적·처리 불투수 면적을 선택하여 기준안/공동 설계의 관망 계산 요청. 카탈로그·원 관망·수치 정책·제원을 서버 입력 해시에 고정하고 회원 소유 작업·공용 lease 큐로 처리. 원 입력의 2010 강우·추정 외부 유입·초기 상태는 보존. 성공/수치 실패·월류/방류 변화·파일을 보관하며 계산 실패를 효과 0으로 대체하지 않음. 좌표계/기준고·현장 입지/가격 미확정으로 지리 배치·주간 점유/예산·당시 침수 복원·순위와 분리. 원가를 임의 부여하여 시설을 운영 개방하지 않음.

공통 시설 선택창: 주간·재해 모드 지도 하단에는 `시설 설치하기` 버튼 하나만 두고 오른쪽 패널에서 시설 선택. 기존 3종 버튼과 전체 필터의 중복 하단 나열 제거, 전체 후보 보기는 같은 패널에서 제공. 지도 설치 6종·관망 계산 전용 4종·연결 준비 2종(생물저류시설·식생수로·침투 트렌치는 관망 비교에서도 지원)의 현재 사용 범위를 표시하며 `시설 12종`을 설치 완료 수처럼 안내하지 않음. 관망 비교 7종은 회원 본인의 집수구역별 시설 면적·처리 면적 또는 저류조/관로 제원을 입력하여 같은 패널에서 계산 요청·진행 조회·기준안/설계안 비교·재현 묶음 다운로드 제공. 선택한 재해/실시간 강우와 별개인 공개 원 관망의 2010 강우 비교임을 제출 전 명시. 비용 미확정을 무료 설치로 표시하지 않으며 지도 점유·예산·순위에 합산하지 않음. 좌표계 미확인 관망을 서울 지도에 임의 배치하지 않음. 월류 감소와 외부 방류 증가는 각각 표시하고 수치 실패 시 효과 비교 보류. 계정 전환 시 이전 회원의 설계·결과 제거, 닫힌 패널의 자동 조회 중단.

관망 설계의 첨두 비교: 같은 원 관망의 모든 외부 출구와 엔진 평가 창을 고정하고 내부 수리 단계마다 방향별 체적·출구별 첨두·동시 유량 합의 첨두와 발생 시각 보존. 개별 출구 첨두를 합산하거나 표시 프레임에서 최고값을 추출하지 않음. 기준안/설계안의 수치 검사와 평가 창·출구 일치가 확인된 경우만 차이를 표시하며 음의 감소량은 증가로 표시. 이전 기록의 첨두 누락은 0으로 대체하지 않음. 입력·물리 계산·기존 결과를 보존하는 별도 읽기 전용 관측 빌드 사용. 첨두는 해당 연구 관망의 방류 지표이며 실제 서울 침수 위험·순위가 아님.

추가 이용조 설계의 원가 연결: 공개 논문에 수록된 2.35m³ 견적을 정확한 개별 용량·수량에 연결하고 물통·배관·펌프 등 세부 항목·연간 가정 유지비를 물리 결과와 함께 보존. 견적 업체만 변경하면 물리 결과 불변. 미산정 공사·세금·다른 시설은 무료로 취급하지 않으며 완전한 설치비는 미확정 유지. 문헌 발표 연도와 실제 가격 기준 연도를 구분하고 현재 서울 가격 또는 재해 당시 지출 승인으로 사용하지 않음.

운영 시설의 원가 기록: 신규 주간 설치·재해 실행의 수량×공개 참고 단가·원문/후보 해시·포함/미산정 범위를 같은 입력으로 고정. 주간 선택 시설과 재해 계산 결과에서 당시 내역 조회, 예산 반영 참고비와 미확정 전체 현장 공사비 구분. 원문에 없는 공종 비율·미산정 0원·과거 가격 소급 적용 금지. 원가·수량이 계산 입력과 다르면 실행 거부, 재현 묶음에 같은 원가 원문과 대조 코드 보존. 새 시설의 공사비·연결 근거 확보와 운영 개방은 계속 진행 대상.

연결 침수 계산의 원 지표는 선행 구간을 제외한 고정 평가 기간·외부 출구·침수 노출영역으로 집계. 깊이×면적×지속시간, 방향별 유출/역류 체적, 같은 시각 출구 유량 합의 첨두와 격자별 최대 수심/젖음 지속시간 보존. 화면 프레임·재생 배속 변경은 집계에 영향 없음. 원 지표 집계·고정 효과 정책·회원 시설 묶음의 표본 Shapley 계산·보관 결과 재생은 수치 사례로 구현. 서울 실제 노출영역/관망 연결, 시즌/사건 기준량 승인, 게임 효과 카드·서버 소유권/동의·새 순위 게시 연결은 별도 진행 대상.

새 공개 원본·API 권한은 구현 필요성을 조사해 한 번에 요청하고 기확보 항목을 재요청하지 않음. 최신 강우 API 직접 조회와 계산 사용 원문 보존을 분리. 자료 부족을 가짜 관측·무한 배수·임의 효과계수로 채우지 않음. 기존 기록·입력·점수·비용은 소급 변경하지 않음.

2026-10-18 연결 물리 진행: EPA 수평 유입부와 ANUGA 지표의 양방향 체적 교환 구현. 관망 수위·유입부 단면으로 유입/월류/재유입을 계산하고 지표 가용수량으로 교환 간격 제한. 현재는 수치 사례 실행 단계이며 공개 서울 연결 관망·지표 입력, 게임 침수 레이어·새 순위 연결은 진행 대상. 수치 실패와 미확보 영역을 숨기거나 가짜 침수로 표시하지 않음.

2026-10-19 풍응력 계산 기반: 보관 기상청 분 풍향·풍속과 풍속계 높이를 검증하여 ANUGA 4.0.1 수면 운동량에 연결. 바람으로 물을 생성하지 않으며 원문·방향 변환·높이 환산·밀도·항력·적분 정책과 운동량/일 원장을 보존. 같은 실제 기상자료를 사용하는 합성 수조에서 수심 재분포·수지·시간/격자 세분·동일 입력 재현을 확인. 현장 공간 대표성·도시 차폐·실제 연결 지형/관망/경계가 미검증이므로 주간/재해 운영에는 아직 미활성화. 진단 결과를 서울 침수나 점수로 게시하지 않으며 삭제한 별도 강우 UI를 복원하지 않음. 근거 `data/benchmarks/surface-wind-v1.json`.

## 기본 모드: 서울 공동 주간 리그

- 가입 시 서울 25개 구 중 거주 구 또는 원하는 소속 구 하나 선택. 상세 주소·거주 증빙 수집 없음. 기존 회원은 첫 공동 설치 전에 소속 구 선택. 선택 이후 구 이동은 기본 모드에서 제공하지 않음.
- 홈은 서울 전체 3D 지도. 현재 공유 설치·구별 합계 점수·개인 순위·현재 주 종료 시각과 직전 주 우승 구 표시. 다른 구도 상태 조회 가능하며 소속 구와 불투명도·경계 표시 구분.
- 로그인한 승인 회원만 자신의 소속 구에 설치 가능. 서버가 회원 상태·소속 구·실제 후보 위치·시설·면적·원화 예산 검사. 방문자·타 구·다른 회원 시설은 조회만 허용.
- 하나의 설치 위치는 한 회원만 점유. 이미 설치된 위치는 다른 회원 설치 불가. 동시에 들어온 요청도 데이터베이스 고유 제약과 트랜잭션으로 하나만 승인. 시설 변경·철거는 설치자만 가능하며 이력 보존.
- 기존 구별 도전 선택은 기본 진입 경로에서 제외. 과거 실측 강우의 개인 설계·기관 연구는 별도 연구 기능으로 유지. 기존 불변 기록·원본 자료 보존.

## 실시간 강우와 점수

- 최신 강우는 서버가 기상청 공식 API에서 직접 조회. 미리 수집·저장한 관측 테이블을 실시간 조회의 원천으로 사용하지 않음. 키는 서버에서만 사용하며 브라우저에 노출하지 않음. 공간 원본 등 다른 공개자료의 프로젝트 보관 원칙 유지.
- 관측소·관측 시각·조회 시각·지연/결측 상태 표시. 실패·결측을 무강우 0 또는 과거 강우로 대체하지 않음. 외부 호출 중복 억제는 같은 진행 중 요청에만 적용하고 오래된 응답을 최신값처럼 반환하지 않음.
- 서울 지도 비 효과는 최신 관측의 강수 감지(RE) 또는 연속 두 분의 일 누적 차이가 양수인 구에만 표시. 15·60분 누적만으로 현재 비 판정 금지. 자정 누적 초기화·직전 분 결측·역전은 분량 미확인 처리. 5분 초과 관측·조회 실패는 효과 중지. 구 경계 안의 설명용 빗줄기이며 구 전체 동일 강우·실제 침수·물리 입자 수를 뜻하지 않음. 3D/2D 동일 판정, 화면 숨김·동작 줄이기 설정 시 움직임 중지.
- 점수 계산 시 실제 사용한 관측 응답·출처·시간 범위·모델·엔진·배치 버전을 계산 재현 기록에 고정. 이는 최신 강우를 대신 조회하는 저장소가 아님.
- 신규 주간 설치는 서버 1초 해상도의 설치 시각을 고정하고 해당 순간의 SWMM 상태 이후부터 자동 계산. 첫 부분 분도 포함하며 기존 설치의 첫 완전한 분 규칙·원 점수는 보존. 이전에 사용한 관측 입력과 새 직접 조회 구간을 연결해 전체 상태를 재생하며 임대 토큰·만료 시각으로 중복 작업 결과 게시 차단. 최신 구간 결측·실패 시 마지막 성공 시각과 보류 상태 표시, 수분 상태·기간·주간 경계 초기화 금지. 겹친 과거 분량이 수정된 응답은 기존 입력에 조용히 덮어쓰지 않고 검토 상태로 보류. 실제 시설 목록의 선택창에서 계산된 침투·유출·저류·수심·토양수분 조회.
- 한 주는 한국시간 월요일 00:00부터 다음 월요일 00:00 직전까지. 주간 개인 점수의 합이 구 점수. 같은 계산/관측 구간의 중복 적립 금지. 설치 시각 이후의 유효 계산만 반영하며 주 경계에서 설치가 자동 삭제되지는 않음.
- 주간 점수는 시설 없는 조건과 설치 조건의 SWMM 평가체적 차이(m³)에 근거. 개인 기여의 합과 구 합계가 일치해야 함. 현 모델의 독립 표면 가정을 명시하고 공유 유역 상호작용·실제 현장 저감량으로 해석하지 않음. 점수 산식·입력·기간을 고정하고 검증 전 임의 점수 표시 금지.
- 물수지·관측·계산 오류 구간은 미평가 상태. 종료 주의 미평가 구간이 있으면 잠정 결과로 표시하며 성공 구간만으로 완료 우승을 확정하지 않음. 동점 공동 순위·공동 우승, 빈 주는 우승 없음.
- 공동 게임 순위는 `EXPLORATORY` 계산 기여(m³)를 표시하는 게임 규칙이며 공식 현장 성과 순위와 분리. 계산 기여는 기준 대비 유출·배수·순저류 차이의 분별 증가량, 음수 보존. 10⁻⁹m³ 단위 누적값 차분으로 집계하고 화면 반올림은 순위에 사용하지 않음. 설치별·주별 합산과 완료 분 수만 DB에 저장하고 분별 근거는 계산 산출물에 보존. 같은 구간 재생은 중복 적립하지 않음. 평가된 기록이 없는 참가자·구에는 순위를 부여하지 않으며, 완료된 지난주의 최고 기여가 양수일 때만 공동 우승 표시.
- CPU 점수·자동 탐색 기준안·관련 화면/API/생성 자료 삭제. 시설 없는 수문 계산과 EPA 엔진 검증 사례는 물리 비교·검증에 필요하므로 유지.

## 범위와 공정성

서울 25개 구 공유 설치·실시간 관측 조회·주간 구/개인 경쟁을 기본으로 구현. 공개 공간자료 기반 후보 위치·시설 6종·원화 비용·3D 조작·변경 이력·기관의 동의된 기록 분석과 재현 유지. 전국 자동 모델·실제 장치 제어·검증 없는 침수깊이/수질 효과·자동 시공 승인은 제외.

같은 소유역에서 면적·연결이 같으면 화면상 위치만 이동해도 결과가 같을 수 있다. 위치 보너스 등 임의 물리 효과 금지. 구별 합계는 참여 인원·시설 규모·실제 강우 차이를 포함하는 게임 규칙이며, 구의 정책 역량이나 현장 안전성 비교로 해석하지 않음. 공개 규칙 변경은 새 버전부터 적용. 개인 정보·연구 동의는 공동 지도 공개와 분리.
