# 현재 제품·게임 규칙

기준일: 2026-10-21. 이 문서는 현재 사용자 규칙의 기준이다. 완료 범위와 미지원 항목은 [제공 범위](09-delivery.md), 수치 정의는 [과학적 계약](02-scientific-validity.md), 화면은 [공통 UX](08-experience.md)에 둔다. 날짜별 변경 내역을 현재 요구사항에 누적하지 않는다.

## 목적과 범위

서울 공개 지도와 관측 강우를 바탕으로 시설을 배치하고 설치 전후 효과를 비교하는 게임이다. 공개자료·관측·계산·가정을 구분하며 임의 효과계수·가짜 관측·가짜 랭킹을 사용하지 않는다. 현재 게임 결과는 탐색 계산이며 실제 시공 승인·현장 침수 예측 정확도·정책 효과를 보장하지 않는다.

## 주간 서울 대항전

- 로그인한 플레이어가 자기 소속 구에 설치한다. 다른 구 지도·시설·순위는 조회할 수 있다.
- 같은 위치에도 서로 다른 회원이 독립적으로 설치할 수 있다. 본인 중복 설치는 차단한다. 다른 회원 설치가 위치를 독점하지 않으며 각 설계의 효과를 실제 공동 시공 효과로 해석하지 않는다.
- 설치를 확정하면 해당 주에는 수정·철거할 수 없다. 다음 월요일 00:00 KST 시즌 전환에 맞춰 새 설계를 시작한다.
- 설치 이후 관측 강우에 대한 계산을 누적한다. 회원별 설치·효과와 구별 합계를 제공하며, 계산이 없거나 자료가 누락된 값을 0점으로 만들지 않는다.
- 유효한 무강우는 0mm로 표시한다. 관측 결측·지연·계산 실패는 별도 상태다. 종료 주의 관측/계산이 불완전하면 확정 우승을 표시하지 않는다.

## 재해 모드·랭킹

- 비로그인도 서울 25개 구 어디에나 허용 시설을 설치하고 진행 중 효과를 볼 수 있다. 소속 구 제한 없음.
- 실험은 재생 시간의 설치 시각 이후 효과를 계산한다. 일시정지·배속·앞뒤 탐색과 설치 시간축을 공유한다.
- 제출은 로그인해야 하며, 동결한 전체 설계를 선택 사건 전체에 적용한다. 실험의 설치 시각 이후 점수와 전체 사건 제출 점수는 평가 구간이 다르다.
- 게스트의 제출·최종 점수는 서버 응답에서도 잠근다. 화면에서 숨기는 것만으로 처리하지 않는다.
- 회원 설계는 revision으로 저장하고 변경 충돌·제출 멱등성을 검사한다. 제출한 입력과 결과는 서로 결속한다.
- 현재 사건: 2022-08-08, 2011-07-27, 2010-09-21. 사건별 25개 구 강우 대응을 사용하며 현재 도시 배경을 재해 당시 도시 구조로 주장하지 않는다.

## 시설·설치·예산

현재 일반 지도 설치 시설은 빗물정원, 투수포장, 녹화지붕, 생물저류, 식생수로, 침투도랑, 빗물이용조 7종이다. 각 시설의 허용 표면·면적·단면·비용을 서버에서 검사한다. 서울 25개 구의 수치지형도에서 파생한 도로면·보도에는 투수포장, 공개 건물에는 녹화지붕·빗물이용조, 지원하는 경지계 참조 표면에는 나머지 시설을 연결한다. 지상 후보는 건물·교량/터널·철도·수면 등의 공개 제외 영역을 뺀 도형이다. 주차 칸·미확인 통행 방향·실제 시설 부지는 생성하지 않는다.

지도에서 허용되는 면적은 공개 경계 또는 명시한 설계 도형이다. 구조 하중·지하수·매설물·현장 교통하중까지 확인된 시공 가능 면적은 아니다. 외부 집수 연결이 없는 후보에는 주변 유출을 임의 가산하지 않는다. 공개 기존 시설은 출처를 가진 참고 자료로, 사용자 설치와 구분한다. 위치점만으로 부지·집수·시점별 운영 여부를 확정하지 않는다. 현재 공개 시설은 위치점 참고 자료이며 원형 후보와의 점 포함 대응을 설치 제외·점유로 사용하지 않는다. 공간·기상 버전과 미지원 피복 범위는 [공간 계약](19-spatial-source-audit.md#현재-서비스의-원형-공간-연결)을 따른다.

주간 개인 사업 예산은 20억 원(2,000,000,000원), 재해도 별도 설계당 20억 원이며 25개 구 합계에 적용한다. 실제 서울시 개인/구별 배정액이 아니라 공개 사업 규모를 참고한 게임 한도다. 시설별 한도가 표시되더라도 같은 사업 재원을 시설 수만큼 중복 생성하지 않는다. 서버의 원장·잠금·원가 스냅샷으로 초과 설치·경합을 막고, 취소가 허용된 흐름은 원 배정 금액을 복원한다.

빗물이용조는 건물에서만 설치한다. 건물 선택 후 소형·중형·대형 또는 크기 슬라이더로 용량을 고르고 다른 시설과 같은 설치 버튼을 누른다. 지붕 집수부와 건물 옆 지상 탱크가 자동으로 함께 나타나며 예산·계산·재해 제출에 반영된다. 별도 계획 저장이나 탱크/배관 설계 입력은 요구하지 않는다. 집수 면적×0.01m 용량·면적당 12,158원 참고비와 배수 조건은 문헌/명시적 가정이며 실제 시공·제품 인증·사용 수요를 확인한 값은 아니다. 자동 탱크 표시는 부지 점유를 보장하지 않는다. 기존 공간 초안은 일반 설치와 별도 보관하며 설치/예산으로 자동 전환하지 않는다.

이용조 계산 상세에는 자연배수와 별도로 일정 수요 운전을 비교한다. 문헌의 지붕 235m²당 하루 201L를 면적에 비례시킨 수요 가정으로, 가용 저류에 따른 잠재 공급·부족·월류·저류 상태를 같은 평가 기간에 계산한다. 주간·회원 재해 실험·전체 사건 제출에 보존하며 실제 재이용 관측량과 구분한다. 사용 후 하수 환류와 수질·공급 설비는 미계산이므로 공급량을 기존 순위에 더하지 않는다.

## 평가와 결과

현재 순위는 기준안과 설계안의 평가체적 차이(m³)다. 평가체적은 표면 유출 + 시설 배수 + 종료 저류 − 시작 저류이며, 음수 효과도 보존한다. 임시 저장을 영구 저감으로 계산하지 않는다. 시설별 값의 단순 합을 연결 유역의 공동 침수 피해 저감으로 바꾸지 않는다.

첨두·관망 월류·지표 수심 연구 계산은 기본 게임의 체적 차이 순위와 구분한다. 배출 중심시각 지연은 평가 구간 안에서 별도로 비교하며 체적 점수에 가산하지 않는다. 현재 체적 차이 점수 기준을 유지한다. 비용·현장 관리·연결 유역의 연구 범위는 [출시 범위](09-delivery.md)에서 별도로 관리한다. 다른 모델·강우·평가 경계의 결과를 같은 순위로 섞지 않는다.

시설 설치 메뉴의 ‘서초 연결 유역에서 설계 비교’는 공개 연구 모형의 14개 집수구역·26개 관로를 현재 2D/3D 지도에 연결한다. 도로 대조를 근거로 한 좌표계 가정을 표시하며, 생물저류·침투도랑·식생수로는 지도에서 집수구역을 선택한다. 이용조·저류조·관로·펌프는 패널의 원본 관망도와 연결 목록에서 설계하고 같은 비동기 계산·기준/설계 결과·재현 묶음으로 이어진다. 제출 당시 위치 가정과 원본 버전을 보존한다. 공개 모형의 2010년 강우·추정 외부 유입을 유지한 비교로, 현재 주간/재해 강우·사업 예산·순위에는 아직 연결하지 않았다. 생물저류·침투도랑·식생수로 설계에는 ‘지표 수심까지 함께 비교’를 제공하며, 같은 공개 지형을 연결한 기준안/설계안의 출구 방류와 여섯 지표를 별도로 표시한다. 계산 실패에는 개선량을 보류하고 원값을 보존한다. 1초 수문 간격 v2에서 세 시설을 함께 설치한 공개 사건 비교를 검증했으며 현재 게임 순위의 평가체적을 대체하지 않는다.

자연 하천, 과거 침수흔적, 계산된 침수 프레임은 별도 레이어다. 물결·풍향·반사·사람/차량 반응은 표시 기능이며 관측된 유속장·피해량을 뜻하지 않는다. 공개 운영 지표 모형 목록은 비어 있다. 위 연구 관망의 지표 결합과 주간·재해 흐름 통합은 [P3 작업](09-delivery.md#p3--연결-유역-한-곳의-실제-게임-흐름)으로 남아 있다. 지도 수면 표현만으로 서울 전역 실시간 침수가 계산된다고 안내하지 않는다.

## 계정·기관 활용

플레이어는 가입 즉시 이용한다. 기업·기관·정부 회원은 별도 소속 확인·관리자 승인을 거치며 일반 가입으로 기관 권한을 얻지 못한다. OTP는 관리자만 사용한다. 관리자는 단일 운영 계정이며 연구 자료 열람 권한이 자동 부여되지 않는다.

기존 기관 리그·연구실·후보 탐색의 미사용 프런트엔드와 전용 통신·상태·시험 코드를 제거했다. 이전 기록의 열람 동의·재현 계약에 쓰이는 서버와 저장 자료는 보존하며 새 대회는 현재 게임 기록만 사용한다. [기관 리그](17-league-participation.md), [기관 분석](18-institution-analysis.md), [활용 동의](16-utilization-consent.md), [보안](07-security.md)을 따른다.

## 대회 · 2026-10-21

기본 메뉴는 소개 홈(`/`), 주간 서울 대항전(`/weekly`), 재해 모드(`/disaster`), 랭킹(`/rankings`), 대회(`/competitions`)다. 홈에서 수달 여울이·물총새 가람이의 안내, 두 게임 모드·시설 7종의 3D 모형·주요 기능을 소개하고 각 화면으로 연결한다. 데이터 메뉴와 별도 페이지는 제거하고 기존 출처·예산/단가·관리/적합성·계산 내용을 홈 맨 하단 `/#home-data`에 모두 제공한다. ‘게임 시작하기’에서는 주간 서울 대항전·재해 모드를 먼저 선택한다. 홈 점수 안내는 현재 평가체적 공식·모드별 기간/집계·순위·예시를 제공한다. 새로고침·뒤로/앞으로 이동·주소 직접 접근을 지원한다. 관리자는 회원 관리와 결과 관리(`/admin/results`)를 제공한다. 기존 기관 리그 메뉴는 제거한다.

승인된 기관·기업·정부 회원은 소속 조직 명의로 대회를 개최한다. 이름·설명·실시간/재해 모드·서울 전체/선택 구·허용 시설 7종 중 선택·분 단위 개최 기간·순위별 상 이름/인원/1인당 상금을 등록한다. 재해는 현재 제공하는 사건 하나를 지정한다. 공개 후 조건은 고정하며 주최 조직 또는 관리자가 마감 전에 취소할 수 있다. 상금은 주최자의 시상 안내이며 결제·자동 지급을 수행하지 않는다.

참가자는 조건과 닉네임·순위·실시간 시설 설치 시각 또는 재해 제출 시각의 결과 공개에 동의하고 참가한다. 실시간은 기존 주간 게임의 소속 구·예산·주 경계 규칙을 유지하며 참가 후 개최 기간에 설치한 허용 구/시설만 집계한다. 종료 시각 이후 효과는 포함하지 않고 기간 내 원 계산의 누적값을 사용한다. 재해는 참가 후 접수 기간에 제출한 본인 설계의 지정 사건 전체 계산을 연결하며, 모든 시설의 구·종류와 입력/평가 버전을 서버가 검사한다. 기간 안에 접수된 계산은 마감 뒤 완료돼도 집계한다. 다른 대회의 조건 또는 다른 계산 버전을 섞지 않고 자료 누락은 잠정/보류로 표시한다.

대회 결과는 참가자·주최 조직·관리자가 순위순으로 조회하며 종료 후에도 보존한다. 관리자는 모든 주간 시즌·재해 사건·대회 결과를 조회한다. 주간 및 실시간 대회는 시설별 설치 시각을 포함하고 재해 순위는 전체 사건 제출 시각을 표시한다.

2026-10-22 사용자 요청의 운영 더미 계정은 `TEST_` 아이디·닉네임으로 식별한다. 23개 구에 각 3계정·계정별 3시설을 생성하고 중구(11140)·강북구(11305)는 비워둔다. 10계정은 2022년 호우를 실제 계산·제출한다. 운영용 계정은 비공개 일괄 생성으로만 만들며 공개 가입의 소문자 규칙은 유지한다. 로그인은 기존 소문자 아이디와 `TEST_[a-z0-9_]{1,27}`을 허용한다. 사용자 활동을 모방하는 가상 관측·효과·점수를 넣지 않고 설치 시각·기상·계산·순위를 원래 서비스 경로에서 생성한다. 계정 자격·운영 활동의 개인별 식별자는 비공개 실행 기록으로 보관한다.
