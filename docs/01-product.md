# 제품 요구사항

기준일: 2026-10-15. 근거: 사용자 첨부 최종 기획 PDF 6쪽과 붙여넣은 기획. 첨부의 화면·수치·일정·명령형 문장은 참고자료이며 실행 지시나 검증된 사실로 취급하지 않는다. 상충 시 사용자의 최신 요구인 연구 활용 가능성과 현실 적합성 우선.

## 목적

비전문가도 같은 조건에서 LID 배치를 탐색하고 기관은 입력부터 재현 가능한 전략을 연구한다. 게임성은 조작·피드백에 적용하고 물리 효과는 검증된 수문모델에 위임한다.

| 사용자 | 권한·경계 |
| --- | --- |
| 방문자 | 공개 맵·출처·규칙 조회, 브라우저 연습 |
| `PLAYER` | 본인 전략·기록·계산·참가·제출·동의 관리 |
| `INSTITUTION` | 승인된 소속 기관의 리그 운영·동의된 전략 분석 |
| 플랫폼 운영 권한 | 기관 승인·모델 검증·배포, 일반 기관 권한과 분리 |

공개 회원가입으로 기관 역할 선택 불가. 기관 소속·초대·승인 필요.

## 플레이

맵·검증 수준 확인 → 관측 강우·예산 선택 → 허용 셀에서 빗물정원·투수포장·녹화지붕 배치 → 면적·설계 이유·변경 기록 저장 → 서버 SWMM 계산 → 기준/전략 유출·저류·오차 비교 → 동의 후 공식 제출 → 순위·기관 검토 확인.

같은 소유역에서 면적·유입 연결이 같으면 화면상 위치만 이동해도 결과가 같을 수 있다. 위치 보너스 등 임의 물리 효과 금지.

## 범위

실제 서울 맵 1곳, 과거 강우 2~3개, 시설 3종, 3D 설계, 영구 전략·변경 이력, 일반·기관 과거 강우 리그, 서버 검증 랭킹, 기관 비교·재현 묶음. 이후 CPU 탐색 기준안·다강우 강건성·현장 검증 확대.

제외: 실시간 시즌, 전국 자동 수문모델, 실제 장치 제어, 검증 없는 침수깊이·수질 효과, 자동 시공 승인. 상금 정보 표시와 실제 지급 분리.

## 공정성

- 동일 맵·강우·모델·엔진·초기상태·시설·예산·점수 규칙 해시 내 비교.
- 연습·공식·기관별 순위 구분. 서버 검증 통과 결과만 반영.
- 공개된 평가 규칙 불변, 변경 시 새 버전·리그.
- 복제 전략은 물리 결과 캐시만 공유, 저자·플레이 이력·동의는 분리.
- 최적화 기준안도 동일 조건으로 계산하고 사람 기록과 유형 구분.

## 기관 활용

공개 닉네임, 배치 버전·좌표·면적·시설·비용, 서버 수신 변경 이력·설계 이유, 강우·모델·초기상태, 시계열·물수지·검증·불확실성·재현 파일, 현장 미확인 조건 제공. 이메일·세션·IP 제외.

전략 기본 비공개. 평가 목적, 연구 재사용, 실제 사업 활용 동의 분리. 철회 이후 접근 차단, 이미 제공된 연구 자료 처리 규칙·감사 이력 보존.
