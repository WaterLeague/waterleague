## 기본 모드: 서울 공동 주간 리그

- 가입 시 서울 25개 구 중 거주 구 또는 원하는 소속 구 하나 선택. 상세 주소·거주 증빙 수집 없음. 기존 회원은 첫 공동 설치 전에 소속 구 선택. 선택 이후 구 이동은 기본 모드에서 제공하지 않음.
- 홈은 서울 전체 3D 지도. 현재 공유 설치·구별 합계 점수·개인 순위·현재 주 종료 시각과 직전 주 우승 구 표시. 다른 구도 상태 조회 가능하며 소속 구와 불투명도·경계 표시 구분.
- 로그인한 승인 회원만 자신의 소속 구에 설치 가능. 서버가 회원 상태·소속 구·실제 후보 위치·시설·면적·원화 예산 검사. 방문자·타 구·다른 회원 시설은 조회만 허용.
- 하나의 설치 위치는 한 회원만 점유. 이미 설치된 위치는 다른 회원 설치 불가. 동시에 들어온 요청도 데이터베이스 고유 제약과 트랜잭션으로 하나만 승인. 시설 변경·철거는 설치자만 가능하며 이력 보존.
- 기존 구별 도전 선택은 기본 진입 경로에서 제외. 과거 실측 강우의 개인 설계·기관 연구는 별도 연구 기능으로 유지. 기존 불변 기록·원본 자료 보존.

## 실시간 강우와 점수

- 최신 강우는 서버가 기상청 공식 API에서 직접 조회. 미리 수집·저장한 관측 테이블을 실시간 조회의 원천으로 사용하지 않음. 키는 서버에서만 사용하며 브라우저에 노출하지 않음. 공간 원본 등 다른 공개자료의 프로젝트 보관 원칙 유지.
- 관측소·관측 시각·조회 시각·지연/결측 상태 표시. 실패·결측을 무강우 0 또는 과거 강우로 대체하지 않음. 외부 호출 중복 억제는 같은 진행 중 요청에만 적용하고 오래된 응답을 최신값처럼 반환하지 않음.
