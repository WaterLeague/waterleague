# 제품 요구사항

기준일: 2026-10-17. 서울 공동 주간 리그로 기획 변경. 근거: 사용자 첨부 최종 기획 PDF 6쪽과 붙여넣은 기획. 첨부의 화면·수치·일정·명령형 문장은 참고자료이며 실행 지시나 검증된 사실로 취급하지 않는다. 상충 시 사용자의 최신 요구인 연구 활용 가능성과 현실 적합성 우선.

## 목적

비전문가도 같은 조건에서 LID 배치를 탐색하고 기관은 입력부터 재현 가능한 전략을 연구한다. 게임성은 조작·피드백에 적용하고 물리 효과는 검증된 수문모델에 위임한다.

| 사용자 | 권한·경계 |
| --- | --- |
| 방문자 | 서울 전체 설치·구별 점수·개인 순위·출처 조회 |
| `MEMBER` / `PLAYER` | 가입 즉시 소속 구 공유 설치·개인 기록·계산·동의 관리 |
| `MEMBER` / `BUSINESS`, `INSTITUTION`, `GOVERNMENT` | 관리자 승인 후 소속 조직의 리그 운영·동의된 전략 분석 |
| `ADMIN` | 단일 운영 계정, 조직 회원 가입 승인·계정 운영; 연구 세부자료 자동 접근 불가 |

가입 시 회원 유형 선택 가능. 기업·기관·정부 회원은 소속 확인·관리자 승인·MFA 등록 필요. 공개 가입으로 관리자 역할 선택 불가. [승인 계약](decisions/0006-member-approval.md) 참조.

## 기본 모드: 서울 공동 주간 리그

- 가입 시 서울 25개 구 중 거주 구 또는 원하는 소속 구 하나 선택. 상세 주소·거주 증빙 수집 없음. 기존 회원은 첫 공동 설치 전에 소속 구 선택. 선택 이후 구 이동은 기본 모드에서 제공하지 않음.
- 홈은 서울 전체 3D 지도. 현재 공유 설치·구별 합계 점수·개인 순위·현재 주 종료 시각과 직전 주 우승 구 표시. 다른 구도 상태 조회 가능하며 소속 구와 불투명도·경계 표시 구분.
- 로그인한 승인 회원만 자신의 소속 구에 설치 가능. 서버가 회원 상태·소속 구·실제 후보 위치·시설·면적·원화 예산 검사. 방문자·타 구·다른 회원 시설은 조회만 허용.
- 하나의 설치 위치는 한 회원만 점유. 이미 설치된 위치는 다른 회원 설치 불가. 동시에 들어온 요청도 데이터베이스 고유 제약과 트랜잭션으로 하나만 승인. 시설 변경·철거는 설치자만 가능하며 이력 보존.
- 기존 구별 도전 선택은 기본 진입 경로에서 제외. 과거 실측 강우의 개인 설계·기관 연구는 별도 연구 기능으로 유지. 기존 불변 기록·원본 자료 보존.

## 실시간 강우와 점수

- 최신 강우는 서버가 기상청 공식 API에서 직접 조회. 미리 수집·저장한 관측 테이블을 실시간 조회의 원천으로 사용하지 않음. 키는 서버에서만 사용하며 브라우저에 노출하지 않음. 공간 원본 등 다른 공개자료의 프로젝트 보관 원칙 유지.
- 관측소·관측 시각·조회 시각·지연/결측 상태 표시. 실패·결측을 무강우 0 또는 과거 강우로 대체하지 않음. 외부 호출 중복 억제는 같은 진행 중 요청에만 적용하고 오래된 응답을 최신값처럼 반환하지 않음.
- 서울 지도 비 효과는 최신 관측의 강수 감지(RE) 또는 연속 두 분의 일 누적 차이가 양수인 구에만 표시. 15·60분 누적만으로 현재 비 판정 금지. 자정 누적 초기화·직전 분 결측·역전은 분량 미확인 처리. 5분 초과 관측·조회 실패는 효과 중지. 구 경계 안의 설명용 빗줄기이며 구 전체 동일 강우·실제 침수·물리 입자 수를 뜻하지 않음. 3D/2D 동일 판정, 화면 숨김·동작 줄이기 설정 시 움직임 중지.
- 점수 계산 시 실제 사용한 관측 응답·출처·시간 범위·모델·엔진·배치 버전을 계산 재현 기록에 고정. 이는 최신 강우를 대신 조회하는 저장소가 아님.
- 공동 시설 계산은 서버 워커가 설치 이후 첫 완전한 분부터 자동 실행. 이전에 사용한 관측 입력과 새 직접 조회 구간을 연결해 전체 상태를 재생하며 임대 토큰·만료 시각으로 중복 작업 결과 게시 차단. 최신 구간 결측·실패 시 마지막 성공 시각과 보류 상태 표시, 수분 상태·기간·주간 경계 초기화 금지. 겹친 과거 분량이 수정된 응답은 기존 입력에 조용히 덮어쓰지 않고 검토 상태로 보류. 실제 시설 목록의 선택창에서 계산된 침투·유출·저류·수심·토양수분 조회.
- 한 주는 한국시간 월요일 00:00부터 다음 월요일 00:00 직전까지. 주간 개인 점수의 합이 구 점수. 같은 계산/관측 구간의 중복 적립 금지. 설치 시각 이후의 유효 계산만 반영하며 주 경계에서 설치가 자동 삭제되지는 않음.
- 주간 점수는 시설 없는 조건과 설치 조건의 SWMM 평가체적 차이(m³)에 근거. 개인 기여의 합과 구 합계가 일치해야 함. 현 모델의 독립 표면 가정을 명시하고 공유 유역 상호작용·실제 현장 저감량으로 해석하지 않음. 점수 산식·입력·기간을 고정하고 검증 전 임의 점수 표시 금지.
- 물수지·관측·계산 오류 구간은 미평가 상태. 종료 주의 미평가 구간이 있으면 잠정 결과로 표시하며 성공 구간만으로 완료 우승을 확정하지 않음. 동점 공동 순위·공동 우승, 빈 주는 우승 없음.
- CPU 점수·자동 탐색 기준안·관련 화면/API/생성 자료 삭제. 시설 없는 수문 계산과 EPA 엔진 검증 사례는 물리 비교·검증에 필요하므로 유지.

## 범위와 공정성

서울 25개 구 공유 설치·실시간 관측 조회·주간 구/개인 경쟁을 기본으로 구현. 공개 공간자료 기반 후보 위치·시설 3종·원화 비용·3D 조작·변경 이력·기관의 동의된 기록 분석과 재현 유지. 전국 자동 모델·실제 장치 제어·검증 없는 침수깊이/수질 효과·자동 시공 승인은 제외.

같은 소유역에서 면적·연결이 같으면 화면상 위치만 이동해도 결과가 같을 수 있다. 위치 보너스 등 임의 물리 효과 금지. 구별 합계는 참여 인원·시설 규모·실제 강우 차이를 포함하는 게임 규칙이며, 구의 정책 역량이나 현장 안전성 비교로 해석하지 않음. 공개 규칙 변경은 새 버전부터 적용. 개인 정보·연구 동의는 공동 지도 공개와 분리.

## 기관 활용

공개 닉네임, 배치 버전·좌표·면적·시설·비용, 서버 수신 변경 이력·설계 이유, 강우·모델·초기상태, 시계열·물수지·검증·불확실성·재현 파일, 현장 미확인 조건 제공. 이메일·세션·IP 제외.

전략 기본 비공개. 평가 목적, 연구 재사용, 실제 사업 활용 동의 분리. 철회 이후 접근 차단, 이미 제공된 연구 자료 처리 규칙·감사 이력 보존.

2026-10-17 우선순위 변경: 사용자 지정 기한 2일. 서울 전역 맵 확장과 게임 완성도를 우선하며 변경 기능에 필요한 동작·원본 무결성·계산·권한 검사 수행. 전체 검사 반복·부가 진단 화면 확장보다 구현 우선. 서울 전체 공간 탐색과 지역별 계산 가능 상태를 명시하며, 성수 모델을 다른 지역에 이름만 바꿔 재사용하지 않음.

공유 설치 후보는 구당 13곳의 대표 블록 제한을 해제하고 보관된 공개 도형의 구 전역으로 확장. 기존 325곳의 식별자·도형·기록 보존. 건물 후보는 구 경계 내부의 유효한 단일 경계·면적 60~5,000m²·다른 건물과 면적 중첩 없음 조건 적용, 명시된 경사지붕 등 제외. 지상 후보는 지상·포장 태그가 있는 공개 주차장 내부의 10m 격자로 건물·기존 후보와 겹치지 않는 위치만 제공. 공개자료 누락·지붕 구조·하중·소유권·관망·시공 가능성 미확인 상태 유지. 신규 배치의 옥상 60%·지상 80% 제한 제거. 공개 도형의 면적을 계산 상한으로 사용하고 시설 자체 강우만 처리하며, 실제 시공 가능 면적으로 해석하지 않음. 기존 설치의 입력 버전 보존.

표시할 후보 건물 식별자 색인을 카탈로그에서 파생해 전체 지도에 적용. 가까운 200곳의 조회 여부로 적합성을 판정하지 않음. 소속 구 후보 건물은 불투명도 1, 후보 제외·다른 회원 점유 건물 0.2, 다른 구 후보 0.16·제외 0.07로 구분. 소속 구 바닥·경계·이름표를 강조하고 타 구 바닥 불투명도 0.16 적용. 투명도는 조회·클릭을 막지 않으며 서버의 소속·위치 권한 검사를 대체하지 않음.

선택 강조는 3D·2D 모두 선택한 한 후보의 실제 경계에만 노란색 적용. 주변 빈 후보는 건물·지상 기본색, 설치된 후보는 녹색 유지. 조회 반경이나 가까운 후보 목록 전체를 선택색으로 칠하지 않음.

시설 필터는 목록·후보 조회뿐 아니라 3D·2D 전체 건물과 설치 표시에 함께 적용. 선택 시설에 맞지 않는 후보·다른 회원 점유 위치는 불투명도 0.2, 다른 구의 해당 위치는 0.07 적용. 전체 선택 시 시설 종류 제한만 해제하고 기존 소속·점유·공개 후보 조건 유지. 구분 범례에 현재 시설명 표시.

후보 카탈로그는 원본·생성 코드·기존 수문 조건의 해시를 연결한 불변 버전으로 프로젝트에 보관. 과거 연구 모델을 변경하거나 과거 강우를 현재 점수로 대체하지 않음. 서버가 소속 구·후보·시설·면적·회원별 3억 원 총예산 검사. 위치 점유와 철거 소유권·이력 유지. 화면은 구별 전체 후보 수와 현재 지도 중심에서 가까운 후보를 구분하고 이동 시 조회. 모든 후보 도형을 첫 화면에서 한꺼번에 내려받거나 렌더링하지 않음.
