# 0007 — 실측 강우 카탈로그와 조건별 비교

2026-10-16 · 승인된 구현 계약

## 목적

한 관측소·한 강우 창의 효과를 서울 전체의 성능으로 일반화하지 않는다. 성수 공간모델을 고정하고 기상청 실제 분 관측의 강우 창을 교체하여 조건별 계산·순위·연구 비교를 제공한다. 이번 작업은 강우 입력의 확장이며 현장 유출 보정이나 독립 검증이 아니다.

## 자료 수집·품질

- 기상청 AWS 매분자료의 실제 응답과 인증정보를 제외한 요청 조건·수집 시각·SHA-256 기록
- 성동 421의 2024-06-22, 07-02, 07-18 후보를 수집하고 기존 서울 108의 07-18과 동일 창 비교
- 날짜 선택은 강우 분포를 달리하는 탐색 표본이며 재현기간·설계호우·전체 폭우 사상 표방 금지
- 일 누적 강우 차분, 1분 연속성·관측소·음수/결측·이동 15/60분 누적 교차 검사 유지
- 일 누적 초기화 경계의 강우 추정·누락 구간의 0 보간 금지. 끝 관측 이후 임의 무강우 연장 금지
- 관측 창의 시작·종료, 누적·최대 15/60분 강우, 최초·최후 강우, 관측된 선행/후행 무강우 길이 기록
- 관측소 좌표·이력의 공식 출처 확보. 현 좌표와 과거 유효 좌표를 구분하고 미확인 이력 명시
- 관측소와 구역 중심 거리는 WGS84 지오데식으로 계산. 가까운 관측소라는 이유만으로 현장 대표성 보증 금지
- 출처와 기본 검사 상태 표시. 자체 검사 성공을 기상청 품질인증·현장 검증으로 표시 금지

## 모델 저장·호환

`data/models/catalog.json`에 고정 ID·파일명·정확한 원문 해시·기본 모델 등록. 파일명은 로컬 단순 JSON 이름만 허용하고 등록 해시와 실제 바이트 일치 검증. 서버 리소스와 워커 카탈로그 동기화 검사. 런타임 사용자 파일·URL·임의 경로 로딩 금지.

기존 `seongsu-lab.json` 원문과 해시 유지. 새 강우는 별도 모델 파일로 추가하며 기존 저장 버전·리그·재현 묶음 불변. 카탈로그 수록 모델만 새 저장·실행 허용. 과거 비활성 모델의 연구 열람은 기존 해시 검증 묶음 경로 유지.

시설 제원·셀·예산·단가가 같은 모델끼리만 동일 배치 복사 비교. 모델 변경 시 저장 버전·계산 결과 연결 초기화. 미저장 배치는 유효성 확인 후 별도 설계로 보존하며 원본 버전 수정 금지.

## API·권한

- `GET /api/v1/lab` 기존 기본 모델 응답 유지, 선택 시 `modelHash` 허용
- `GET /api/v1/lab/catalog` 공개 목록: 해시·제목·강우·등급·조건 요약
- 전략 저장·계산은 요청 버전의 등록 모델로 검증·실행. 기본 모델로 치환 금지
- 공개 순위는 `modelHash`로 분리. 서로 다른 강우·엔진·모델의 점수 혼합 금지
- 기관 리그 생성/수정에 선택 모델 해시 적용, 공개 후 고정. 등록된 다른 모델이라는 이유로 과거 리그 비활성화 금지
- 연구 목록에 조건 표시, 계산별 원본 모델 제공. 기존 조직 승인·MFA·플레이어 동의 범위 유지
- 워커는 카탈로그 원문 해시 검증 후 모델 복사, 입력 해시·실행 해시·lease 검증 유지

## 화면

설계실에 관측소·날짜·강우량 선택과 조건 정보 제공. 짧은 이름만으로 실측·가정 경계가 사라지지 않도록 상세 정보에서 관측 창과 거리 근거 표시. 새 조건 선택 시 결과 초기화·배치 복사 안내. 순위와 리그에 같은 조건 명시.

## 검증

새 관측 창의 원본→파생 통계 재현, 오염된 카탈로그 해시·경로·중복 거부, 기존 모델 바이트 보존. 다른 강우에서 저장·계산·제출·조회 통합 확인, 조건 간 순위 격리. 기존 기관 리그·연구 권한 회귀 검사와 실제 PostgreSQL/SWMM 실행, 브라우저 전환 검증. 검사·빌드·CI 후 기능별 커밋·푸시.
