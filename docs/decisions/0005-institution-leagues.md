# 기관 탐색 리그와 고정 평가 조건

2026-10-16. 구현 전 결정. 실제 현장 검증과 제품 기능 완료는 별도 판정한다.

## 계약

관리자가 승인한 `MEMBER` 역할의 기업·기관·정부 회원이 리그 초안을 작성한다. 제목·연구 질문·기간·원화 예산·허용 시설·회원별 제출 한도를 설정한다. 현재 배포된 모델을 선택하며 강우·초기상태·시설 제원·단가·SWMM 소스 버전·생성기 해시는 모델 원문과 함께 고정한다. 현재 모델은 탐색용이므로 기관이 만들어도 공식 현장 평가가 되지 않는다.

초안은 소속 기관만 조회·수정한다. 공개 시 규칙 JSON·SHA-256·공개 시각을 기록한다. 공개 뒤 수정·삭제 API를 제공하지 않는다. 오류가 있으면 사유를 남겨 취소하고 새 리그를 만든다. 상태는 `DRAFT → PUBLISHED → CANCELLED`; 접수 예정·접수 중·마감은 서버 UTC 시간으로 계산한다. 마감 뒤 기록·규칙은 조회 가능하다.

플레이어가 계산한 버전을 선택하고 고정 규칙 해시를 확인하여 제출한다. 서버가 소유권·성공 상태·모델/입력 해시·엔진/생성기·물수지·공개 이후 계산·기간·시설·예산·제출 한도를 검증한다. 클라이언트 점수·비용을 받지 않는다. 점수는 기존 평가체적 감소율을 서버에서 재계산한다. 동일 작업 재제출은 멱등 처리하며 참가자 행 잠금으로 동시 제출 한도를 지킨다. 취소와 제출은 리그 행 잠금으로 직렬화한다.

현재 배포 모델과 다른 리그는 새 계산 진입을 막고 보관 기록을 제공한다. 향후 다강우 모델 카탈로그를 추가할 때도 공개 규칙은 교체하지 않는다. 단일 비교 집단 내 엔진 바이너리·생성기가 달라지는 경우 첫 제출의 실행 지문과 다른 결과를 거부한다. 플랫폼별 빌드 차이를 무시한 혼합 순위를 금지한다.

## 순위·기관 접근

리그별 회원 최고 점수 하나, 서버 소수 8자리 기준 동점 같은 순위. 공개 닉네임·점수·원화 비용·제출 시각만 공개한다. 비공개 메모·배치·이력·작업 ID는 공개 순위에서 제외한다. 비활성 회원과 승인 취소 기관의 신규 활동을 차단한다.

제출은 공개 순위 참가 의사이며 연구 재사용 동의가 아니다. 기관 연구 동의는 별도 화면에서 지정·철회한다. 주최 기관도 동의가 없으면 세부 기록을 보지 못한다. 기관 리그 제출은 해당 주최 기관에 한해서 기존 연구 동의 확인 후 조회·내보내기 허용한다. 일반 탐색 기록의 기존 동의 경로는 유지한다. 사업 활용은 별도 동의·실제 현장 검토 없이 승인되지 않는다.
