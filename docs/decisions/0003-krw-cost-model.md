# 원화 비용 모델

2026-10-16. 사용자 요청에 따라 모든 예산·시설비·연구 내보내기 비용 단위를 원(KRW)으로 통일.

- 예산 300,000,000원, 면적당 단가와 합계를 원 단위로 저장·표시. 게임 화폐 사용 금지.
- 현재 빗물정원 180,000원/㎡, 투수포장 120,000원/㎡, 녹화지붕 220,000원/㎡는 출처 미확보 가정 단가. 실제 발주·표준시장단가·견적으로 간주 금지.
- 초기 설치비 비교만 포함. 부가세·설계·철거·폐기·토지·구조보강·유지관리·예비비 미산정. 기준연도 미확정. 부지별 사업비 산출 불가.
- 모델에 통화·단가 단위·근거 상태·제외 항목 보존. 단가·근거 변경은 모델 해시 변경으로 기존 순위와 분리.
- 승인된 원가 내역의 시설 규격·지역·기준연도·공종·수량·부가세 조건 확인 후 검증 단가로 교체. 보조금 상한·해외 단가를 국내 실제 공사비로 전용 금지.
- 실제 연구에는 수문 검증 외에 비용 모델의 독립 검토 필요. 가정 단가 사용 결과로 경제성·사업 타당성 확정 금지.
