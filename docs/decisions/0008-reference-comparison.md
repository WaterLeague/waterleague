# 0008 — CPU 기준안·동일 배치 다강우 비교

2026-10-16 · 구현 계약

## 비교 의미

기관과 플레이어가 같은 배치를 여러 실제 강우 창에서 살펴보도록 한다. 순위 점수를 합산하여 새 공식 등급을 만들지 않는다. 강우별 원래 점수·유출·저류·물수지 오차를 병렬 표시하고 최저/최고 점수는 해당 관측 창에 한정한 기술 통계로 표기. 이 범위를 신뢰구간·현장 검증으로 해석하지 않는다.

## CPU 탐색 기준안

2026-10-17 공간 버전 확장: OSM 기준안·원장·생성기 원문은 보존한다. 수치지형도 v2의 성동 421 2024-07-18 모델에서 같은 알고리즘·10m² 증분·세 예산으로 새 탐색을 수행하고, 배치 확정 후 같은 공간 버전의 나머지 세 관측 창에서 재계산한다. 다른 공간 버전의 점수·배치·원장을 혼합하지 않는다. 모델별 기준안 등록 목록에 보고서/원장 파일·보고서 해시·해당 모델 해시를 고정한다.

`GET /api/v1/references`, `/source`, `/ledger`는 `modelHash`로 해당 공간 버전의 기준안을 조회한다. 생략 시 현재 기본 모델 기준이며, 미등록 모델이나 기준안이 없는 조건은 다른 기준안으로 대체하지 않는다. 서버 시작 시 등록 해시·배치 비용·모든 비교 모델의 공간/시설/물리 조건을 검사한다. 화면 전환 중 이전 조건의 배치·결과를 노출하지 않고, 다운로드도 선택한 모델에 고정한다.

고정된 성동 421의 2024-07-18 모델만 후보 선택에 사용. 6월 22일·7월 2일은 배치 확정 후 계산하며 탐색 의사결정에 사용하지 않는다. 동일 2024-07-18의 서울 108도 관측소 민감도 대조로만 사용한다. 이는 강우 입력의 별도 비교이며 실제 유출 관측을 이용한 독립 검증은 아니다.

- 결정적 탐욕 탐색, 10m² 증분, 동일 셀 1종 시설·면적·원화 비용·등록 모델 제약 준수
- 각 단계에서 후보 SWMM 계산 후 추가 원당 평가체적 저감이 큰 후보 선택, 동률은 낮은 비용·정렬된 시설/셀 순서
- 기존 셀의 시설 유형 교체는 탐색하지 않음. 양의 개선이 없거나 예산·탐색 상한 도달 시 중단
- 3천만·1억·3억 원 상한 각각 별도 탐색, 총 후보 계산 수·중복 캐시·선택 단계·중단 이유 기록
- 최대 2,000회 고유 후보 계산, 고정 소스·모델·엔진·알고리즘 해시와 환경 기록
- 현장 최적해·전역 최적해·AI 학습모델로 표현하지 않음. 사람과 계산 횟수가 다른 점 표시
- 실제 SWMM 결과만 배포. CPU 기준안은 사람 순위·회원 기록에 삽입하지 않음
- 탐색 이후 확정 배치를 모든 등록 강우에서 같은 엔진으로 재계산. 결과·배치·입력/출력 해시 보존
- 학습 강우·모델/단가/시설 제원이 달라진 경우 기준안을 재사용하지 않음

## 사용자 비교

소유한 저장 버전의 배치를 서버에서 읽고 시설 제원·셀·단가·예산이 동일한 등록 모델 최대 3개로 복사. 각 모델 해시를 가진 별도 불변 버전·계산 작업으로 수행, 비교 그룹에 원본 버전·작업 연결·소유자·생성 시각 보존. 사용자 입력으로 점수·비용·원본 배치를 덮어쓰지 않는다.

멱등 요청 키·회원 소유권·계산 큐 한도·그룹 생성의 트랜잭션 적용. 부분 생성 실패 시 모두 롤백. 재조회 시 다른 회원 그룹·작업 미노출. 실패 작업은 실패 상태를 보존하며 성공한 강우만으로 전체 비교 성공처럼 표시하지 않는다.

기존 연구 동의를 자동 확대하지 않는다. 비교 그룹 생성만으로 기관 열람·사업 활용 권한 부여 금지. CPU 배치 불러오기는 새 개인 설계로 복사, 공개 제출은 별도 동작.

## 검증

탐색 결정성·예산/면적/유형 제약·고정 비교 강우 미사용 검사. 원문 해시·공식 미검증 등급·양의 개선 중단·상한 보존. 실제 엔진으로 기준안 생성·재현 확인. 비교 API의 소유권·멱등·한도 롤백·모델 호환성 검사 및 실제 PostgreSQL→워커→다강우 결과 브라우저 확인.
