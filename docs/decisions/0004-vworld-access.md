# 브이월드 연결과 자료 사용 범위

2026-10-16. 기존 `.env.local`의 `VWORLD_API_KEY` 사용. 프론트 번들·로그·Git·계산 워커로 키 전달 금지.

- 공식 2D 데이터 API 2.0의 도로명주소 건물 `LT_C_SPBD`를 성수 후보 영역에서 조회. 좌표계 EPSG:4326, 등록 도메인 `http://127.0.0.1:5173` 지정.
- 첫 조회 결과 `INCORRECT_KEY` / 인증키 정보가 올바르지 않습니다. 키 형식은 UUID이며 따옴표·환경변수 덮어쓰기 문제는 발견되지 않음. 승인·API 사용·등록 주소 확인 요청.
- 사용자 설정 수정 후 재조회도 동일 오류. 공식 레퍼런스는 이 코드의 예로 등록 도메인 불일치를 명시. 실제 등록 서비스 URL 확인 요청. 진단 도구는 `VWORLD_DOMAIN` 설정 지원, 미설정 시 위 개발 주소 사용.
- 사용자가 등록 주소를 바로잡은 뒤 `OK` 확인. 성수 영역 10개 표본, MultiPolygon 도형과 지상 층수 필드 수신. 실측 높이·지표고 필드 없음. 공간 원본은 보관하지 않음.
- 이 서비스는 건물 도형과 지상 층수 `gro_flo_co` 등을 제공. 층수는 실측 높이나 지표고가 아니므로 DEM·수문 경사로 전환하지 않음.
- 공식 API 목록에서 3D 지도 API와 다운로드용 DEM 제공 여부를 구분. 3D 화면의 가시화 고도만으로 연구 입력의 정확도·수직기준·측량 시점 보장 불가.
- 공식 이용약관 제약 때문에 인증 성공을 원본 저장·가공·재배포 허락으로 간주하지 않음. 현재 진단 도구는 응답을 메모리에서 검사하고 상태·건수·필드명만 출력. 형상·속성 원본 저장 없음.
- 연구 모델에 편입하려면 개별 자료의 이용허락, CRS·수직기준·시점·해상도, 결측과 부지 대표성 확인 필요. 재현 묶음에 포함 가능한 원본을 별도 확보한 후 모델 해시 갱신. 기관별 동의와 별개로 자료 제공자의 이용 조건 준수.
