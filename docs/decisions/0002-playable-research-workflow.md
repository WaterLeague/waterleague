# 실행 가능한 연구 워크플로 결정

2026-10-15. 사용자 요청에 따른 전체 기능 구현 계속. D0 문서를 대체하지 않는 구현 세부 결정.

- 서버 PostgreSQL 영속 저장, Argon2id 회원 인증, 서버 세션·CSRF, 소유권 검증. 공개 가입은 PLAYER 고정. 기관 계정은 운영 명령으로만 승인.
- 불변 전략 버전과 편집 이벤트, 서버 고정 비용·설치 제약, 멱등 계산 요청, 작업 lease·fencing·재시도 상한.
- EPA SWMM 5.2.4 공식 소스 커밋 고정 빌드. 임의 입력 파일 수신 금지. 실행별 입력·보고서·시계열·해시·오류 보존.
- NOAA 서울 자료의 AA 조건 코드 3은 누적기간 시작으로 정의. 숫자가 존재해도 개별 시간 강우로 승인하지 않음. 2026-10-16 기상청 AWS 조회 승인 후 2024-07-18 서울 108 관측 분강우 확보, 자체 품질 검사 통과. 원본 1,140행에서 1,139분·109.7 mm 추출.
- 인터페이스·계산 통합 검증용 모델은 실측 강우와 가정 시설 제원을 사용하는 EXPLORATORY. 실제 건물 형상은 공개 OSM 사용. 관측소 강우의 부지 대표성·실제 배수경계·토양·관망은 미검증. 탐색 순위와 공식 순위 별도. 현장 효과·공식 연구 검증으로 승격 금지.
- 공개 순위는 사용자가 제출한 최고 기록만 노출. 상세 연구 열람은 기관별 동의에 종속, 철회 즉시 차단. 연구 export는 입력·가정·엔진·버전·시계열·변경 이력 포함, 다운로드 시 재인가.
- 운영 공개는 기상청 강우 확보, 현장 수문자료·독립 검증, TLS·기관 MFA·백업·운영 점검 이후. 서비스 코드 구현과 현장 검증 완료 구분.
