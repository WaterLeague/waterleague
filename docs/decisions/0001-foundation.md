# ADR 0001: 현실 적합성을 우선한 초기 구조

상태: 초기 설계 채택. 일자: 2026-10-15.

빈 저장소·서울 실제 자료·플레이어/기관 구분·연구 재사용·Oracle CPU 환경 요구.

1. 도메인 레이어 React·Spring Boot와 격리 SWMM 워커 채택.
2. 관측·파생·보정·가정 구분, 불변 버전·원본·해시 보존.
3. 수치·참조·현장 검증을 등급·목적으로 분리, 공식 사용 게이트 적용.
4. 서울 부지는 배수·관측·검증 자료 확보 가능성 우선 선정.
5. PostgreSQL lease 큐로 원자적 전략·작업 생성, Redis 후속 검토.
6. 서버 세션·CSRF·소유권·기관·동의 검증, 클라이언트 점수·역할 불신.
7. 문서 커밋·푸시 후 구현. 가상 효과·랭킹으로 미완료 대체 금지.

공개자료만으로 현장 검증이 불가능하면 탐색용 범위 표시, 필요한 관측·기관 협력 작업화. 기반 구현을 전체 연구용 서비스 완성으로 주장하지 않는다.
