# 성수 지형·피복 원자료 접근

2026-10-17 갱신. 공식 사이트 검색·신청 후 사용자가 내려받은 DEM 2건과 토지피복 1건 확보. 아래 접근 기록과 취득 후 품질 검사를 구분. 모델·순위 해시 변경 없음.

## 대상지와 검색 결과

2025년 제작 표기를 2024년 현장 상태의 증거로 사용하지 않음. GRS80은 타원체 정보이며 EPSG 코드·투영 원점·수직 기준을 대신하지 않음. 수치지형도의 등고선·표고점과 래스터 DEM, 건물·식생이 포함된 DSM 구분.

## 접근 상태와 인증

국토정보맵에서 DEM·수치지도 다운로드를 눌렀으나 파일 전송이나 다음 화면을 확인하지 못함. 실패 원인을 인증 부족으로 확정하지 않음. 공식 서울시 안내는 1:1,000 자료 다운로드에 로그인이 필요하다고 명시. 메인 페이지의 로그인 경로에서는 정부 통합인증(Any-ID)과 기존 아이디 로그인 화면 정상 진입 확인.

환경공간정보서비스 자료신청 안내는 제작시기별 대·중·세분류 토지피복의 신청·다운로드를 로그인 사용자에게 제공한다고 명시. 실제 로그인 링크는 정부 통합로그인 `aid.mcee.go.kr`로 이동, 간편인증·민간 ID 화면 확인. 공간 원본 신청과 지도 Open API는 별개.

사용자에게 두 사이트 로그인을 묶어서 요청. 인증값 수집·대리 회원가입·약관 동의·자료 신청 전송 없음. 추가 API 키 발급 요청 없음. 로그인 후 공개 자료의 다운로드 절차와 이용 범위 확인을 계속하며, 별도 공문·문의 발송은 사용자 지시 필요.

## 로그인 후 신청 준비

2026-10-16 사용자 로그인 완료 후 두 공식 사이트에서 로그인 상태 확인. 국토정보플랫폼의 성동 37705 공개 DEM 2024·2025년 2건 선택, 사용목적을 ‘제작 및 활용 → 교육, 학술, 연구’로 지정하고 성수 물환경 연구용 지형 검토·웹 시각화 목적 작성. 최종 창의 필수 생년월일과 사용자 준수사항 동의는 사용자 직접 처리 대기. 계정 이름·생년월일·인증값은 저장소에 기록하지 않음.

환경공간정보서비스의 실제 로그인 후 경로 `https://aid.mcee.go.kr/req/write.do`에서 세분류 [2024] 전국 → 서울특별시 → 성동구 → 성수동2가 검색. 성동073(37705073, 3.63MB)·082(37705082, 2.37MB)·083(37705083, 3.3MB), 모두 축척 1:5,000·화면 제작일 2024-11-20 확인. 실험 구역 후보인 성동083 1건만 신청 목록에 추가하고 연구용 신청명 작성. 자동입력 방지 문자와 최종 등록은 사용자 직접 처리 대기. 화면의 제작일은 영상 취득일·2024년 강우 당시 상태의 증거가 아님.

두 사이트의 마지막 확인을 한 번에 요청. 이후 사용자 완료 응답과 국토정보플랫폼의 필수 입력 대행 요청 접수. 아래 상태로 갱신하며 개인정보는 기록하지 않음.

## 최종 제출 후 확인

2026-10-16 환경공간정보서비스의 ‘자료신청 완료 / 저장되었습니다’ 확인 후 신청 목록에 1건 등록 확인. 다운로드 목록에 `SG05_37705083_20241120.zip`(3.3MB) 표시. 전체 다운로드 실행 시 전용 전송 창이 나타났으나 완료 신호나 로컬 파일은 확인하지 못함. 신청 등록 완료와 원본 취득 완료를 구분.

국토정보플랫폼의 달력에서 사용자 지정 일자를 선택·확인하고 같은 DEM 두 건을 제출. 최종 창은 닫혔으나 다운로드신청내역 0건, 신청내역관리의 공개 DEM 다운로드 0건, 파일 미확인. 직접 입력이 달력의 현재 날짜로 치환되는 동작을 발견해 달력 선택으로 재진행했으며, 제출 성공으로 판정하지 않음. 오류 원인은 확인되지 않아 브라우저·계정·사이트 중 특정 원인으로 단정하지 않음.

사용자에게 일반 브라우저에서 두 원자료를 내려받아 Downloads에 저장하거나 기존 저장 경로를 알려줄 것을 한 번에 요청. 추가 키·신청 항목 없음. 전송 확인을 기다리는 동안 서버·연구 기능 구현 계속. 원본 취득·해시·CRS·해상도·이용 범위 검증 전 모델 입력이나 품질 수준 변경 없음.

사용자가 제공한 [국토정보플랫폼 설치 페이지](https://nlippd.ngii.go.kr/nlippd/install/install.html)를 Apple Silicon 환경에서 확인. 파일 전송 프로그램 다운로드 확인 후 브라우저에 `ReferenceError: macMchipInstallFileURL is not defined`(install.html:47:38) 발생. 현재 설치 페이지의 M칩 분기에서 다운로드 시작 실패 확인. INNORIX의 일반 제품 안내는 macOS를 지원하지만, 해당 기관에 배포된 버전·설치 파일의 호환성을 보증하는 근거로 사용하지 않음. 보안 설정 변경·임의 설치 파일 실행 없이 기관의 올바른 M칩 설치 파일 또는 Windows에서의 원자료 취득 필요. 이 오류만으로 앞선 모든 다운로드 실패 원인이 동일하다고 단정하지 않음.

## 취득 후 확인

2026-10-17 사용자가 INNORIX 설치와 세 원자료 직접 다운로드 완료 통지. Downloads의 ZIP 세 개 CRC·크기·경로·링크 검사 후 `data/private/seongsu-official-20261017/`에 원본 보존·분리 추출. 원본/좌표 파일은 Git 제외. 설치 페이지의 `macInstallFileURL`이 가리키는 공식 PKG를 확보했고 INNORIX 개발자 서명·Apple 공증·M1 패키지 표기 확인. 사용자 직접 설치 완료이며 이 파일을 프로젝트 의존성으로 취급하지 않음.

원본 파일·원본 설명서·이용조건을 함께 보관하고 SHA-256 기록. 압축 내부 경로·크기·형식 검사 후 별도 작업 디렉터리에서 검사. 지형은 CRS·수직 기준·셀 크기·취득/제작 시점·bbox 포함·NoData·표고 범위 확인. 피복은 도엽·제작시기·분류 코드·CRS·유효 도형·구역 피복률·중복/빈 영역 확인.

보간으로 원자료 해상도가 높아졌다고 주장하지 않음. 지도 분류를 현장 불투수율·침투율 측정치로 취급하지 않음. 적용 가능한 새 자료는 별도 모델 버전과 재현 근거로 연결하며 기존 계산·리그 조건 보존. 지형 원본 확보만으로 관망 연결·배수 유역·현장 유출 검증이 완료되지는 않음.
