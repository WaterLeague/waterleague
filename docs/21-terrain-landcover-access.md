# 성수 지형·피복 원자료 접근

2026-10-16. 공식 사이트의 화면에서 대상 지역을 검색한 결과. 파일 목록 확인과 원본 취득·품질 검사를 구분. 현재 원본 미취득, 모델·순위 해시 변경 없음.

## 대상지와 검색 결과

성수 실험 bbox는 EPSG:4326 `[127.0525,37.5430,127.0555,37.5455]`. 국토정보플랫폼의 아연디지털타워(성동구 성수동2가 314-37, 성수일로6길 33) 위치 검색 후 주변 자료 목록 확인. 아래는 검색 반경에 나온 후보이며 실제 파일 경계로 bbox 전체 포함 여부를 다시 확인해야 함.

| 자료 | 공식 화면 표시 | 현재 증거 범위 |
| --- | --- | --- |
| 공개 DEM | 성동 `37705`, 2014·2021·2022·2023·2024·2025년 | 2024년 항목 존재. 격자 크기·취득일·수직 기준·결측·파일 형식 미확인 |
| 수치지형도 Ver2.0 | 성동083 `37705083`, 1:5,000, 2025, GRS80 | 검색 목록만 확인 |
| 수치지형도 Ver2.0 | `377052201`·`377052202`·`377052211`·`377052212`, 1:1,000, 2025, GRS80 | 각각 화면 명칭 수원0330·수원0331·수원0340·수원0341. 명칭을 임의 수정하지 않음 |
| 과거 지도 이력 | `377052201` 이력보기: 이력정보 없음 | 이 결과만으로 다른 도엽·자료의 과거 이력 부재를 단정하지 않음 |

2025년 제작 표기를 2024년 현장 상태의 증거로 사용하지 않음. GRS80은 타원체 정보이며 EPSG 코드·투영 원점·수직 기준을 대신하지 않음. 수치지형도의 등고선·표고점과 래스터 DEM, 건물·식생이 포함된 DSM 구분.

## 접근 상태와 인증

국토정보맵에서 DEM·수치지도 다운로드를 눌렀으나 파일 전송이나 다음 화면을 확인하지 못함. 실패 원인을 인증 부족으로 확정하지 않음. 공식 서울시 안내는 1:1,000 자료 다운로드에 로그인이 필요하다고 명시. 메인 페이지의 로그인 경로에서는 정부 통합인증(Any-ID)과 기존 아이디 로그인 화면 정상 진입 확인.

환경공간정보서비스 자료신청 안내는 제작시기별 대·중·세분류 토지피복의 신청·다운로드를 로그인 사용자에게 제공한다고 명시. 실제 로그인 링크는 정부 통합로그인 `aid.mcee.go.kr`로 이동, 간편인증·민간 ID 화면 확인. 공간 원본 신청과 지도 Open API는 별개.

사용자에게 두 사이트 로그인을 묶어서 요청. 인증값 수집·대리 회원가입·약관 동의·자료 신청 전송 없음. 추가 API 키 발급 요청 없음. 로그인 후 공개 자료의 다운로드 절차와 이용 범위 확인을 계속하며, 별도 공문·문의 발송은 사용자 지시 필요.

## 로그인 후 신청 준비

2026-10-16 사용자 로그인 완료 후 두 공식 사이트에서 로그인 상태 확인. 국토정보플랫폼의 성동 37705 공개 DEM 2024·2025년 2건 선택, 사용목적을 ‘제작 및 활용 → 교육, 학술, 연구’로 지정하고 성수 물환경 연구용 지형 검토·웹 시각화 목적 작성. 최종 창의 필수 생년월일과 사용자 준수사항 동의는 사용자 직접 처리 대기. 계정 이름·생년월일·인증값은 저장소에 기록하지 않음.

환경공간정보서비스의 실제 로그인 후 경로 `https://aid.mcee.go.kr/req/write.do`에서 세분류 [2024] 전국 → 서울특별시 → 성동구 → 성수동2가 검색. 성동073(37705073, 3.63MB)·082(37705082, 2.37MB)·083(37705083, 3.3MB), 모두 축척 1:5,000·화면 제작일 2024-11-20 확인. 실험 구역 후보인 성동083 1건만 신청 목록에 추가하고 연구용 신청명 작성. 자동입력 방지 문자와 최종 등록은 사용자 직접 처리 대기. 화면의 제작일은 영상 취득일·2024년 강우 당시 상태의 증거가 아님.

두 사이트의 마지막 확인을 한 번에 요청. 현재 다운로드 파일·신청 완료 증거 없음. 원본 취득·해시·CRS·해상도·이용 범위 검증 전 모델 입력이나 품질 수준 변경 없음.

## 취득 후 확인

원본 파일·원본 설명서·이용조건을 함께 보관하고 SHA-256 기록. 압축 내부 경로·크기·형식 검사 후 별도 작업 디렉터리에서 검사. 지형은 CRS·수직 기준·셀 크기·취득/제작 시점·bbox 포함·NoData·표고 범위 확인. 피복은 도엽·제작시기·분류 코드·CRS·유효 도형·구역 피복률·중복/빈 영역 확인.

보간으로 원자료 해상도가 높아졌다고 주장하지 않음. 지도 분류를 현장 불투수율·침투율 측정치로 취급하지 않음. 적용 가능한 새 자료는 별도 모델 버전과 재현 근거로 연결하며 기존 계산·리그 조건 보존. 지형 원본 확보만으로 관망 연결·배수 유역·현장 유출 검증이 완료되지는 않음.
