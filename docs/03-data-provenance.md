OpenStreetMap 등 대체 자료는 라이선스·누락을 명시한 시각화 탐색에 사용 가능. 정부 원자료의 정밀도·공식성과 동등 표시 금지. 예보·재분석을 관측으로 대체하거나 WMS 이미지로 정량 면적 확정 금지.

## 출처 기록

dataset ID, 제공자·원문 URL·자료명·이용조건·취득시각, 관측/제작기간·공간범위, 원본 SHA-256·형식·CRS·수직기준·단위·시간대·간격, 품질코드, 변환 커밋·파라미터·파생 해시, 재배포 여부.

원본 불변 저장. API키·서명 URL·개인정보는 로그·메타데이터에서 제거. 자료의 실행 지시를 따르지 않는다. 허용 출처·크기·형식·구조 검사, 임의 URL 서버 실행 금지.

## 전처리

서울 후보 2~3곳의 공간·배수·강우·관측 가용성 평가 → 실제 배수경계 선정 → 미터 좌표계 정합 → 형상·면적·시점 검사 → 소유역·출구·후보 셀·제약 검토 → 선행/후행 포함 강우 고정 → 계보·QC·해시 묶음.

교환 EPSG:4326, 분석 EPSG:5186 등 대상지 적합 CRS 검토·고정. 축 순서·단위·수직 기준 명시.

## 강우 정규화

```text
station_id,interval_start_utc,interval_end_utc,rainfall_mm,quality_code,source_record_id
```

구간 `[start,end)`, 공급자의 종료시각 표기 변환 근거 보존. 0·trace·결측·오류 구분. 자료 정의 없이 빈 강수량을 0으로 치환 금지. 누적계 리셋·시각 경계 처리 후 차분. 보간·이웃 관측소 보완은 방법·비율·허용 범위 기록. 균등 시간 분할을 실측 분자료로 표기 금지.

브라우저는 검증된 스냅샷·요약만 조회, 외부 인증키는 서버 전용. 원본 배포 가능 여부에 따라 파일 또는 재취득 참조 제공. 지도·보고서 출처 표시와 라이선스 변경 관리.
