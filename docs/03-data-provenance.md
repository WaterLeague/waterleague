## 전처리

서울 후보 2~3곳의 공간·배수·강우·관측 가용성 평가 → 실제 배수경계 선정 → 미터 좌표계 정합 → 형상·면적·시점 검사 → 소유역·출구·후보 셀·제약 검토 → 선행/후행 포함 강우 고정 → 계보·QC·해시 묶음.

교환 EPSG:4326, 분석 EPSG:5186 등 대상지 적합 CRS 검토·고정. 축 순서·단위·수직 기준 명시.

## 강우 정규화

```text
station_id,interval_start_utc,interval_end_utc,rainfall_mm,quality_code,source_record_id
```

구간 `[start,end)`, 공급자의 종료시각 표기 변환 근거 보존. 0·trace·결측·오류 구분. 자료 정의 없이 빈 강수량을 0으로 치환 금지. 누적계 리셋·시각 경계 처리 후 차분. 보간·이웃 관측소 보완은 방법·비율·허용 범위 기록. 균등 시간 분할을 실측 분자료로 표기 금지.

고정 지도·시설·과거 기상은 검증된 저장 스냅샷·요약을 조회한다. 주간 KMA 관측과 서울 현재 도시자료는 서버의 제한된 실시간 조회 경로를 사용하며 취득/관측 시각·원문 해시·결측/만료를 보존한다. 그 외 원자료 수집은 도구에서 수행한다. 외부 인증키는 브라우저와 계산 자식 프로세스에 전달하지 않는다. 원본 배포 가능 여부에 따라 파일 또는 재취득 참조 제공. 지도·보고서 출처 표시와 라이선스 변경 관리.

## 서울 공개 기존 시설 자료 (2026-10-18)

공개 지도 저류 경계 v1: 보관한 2026-10-16 OSM PBF·서울 도형 원본의 해시를 검증하고 `basin=detention/retention/infiltration`인 지표 도형만 사용. 잠실유수지·신내저류지·이름 미등록 저류 영역의 3도형을 원 좌표·구멍·다중 도형·출처 식별자와 함께 보존. 이름만 유수지인 공원·주차장, 위치점, 도시계획 지정 범위로 부지를 생성하지 않음. ODbL-1.0 출처와 파생 GeoJSON·교차 정책을 프로젝트에 포함. 측량/준공도·현재 운영·용량·과거 존속은 미확인.

당시 v6 지상 후보와 양의 면적이 겹치는 86곳을 신규 게임 설치에서 제외하며 옥상·경계 접촉만 있는 후보는 제외하지 않음. 같은 현재 형상을 사용하는 주간·재해 화면의 공통 규칙이며 재해 당시 시설 존재 판정이 아님. 정책 해시를 신규 설치 및 연구 요청에 고정하고 재현 묶음에 해당 정책 원본을 보존. 이전 설치·요청은 소급 삭제/변경하지 않음. 위치점만 확보한 기존 1,604기록은 계속 참고 표시만 제공. 카탈로그 v2는 이 3도형을 더한 표시 1,607기록·10출처이며 v1 원본 보존.

서울 열린데이터광장 OA-21179·21192·21193·21194·21195·21196·21197·21199 공간 ZIP과 강서구 15148889 펌프장 CSV를 프로젝트 원본으로 보관. 공식 메타데이터의 EPSG:5186·CP949와 CSV의 위경도/단위 사용. 모두 공공누리 제1유형. 2026 포털 갱신일과 2022-04-03 공간 파일 수정일을 별도 보존하며 수정일을 준공일·존재 증거로 사용하지 않음.

`prepare_public_infrastructure.py`로 원본 해시 검증 후 불변 참고 카탈로그 생성. 원본은 기존 정책대로 data/raw 로컬 보관, 해시·재취득 URL/form과 파생 카탈로그 Git 포함. DEL_YN=Y는 원본 삭제 표시로 보존하고 지도에서 제외하되 실제 철거로 단정하지 않음. 삭제 필드 결측·서울 경계 밖 기록도 별도 집계. 위치점은 원형 부지·배수 경로로 변환하지 않음. 강서구 같은 시설의 호기 행은 하나의 참고 기록에 묶고 유수지 용량·유역면적을 호기 수만큼 더하지 않음. 원문 CSV의 양수량 단위는 m³/min.

주간·재해 공통 지도에서 공개시설 참고 위치·원문 제원·출처·자료 기준일을 조회. 다른 출처의 동명 기록은 동일 자산으로 자동 병합하지 않으며 표시 건수는 고유 시설 수가 아닌 자료 건수. 재해 화면의 참고 레이어는 당시 기본 시설이 아님을 표시. 준공/폐지·운전·관망·부지 경계 미확보 시설은 시점별 계산/중복 설치 차단의 확정 입력에서 제외.

광진구 15021421 CSV(자료 기준 2022-01-18, 이용허락 제한 없음)의 9개 설비 묶음은 설치·증설 연도를 별도 이력으로 연결. 광진구·시설명과 검토한 공개 위치 식별자의 명시적 대응표를 사용하며 원본 행·주소·혼합 단위 표기·수량·해시 보존. 2012년 추가 구의 설비를 2010/2011 사건의 설비로 포함하지 않음. 설치/증설 연도와 사건 연도가 같으면 일자 불확실, 사건 이후 증설이면 현재 제원의 과거 전용 불가, 자료 기준일 이후 사건이면 제원 갱신 여부 미확인. 설치 이력은 당시 존속·운전 증거를 대체하지 않으며 계산 입력은 계속 보류. 신규 부지 경계는 미확보; OA-20962는 도시계획 지정 자료이고 포털의 변경금지 조건도 있어 실제 시설 경계로 편입하지 않음.

## 도로·보행로 투수포장 후보 (2026-10-19)

`shared-sites` v10은 v9을 대체하지 않는 추가 목록이다. 기존 후보 식별자·해시·점수 입력은 보존한다. 해시를 검증한 `seoul-streets-v1`과 같은 2026-10-16 OSM 중심선에 길이 20m 이하, 차도 폭 2m 이하, 보행로/명시된 보도 폭 1.2m 이하의 설계 띠를 만든다. `PUBLIC_CENTERLINE_DESIGN_STRIP`은 측량된 도로 부지와 구분하며, OSM 보도 태그가 있는 구간만 옆 보도를 생성한다. 교량·지하·고속도로·비공개 접근·명시적 비포장면, 구 경계에 걸친 띠, 건물·수면·저류지·주차장·기존 후보와 겹친 띠 및 신규 띠끼리의 양의 면적 중첩을 제외한다. OSM 누락 또는 현장 시공 적합성 확인을 의미하지 않는다.

도로 원본 식별자, 형상·폭 가정, 원문/변환 해시와 ODbL 출처를 보존한다. 면적은 설계 도형의 EPSG:5186 면적이며 소수 둘째 자리 내림을 설치 상한으로 사용한다. 공개 DEM 지역 경사·단일 도형을 완전히 포함하는 토성 문헌 추정만 기존 규칙으로 연결하며 결측은 기존 설계 가정으로 명시한다. 시설 제원·단가는 기존 검증된 설계 목록을 사용하고 외부 도로 유출을 임의로 유입시키지 않는다. 주간에는 실제 관측 강우, 재해에는 선택 사건 강우를 적용하되 현재 도로망을 과거 존재 증거로 해석하지 않는다.
