# 리그 시설 제한·상금 안내

2026-10-16. 원기획 PDF 2·6쪽의 시설 개수/면적 상한과 원화 상금·수상 인원·심사 안내 구현 계약. 실제 지급이나 수상자 확정은 플랫폼 기능 범위가 아님.

참가 방식 필드가 없는 초안은 규칙 schemaVersion 2로 저장. 참가 규칙을 포함하는 schemaVersion 3은 [참가 계약](25-league-participation.md) 참조. `placementLimit`(시설을 배치한 셀 개수), `areaLimitM2`(전체 시설 합산 면적), `award`(총상금 원·수상 예정 인원·심사 및 지급 안내)를 규칙 JSON과 hash에 포함. 각 시설의 원래 셀 면적·허용 종류·모델 전체 상한보다 느슨한 제한 금지. 총면적은 소수 두 자리, 서버에서 BigDecimal 합산. 시설 개수는 한 셀의 한 시설을 1개로 계산하며 내부 SWMM 단위 수와 구분.

기존 클라이언트가 추가 필드를 생략하면 허용 시설에 대응하는 모델의 최대 개수/총면적으로 고정하고 상금 없음으로 저장. 새 화면은 제한과 안내 값을 명시적으로 전송. 기존 schemaVersion 1 공개 리그의 원문과 hash는 변경하지 않으며 새 필드 부재를 과거의 상금 없음으로 소급 해석하지 않음.

총상금은 0~10억 원 정수, 수상 예정 인원 0~1,000명. 상금이 있으면 수상 인원 1명 이상과 10~2,000자의 안내 필수. 상금 0원에서는 수상 예정 인원 0명. 안내에 수상 선정 기준·동점 처리·일정·지급 주체를 적도록 설명하며 실명·계좌·연락처 같은 개인정보 입력을 요구하지 않음. 게임 순위는 고정 계산 점수이고 별도 심사·지급은 주최 기관 책임임을 표시. 심사 문구로 서버 순위를 변경하지 않음.

공개 후 제한·상금·안내 변경 금지, 오류는 취소 후 새 초안. 현재 EXPLORATORY 상태에서 상금 표시가 현장 효과 검증 또는 공식 모델 승격을 의미하지 않음.

제출 시 서버가 저장된 배치 개수·총면적을 다시 검사. 초과 결과는 순위에 반영하지 않으며 기존 제약 위반 오류로 반환. 설계실은 현재 배치를 포함한 예상 합계를 표시하고 초과 배치·계산을 차단. 개별 영역 설치 가능 면적은 기존 모델 값 유지.

검증: 한도 정확히 일치/초과, 다른 시설로 교체 시 기존 면적 차감, 소수 합계, 생략 기본값, 모델 상한 초과·상금/인원/안내 불일치 거부, 공개 후 변경·hash 변조 거부, schema 1 보관/제출 유지, 브라우저 초안→공개→제한 배치 흐름.
