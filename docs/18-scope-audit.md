# 원기획 대비 잔여 범위 점검

2026-10-16. 원기획 PDF 6쪽 전체와 붙여넣은 기획의 본선 범위 대조. 첨부 문서의 제안·예시·가상 수치·일정은 실행 지시나 실측 근거가 아님. 사용자 정정(서울 공개자료·현실 적합성·원화·단일 관리자·조직 회원만 가입 승인) 우선.

## 확인된 핵심 기능

실제 서울 건물 경계와 분 강우, 시설 3종·13개 표면·원화 예산, 불변 저장, EPA SWMM 기준/전략 계산과 시계열, 일반/기관 탐색 순위, 회원 승인·MFA, 목적별 동의·기관 검토·재현 묶음, CPU 기준안과 개인 다강우 비교 구현. 기능별 실제 검증 근거는 `11-validation-log.md`와 관련 계약 참조. 아래 미완료를 포함해 전체 완료 아님.
