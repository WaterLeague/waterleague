# 서울 공동 플레이·주간 결과 흐름

## 최신 게임 규칙 · 2026-10-19

이 절은 이전의 공유 위치 독점·시즌 중 철거·주간 과거 흔적 미제공·침수 체크박스·재해 전체 기간만의 실험 계약보다 우선한다. 아래는 요구사항이며 검증 전 구현 완료 표시가 아니다.

- 주간 서울 대항전: 소속 구에 설치하되 다른 회원과 같은 위치 허용. 회원별 설계는 독립 비교 시나리오이며 서로 겹친 회원 시설을 같은 물리 공간에 중복 합성하지 않음. 본인의 동일 위치 중복 배치는 금지. 설치 확정부터 해당 주간 시즌 종료까지 변경·철거 불가. 설치 시각 이후 실제 관측을 연속 계산하고 시설별 누적 원 지표/점수·다른 회원 시설 점수·개인/구 순위를 공개. 시즌 종료 시 확정 기록 보존, 미계산·실패는 0점으로 위장하지 않음. 지도 구 표식의 일괄 `평가 대기` 문구 제거.
- 지도 물리: 실제 관측 강우·기상과 공개 지형·연결 입력을 SWMM/ANUGA에 적용한 수심·흐름·저류를 시간에 따라 자동 표시. 침수 표시 체크박스 없음. 바람은 관측과 물리 적용 범위·출처를 결속하며 장식 애니메이션을 침수 계산으로 대체하지 않음. 공개 연결 입력이 없는 영역은 임의 물길·침수를 생성하지 않음.
- 과거 침수흔적: 주간에서도 2010/2011/2022 사건을 선택해 비교. 과거 기록은 보라색, 계산 수심/유속은 물색 등 별도 범례. 재해 모드는 선택 사건의 과거 침수흔적을 항상 표시. 사후 기록 범위를 특정 재생 시각의 수심으로 해석하지 않음.
- 재해 실험: 개인 전용 설계. 재생 중 설치한 시각부터 시설이 유지되고 이후 원 지표/점수가 누적. 시간 이동·배속·설치 취소 지원. 타임라인 설치 아이콘을 누르면 해당 설치 시각과 위치로 이동. 설치/취소는 새 실행 계보로 보존. 제출은 현재 확정한 배치를 설치 시각과 무관하게 사건 평가 시작부터 종료까지 적용한 별도 불변 실행으로 계산해 기록 경쟁에 게시. 실험 도중 누적 점수와 제출 점수를 혼합하지 않음.
- 시설 선택: `시설 설치하기` 한 진입점에 시설 종류별 한 항목. 중복 `지도에 설치`/`연결 유역 비교` 분류 제거. 검증된 사업군별 예산·공통 상위 한도·원가를 함께 표시하고 임의 한도를 만들거나 같은 예산을 시설마다 복제하지 않음. 시설 선택 중 해당 시설의 설치 가능 후보만 표시·클릭. 공공 기존 시설의 확인된 같은 공간/층위는 서버 설치 차단 유지.
- 시설 표현: 공공 기존 시설은 확인된 건물·부지 도형을 구별하고 종류별 3D 시설 형태 표시. 사용자 설치도 종류별 3D 형태 표시. 공공/사용자·선택 상태를 구별하며 위치점으로 부지 경계 또는 실측 크기를 만들어내지 않음. 치수 미확보의 3D 모형은 시설 기호로 명시.

2026-10-17. 첨부 최종 기획 PDF 1·2·4·6쪽과 사용자의 게임성 보완 요청 기준. 기존 계산·권한·불변 모델 계약 유지.

## 기존 연구 도구의 흐름

기존 화면은 기능이 모인 설계 도구에 가까웠다. 기능 구현 완료를 게임 경험 완료로 분류하지 않는다. 실제 관측 이벤트를 선택하고, 예산 안에서 시설을 배치하고, 서버 계산 결과를 확인한 다음 수정·재도전·기록 제출로 이어지는 한 판을 구성한다.

- 도전 화면: 성수 실제 건물 미리보기, 관측일·관측소·강우량 선택, 목표·예산·시설·탐색 수준, 시작/이어서 플레이.
- 플레이 화면: 지도 중심의 공간, 목표·남은 원화 예산·배치 수, 선택 시설/면적 편집, 배치 확인 피드백, 계산 버튼. 강우 변경과 자료 상세는 별도 도전/자료 화면.
- 계산 대기: 실제 QUEUED/RUNNING 상태만 표시. 가짜 백분율·예상 순위·진행 시간·침수 연출 없음.
- 결과 화면: 서버 탐색 점수, 기준 대비 총 유출·잔여저류·초기저류·보정 평가량(유출+최종저류−초기저류), 비교 그래프, 민감도 범위, 계산한 버전의 배치, 수정 후 재도전·기록 제출.
- 결과가 생성된 불변 버전과 현재 편집 배치를 구분. 순서만 다른 동일 배치는 동일 판정, 모델·시설·면적이 다르면 이전 결과 표시. 제목·메모 변경은 물리 입력 변경으로 취급하지 않음.
- 기관 리그는 고정 조건을 유지. 일반 도전으로 전환 시 명시적으로 리그 맥락 해제. 기존 저장 기록·연구 복사 유지.

## 시각·조작 원칙

진한 잉크색 도전 화면과 밝은 입체 도시를 대비하고, 큰 목표 문구와 실제 수치를 우선한다. 플레이 화면에서 장문의 연구 설명과 항상 펼친 그래프를 줄이고, 결과에서 수문 상세를 제공한다. 기존 실제 건물·도로 좌표는 변경하지 않는다. 시각 표현의 품질과 현장 정확성은 별도 검증.

모바일에서도 지도·목표·계산 버튼을 먼저 확인하고 시설 편집으로 이동한다. 키보드 구역 목록·2D 대안·undo/redo·reduced-motion 유지. 계산 완료 시 결과 제목으로 초점 이동, 재도전 시 지도 제목으로 복귀. 상태 설명에 색상만 사용하지 않는다.

## 사실성 제약

점수·시설 효과·참가자·순위·예산은 실제 API/모델 값에서만 표시한다. 강우량이 크다는 이유로 임의 난이도나 홍수 위험을 부여하지 않는다. 결과의 피크는 표면 단위 합계이며 실제 배수구 홍수량으로 해석하지 않는다. 탐색 모델 고지와 자료 출처는 도전·플레이·결과에서 접근 가능하게 유지.

## PDF와 사용자 변경

PDF의 게임 포인트는 사용자 지시에 따라 원화로 대체한다. 회원은 플레이어·기업·기관·정부, 기업·기관·정부만 가입 승인, 관리자 1계정 유지. PDF 목업의 수치·닉네임은 구현 데이터가 아니다. 출품 대상은 사용자 정정에 따라 제13회 대학생 물환경 정책·기술 공모전이다. PDF의 본선 일정은 공식 공고와 대조 후 출품 문서에 사용한다.

## 계산 결과의 시간 재생

결과 요약과 강우 재생을 전환한다. 재생은 저장된 계산 버전의 배치와 해당 모델 지도만 사용하고 현재 편집 배치를 대신 표시하지 않는다. 모델·입력·버전 연결을 검사하며 불일치 시 재생하지 않는다.

현재 1분 강우 구간의 종료 시각에 같은 보고시각의 SWMM 기준/전략 유량을 연결한다. 강우는 해당 1분 깊이(mm)와 시작 이후 누적 깊이(mm), 유량은 보고시각의 표면 단위 합(m³/s)으로 구분한다. 분 평균 유량이나 시간별 실제 관망·셀별 침수 분포로 해석하지 않는다. 유량 시계열을 적분해 정확한 총량으로 다시 표시하지 않는다.

재생/정지·시간 슬라이더·처음/첫 비/강우 최대/기준 유출 최대 시각 이동과 재생 속도를 제공한다. 수치는 원본 배열의 동일 인덱스만 사용하고 중간값이나 계산 범위 밖 자료를 생성하지 않는다. 초기 자동 재생 없음. 화면 이탈·숨김 시 정지, reduced-motion 시 장식 움직임 제거. 3D와 2D 전환에서도 같은 계산 배치와 시각 유지.

지도에는 시설 없음/계산한 설계를 전환해 실제 배치 차이를 보여준다. 빗줄기는 관측 강우의 상대 크기를 알리는 설명용 표시이며 입자 수·크기·속도는 측정값이 아니다. 침수 깊이·지표 물길·구역별 유출을 임의 생성하지 않는다. 결과 요약의 최종 점수·물수지·민감도·재현 자료는 그대로 유지한다.

구현 확인: 관측 구간 종료 시각·유량 인덱스·자정 경계·누적 강우·해시/버전/시간축 불일치·마지막 프레임 상한 검사 통과. 실제 저장된 성수 수치지형도 계산의 06:05에서 강우 1 mm, 누적 9 mm, 기준 0.09430922116735019/설계 0.06774380338174524 m³/s와 화면 표시 일치. 재생/정지·강우 최대 이동·23:59 마지막 구간·3D/2D·시설 없음/계산한 설계 전환 확인. 현재 배치를 300→400 m²로 편집해도 이전 결과 재생에는 저장 당시 300 m² 유지. 480px 화면의 가로 넘침 없음. 자동 재생 없이 시작하며 빗줄기는 설명용 표시. 프로덕션 빌드 통과, 공개 순위 제출 없음.

공동 설치 확인(2026-10-17): 가입 소속 구·1회 선택, 허용 위치/유형/면적·동시 점유·철거 소유권 검사 통과. 실제 PostgreSQL HTTP 동시 요청 201/409, 타 구 설치/타인 철거 403, 소속 재선택 409. 브라우저에서 강남 공유 G2 빗물정원 20m² 설치→2곳/남은 예산 286,600,000원 표시와 강동 읽기 전용·설치 버튼 없음 확인. 시험 회원 2개·시설·세션만 제거. 주간 점수/승자 집계는 아직 구현 중.

후보 확장·조작 확인: 원문 154,784곳의 해시·도형·중첩 및 기존 수문 조건 참조 검사, 서버 공동 설치 4개·프런트 건물 선택/시설 도형/불투명도 검사 통과. 실제 PostgreSQL에 연결된 브라우저에서 추가 지상 후보와 옥상 후보 20m²씩 설치, 예산 300,000,000→283,600,000원·시설 2곳 반영 확인. 건물 벽면 직접 클릭으로 후보 패널 갱신, 3D/2D 전환, DOM 유효 폭 600px에서 가로 넘침 없음 확인. 후보 여부는 전체 건물 색인으로 판정하며 가까운 후보 페이지와 독립. 소속 구 바닥·두꺼운 경계·이름표 강조와 타 구 투명도 구분 확인. 확인용 계정·시설은 제거하고 기존 회원 기록 보존.


## 2026-10-19 주간 시즌 구현

주간 신규 설치의 위치 키는 회원·구·후보 조합이며 서로 다른 회원의 같은 위치 설치를 허용. 동일 회원의 중복 설치와 예산 지출은 회원 행 잠금과 DB 유일 제약으로 직렬화. 확정 시각은 DB 벽시계로 읽고 다음 월요일 00:00 KST를 종료 시각으로 저장. 종료 이전 변경·철거 API 거부. 종료 이후 배정 해제는 최초 원장 금액·정책을 그대로 복사하며 종료 시각에 한 번만 기록. 스케줄러 지연 시에도 후보 목록·점수 평가 창은 종료 시각으로 제한하고 다음 설치/예산 조회가 미처리 종료를 정리.

기존 활성 설치는 전환 주 종료에 고정하며 설치 시각·원가·모델·예산 원문은 보존. 이미 철거된 과거 기록은 그대로 유지. 주간 설치 목록의 지도 대표는 본인 우선, 같은 위치 회원들의 기록은 공개 시설별 점수 패널로 구분하고 50건씩 조회. 누적 기여·계산 완료 시각을 15초 간격으로 조회하며 미계산·0·음수 구분. 물리 점수는 현재 독립 LID 유출 평가량이며 회원 묶음의 연결 유역 계산 완료를 뜻하지 않음.

시설 메뉴는 종류별 단일 항목, 설치 확정 버튼은 시설 이름으로 표시. 선택 중 해당 시설 후보만 표시·클릭하며 타 회원 시설은 후보를 막지 않음. 본인 시설은 별도 목록에서 다시 조회. 현재 지도 설치 가능 6종과 아직 설치 연결/예산 확인 중인 6종 구분. 기존 관망 연구 도구 코드는 보존했지만 새 설치 화면에 연구 실행을 설치 버튼으로 위장하지 않음. 주간 과거 사건 선택·재해 사건 고정 보라색 흔적과 계산 수심의 별도 표시, 침수 표시 체크박스 제거. 입력이 없는 현재 침수는 생성하지 않음.
