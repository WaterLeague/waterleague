# 도전·플레이·결과 흐름

2026-10-17. 첨부 최종 기획 PDF 1·2·4·6쪽과 사용자의 게임성 보완 요청 기준. 기존 계산·권한·불변 모델 계약 유지.

## 목적과 완료 기준

기존 화면은 기능이 모인 설계 도구에 가까웠다. 기능 구현 완료를 게임 경험 완료로 분류하지 않는다. 실제 관측 이벤트를 선택하고, 예산 안에서 시설을 배치하고, 서버 계산 결과를 확인한 다음 수정·재도전·기록 제출로 이어지는 한 판을 구성한다.

- 도전 화면: 성수 실제 건물 미리보기, 관측일·관측소·강우량 선택, 목표·예산·시설·탐색 수준, 시작/이어서 플레이.
- 플레이 화면: 지도 중심의 공간, 목표·남은 원화 예산·배치 수, 선택 시설/면적 편집, 배치 확인 피드백, 계산 버튼. 강우 변경과 자료 상세는 별도 도전/자료 화면.
- 계산 대기: 실제 QUEUED/RUNNING 상태만 표시. 가짜 백분율·예상 순위·진행 시간·침수 연출 없음.
- 결과 화면: 서버 탐색 점수, 기준 대비 총 유출·잔여저류·초기저류·보정 평가량(유출+최종저류−초기저류), 비교 그래프, 민감도 범위, 계산한 버전의 배치, 수정 후 재도전·기록 제출.
- 결과가 생성된 불변 버전과 현재 편집 배치를 구분. 순서만 다른 동일 배치는 동일 판정, 모델·시설·면적이 다르면 이전 결과 표시. 제목·메모 변경은 물리 입력 변경으로 취급하지 않음.
- 기관 리그는 고정 조건을 유지. 일반 도전으로 전환 시 명시적으로 리그 맥락 해제. 기존 저장 기록·연구 복사·CPU 기준안 진입 유지.

## 시각·조작 원칙

진한 잉크색 도전 화면과 밝은 입체 도시를 대비하고, 큰 목표 문구와 실제 수치를 우선한다. 플레이 화면에서 장문의 연구 설명과 항상 펼친 그래프를 줄이고, 결과에서 수문 상세를 제공한다. 기존 실제 건물·도로 좌표는 변경하지 않는다. 시각 표현의 품질과 현장 정확성은 별도 검증.

모바일에서도 지도·목표·계산 버튼을 먼저 확인하고 시설 편집으로 이동한다. 키보드 구역 목록·2D 대안·undo/redo·reduced-motion 유지. 계산 완료 시 결과 제목으로 초점 이동, 재도전 시 지도 제목으로 복귀. 상태 설명에 색상만 사용하지 않는다.

## 사실성 제약

점수·시설 효과·참가자·순위·예산은 실제 API/모델 값에서만 표시한다. 강우량이 크다는 이유로 임의 난이도나 홍수 위험을 부여하지 않는다. 결과의 피크는 표면 단위 합계이며 실제 배수구 홍수량으로 해석하지 않는다. 탐색 모델 고지와 자료 출처는 도전·플레이·결과에서 접근 가능하게 유지.

## PDF와 사용자 변경

PDF의 게임 포인트는 사용자 지시에 따라 원화로 대체한다. 회원은 플레이어·기업·기관·정부, 기업·기관·정부만 가입 승인, 관리자 1계정 유지. PDF 목업의 수치·닉네임은 구현 데이터가 아니다. 출품 대상은 사용자 정정에 따라 제13회 대학생 물환경 정책·기술 공모전이다. PDF의 본선 일정은 공식 공고와 대조 후 출품 문서에 사용한다.

## 계산 결과의 시간 재생

결과 요약과 강우 재생을 전환한다. 재생은 저장된 계산 버전의 배치와 해당 모델 지도만 사용하고 현재 편집 배치를 대신 표시하지 않는다. 모델·입력·버전 연결을 검사하며 불일치 시 재생하지 않는다.

현재 1분 강우 구간의 종료 시각에 같은 보고시각의 SWMM 기준/전략 유량을 연결한다. 강우는 해당 1분 깊이(mm)와 시작 이후 누적 깊이(mm), 유량은 보고시각의 표면 단위 합(m³/s)으로 구분한다. 분 평균 유량이나 시간별 실제 관망·셀별 침수 분포로 해석하지 않는다. 유량 시계열을 적분해 정확한 총량으로 다시 표시하지 않는다.

재생/정지·시간 슬라이더·처음/첫 비/강우 최대/기준 유출 최대 시각 이동과 재생 속도를 제공한다. 수치는 원본 배열의 동일 인덱스만 사용하고 중간값이나 계산 범위 밖 자료를 생성하지 않는다. 초기 자동 재생 없음. 화면 이탈·숨김 시 정지, reduced-motion 시 장식 움직임 제거. 3D와 2D 전환에서도 같은 계산 배치와 시각 유지.

지도에는 시설 없음/계산한 설계를 전환해 실제 배치 차이를 보여준다. 빗줄기는 관측 강우의 상대 크기를 알리는 설명용 표시이며 입자 수·크기·속도는 측정값이 아니다. 침수 깊이·지표 물길·구역별 유출을 임의 생성하지 않는다. 결과 요약의 최종 점수·물수지·민감도·재현 자료는 그대로 유지한다.
