# 서울 하수관로 수위 자료 점검

2026-10-16. [서울시 하수관로 수위 현황 OA-2527](https://data.seoul.go.kr/dataList/OA-2527/S/1/datasetView.do?tab=A)의 2024 ZIP 공개 파일을 조사. 공식 목록 표기 710.85 MB, 2025-05-26 갱신. 원본 보존·SHA-256·다운로드 요청과 제공 조건 기록.

## 확보·검사 순서

1. 고정된 서울시 다운로드 주소에서 스트리밍 수집, 최대 크기·전체 시간·남은 디스크·ZIP 형식 검사. 전체 응답을 메모리에 적재하지 않음
2. 압축 목록과 CSV 헤더 확인 후 성동구·성수 인접 관측점, 2024-06-22·07-02·07-18 범위 우선 조회. 전체 압축 해제 금지
3. 코드·이름·좌표·시간대·관측 간격·수위 단위·기준 높이·통신 코드 의미를 각각 확인. 제공되지 않은 속성 추정 금지
4. 원본 행 수, 중복·누락·통신 이상·비정상 수위 별도 보고. 실패·결측을 수위 0으로 대체하지 않음
5. 해당 관측점과 실제 모델 유역·출구의 연결, 관측 단면·관저고·수위유량곡선 확보 전 보정/검증 입력 등록 금지

## 해석 경계

제공자는 관측 당시 현황을 나타내는 참고 자료이며 실제와 차이가 있을 수 있다고 안내. 수위는 유량과 다른 관측량이고, 센서 기준면·관망 단면·하류 조건 없이 모델 유출량에 직접 대응하지 않음. 위치가 성수동이라는 이유만으로 현재 가상 소유역 출구와 연결하지 않음. 공개 수위 자료 확보와 관망 원자료 확보를 구분.

확인된 상태와 미제공 항목은 아래 결과에 기록하고 [접근·신청 목록](12-data-access.md)에 반영.

## 공개 연구 관망 입력 · 서초2동

[Park·Kim·Yun·Kang, Mendeley Data v3](https://data.mendeley.com/datasets/dzzwvd8rjk/3), DOI `10.17632/dzzwvd8rjk.3`, 2024-04-19 공개, CC BY 4.0. 관련 논문 DOI `10.1016/j.jenvman.2024.122344`. 전체 ZIP 200파일·9 INP를 `data/raw/mendeley-seocho-v3/`에 보관하고 `data/manifests/mendeley-seocho-network-v3.json`에 원본/멤버 해시·저자·라이선스 고정. 연구 모형이며 서울시 공식 관망 현황이나 실제 시설의 확정 제원으로 대체하지 않음.

가져오기 계약: ZIP 경로·크기·해시 검사 후 원 INP 바이트, 모든 원문 항목, 노드/관로/집수 연결·좌표·다각형·외부 유입을 보존. 좌표값 크기만으로 EPSG나 기준고를 추정하여 서울 지도에 배치하지 않음. 미확인 관측 계보·시점·경계·비유한 입력은 별도 진단. 원본의 `NaN`을 임의 값으로 고치지 않음. LID 상세 출력 경로만 `*`로 바꾼 실행본은 원본과 변경 행/해시를 함께 보관하고 물리 입력 변경과 구분. 외부 입력 파일, 미지원 단위/시간/연결은 자동 보완 없이 거부.

실행 계약: 기존 고정 EPA 5.2.4 관망 어댑터를 격리 프로세스에서 사용하고 실제 내부 수렴·물수지·경고·실패를 보존. 출판된 5.2.2 결과와 이번 실행을 별도 엔진 결과로 구분. 수치 성공도 현장 검증/게임 순위 승인으로 전환하지 않음. 지표 결합에는 좌표계·수직 기준·지표 유입구·외부 유입 계보의 추가 근거가 필요하며 기존 연구 결과를 임의 계수로 게임에 적용하지 않음.

2026-10-18 실행 결과: 기준안 90.164575ha, 14집수·26접합점·2방류구·26관로. 모든 노드에서 원 방향 방류구 경로 확인, 6개 외부 유입 포함. 9개 입력에서 `CurbLen NaN` 14개씩 발견. 해당 값은 EPA의 오염물질 축적 계산용이며 수질/토지이용 계산을 허용하지 않는 진단 실행에서 원문 보존. 원본 내장 2010-09-21 강우는 1시간 간격 24값이며 관측소·시간대의 원 관측 계보는 미확인.

공개 연구 기준안의 모든 관로는 단면 2.2m×2.2m·조도 0.0147, 접합점 최대 깊이 3.2m. 이를 도시 전체 실측값으로 복제하지 않음. 원본 외부 유입은 기준안에서 약 346.97만m³로 집수 유출 약 22.94만m³보다 크므로 외부 유입을 생략하거나 강우만 교체해 현실 재현을 주장하지 않음. 방류구 `FREE`, 증발 0, 초기 수심 0 등 출판 입력 그대로 보존.

9입력 전체가 엔진 실행 완료지만 내부 비수렴 530~2,380단계로 현재 판정 실패. 기준안 1,534단계, 물수지 오차 약 -0.04527%. 보고 오차가 작다는 이유로 성공 처리하지 않음. EPA 날짜 차 내림으로 원 종료가 선언된 종료보다 1초 짧은 입력은 명시적 `NATIVE_DURATION_DIAGNOSTIC`에서만 원형 재실행, `calendarShortfallSeconds` 보존. 기존 게임 평가 시간 누락 거부 유지. 300초 표시 요청은 내부 단계를 자르지 않고 다음 원 단계 결과를 보관. 수치 변경·원본 수정 없는 기준안/LID의 `.out` 전체 바이트 일치 확인.

수치 파생 입력 계약: 원본을 고정하고 `SURCHARGE_METHOD`, `ROUTING_STEP`, `MINIMUM_STEP`, `MAX_TRIALS`만 별도 실험에서 변경 가능. 물성·단면·표고·강우·유입·평가 기간·수위 허용오차의 변경은 거부. 변경 행/해시, 파생 전후 수리 입력의 동일 해시, 원 압력 해법과 새 압력 해법을 보존. SLOT의 가상 슬롯도 수치 근사이므로 동일한 해법을 서로 다른 계산 간격에서 비교하고 독립 현장 검증으로 해석하지 않음. 실패를 삭제하거나 통과 설정을 원본/운영 설정으로 자동 교체하지 않음.

논문 본문 3.1~3.3 추가 확인: 정확한 침수지도 복원보다 배수망 설계 전략 비교가 목적. 외부 기저 오수 유입은 2018~2022년 평균 관로 사용률 18.2%·단면·설계 유속에 따른 추정이며, 2010년 직접 유입 관측값이 아님. 피복은 2021년, DEM은 2022년, DSM은 2010년 자료를 사용했다고 명시. 따라서 당시 입력만을 갖춘 2010년 재해 복원으로 등록하지 않고 사후 자료가 포함된 설계 비교 연구로 분류. 원 INP 좌표의 EPSG·수직 기준을 확인한 것으로 확대하지 않음. 출처: [공개 논문](https://doi.org/10.1016/j.jenvman.2024.122344).

파생 실행 결과: 기준안/LID 각각 SLOT·최대 반복 200회·최대 62.5ms/최소 25ms와 최대 31.25ms/최소 10ms에서 내부 비수렴 0회, 물수지 오차 절댓값 0.017% 미만. 수위 수렴 허용오차는 원 0.0015m 유지. 최대 125ms/최소 50ms는 각각 40회/1회 비수렴으로 실패 유지. 원본 EXTRAN도 기존 1,534회/530회 실패 유지. 세분한 두 설정에서 기준안 월류 총량 차이 21.215467m³, LID안 0.093756m³. 31.25ms의 기준안 대비 LID 월류 감소 126,403.445913m³는 이 연구 입력의 계산 차이이며 실제 2010 피해 감소나 지표 침수 깊이·첨두를 뜻하지 않음. `data/benchmarks/seocho-network-resolution-v1.json`에 전체 설정·실패·원 총량·차이·근거 해시 보존. 다른 설계·40일 창·현장/격자 수렴으로 일반화하지 않음.
