# 서울 하수관로 수위 자료 점검

2026-10-16. [서울시 하수관로 수위 현황 OA-2527](https://data.seoul.go.kr/dataList/OA-2527/S/1/datasetView.do?tab=A)의 2024 ZIP 공개 파일을 조사. 공식 목록 표기 710.85 MB, 2025-05-26 갱신. 원본 보존·SHA-256·다운로드 요청과 제공 조건 기록.

## 확보·검사 순서

1. 고정된 서울시 다운로드 주소에서 스트리밍 수집, 최대 크기·전체 시간·남은 디스크·ZIP 형식 검사. 전체 응답을 메모리에 적재하지 않음
2. 압축 목록과 CSV 헤더 확인 후 성동구·성수 인접 관측점, 2024-06-22·07-02·07-18 범위 우선 조회. 전체 압축 해제 금지
3. 코드·이름·좌표·시간대·관측 간격·수위 단위·기준 높이·통신 코드 의미를 각각 확인. 제공되지 않은 속성 추정 금지
4. 원본 행 수, 중복·누락·통신 이상·비정상 수위 별도 보고. 실패·결측을 수위 0으로 대체하지 않음
5. 해당 관측점과 실제 모델 유역·출구의 연결, 관측 단면·관저고·수위유량곡선 확보 전 보정/검증 입력 등록 금지

## 해석 경계

제공자는 관측 당시 현황을 나타내는 참고 자료이며 실제와 차이가 있을 수 있다고 안내. 수위는 유량과 다른 관측량이고, 센서 기준면·관망 단면·하류 조건 없이 모델 유출량에 직접 대응하지 않음. 위치가 성수동이라는 이유만으로 현재 가상 소유역 출구와 연결하지 않음. 공개 수위 자료 확보와 관망 원자료 확보를 구분.

확인된 상태와 미제공 항목은 아래 결과에 기록하고 [접근·신청 목록](12-data-access.md)에 반영.

## 확보 결과

- ZIP 실제 크기 727,913,789 bytes, SHA-256 `a1499be45fab2798375b75050acd0f826e34dd462c646747be043dc862a082e4`. 월별 CSV 12개 포함, 원본 git 제외
- 6월 12,407,930행·7월 13,265,236행을 스트리밍 검사하고 월별 원문 해시 보존. 원본 CP949, 첫 필드명에 실제 `?` 문자가 있으며 원본 그대로 유지
- 성동구 코드 `04`의 11개 관측소 식별. 대상 3개 날짜 46,080행을 별도 UTF-8 CSV로 추출·해시 보존. 10개 관측소는 세 날짜 모두 1,440개 정시 분 관측, `04-0012`는 두 7월 날짜만 존재. 6월 미제공 원인·설치 시점 미확인
- 선택된 32개 관측소·날짜 조합에서 중복·분격자 누락·음수·비유한 수치 없음, 통신상태는 모두 `통신양호`. `04-0002`의 6월 22일은 1,440행이 모두 원시값 0.21로 동일. 통신 상태와 별개로 장시간 고정값의 계측 유효성 확인 필요
- 역사 CSV에는 위치·단위·기준면·시간대 필드 없음. `measurementUnit=UNVERIFIED`, `verticalDatum=NOT_PROVIDED`, `calibrationEligible=false` 유지
- 공식 `DrainpipeMonitoringInfo` API 공개 샘플 5건에 위치 설명 존재. `04-0005`는 성동구 성수일로 17-1 인근 맨홀로 표기. 요청이 과거 시점이어도 반환된 위치 문자열이 과거 위치를 보증하는지는 미확인. [샘플 위치 계보](../data/derived/seoul-sewer-sample-locations.json) 보존
- 웹 공개 표의 최근 1시간·성동 필터 조회는 빈 목록 반환. 샘플 한도 밖의 전체 위치는 확보하지 않았으며 일반 API 인증키가 필요할 수 있음. 과거 원본 수집에는 키 불필요

[품질 보고서](../data/derived/seoul-sewer-audit.json)에 관측소별 건수·최소/최대 원시값·상이한 값 개수·통신 상태·누락 기록. `scripts/audit_seoul_sewer.py`로 원본 ZIP에서 재생성 가능. 별도 CSV 재읽기로 46,080행과 32개 구간의 시각 수·값 개수·통신 상태 대조 통과.

## 현장 연결에 필요한 추가 항목

관측소 전체 좌표와 이전/설치 이력, 수위 단위·센서 영점·관저/지표 표고, 단면과 유량 환산 조건, 상하류 연결·유역·펌프 운전 이력, 장시간 고정값/통신양호의 QC 의미. API 키만으로 이 항목 전체가 제공된다고 가정하지 않음. 해당 자료 확보 전 현재 SWMM의 가상 출구와 실제 수위를 비교한 정확도 지표 산출 금지.
