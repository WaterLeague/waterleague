# 자료 접근·신청 목록

2026-10-17 갱신. 성수 연무장길 실험 구역과 2024년 강우 창 기준. 구현에는 공개데이터만 사용한다. 공개 파일·API 권한을 전체 구현 범위로 조사해 묶어서 안내하며, 배포 준비·기관 협조·비공개 자료 요청은 포함하지 않는다. 신청 권한 확보와 물리 모델 검증은 별개 단계.

현재 구현을 진행하기 위해 새로 발급해야 하는 필수 API 키 없음. `.env.local` 기존 파일만 사용, 외부 API 키는 수집·진단 도구 전용. 필요성이 확인되지 않은 서비스의 일괄 키 발급 요청 금지. 추가 키가 필요한 경우 서비스명·신청 링크·용도·환경변수·실제 오류를 이 문서에 함께 기록.

## 현실 모델에 필요한 자료 묶음

성수 실험 구역 및 그 구역이 연결되는 실제 배수 유역을 범위로 지정. 임의 사각형 구역 밖의 유입·하류 경계도 포함.

- 지형: DEM 해상도·수평/수직 기준·취득일·건물/식생 제거 여부·품질 정보. 도로 경사와 저지대 표현에 충분한 자료인지 검사
- 피복: 관측 연도에 대응하는 토지피복 경계·불투수 포장·지붕 배수 연결·토지 이용, 재배포 조건
- 관망: 맨홀 좌표·지표고·관저고, 관로 시작/끝 연결·길이·관경/단면·재질·거칠기, 월류구·토구·유입구, 펌프 용량과 작동 수위/운전 이력, 하천 수위 경계
- 토양: 표토/심토 토성·유효 토심·배수 등급, 현장 침투/포화수리전도도·다짐·지하수위. 농경지 토양도의 도시 성토지 대표성 별도 확인
- 검증: 모델 출구에 대응하는 유량 또는 유량 환산 가능한 수위·수위유량곡선·관측 단면, 시간대·간격·결측/검보정 이력, 강우 동시 관측, 여러 사상 중 보정/검증 구간 분리
- 시설: 실제 설치 가능 면적·구조 하중·유입 연결, 시설 제원·유지관리·공사비 근거와 기준 연도

위 항목을 모두 사용자에게 구해 달라는 요청으로 취급하지 않음. 공개자료의 좌표·시간·관측량이 모델과 연결되는지 확인하기 전 보정에 사용하지 않음. 상세 관망이 확보되지 않은 상태의 표면 유출 계산을 도시 침수 깊이·관거 역류 예측으로 표현하지 않음. 현재 작업에서 기관 협조·공문 요청을 추진하지 않음.

## 2026-10-19 수면 표시용 관측 연결

재해 3사건의 기존 AWS 분 원문 WD1·WS1 재사용 완료. 기존 강우 선정 매니페스트·강우 변환 파일·원문 해시를 대조해 동일 관측소의 25개 구 대응을 보존한다. 추가 키나 자료 재요청 없음. 분 단위 바람은 시각 물결에만 사용하며 과거 사건 전체의 공간 풍장 복원을 주장하지 않는다.

[한강홍수통제소 공식 Open API](https://www.hrfco.go.kr/web/openapiPage/reference.do)의 수문 조회는 WLOBSCD·YMDHM·WL(수위 m)·FW(유량 m³/s)를 제공한다. 확보된 수위·유량만으로 하천 표면의 공간 유속 벡터를 만들지 않는다. [WAMIS 유량측정성과](https://www.wamis.go.kr/wkw/wkw_flwsrrs_lst.do) 역시 시점별 측정 성과이며 현재 장면 전체의 실시간 유속장으로 연결하지 않았다. 실제 단면·수직 기준·모델 연결이 확인되기 전 자연 하천의 유속은 미연결 상태로 유지한다. 이것은 수면 광학·기상 물결 구현의 선결 조건이나 추가 사용자 자료 요청이 아니다.
