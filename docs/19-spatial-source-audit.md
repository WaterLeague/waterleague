# 성수 공간 원자료 품질 검사·적용 계약

범위: 취득 시점별 공간 원본·도형·좌표/표고 품질과 모델 편입 근거. 아래 날짜별 후보 수·시험 사례는 해당 버전의 기록이며 현재 전체 게임 범위는 [제품 계약](01-product.md), 확보 여부는 [자료 현황](13-data-access.md)을 따른다.

## 수치지형도 플레이 모델 연결

2025 공개 수치지형도의 건물 246개와 도로·철도·교량 면 경계를 별도 지도에 연결한다. EPSG:5186 원문 좌표에서 고정 원점을 뺀 미터 좌표를 사용하며 내부 구멍·복수 도형을 보존한다. 교통 면은 화면 경계로 절단하되 건물 원형은 보존한다. 층수×3.2m 및 층수 누락 시 9m는 시각화 가정으로만 사용한다. 평탄 지면 유지, 교량의 실제 고도·도로 경사 추정 금지.

검사된 후보 13개를 새 모델의 셀로 연결한다. 옥상 면적은 원문 투영 면적, 지상은 도로 경계 안의 25m² 설계 격자다. 옥상 60%·지상 80% 상한은 설계 가정이며 설치 적합성 UNKNOWN을 유지한다. 토양·경사·유입·시설 제원은 기존 가정을 명시적으로 계승하며 DEM·피복을 반영한 보정 모델로 표시하지 않는다. 기존 모델·순위·재현 자료는 수정하지 않는다.

2026-10-17. 사용자 제공 원본 3건([공개자료 확보 현황](13-data-access.md)) 검사를 먼저 수행한 뒤 모델 적용 여부 결정. 원본 취득·정합·현장 검증은 별도 단계. 운영 강우/모델/기존 점수 불변, EXPLORATORY 유지.

## 검사 입력과 산출물

- 대상 경계: 기존 성수 모델의 EPSG:4326 `[127.0525,37.5430,127.0555,37.5455]`. 기존 모델 원문 hash와 함께 검사 기록.
- 원본 ZIP의 전체 hash·CRC·크기·각 구성 파일 hash 보존. 절대/상위 경로·링크·중복/암호화·과도한 압축 크기 거부. 기존 원본 덮어쓰기 금지.
- 공식 DEM 2024/2025 원문 WKT·geotransform·크기·밴드 유형·NoData·메타데이터·유효 범위 기록. 재투영/보간 전 원본 격자 값을 검사.
- 토지피복 원문 PRJ·DBF 필드/문자셋·XML 제작/원영상 설명·IMG_DATE·L1/L2/L3 코드/도형 유효성 검사. 표본을 원자료 해상도/현장 측정으로 대체하지 않음.
- 사용 도구 버전·변환 방향/축 순서·accuracy/ballpark 여부 기록. 원문 datum·epoch·수직 기준 부족을 EPSG 추정으로 숨기지 않음.
- 산출물은 로컬 검사 JSON·도엽/실험 구역 통계. 원본과 파생 좌표는 이용조건 확인 전 비공개 경로. 공개 문서에는 출처·해시·검사 방법·허용 범위·누락 근거만 기록.

## DEM 적용 제한

현재 파일은 90m 격자이며 실험 구역은 약 0.3km 블록. 영역과 교차하는 원본 셀 수·유효 값·범위 및 두 연도 동일 격자에서 값 차이 확인. 유효 표고가 있어도 수직 기준과 취득/제작 이력 확인 전 정확한 현장 높이·도로 경사로 승인하지 않음. 두 파일의 차이를 실제 지형 변화로 단정하지 않음.

미세 배수 경사·우수받이·도로 턱·관망 연결·침수 깊이는 90m 자료로 복원할 수 없음. 보간한 조밀한 격자도 원자료 90m와 가정 표기 유지. 필요 시 성수 1:1,000 수치지형도 원본의 등고선/표고점·건물·도로와 배수 관망 요청 범위를 검토, 필요한 자료를 묶어서 사용자에게 안내.

## 토지피복 적용 제한

원문 CRS에서 전체 유효성·중복·결측 검사 후 명시한 변환으로 실험 경계를 대조. 원도형을 자동 복구하지 않고 잘못된 도형의 위치/수·영향 범위 보고. 실험 경계와 교차하는 도형의 L3별 면적, 합/합집합/중복/미피복 면적을 별도로 계산. 단위는 투영 좌표의 m², bbox를 실제 배수 유역으로 간주하지 않음.

영상 날짜는 개별 필드·도엽 XML·XLSX의 범위를 구분. 전국 메타데이터의 0.25m 영상 해상도는 피복 경계의 측량 정확도나 DEM 해상도가 아님. 공업/상업/도로 등 토지 이용 분류를 불투수율 100%·침투율·설치 가능 면적의 실측값으로 변환하지 않음. 기존 OSM 건물/설치 후보와 충돌하면 출처/시기/분류 차이를 공개하고 추가 확인.

## 모델 편입 조건

원본 이용조건·출처 표시·파생물 재배포 범위, 공간/시간 정합과 사용 목적에 맞는 정밀도 확인 후 별도 모델 버전 생성. 모델·시설 가능 면적/토양/관망 등 연관 입력 변경과 기본안·민감도·수지·재현을 함께 검증. 원자료 확보만으로 보정/독립 사상 검증·현장 적용 가능 등급을 부여하지 않음. 기관 보고서와 화면은 공개자료·계산·가정·미확인을 구분.

## 첫 검사 결과

`scripts/audit_spatial_sources.py`로 등록 원본 hash·ZIP CRC/경로/중복/크기를 검증한 뒤 임시 디렉터리에서 읽기 전용 검사. GDAL 3.8.5, pyproj 3.8.0 및 실행 당시 PROJ/GEOS 버전 기록. 네트워크 좌표계 격자 자동 취득과 GDAL 원본 보조 파일 저장 비활성화. 원문 WKT 유지, 대상지 AreaOfInterest·항상 x/y·경계 변별 20분할 적용. 수평 변환 연산의 정확도를 측량 정확도로 표현하지 않음.

- DEM 두 연도 모두 79,380개 원본 격자 값. 실험 경계에 걸친 16개 셀은 유효하며 NoData 없음. 격자는 90m, 표고 단위 필드·수직 기준·취득일 미제공. 두 연도 투영 격자 수치는 같지만 원문 WKT와 모든 원본 값은 다름. 제작 차이를 지형 변화로 판정하지 않음.
- 토지피복 12,330개 중 원도형 4개에 자기교차 오류. 그중 도로 분류 2개의 envelope가 실험 구역과 겹쳐 검사 상태 `INCOMPLETE_INVALID_GEOMETRY`. 오류점 자체가 블록 안에 있다는 의미는 아님.
- 유효 도형만 교차 계산한 경우 173개·9개 세분류·약 52.73% 면적 포함. 제외한 잘못된 도로 도형 때문에 남은 비율을 실제 미피복/결측으로 해석할 수 없음. 원도형 자동 보정이나 불투수율 대입 없음.
- 교차한 유효 도형의 IMG_DATE 필드는 모두 `2023-12-31`. XML은 2023년 영상 기반 2024 현행화 표기. 실제 촬영일·2024 강우 당일 현장 상태는 별도 확인 대상.

해시·도구 버전·오류 수·승인 제한은 `data/manifests/seongsu-spatial-audit.json` 보존. 원본·각 셀 값·상세 CRS/변환·도형 식별/면적이 포함된 전체 보고서는 `data/private/seongsu-official-20261017/`에만 보존. 같은 실행 코드·입력으로 두 번 생성한 보고서의 byte 일치 확인. 기존 모델·기하·랭킹 입력 변경 없음.

검사 7개 추가(압축 경로/링크/CRC/해시/정규화 중복/덮어쓰기, 미터 CRS/면적, NoData, 중첩/빈 영역, 잘못된 도형과 원본 보존). Python 전체 42개 통과, 기존 실제 SWMM 수치 검사 포함. CI의 data job도 고정 pyproject 의존성 설치 후 동일 검사 실행. 원본이 필요한 실제 GDAL 검사는 로컬 수행, CI 단위 검사를 원자료 검사로 대체하지 않음.

보완 자료로 공식 화면에서 2025년 1:1,000 수치지형도 Ver2.0 `377052201·377052202·377052211·377052212`를 선택하고 신청서 작성. 사용자에게 준수사항 동의·SHP와 제공 설명/좌표계 파일 다운로드를 묶어서 요청. 추가 API 키·프로그램 없음. 2025 자료는 2024 지형 상태의 직접 증거로 사용하지 않음.

```sh
simulation/.venv/bin/python scripts/audit_spatial_sources.py \
  --sources data/private/seongsu-official-20261017 \
  --output data/private/seongsu-official-20261017/audit-new.json
```

입력 ZIP 이름은 `dem-2024.zip`, `dem-2025.zip`, `landcover-2024.zip`. 등록 hash가 다른 재배포 원본은 자동 수락하지 않으며 출처 계약 갱신 필요. 기존 검사 출력 덮어쓰기 거부.

도구 근거: [GDAL raster info](https://gdal.org/en/stable/programs/gdalinfo.html), [GDAL XYZ 변환](https://gdal.org/en/stable/programs/gdal_translate.html), [Shapefile 문자셋](https://gdal.org/en/stable/drivers/vector/shapefile.html), [pyproj TransformerGroup](https://pyproj4.github.io/pyproj/stable/api/transformer.html).

## 자기교차 도형 진단 계약

원본 검사와 별도 명령으로 `make_valid`의 `linework`·`structure` 두 보정 후보를 비교. 원본 ZIP 검증 후 임시 디렉터리에서 계산하며 원본/기존 검사 보고서/모델은 덮어쓰지 않음. 원도형을 수정한 파생 데이터는 공개하지 않고 로컬 진단 보고서만 생성. [Shapely 공식 문서](https://shapely.readthedocs.io/en/stable/reference/shapely.make_valid.html)에 따라 전자는 선분과 꼭짓점 보존, 후자는 외곽/내부 링의 분류가 맞다는 가정에 기반. 두 방식의 일치도 현장 경계의 정확성 증명은 아님.

- 각 오류 도형의 원본 순번·속성 hash·원도형 WKB hash·오류 이유 기록. 후보의 WKB hash·유형·면적·꼭짓점 수와 비면적 선/점 성분을 별도 기록. 단순 `buffer(0)`·반올림·격자 스냅 없음.
- 면적 성분만으로 대상 구역 교차를 계산하되 선/점 성분의 수·길이는 버리지 않고 보고. 두 방식의 대상 구역 내 대칭차 면적과 각 분류별 합/합집합/중복·전체 빈 영역 비교. 오류 원도형의 수치 면적은 참고값이며 실측 기준으로 사용하지 않음.
- 원래 유효한 도형과 속성은 동일하게 보존. 보정 후 빈 도형·비면적 성분·방법 간 불일치·전체 중복/빈 영역은 검토 대상으로 유지. `modelEligible=false`, `calibrationEligible=false`, `DIAGNOSTIC_ONLY` 고정.
- 공개 보고는 원본/코드/로컬 결과 hash와 요약 수치만 포함. 기존 EXPLORATORY 모델과 랭킹은 불변. 최종 후보 채택은 이용조건·현장/영상 대조·좌표/시기 정합 검토 이후 별도 계약.

2026-10-17 [EGIS 저작권 정책](https://aid.mcee.go.kr/bbs/copyright.do) 확인. 정책은 자료별 공공누리 표시 확인과 출처 표시를 요구. 제공 XML에는 저작권자 `환경부`가 있으나 이 ZIP에 적용되는 공공누리 유형은 아직 확인되지 않음. 사이트 전체 정책을 개별 원본/파생 좌표의 무제한 재배포 허가로 취급하지 않음. 현재 GitHub에는 원자료/파생 좌표를 제외한 코드·검사 요약만 저장.

## 두 보정 후보 진단 결과

`scripts/diagnose_landcover_topology.py`의 GEOS 3.14.1 `linework`/`structure`, `keep_collapsed=true` 적용. 오류 4개 모두 유효 Polygon 후보가 되었으며 선/점 퇴화 성분 없음. 유효 원도형 12,326개·전체 속성 원문은 그대로 유지. 두 방식은 WKB의 순서/방향에 따른 hash는 다르지만 4개 후보 각각의 면적 도형이 같고 전체/대상 구역 대칭차 면적 0m². 이는 경계의 현장 정확성 승인과 별개.

대상 구역은 기존 유효 173개와 보정한 도로 2개를 포함해 175개. 두 방식 모두 합집합 면적 73,562.72154458915m², 대상 경계 73,562.72154458817m². 계산 피복률 1.0000000000000133으로 부동소수 오차를 그대로 보존, 중첩/빈 영역 계산값 0m². 도로 후보가 구역과 겹치는 면적은 약 31,273.37m²·3,502.68m². 이전 52.73%는 오류 도형을 제외한 부분 검사였으며 실제 미피복 비율이 아님. 분류별 합집합도 두 방식 간 대칭차 0m².

오류 도형의 원본 순번·속성/WKB hash·후보 구조·면적과 변환 근거를 로컬 `topology-final.json`에 기록, 같은 코드 재실행 `topology-final-repeat.json`과 byte 일치. 공개 요약 `data/manifests/seongsu-topology-diagnostic.json`은 좌표·원본 속성을 제외. 원본 ZIP·기존 검사 보고서·모델/점수 입력 불변.

교차 도형·겹친 내부 링의 방법별 차이·선으로 퇴화한 도형·기존 중첩/빈 영역·구역 밖 오류·잘못된 경계/3D 입력·원본 보존/결정성을 6개 검사로 확인. 기존 SWMM 검사를 포함한 Python 전체 48개 통과. 시험용 도형은 진단 규칙 검증이며 현장 경계의 정확도 검증 자료가 아님.

```sh
simulation/.venv/bin/python scripts/diagnose_landcover_topology.py \
  --source data/private/seongsu-official-20261017/landcover-2024.zip \
  --output data/private/seongsu-official-20261017/topology-new.json
```

## 배치 구역 연결

같은 원본을 13개 배치 구역과 대조한다. 옥상은 연결된 OSM WGS84 원형상, 지상은 생성기의 가정된 10×10m 화면 패치를 역투영한다. 지도/모델/원본 해시와 좌표 근거를 검증하고 지오데식·모델·피복 좌표계 면적을 분리한다. 원본 유효 도형 및 두 보정 후보의 구역별 분류·합/합집합/중복/미피복·방법별 대칭차, 배치 구역끼리 중첩과 블록 밖 면적을 기록한다. 경계 접촉과 양의 면적 교차, 잘못된 원도형의 envelope 영향과 보정 후보의 실제 교차를 구분한다.

상세 보고서는 비공개 경로에 덮어쓰기 없이 보존하고 공개 산출물에는 해시·건수·집계만 포함한다. 분류를 실측 침투율·불투수율·시공 적합성으로 치환하지 않으며 기존 모델/순위 불변. 합성 도형의 경계/중첩/결측/후보 불일치·잘못된 속성/좌표 연결 거부와 실제 원본 반복 실행의 결정성 검증 후 적용 가능 범위 판단.

같은 배치 구역을 보관한 2025 수치지형도 건물 스냅샷과도 대조한다. 구역별 양의 면적 교차 건수·합집합 면적/비율을 기록하고 경계 접촉만으로 건물을 포함하지 않는다. 수치지도·토지피복의 시점/분류/경계 차이를 부지 변화나 원자료 오류로 단정하지 않는다. 공개 요약은 구역별 집계·분류명·IMG_DATE·자료/코드/상세 결과 해시만 포함하며 원본 좌표·속성 전체는 제외. 원본 해시와 코드·모델의 검사 중 변경을 거부한다.

## 표고점·DEM 공간 지지 범위 진단

2025 수치지도 4개 도엽의 `N1P_F0020000` 표고점과 `N1L_F0010000` 등고선 목록, 2024/2025 DEM을 대조한다. 원본 hash/CRS·유효 2차원 도형/유한 속성·중복 ID를 검사한다. 표고점은 구역 밖을 포함한 전체 12개를 보존하고 값 차이가 큰 점을 임의 제외하지 않는다. 등고선의 전체 수·연구 경계 교차·최근접 거리를 기록하며 등고선 없이 표고점만의 Delaunay 삼각망 선형 보간을 별도 진단한다. 원본 점의 볼록껍질 밖 외삽은 금지한다.

원본 표고점 위치와 새 모델 13개 구역 중심에서 DEM의 해당 원본 격자 값을 읽는다. 90m 셀 중심의 값을 위치의 실측값으로 부르지 않는다. DEM과 표고점의 차이·삼각망 보간과 DEM의 차이는 해상도·시점·수직 기준이 통일되지 않은 자료 간 수치 차이다. 어느 자료를 정답으로 삼거나 RMSE를 현장 정확도 지표로 사용하지 않는다. DEM 단위/수직 기준 메타데이터 부족을 보존하며, 차이만으로 보정량·도로 경사·유출 경계를 결정하지 않는다.

전체 점·삼각망·좌표 변환·DEM 원본 셀 번호/값·구역별 진단은 로컬 비공개 보고서로 보존한다. 공개 요약에는 원본/도구/코드/상세 보고서 해시, 건수, 수치 차이 범위와 적용 제한만 포함한다. 공개 요약 파일은 수문 모델 입력과 구분한다. 자료 화면 연결은 서울 전역 맵 확장 우선순위 이후 진행한다. 이번 진단에서 모델·지도 지형·과거 기록·순위는 변경하지 않는다. 실제 공개 원본 반복 실행과 합성 평면의 보간·외삽/중복/비유한 입력 거부를 검증한다.

진단 구현 결과: 전체 표고점 12개 중 연구 경계 내부 1개, 등고선 전체 5개 중 경계 교차 0개, 최근접 등고선 약 267.37m. 원본 점의 볼록껍질은 현재 13개 후보 중심을 포함하나 지형 정확도 근거는 아님. `scripts/audit_terrain_support.py`의 실제 원본 반복 결과 일치, 합성 평면·격자·누락·형식·공개 요약 검사 7개 통과. 모델 반영과 자료 화면 연결은 미완료.


## DEM 삼각형별 토양·피복 면적 연결

`prepare_surface_coverage.py`는 원본 2025 DEM 288삼각형(1,166,400m²)에 보관 공개 심토토성 8,266개와 2024판 피복 12,330개 도형을 연결. CRS를 덮어쓰지 않고 PROJ의 비근사 변환을 사용하되 두 연산의 정확도 값 -1(미확인)·좌표 epoch 미확인을 보존. 원본 꼭짓점 변환 후 직선 연결이며 변환 정확도를 현장 측량 정확도로 표시하지 않음. [PROJ/pyproj 변환 정의](https://pyproj4.github.io/pyproj/stable/api/transformer.html), [Shapely 좌표 변환](https://shapely.readthedocs.io/en/stable/reference/shapely.transform.html), [공간 교차 인덱스](https://shapely.readthedocs.io/en/stable/strtree.html) 기준 적용.

미수정 원본의 내부 구멍·다중 도형 유지, 경계 접촉 면적 0 제외. 동일 분류라도 양의 면적 중첩은 중복 영역으로 제외하며 원본 순번/ID 보존. 오류 도형은 복구하지 않고 변환 후 envelope의 영향 가능 범위를 기록. 정상 도형이 그 범위를 덮더라도 독점 배정으로 확정하지 않음. 모든 작은 양의 면적을 원값으로 남기므로 수치 반올림 크기의 조각이 실제 필지의 존재를 뜻하지 않음. 미피복·중복·오류 영향 지표는 서로 겹칠 수 있으며 단순 합산 금지.

## 명시적 파생 도형과 도시생태 표면 구성

원본 감사와 분리한 탐색용 파생 정책 `EXPLICIT_TWO_METHOD_AREA_CONSENSUS_v1` 추가. 원본 투영 좌표에서 `linework`·`structure` 양쪽이 유효한 Polygon/MultiPolygon이고, 선/점 퇴화 성분이 없고, 면적 도형이 위상적으로 같은 경우에만 파생 도형 생성. 정점 순서 정규화 외 스냅/반올림/buffer 처리 없음. 불일치·퇴화는 오류 상태 유지. 원본과 파생 입력의 배정을 각각 보존하며 이 채택은 현장/영상 정확도 검증이나 운영 모델 승인과 구분. 원본·기존 결과/순위 불변.

불투수율의 직접 근거로 서울도시공간포털 자료실의 2025·2020·2010 도시생태현황도와 2025 최종보고서 추가 확보. 공개 첨부파일은 키·사용자 로그인 없이 수신 가능. 원본 ZIP/PDF와 메타자료를 프로젝트에 보관하고 파일별 URL·크기·SHA-256을 `data/manifests/seoul-biotope-20261018.json`에 기록. 2025 원본의 조사 블록은 42,544개이며 고유번호 중복 72건을 삭제/병합하지 않고 원문 순번으로 구분. 원본 값과 모순·범례 차이를 분리하고 전체 면적을 자동 정규화하지 않음.

`prepare_seoul_biotope.py`는 원본 WKT(EPSG:5174로 식별)에서 대상 DEM 원문 좌표계로 변환, 삼각형과 조사 블록의 교차 면적으로 건물·불투수포장·투수포장·녹지·나지의 면적을 배정. 변환 후 새로 발생한 도형 오류도 원본 오류와 함께 제외하고 임의 복구하지 않음. 원본 블록 내부 균질 배정은 명시적 근사이며 실제 포장 위치 분포와 다름. 숫자 불일치·겹침·미피복 면적을 미해결로 남기며 물리 입력 전체 완성을 주장하지 않음. 투수포장 제원·수면/습지·조사불가능지의 추가 물리 조건을 원지반 침투 후보와 구분. 2010/2020의 필드 이름이 같아도 2025 조사의 세부 방식·정확도·사건 당일 유효성을 소급 적용하지 않음.
