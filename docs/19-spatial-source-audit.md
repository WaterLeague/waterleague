범위: 취득 시점별 공간 원본·도형·좌표/표고 품질과 모델 편입 근거. 아래 날짜별 후보 수·시험 사례는 해당 버전의 기록이며 현재 전체 게임 범위는 [제품 계약](01-product.md), 확보 여부는 [자료 현황](13-data-access.md)을 따른다.

## 서울 25개 구 전환 계약

2026-10-20 서울 25개 구의 `수치지형도v2.0(1:1000)` SHP ZIP과 데이터 설명서를 `data/private/vworld-seoul-topography-20260307/originals/`에 복사했다. [원본 목록](../data/manifests/vworld-seoul-topography-20260307.json)의 프로젝트 상대 경로·크기·SHA-256을 기준으로 읽으며 개인 다운로드 경로에 의존하지 않는다. 공통 입력 카탈로그의 수집·구성 검사를 완료했으며 일반 게임의 OSM 교체는 [P0 구현 계획](09-delivery.md#p0--서울-수치지형도-전환과-공통-공간-기반)의 미완료 항목이다. 아래 성수 4도엽의 기존 적용·재현 기록은 그대로 구분한다.

사전 검사: ZIP 25개 540,518,560바이트, 도엽 참조 3,075개, 고유 도엽 2,488개, 반복 참조 587개. 반복된 같은 도엽의 SHA-256 충돌은 없고 원본/고유 도엽 내부 CRC 검사 통과, 레이어는 121종이다. 선택한 건물·도로경계·교량·등고선·표고점의 PRJ 10,847건은 EPSG:5186이다. 이는 모든 레이어의 CRS·도형 유효성·서울 전역 피복·필드값의 완전성·실측 정확도 통과가 아니다. 상세 검사 파일은 원본 목록에 경로·해시로 결속했다.

`연속수치지형도_데이터_설명서.pdf`의 표제는 「전국 연속수치지형도 코드 및 레이어 설명서」, Version 5.1.1, 작성일 2014-12-30, 153쪽이다. 설명서의 DB 설계를 현재 배포 SHP의 동일 스키마로 가정하지 않는다. 예를 들어 설명서 16쪽 보도는 `N1L_A0033320`이지만 확보 파일에는 면 레이어 `N1A_A0033320`도 있으며, 설명서의 `SCLS`·`FMTA`가 실제 DBF에 있다고 가정할 수 없다. 실제 레이어·도형 종류·필드·코드 값을 대조하고 차이/결측을 기록한다. 설명서 작성일·페이지의 배포 갱신일 2026-03-07·개별 도엽 제작연도는 서로 다르다.

| 역할 | 확보 파일에서 확인한 레이어·필드 | 적용 규칙 |
| --- | --- | --- |
| 건물 | `N1A_B0010000`, 층수·용도·종류·UFID | 면적/옥상 후보의 수평 경계. 층수로 추정한 높이는 표시 가정이며 실측 건물 높이·지붕 경사·하중이 아님. 설명서 42~44쪽과 대조 |

| 도로중심선 | `N1L_A0020000`, 도로폭·차로수·포장재질·일방통행·자동차전용 | 설명서 13~15쪽과 실제 코드/결측 대조. 일방통행 여부만으로 선 좌표의 정/역방향을 확정하지 않음. 그래프 연결/입체 교차 검증 필요 |

전환 시 다음 규칙을 적용한다.

- 원본 ZIP을 보존하고 도엽 ID+해시로 중복을 제거한다. 다른 버전 충돌은 자동 선택하지 않는다. 원본 레코드 ID는 도엽·레이어·레코드 위치·원본 해시에 결속하고 UFID의 공백/중복/도엽 분할을 검사한다. 실제 시설 단위 병합은 대응표·방법·오차를 가진 별도 파생 과정이다. 도형 건수를 고유 건물 수로 표시하지 않는다.
- 원 도형의 구멍·다중 도형·좌표를 보존한다. 보정 전후·도엽 접합부·중복 면적·서울 경계 안 누락을 검사한다. 유효하지 않은 도형은 자동 복구 후 정상 원본으로 표시하지 않는다. 표시 타일/단순화 형상과 계산용 원형상을 같은 식별자로 연결하되 면적·집수 계산에는 원형상을 사용한다.
- 같은 공간 버전으로 건물/도로·시설 선택·설치 면적·집수면·관망/지표 격자 연결을 생성한다. 공유 집수면과 시설 연결은 면적·유량 배분을 한 번만 계산하며 중복 유입을 거부한다. 구 경계는 소속/집계 기준이고 유역·관망·상하류 경계를 절단하는 기준이 아니다.
- 기존 SWMM/ANUGA에 기상청 강우·기상, 토양·피복, 공개 관망/시설·운영, 경계 수위를 출처/시점/단위/수평·수직 기준으로 결속한다. 시설 위치점·지도 분류는 관경·관저고·연결·운전의 증거가 아니다. 확인되지 않은 배수 경로는 연결 모델로 등록하지 않고 직접 강우 탐색 또는 미지원 상태를 표시한다.
- 등고선/표고점·DEM의 한계를 유지한다. 보간·3D 돌출을 실측 지면/지붕으로 사용하지 않고 정밀도를 축척이나 출력 격자 간격에서 추정하지 않는다. 현재 지형과 과거 강우의 조합을 재해 당시 도시 복원으로 설명하지 않는다.
- 새 기본 지도·후보·공개 시설 결속·모델 경로에서 OSM 의존을 제거한다. 수치지형도에 없는 속성은 검증한 공개 보완자료와 별도 출처 또는 미지원으로 처리한다. 기존 OSM 원본/파생물의 출처·라이선스와 수치 재현 근거는 보존하고 신규 수치지형도의 계보에 섞지 않는다.
- 서울 전역 공간 자료 전환, 유역별 입력 연결, 수치 검증, 현장 대조의 완료 상태를 구분한다. 자료가 확보된 한 유역부터 검증한 뒤 동일 계약으로 확장하며 비공개 자료나 기관 협조를 개발의 선결조건으로 두지 않는다.

### 공통 입력 카탈로그

`scripts/prepare_seoul_topography.py`는 등록 원본 전체의 크기·SHA-256을 검사하고 고유 도엽 ZIP을 원 바이트 그대로 한 번씩 보관한다. 같은 ID의 다른 해시, 경로/파일 링크, 정규화·대소문자 중복 이름, 암호화·지원하지 않는 압축 방식, 선언/실제 해제 크기와 전체 크기 제한 위반은 거부한다. 검사 중 원본 변경과 기존 출력 덮어쓰기도 거부하며 실패한 부분 출력은 제거한다.

`catalog.sqlite`의 `tiles`·`tile_sources`·`layers`에는 도엽 해시, 구별 원본 대응, 구성 파일 해시, 원 PRJ, DBF 필드·레코드 수·삭제 표식·인코딩, SHP/SHX 도형 종류·레코드 수·오프셋을 보존한다. 원 레코드 식별은 `ngii:{도엽}:{레이어}:{1부터 시작하는 레코드 번호}:{도엽 SHA-256}`이며 UFID 공백·중복을 고유 자산으로 병합하지 않는다. ZIP 안의 도형·구멍·다중 도형·속성 바이트는 수정하지 않는다. 미분류·결측·알 수 없는 속성값을 정상 코드나 0으로 치환하지 않는다.

모든 레이어의 데이텀·투영 매개변수·미터 단위를 EPSG:5186과 대조한다. ESRI WKT의 각도 단위 반올림을 허용하되 원 PRJ와 저장 좌표 순서 `x=easting,y=northing`을 보존한다. 문자셋은 명시적 CP949 엄격 해독이며 CPG의 원 선언도 보존한다. 일부 `EUC-KR` 선언에 CP949 확장 문자가 있는 차이는 레이어·행 수로 기록하고 대체 문자로 바꾸지 않는다. 원 DBF 값의 의미·설명서 코드 대조는 별도 미완료 항목이다.

```sh
simulation/.venv/bin/python scripts/prepare_seoul_topography.py
```

기본 출력은 `data/private/vworld-seoul-topography-20260307/catalog-v1/`이고 `summary.json`은 모든 검사가 끝난 뒤 생성한다. 다른 빈 출력 경로를 `--output`으로 지정해 재생성할 수 있다. [공개 검사 요약](../data/manifests/seoul-topography-catalog-v1.json)은 원본 목록·생성기·SQLite 해시와 집계·도구 버전만 포함한다. 원본/카탈로그/좌표는 Git 제외 경로에 보관한다. 이 단계의 통과는 압축·구성·좌표계·문자셋 검사이며 도형 유효성·접합·서울 피복·현장 정확도·서비스 전환 검증이 아니다.

구성 검사 근거: [Esri SHP/SHX 기술 설명](https://www.esri.com/library/whitepapers/pdfs/shapefile.pdf), [GDAL Shapefile 문자셋](https://gdal.org/en/stable/drivers/vector/shapefile.html), [Python ZIP 해제 제한](https://docs.python.org/3.13/library/zipfile.html#decompression-pitfalls).

### 원 레코드 공간 카탈로그

`scripts/prepare_seoul_spatial.py`는 위 입력 카탈로그에서 모든 원 레코드의 도형·속성·출처를 `spatial.sqlite`로 정규화한다. 원 식별자와 SHP 레코드·DBF 행의 해시를 보존하고 유효 도형의 원 좌표 WKB·미터 면적/길이·부분 대응을 저장한다. 링을 자동으로 닫거나 방향을 뒤집거나 `make_valid`로 복구하지 않는다. 구멍은 ESRI의 시계 방향 외곽·반시계 방향 내부 링 규칙과 유일한 포함 관계가 확인될 때만 연결한다. 해석할 수 없는 링·자기교차·퇴화 선은 원본 대응과 오류 상태를 보존하고 계산용 면적을 부여하지 않는다.

R-tree는 범위 후보 검색에만 사용하며 조회 결과는 원 WKB의 실제 교차로 다시 검사한다. 완성 파일에 인덱스 통계를 저장하고 조회는 범위 검색부터 수행한다. 지도 절단·단순화·공간 인덱스의 부동소수점 범위를 설치/집수 면적으로 사용하지 않는다. 동일한 조회 객체에 원 식별·형상·면적·속성·축척·공간 카탈로그 해시를 반환한다. 구 경계 병합·도엽 접합·후보 생성·모델 편입은 이 단계에 포함되지 않는다.

[레이어 해석 계약](../data/manifests/seoul-topography-semantics-v1.json)에 설명서 해시·페이지, 실제 121종 레이어의 이름/도형/축척 대조, 필드표와 게임 관련 12개 코드군을 결속했다. 실제 레이어의 110종은 목록과 일치하고 8종은 해당 축척이 목록에 없으며, 2종은 공간형태가 다르고 1종은 목록에 없다. N3는 1:5,000 자료로 구분하며 N1의 1:1,000으로 표시하거나 도형을 합치지 않는다. 실제 보도 면 `N1A_A0033320`과 목록에 없는 선 `N1L_A0033330`을 같은 객체로 간주하지 않는다.

코드 또는 설명서의 유일한 정확한 명칭만 해석한다. 결측·미분류·기타·미등록 값·설명서의 축척 범위 밖 값을 구분하고 알려진 코드로 대체하지 않는다. 복합 용도·미등재 포장 재료도 원문 그대로 보존한다. 다른 레이어의 중심선 속성을 도로 면 전체에 복사하지 않으며 일방통행 여부에서 선의 정/역방향을 결정하지 않는다. 원 수치 속성의 값/범위와 미확인 단위는 분리하므로 표고 수치로 지형·수직 기준·미세 경사를 생성하지 않는다. 나머지 코드군 해석과 설치 적합성 검증은 미완료 상태다.

```sh
simulation/.venv/bin/python scripts/prepare_seoul_spatial.py
simulation/.venv/bin/python scripts/verify_seoul_spatial.py \
  --output data/private/vworld-seoul-topography-20260307/gdal-spatial-v1.json
```

기본 공간 출력은 `data/private/vworld-seoul-topography-20260307/spatial-v1/`이다. 기존 출력 덮어쓰기·입력 해시 불일치를 거부한다. 공간 카탈로그·원 값 프로필·상세 진단은 Git 제외이며 [공개 공간 검사 요약](../data/manifests/seoul-spatial-catalog-v1.json)에 집계·원본/코드/산출물 해시·실행 도구 버전과 독립 GDAL 대조 결과만 보존한다. 검사 통과를 서울 전역 피복·도엽 접합·현장 정확도·게임 지도 전환 완료로 표시하지 않는다.

## 수치지형도 플레이 모델 연결

2026-03-07 갱신 공개 수치지형도와 동일한 기존 4개 도엽의 건물 246개와 도로·철도·교량 면 경계를 별도 지도에 연결한다. 원 도엽의 제작연도는 2025년이며 배포 갱신일과 구분한다. EPSG:5186 원문 좌표에서 고정 원점을 뺀 미터 좌표를 사용하며 내부 구멍·복수 도형을 보존한다. 교통 면은 화면 경계로 절단하되 건물 원형은 보존한다. 층수×3.2m 및 층수 누락 시 9m는 시각화 가정으로만 사용한다. 평탄 지면 유지, 교량의 실제 고도·도로 경사 추정 금지.

## DEM 적용 제한

현재 파일은 90m 격자이며 실험 구역은 약 0.3km 블록. 영역과 교차하는 원본 셀 수·유효 값·범위 및 두 연도 동일 격자에서 값 차이 확인. 유효 표고가 있어도 수직 기준과 취득/제작 이력 확인 전 정확한 현장 높이·도로 경사로 승인하지 않음. 두 파일의 차이를 실제 지형 변화로 단정하지 않음.

미세 배수 경사·우수받이·도로 턱·관망 연결·침수 깊이는 90m 자료로 복원할 수 없음. 보간한 조밀한 격자도 원자료 90m와 가정 표기 유지. 확보한 서울 25개 구 1:1,000 수치지형도의 등고선/표고점·건물·도로를 먼저 검사하고 공개 관망의 연결 적합성을 검토한다. 추가 공개자료가 꼭 필요한 항목만 [자료 현황](13-data-access.md)에 모으며 확보 자료를 재요청하지 않는다.

## 토지피복 적용 제한

원문 CRS에서 전체 유효성·중복·결측 검사 후 명시한 변환으로 실험 경계를 대조. 원도형을 자동 복구하지 않고 잘못된 도형의 위치/수·영향 범위 보고. 실험 경계와 교차하는 도형의 L3별 면적, 합/합집합/중복/미피복 면적을 별도로 계산. 단위는 투영 좌표의 m², bbox를 실제 배수 유역으로 간주하지 않음.

영상 날짜는 개별 필드·도엽 XML·XLSX의 범위를 구분. 전국 메타데이터의 0.25m 영상 해상도는 피복 경계의 측량 정확도나 DEM 해상도가 아님. 공업/상업/도로 등 토지 이용 분류를 불투수율 100%·침투율·설치 가능 면적의 실측값으로 변환하지 않음. 기존 OSM 건물/설치 후보와 충돌하면 출처/시기/분류 차이를 공개하고 추가 확인.

원본 이용조건·출처 표시·파생물 재배포 범위, 공간/시간 정합과 사용 목적에 맞는 정밀도 확인 후 별도 모델 버전 생성. 모델·시설 가능 면적/토양/관망 등 연관 입력 변경과 기본안·민감도·수지·재현을 함께 검증. 원자료 확보만으로 보정/독립 사상 검증·현장 적용 가능 등급을 부여하지 않음. 기관 보고서와 화면은 공개자료·계산·가정·미확인을 구분.

## 자기교차 도형 진단 계약

원본 검사와 별도 명령으로 `make_valid`의 `linework`·`structure` 두 보정 후보를 비교. 원본 ZIP 검증 후 임시 디렉터리에서 계산하며 원본/기존 검사 보고서/모델은 덮어쓰지 않음. 원도형을 수정한 파생 데이터는 공개하지 않고 로컬 진단 보고서만 생성. [Shapely 공식 문서](https://shapely.readthedocs.io/en/stable/reference/shapely.make_valid.html)에 따라 전자는 선분과 꼭짓점 보존, 후자는 외곽/내부 링의 분류가 맞다는 가정에 기반. 두 방식의 일치도 현장 경계의 정확성 증명은 아님.

- 각 오류 도형의 원본 순번·속성 hash·원도형 WKB hash·오류 이유 기록. 후보의 WKB hash·유형·면적·꼭짓점 수와 비면적 선/점 성분을 별도 기록. 단순 `buffer(0)`·반올림·격자 스냅 없음.
- 면적 성분만으로 대상 구역 교차를 계산하되 선/점 성분의 수·길이는 버리지 않고 보고. 두 방식의 대상 구역 내 대칭차 면적과 각 분류별 합/합집합/중복·전체 빈 영역 비교. 오류 원도형의 수치 면적은 참고값이며 실측 기준으로 사용하지 않음.
- 원래 유효한 도형과 속성은 동일하게 보존. 보정 후 빈 도형·비면적 성분·방법 간 불일치·전체 중복/빈 영역은 검토 대상으로 유지. `modelEligible=false`, `calibrationEligible=false`, `DIAGNOSTIC_ONLY` 고정.
- 공개 보고는 원본/코드/로컬 결과 hash와 요약 수치만 포함. 기존 EXPLORATORY 모델과 랭킹은 불변. 최종 후보 채택은 이용조건·현장/영상 대조·좌표/시기 정합 검토 이후 별도 계약.

2026-10-17 [EGIS 저작권 정책](https://aid.mcee.go.kr/bbs/copyright.do) 확인. 정책은 자료별 공공누리 표시 확인과 출처 표시를 요구. 제공 XML에는 저작권자 `환경부`가 있으나 이 ZIP에 적용되는 공공누리 유형은 아직 확인되지 않음. 사이트 전체 정책을 개별 원본/파생 좌표의 무제한 재배포 허가로 취급하지 않음. 현재 GitHub에는 원자료/파생 좌표를 제외한 코드·검사 요약만 저장.

## 두 보정 후보 진단 결과

`scripts/diagnose_landcover_topology.py`의 GEOS 3.14.1 `linework`/`structure`, `keep_collapsed=true` 적용. 오류 4개 모두 유효 Polygon 후보가 되었으며 선/점 퇴화 성분 없음. 유효 원도형 12,326개·전체 속성 원문은 그대로 유지. 두 방식은 WKB의 순서/방향에 따른 hash는 다르지만 4개 후보 각각의 면적 도형이 같고 전체/대상 구역 대칭차 면적 0m². 이는 경계의 현장 정확성 승인과 별개.

진단 구현 결과: 전체 표고점 12개 중 연구 경계 내부 1개, 등고선 전체 5개 중 경계 교차 0개, 최근접 등고선 약 267.37m. 원본 점의 볼록껍질은 현재 13개 후보 중심을 포함하나 지형 정확도 근거는 아님. `scripts/audit_terrain_support.py`의 실제 원본 반복 결과 일치, 합성 평면·격자·누락·형식·공개 요약 검사 7개 통과. 모델 반영과 자료 화면 연결은 미완료.


## DEM 삼각형별 토양·피복 면적 연결

`prepare_surface_coverage.py`는 원본 2025 DEM 288삼각형(1,166,400m²)에 보관 공개 심토토성 8,266개와 2024판 피복 12,330개 도형을 연결. CRS를 덮어쓰지 않고 PROJ의 비근사 변환을 사용하되 두 연산의 정확도 값 -1(미확인)·좌표 epoch 미확인을 보존. 원본 꼭짓점 변환 후 직선 연결이며 변환 정확도를 현장 측량 정확도로 표시하지 않음. [PROJ/pyproj 변환 정의](https://pyproj4.github.io/pyproj/stable/api/transformer.html), [Shapely 좌표 변환](https://shapely.readthedocs.io/en/stable/reference/shapely.transform.html), [공간 교차 인덱스](https://shapely.readthedocs.io/en/stable/strtree.html) 기준 적용.

미수정 원본의 내부 구멍·다중 도형 유지, 경계 접촉 면적 0 제외. 동일 분류라도 양의 면적 중첩은 중복 영역으로 제외하며 원본 순번/ID 보존. 오류 도형은 복구하지 않고 변환 후 envelope의 영향 가능 범위를 기록. 정상 도형이 그 범위를 덮더라도 독점 배정으로 확정하지 않음. 모든 작은 양의 면적을 원값으로 남기므로 수치 반올림 크기의 조각이 실제 필지의 존재를 뜻하지 않음. 미피복·중복·오류 영향 지표는 서로 겹칠 수 있으며 단순 합산 금지.

실제 결과: 토양 원본 유효 8,244개/오류 22개, 연구 창에 오류 영향 없음. 토양 정상 합집합 1,166,399.895518m², 미피복 0.104482m². 피복 원본 유효 12,326개/오류 4개, 정상 합집합 521,876.227649m². 오류 도형 envelope의 영향 가능 면적 971,055.047457m²를 보수적으로 제외한 피복/토양 공동 배정은 17,071.676395m². 이는 실제 피복 자료가 나머지 지역에 없다는 뜻이 아니며, 오류 도형 전체를 아직 채택하지 않은 판정 결과. 앞선 두 복구 후보의 일치 진단도 원본 검증 등급으로 자동 승격하지 않음.

상세 원본·좌표·변환·배정은 `data/runs/surface-coverage-20261018-v2/`에 보존, 공개 요약은 `data/benchmarks/surface-coverage-v1.json`. 실제 포장률·표면 다짐·수분 근거가 없으면 공간 교차 결과를 침투 입력으로 자동 전환하지 않음. 명시적 재료/토양 매개변수와 전체 공간 분류가 충족된 경우만 침투 v2로 변환. 미분류를 불투수로 채우거나 확인된 조각만 잘라 유역 계산하지 않음. 원본 이용조건 미확정 자료의 좌표·속성 전체는 GitHub에 배포하지 않음.


## 명시적 파생 도형과 도시생태 표면 구성

원본 감사와 분리한 탐색용 파생 정책 `EXPLICIT_TWO_METHOD_AREA_CONSENSUS_v1` 추가. 원본 투영 좌표에서 `linework`·`structure` 양쪽이 유효한 Polygon/MultiPolygon이고, 선/점 퇴화 성분이 없고, 면적 도형이 위상적으로 같은 경우에만 파생 도형 생성. 정점 순서 정규화 외 스냅/반올림/buffer 처리 없음. 불일치·퇴화는 오류 상태 유지. 원본과 파생 입력의 배정을 각각 보존하며 이 채택은 현장/영상 정확도 검증이나 운영 모델 승인과 구분. 원본·기존 결과/순위 불변.

불투수율의 직접 근거로 서울도시공간포털 자료실의 2025·2020·2010 도시생태현황도와 2025 최종보고서 추가 확보. 공개 첨부파일은 키·사용자 로그인 없이 수신 가능. 원본 ZIP/PDF와 메타자료를 프로젝트에 보관하고 파일별 URL·크기·SHA-256을 `data/manifests/seoul-biotope-20261018.json`에 기록. 2025 원본의 조사 블록은 42,544개이며 고유번호 중복 72건을 삭제/병합하지 않고 원문 순번으로 구분. 원본 값과 모순·범례 차이를 분리하고 전체 면적을 자동 정규화하지 않음.

`prepare_seoul_biotope.py`는 원본 WKT(EPSG:5174로 식별)에서 대상 DEM 원문 좌표계로 변환, 삼각형과 조사 블록의 교차 면적으로 건물·불투수포장·투수포장·녹지·나지의 면적을 배정. 변환 후 새로 발생한 도형 오류도 원본 오류와 함께 제외하고 임의 복구하지 않음. 원본 블록 내부 균질 배정은 명시적 근사이며 실제 포장 위치 분포와 다름. 숫자 불일치·겹침·미피복 면적을 미해결로 남기며 물리 입력 전체 완성을 주장하지 않음. 투수포장 제원·수면/습지·조사불가능지의 추가 물리 조건을 원지반 침투 후보와 구분. 2010/2020의 필드 이름이 같아도 2025 조사의 세부 방식·정확도·사건 당일 유효성을 소급 적용하지 않음.
