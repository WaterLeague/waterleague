# 공개자료 확보·접근 현황

기준일: 2026-10-20. 기존 키·원본을 활용하며 현재 구현에 새로 발급해야 할 필수 키는 없다. 자료 취득과 모델 입력 적합성은 별개다. 추가 공개 파일/API 권한이 꼭 필요할 때만 서비스·신청 링크·용도·환경변수·확인한 오류를 이 문서에 모아 안내한다. 확보 항목을 재요청하거나 기관 협조·비공개 자료를 구현 조건으로 추가하지 않는다.

## 외부 호출·이용 경계

브라우저에는 외부 인증키를 전달하지 않는다. 고정 지도/설치/과거 기상은 해시 검증한 저장 자료를 제공한다. 주간 KMA 관측과 서울 현재 도시자료는 서버의 제한된 실시간 조회 경로를 사용한다. `.env.local`의 기존 키를 보존하고 프론트/계산 자식 프로세스에 전달하지 않는다.

서울 현재 인구/도로는 공식 HTTPS `SeoulRtd` 공개 화면의 고정 서비스만 조회한다. 현재 경로에는 `SEOUL_OPEN_DATA_KEY`가 필요하지 않으며 이미 설정한 키를 다시 요청하지 않는다. 비암호화 HTTP에 키를 보내지 않는다. HTML·과거/예보·잘못된 시각/장소·만료 값은 현재 관측으로 사용하지 않는다.

브이월드 토양 `LT_C_ASITSOILDRA`, `LT_C_ASITSOILDEP`, `LT_C_ASITDEEPSOIL`은 2026-10-16 고정 성수 영역 조회에 성공했고 `LT_C_GIMSSCS` 미반환은 모든 토양자료 부재를 뜻하지 않는다. 점검 당시 약관의 저장/가공/제공 제한 때문에 원 도형·속성·인증 URL은 보관하지 않고 상태·건수·필드명만 기록했다. 배수등급/토성/토심은 실측 수리전도도가 아니다. 허용된 공개 원본과 문헌 근거를 우선하며 비공개 원본 분양·기관 공문을 필수 작업으로 만들지 않는다.

재해 3사건의 강우 원문 WD1·WS1은 물결 표현에 재사용한다. 한강 수위·유량 관측만으로 공간 유속 벡터를 만들지 않는다. 자연 하천의 실제 흐름은 단면·기준고·모델 연결이 확인된 범위만 계산할 수 있으며, 광학/기상 물결 구현은 이와 별개다.

옥상 상세설계 CODIL 공개 PDF는 2026-10-19 조회 당시 503으로 미확보였다. 검색 발췌를 확보 원본이나 서울 개별 지붕의 하중·경사·배수구 자료로 취급하지 않는다. 이는 전체 기능 개발을 중단할 조건이 아니며 [이용시설·적합성 계획](09-delivery.md)에 미확인 조건을 남긴다.

## 연결 유역의 입력 점검

첫 연결 유역은 공개자료 가용성으로 선정하며 임의 지도 사각형을 배수경계로 대체하지 않는다. 유역 밖 유입/하류 경계도 포함한다.

- 지형·피복: 수평/수직 기준·해상도·취득일·지표면 여부·배수 지형 적합성·불투수면/지붕 연결
- 관망: 맨홀/관로 연결·좌표·지표고/관저고·단면·길이·거칠기·유입구/토구·펌프 제원과 경계 수위
- 토양·시설: 토성·토심·지하수·다짐·시설 단면·집수/넘침·초기 상태·공개 제원/비용/관리 근거
- 검증: 출구와 연결된 유량 또는 근거 있는 수위 환산, 동시 강우·시각/단위·결측·보정/검증 구간 분리

위 목록은 공개자료 적합성 점검 항목이며 사용자에게 비공개 자료를 모두 구해 달라는 요청이 아니다. 일부가 없으면 지원 범위·가정을 명시하고 가능한 구현을 계속한다.
