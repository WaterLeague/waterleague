# 성수 공간 원자료 품질 검사·적용 계약

2026-10-17. 사용자 제공 원본 3건(문서 21) 검사를 먼저 수행한 뒤 모델 적용 여부 결정. 원본 취득·정합·현장 검증은 별도 단계. 운영 강우/모델/기존 점수 불변, EXPLORATORY 유지.

## 검사 입력과 산출물

- 대상 경계: 기존 성수 모델의 EPSG:4326 `[127.0525,37.5430,127.0555,37.5455]`. 기존 모델 원문 hash와 함께 검사 기록.
- 원본 ZIP의 전체 hash·CRC·크기·각 구성 파일 hash 보존. 절대/상위 경로·링크·중복/암호화·과도한 압축 크기 거부. 기존 원본 덮어쓰기 금지.
- 공식 DEM 2024/2025 원문 WKT·geotransform·크기·밴드 유형·NoData·메타데이터·유효 범위 기록. 재투영/보간 전 원본 격자 값을 검사.
- 토지피복 원문 PRJ·DBF 필드/문자셋·XML 제작/원영상 설명·IMG_DATE·L1/L2/L3 코드/도형 유효성 검사. 표본을 원자료 해상도/현장 측정으로 대체하지 않음.
- 사용 도구 버전·변환 방향/축 순서·accuracy/ballpark 여부 기록. 원문 datum·epoch·수직 기준 부족을 EPSG 추정으로 숨기지 않음.
- 산출물은 로컬 검사 JSON·도엽/실험 구역 통계. 원본과 파생 좌표는 이용조건 확인 전 비공개 경로. 공개 문서에는 출처·해시·검사 방법·허용 범위·누락 근거만 기록.

## DEM 적용 제한

현재 파일은 90m 격자이며 실험 구역은 약 0.3km 블록. 영역과 교차하는 원본 셀 수·유효 값·범위 및 두 연도 동일 격자에서 값 차이 확인. 유효 표고가 있어도 수직 기준과 취득/제작 이력 확인 전 정확한 현장 높이·도로 경사로 승인하지 않음. 두 파일의 차이를 실제 지형 변화로 단정하지 않음.

미세 배수 경사·우수받이·도로 턱·관망 연결·침수 깊이는 90m 자료로 복원할 수 없음. 보간한 조밀한 격자도 원자료 90m와 가정 표기 유지. 필요 시 성수 1:1,000 수치지형도 원본의 등고선/표고점·건물·도로와 배수 관망 요청 범위를 검토, 필요한 자료를 묶어서 사용자에게 안내.

## 토지피복 적용 제한

원문 CRS에서 전체 유효성·중복·결측 검사 후 명시한 변환으로 실험 경계를 대조. 원도형을 자동 복구하지 않고 잘못된 도형의 위치/수·영향 범위 보고. 실험 경계와 교차하는 도형의 L3별 면적, 합/합집합/중복/미피복 면적을 별도로 계산. 단위는 투영 좌표의 m², bbox를 실제 배수 유역으로 간주하지 않음.

영상 날짜는 개별 필드·도엽 XML·XLSX의 범위를 구분. 전국 메타데이터의 0.25m 영상 해상도는 피복 경계의 측량 정확도나 DEM 해상도가 아님. 공업/상업/도로 등 토지 이용 분류를 불투수율 100%·침투율·설치 가능 면적의 실측값으로 변환하지 않음. 기존 OSM 건물/설치 후보와 충돌하면 출처/시기/분류 차이를 공개하고 추가 확인.

## 모델 편입 조건

원본 이용조건·출처 표시·파생물 재배포 범위, 공간/시간 정합과 사용 목적에 맞는 정밀도 확인 후 별도 모델 버전 생성. 모델·시설 가능 면적/토양/관망 등 연관 입력 변경과 기본안·민감도·수지·재현을 함께 검증. 원자료 확보만으로 보정/독립 사상 검증·현장 적용 가능 등급을 부여하지 않음. 기관 보고서와 화면은 공개자료·계산·가정·미확인을 구분.
