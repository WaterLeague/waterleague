# 설계 배치 되돌리기·다시 실행

2026-10-16. 3D·UX 계약의 undo/redo 구현. 배치 추가·면적/시설 변경·제거를 단일 이력으로 관리하며 최근 50번의 실제 변경 보관. 동일 배치 재적용은 이력에 추가하지 않음.

되돌리기는 이전 배치를 복원하고 현재 배치를 다시 실행 목록으로 이동. 다시 실행은 반대 방향으로 이동. 되돌린 상태에서 새로 수정하면 이전 분기의 다시 실행 목록 폐기. 배열과 배치 객체의 참조 공유로 과거 이력이 바뀌지 않도록 복제. 여러 동작이 같은 렌더 주기에 발생해도 순서대로 처리하는 reducer 사용.

새 설계·저장본 열기·강우/리그 모델 전환에서 이력을 초기화. 호환 강우로 배치를 복사할 때 현재 배치는 유지하고 이력만 제거. 기준안 복사에서 새 설계 초기화 직후 첫 배치 적용이 이전 설계를 이력에 포함하지 않도록 확인. 제목·메모·서버 저장 버전·완료 계산·제출 점수는 배치 이력 조작으로 변경하지 않음.

지도 도구에 되돌리기·다시 실행 버튼과 접근성 이름 제공. 버튼은 처리 가능한 이력이 없거나 저장/불러오기 중일 때 비활성. 지도 영역에 포커스가 있을 때 Ctrl/Command+Z, Shift+Ctrl/Command+Z 및 Ctrl+Y 제공. 입력·텍스트 영역·편집 가능한 요소에서는 브라우저의 텍스트 편집 동작 유지. 화면 이력은 서버 연구 원장의 대체물이 아니며 저장 시 서버가 전체 배치 변경을 검증·기록.

검증: 여러 단계 왕복·새 수정 분기·동일 배치 no-op·50개 한도·객체 변경 격리·초기화 직후 변경 순서, 브라우저 배치/면적/비용·지도 표시 왕복, 키보드 조작과 작은 화면 도구 표시. 기존 완료 계산·순위는 이 시험에서 생성하거나 수정하지 않음.
