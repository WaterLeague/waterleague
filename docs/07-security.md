# 보안·권한

인증·인가·입력·격리·공급망·운영의 검증 가능한 통제 적용. 완전한 보안이라는 선언보다 테스트·운영 증거로 관리.

## 인증·요청

서버 세션·프레임워크 사용. 운영 쿠키 __Host- 접두사, Secure·HttpOnly·SameSite=Lax·Path=/·Domain 미설정. 로그인·권한 변경 시 세션 회전, 유휴·절대 만료, 서버 로그아웃. 토큰 localStorage 저장 금지. [OWASP 세션 지침](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html) 참고.

Argon2id 최소 m=19MiB·t=2·p=1에서 성능 측정·상향. 비밀번호 길이 8~128자(2026-10-17 사용자 요청: 최소 8자). 회원가입 폼의 비밀번호 확인란 필수·불일치 제출 차단, 확인값의 서버 전송·저장 없음. 인증 실패 메시지 일반화, 가입·로그인·복구 rate limit. 이메일 검증·재설정·유출 비밀번호 검사와 실제 운영 인증 흐름은 공개 운영 전 검증 항목이다. 관리자·조직 회원의 TOTP는 구현된 아래 경로를 사용한다. [OWASP 비밀번호 지침](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html) 참고.

기관 인증 구현: [RFC 6238](https://www.rfc-editor.org/rfc/rfc6238) TOTP 6자리·30초·인접 1구간 허용, 사용 카운터 조건부 갱신으로 재사용 거부. 기관별 비밀은 계정 ID를 AAD로 한 AES-256-GCM 암호화 저장, `MFA_ENCRYPTION_KEY`는 DB와 분리. 키 부재 시 등록/인증을 거부한다. 승인된 관리자·조직 회원은 비밀번호·CSRF·요청 제한을 검사한 임시 등록 세션에서 직접 인증 앱을 연결하고 OTP 검증 후 업무 세션을 받는다. 기존 비밀의 조회/덮어쓰기와 등록 전 업무 접근은 금지한다. 공개 가입으로 역할·조직 ID·승인 상태를 주입할 수 없으며 운영자가 회원 OTP 비밀을 받아 등록하는 절차는 사용하지 않는다. 기관 MFA는 피싱 저항성을 제공하지 않으므로 운영 IdP/WebAuthn 도입 전 위험 검토 필요.

로그인 세션 절대 만료 8시간, 유휴 만료 30분. 매 요청 계정 활성 상태·현재 역할·기관 MFA 확인. 권한 변경·재등록 시 기존 세션 삭제. JSON 본문 64 KiB 상한, 전역 작업 입장 잠금으로 큐 상한 경합 차단.

상태 변경 CSRF 검사, SameSite만으로 대체 금지. 동일 출처 기본, wildcard CORS+credentials 금지. HTTPS·운영 HSTS·CSP·frame-ancestors none·nosniff·Referrer-Policy. 개발 HMR 예외를 운영에 복사 금지. DTO 검증·과대 본문·unknown field·비유한 수 거부, 매개변수 쿼리·sort allowlist, HTML 원문 렌더링 금지.

## 객체 권한

소유자·기관 소속·대회/연구 리그 소유·동의 범위 매 요청 검증. URL ID나 클라이언트 role 불신. 가입은 MEMBER 역할 고정. PLAYER는 즉시 승인, BUSINESS·INSTITUTION·GOVERNMENT는 관리자 승인 전 이용 차단. ADMIN은 DB 유일 제약으로 한 계정만 허용하며 조직 회원과 분리. 회원의 모델 승인·플랫폼 권한 부여 금지. 권한 철회 시 세션·캐시 무효화. export 다운로드에도 동의 재검사.

사업 활용 검토는 계산·기관·목적 hash와 정책 버전에 묶인 별도 소유자 동의. 요청 상태와 결정 이벤트 원자적 저장, 예상 revision·내용 hash 불일치 거부. 연구 동의를 철회해도 별도로 승인한 사업 동의는 유지되므로 각 활성 동의를 별도 API로 조회·철회한다. 구형 동의 관리 화면은 제거했으며 이를 현재 메뉴로 안내하지 않는다. [상태·검증 계약](16-utilization-consent.md) 참조.

## 대회·관리자 결과 경계

대회 생성은 승인된 조직 회원과 MFA·현재 조직을 서버에서 확인한다. 참가와 재해 제출은 PLAYER 본인만 가능하고 실시간 참가의 소속 구·설치 시각, 재해 전체 배치의 구·시설·점수 정책을 재검사한다. 공개 후 규칙은 불변이고 요청 UUID의 다른 본문 재사용을 거부한다. 취소는 주최 조직 또는 ADMIN이 마감 전에만 수행한다.

결과는 참가자·승인된 주최 조직·ADMIN에게만 제공한다. 관리자 시즌/사건 조회는 매 요청 역할·MFA를 확인한다. 대회 참가·주최·관리자 결과 권한은 연구 원본·사업 활용 동의를 대신하지 않는다. 순위와 공개 닉네임·주간 설치 시각 등 허용된 요약만 제공하며 결과 응답은 `no-store`다. 계산 대기·조건 불일치는 확정 결과와 분리한다.

## 계산·수집

외부 INP·Python·셸·임의 URL 실행 금지. 승인된 모델, 서버 생성 UUID 경로. 워커 비root·read-only rootfs·작업 임시 공간·CPU/메모리/시간/결과크기 제한, 자식 process group 종료. lease·재시도 상한·fencing token·해시 검증. 사용자 쿼터·큐 상한·역압·중복 캐시.

주간·재해·개인/연구 후보·관망·공개 지표 계산은 공통 프로세스 실행 경로를 사용한다. 시간 초과, 작업 임대 갱신 오류, 워커 종료 신호 때 자식 프로세스 그룹을 종료·회수한다. DB 임대는 행 잠금을 획득한 뒤 현재 시각·소유 토큰·상태를 다시 검사하며 잠금 대기 중 만료된 작업을 갱신하지 않는다. 완료 게시에도 같은 만료 검사를 유지한다. 개인/연구 후보·주간·재해·관망의 결과 JSON은 일반 파일만 최대 64MiB·중첩 128단계로 읽고 심볼릭 링크·중복 키·비유한 수·잘못된 UTF-8을 거부한다. 손상된 결과는 해당 작업 실패로 처리한다.

데이터 수집 allowlist·TLS·크기·timeout·구조 검사. export 경로 순회·CSV formula injection·민감 필드 검사.

## 검증

다른 사용자 전략, 다른 기관 자료, 철회 후 접근, 역할 주입 가입, CSRF 누락, 경로 순회, 초과 배치·예산·NaN, 제출 한도 경합, 멱등키 충돌, 만료 워커, 미승인 모델 공식 제출 검사. 정상 흐름만으로 보안 완료 판정 금지.

현재 서버 경계의 집중 검증은 `simulation/.venv/bin/python scripts/verify_league_postgres.py --suite security`로 실행한다. 별도 PostgreSQL에서 Java 64개, 공통 큐 통합 10개, 실제 프로세스/결과 입력 8개를 검사한다. [2026-10-21 검증 근거](../data/benchmarks/security-boundaries-v1.json)에 선택한 시험·소스/로그 해시와 적용 범위를 보존한다.

가입 권한 검사는 정상 입력에 `role`·`organizationId`·`approvalStatus`를 각각 추가해 400과 계정 미생성을 확인하며, 추가 필드 없는 같은 입력은 MEMBER·기관 미소속으로 생성되는지 대조한다. 필수 입력 누락으로 인한 거부와 혼동하지 않도록 보강한 뒤 `--suite account`의 가입/MFA 3개를 추가 통과했다. 전체 64개 실행과 이 후속 실행의 근거·소스 해시는 구분한다.

권한 판단 일부는 격리 DB의 시험 전용 결과를 사용한다. 공통 큐의 실제 SWMM 계산·캐시 재사용과 각 재현 파일 18개의 해시는 별도로 대조했다. 이 통과 범위는 현재 서버 경계이며 미구현 시설/유역, 전체 브라우저 흐름, 현장 수문 정확도, 대상 기기 성능과 공개 배포 검증을 대신하지 않는다.

2026-10-19 게스트 결과 경계: 최종 점수 잠금은 화면뿐 아니라 서버 응답에도 적용. 개별 조회·목록·동일 요청 재응답에서 전체 기간 합계·최종 구간·시설별 전체 기간 비교 제거. 게스트 세션 소유권·CSRF·입장 제한·회원 주간 설치 차단 유지. 원 계산과 재현 자료는 변경하지 않음.

## 도시 공개 화면 수집 (2026-10-19)

서버 고정 `https://data.seoul.go.kr/SeoulRtd/` 호스트와 두 서비스 이름만 사용한다. 브라우저는 자체 API만 호출하며 외부 인증키·사용자 쿠키를 전송하지 않는다. 일반 공개 페이지 Referer를 사용하되 TLS 인증서 검증·리디렉션 차단·Content-Type·크기·타임아웃을 유지한다. 입력 장소는 프로젝트에 고정한 카탈로그 해시로 검증한 이름으로 변환하며 사용자 URL/장소명을 외부 주소에 직접 연결하지 않는다. 원문 HTML·예보/과거 값·잘못된 시각·비유한 값·장소 불일치는 현재 관측으로 승격하지 않는다. `.env.local`의 `SEOUL_OPEN_DATA_KEY`는 프론트/워커 프로세스 상속에서 제거하며 이번 공개 HTTPS 경로는 키를 사용하지 않는다. 비암호화 HTTP API에 키를 보내는 대체 경로 없음.

## 회원 승인과 관리자 경계

역할은 ADMIN/MEMBER, 회원 유형은 PLAYER/BUSINESS/INSTITUTION/GOVERNMENT다. 단일 관리자는 DB 유일 제약과 비공개 초기화 명령으로 생성한다. 공개 가입·관리 API로 추가 관리자를 만들거나 관리자 자신의 권한/정지를 변경할 수 없다.

PLAYER는 즉시 승인한다. 조직 회원은 PENDING으로 접수하며 관리자가 소속·이용 목적을 검토해 APPROVED/REJECTED/SUSPENDED 상태와 사유를 기록한다. 가입 시 조직명만 같다고 기존 조직에 자동 편입하지 않는다. 조직 승인 전 업무 세션을 발급하지 않으며, 승인된 조직/유형은 일반 회원이 변경하지 못한다. 승인/정지·MFA 재등록 시 기존 세션을 폐기한다. 관리자는 계정 운영 권한만으로 연구 자료를 열람하지 못한다.

배포 권한 목록은 마이그레이션의 전체 테이블과 자동 대조하며 불일치 시 배포를 중단한다. 기존 워커 역할은 유역 계산 큐의 상태·lease·결과, 주간 평가 초, 재해 제출의 계산 차이에 필요한 열 권한만 갖는다. 회원·예산 원장·저장 설계 원문 열람, 배치·규칙·입력 hash 변경은 허용하지 않는다. **2026-10-21 점검에서 V33 대회 4개 테이블이 `deploy/database.py`의 허용 목록·역할 권한에 누락된 것을 확인했다.** 현재 대회 로컬 통합 시험을 배포 역할 분리 검증으로 해석하지 않는다. 권한 목록 갱신과 허용/거부 SQL·컨테이너 검증이 남아 있으며 [운영 상태](10-operations.md#대회-배포-상태--2026-10-21)에 기록한다.
