## 완료 조건

- D1: 도메인 레이어·공통 예외·타입·빌드·검증 미달 모델 거부·자동 검사.
- D2: 합법적 실제 자료·단위·CRS·시간·누락 검증, 배수·관측 가용성에 따른 부지 확정.
- D3: SWMM 기준/전략 실행·원본 보존·물수지·참조·해상도 민감도·등급 검토.
- D4: 실제 3D·3종 배치·면적·예산·undo·출처·키보드·2D 대안.
- D5: 세션·CSRF·소유권·불변 이력·작업 lease·timeout·재시작 영속.
- D6: 승인 모델·강우·규칙 고정, 원자적 한도·동점·공개 범위·기관 소유.
- D7: 동의 철회·기관 격리·상세 시계열·불확실성·재현 묶음·동일 실행.
- D8: 현장 목적별 독립 검증, Oracle 실제 환경 성능·장애·백업, TLS·메일·MFA·보존정책.

## 외부 의존성

공공데이터 API 승인·키 또는 합법 원본, 부지 배수·토양·유출 관측, 도메인 전문가 검토, 운영 도메인·메일·기관 검증·Oracle 설정. 비밀키를 채팅에 요구하지 않고 로컬 secret 설정 안내.
