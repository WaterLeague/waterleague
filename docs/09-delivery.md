# 1차 출시 범위와 후속 개선

2026-10-21 사용자 지시에 따라 현재 게임 기능을 1차 출시 범위로 고정한다. 추가 연구·정밀 보정·기능 확장은 출시 후 과제로 관리하며, 아래 미완료 연구 항목 때문에 출시 작업을 반복하지 않는다. 현재 제공 기능은 `01-product.md`, 수치 정의는 `02-scientific-validity.md`, 실제 검증은 `12-validation-log.md`를 따른다.

## 1차 출시 기준

- [x] 기존 주간·재해 게임의 관측 입력, 시설 설치, 예산, 저장·제출, 평가체적 점수와 소유권 검증 유지.
- [x] 이용조 수요·초기 저류 비교, 유출 지연 지표, 확인된 최신 지수 환산 가격 적용. 과거 설계·원가·결과 보존.
- [x] 서초 공개 관망의 지도 설계와 선택형 지표 비교, 실패 상태 표시, 원본·버전 결속과 소유자 재현 자료 제공.
- [x] 식생수로 계산·결과 게시 오류 수정과 실제 회원 작업의 두 안 전체 계산, 필수 회귀 검사 완료.

- [x] 게임 시각 오른쪽 전체화면·게임 영역 지정, 미지원 사선 영역 안내 박스 제거.
- [x] 페이지별 URL·랭킹 명칭·대회 개최/참가/제출/결과·관리자 시즌/사건 결과와 주간 설치 시각 구현 및 자동 검증.
- [x] 미사용 기관 리그·연구실·구형 지도 프론트 139파일 정리, 기존 서버 기록·동의·재현 자료 보존.

새 화면의 직접 브라우저 조작은 Work의 로컬 브라우저 제어 비활성화로 미검증이다. V33 대회 테이블의 배포 역할 권한 누락은 [현재 배포 상태](10-operations.md#대회-배포-상태--2026-10-21)에서 관리한다. 자동 시험·로컬 실행 완료를 공개 배포 완료로 표시하지 않는다.

수치 검사를 통과한 탐색 게임이 출시 대상이며 현장 침수 예측·시공 승인 서비스가 아니다. 서초 지표 비교는 현재 순위에 합산하지 않는다. 공개 서버 배포 완료 여부는 코드 검증과 구분해 보고한다.
