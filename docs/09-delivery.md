# 확장 구현 목표·완료 기준

기준일: 2026-10-21. 사용자 요구사항·현재 코드·프로젝트에 보관한 공개자료를 기준으로 한 실행 계획이다. **첫 구현 단계는 서울 25개 구 수치지형도를 공통 공간 기반으로 연결하고 OSM 의존을 제거하는 작업이다. 아래 미완료 항목은 계획이며, 원본 복사와 문서 갱신만으로 지도·엔진 전환 완료를 뜻하지 않는다.** 현재 사용자 규칙은 [제품 계약](01-product.md), 계산의 의미와 제약은 [과학적 계약](02-scientific-validity.md), 실행 증거는 [검증 기록](12-validation-log.md)을 따른다.

## 목표와 구현 원칙

공개자료로 재현 가능한 시설 배치·침수 피해 저감 게임을 완성한다. 서울 25개 구의 지도·설치 후보를 같은 수치지형도 경계에 맞춘 뒤, 자료를 연결할 수 있는 한 유역에서 설치 → 예산 → 강우 → 유입·침투·저류·배수·월류 → 설치 전후 비교 → 제출·순위를 끝까지 검증한다. 이후 같은 입력 계약과 검증 기준으로 적용 유역·시설을 늘린다. 서울 전역 지도 제공과 서울 전역의 검증된 침수 예측은 별도 완료 조건이다.

- 아직 배포 전이므로 기존 게임 기록·규칙·스키마의 호환성을 확장 조건으로 두지 않는다. 구현 과정에서 중복 엔진·구형 화면·임시 호환 분기를 제거하고 현재 구조로 통합할 수 있다.
- 공개 원자료의 출처·해시, 의미 있는 수치 검증 사례와 재현 근거는 유지한다. 과거 사용자 기록 지원과 과학적 증거 보존을 혼동하지 않는다.
- 원본 26파일의 보관·공통 입력 검사·원 레코드 공간 카탈로그와 자치구 소속·원 객체 대응을 가진 지도/설계 영역 생성 경로를 구현했다. 원형 후보의 시설·공통 문헌 비교 조건·참고 단가를 결속하고 공개 묶음의 Java 조회 API·Python 계산 일치를 검증했다. 공개 행정구에 기본·재해 관측 창 100개를 공간 형상과 독립적으로 결속하고 재해 75개의 7일 선행 관측·증발산 연결을 대조했다. 도곽 범위 밖 면적·건물 겹침·미해석 속성을 보존하며 일반 지도·설치 API·현재 연구 모델·재해 워커를 같은 원형 공간으로 전환하고 실제 브라우저 설치·6종 재해 API/워커·전체 화면 DTO를 대조했다. 미해결 접합·높이 단위/수직 기준을 미지원·미확인 상태로 보존했다. P0의 공간·타일 검증과 현재 독립 표면 녹화지붕의 회원 재해 저장·계산·제출·순위, 주간 실제 관측 연속 계산·순위·재접속 브라우저 흐름을 확인했다. P6 대상 기기 성능·확장 시설/유역의 전체 흐름은 남아 있다.
- 수치지형도는 건물·도로 등 공간 경계의 기준이다. 기존 SWMM/ANUGA 엔진에 기상청 강우·기상, 토양·피복, 공개 관망·시설·경계 수위를 연결한다. 수치지형도만으로 토양 물성·배수관망·운전 조건을 채우거나 새 효과계수를 만들지 않는다.
- 공개 파일과 공개 API만으로 진행한다. 이미 확보한 키·파일을 다시 요청하지 않으며, 추가 접근이 꼭 필요하면 [자료 확보 현황](13-data-access.md)에 조사 근거와 필요한 항목을 한 번에 정리한다. 비공개 자료·기관 협조·배포 준비를 구현의 선결 조건으로 추가하지 않는다.
- 자료가 없는 값은 결측 또는 명시적 설계 가정이다. 임의 효과율·가상 관측·가짜 수심·가짜 순위를 사용하지 않는다. 가정 기반 탐색과 현장 검증을 결과에서 구분한다.

## P0 · 서울 수치지형도 전환과 공통 공간 기반

입력은 [수치지형도v2.0(1:1000) 서울 25개 구 원본 목록](../data/manifests/vworld-seoul-topography-20260307.json)으로 고정한다. ZIP 25개와 `연속수치지형도_데이터_설명서.pdf`는 `data/private/vworld-seoul-topography-20260307/originals/`에서 읽는다. 실행·재생성이 개인 다운로드 폴더를 참조하지 않게 한다. 화면·출처에는 **2026-03-07 갱신 자료**로 표시하되 도엽 제작연도·촬영연도·설명서 작성일·복사일은 별도로 보존한다.

- [x] 원본 ZIP 25개·설명서 1개를 프로젝트에 복사하고 다운로드 원본과 크기·SHA-256 대조. 3,075개 도엽 참조 중 고유 2,488개·동일본 반복 587개, 121종 레이어의 사전 검사 기록 보관.
- [x] 해시를 검증하는 공통 수집·정규화 경로를 만든다. 같은 도엽 ID·같은 해시는 한 번만 처리하고 다른 해시는 충돌로 거부한다. ZIP 경로·링크·중복 이름·압축 해제 크기 제한과 SHP/SHX/DBF/PRJ 구성 검사를 적용한다. [입력 카탈로그 검사 결과](../data/manifests/seoul-topography-catalog-v1.json)는 원본 ZIP·레이어 메타데이터의 정규화이며 도형·설치 후보·서비스 전환 완료는 아니다.
- [x] 설명서의 코드 의미를 실제 레이어명·도형 종류·속성·값과 대조한다. CP949·원 PRJ를 확인하고 EPSG:5186 미터 좌표를 계산 기준으로 사용한다. 미분류·결측·알 수 없는 코드를 정상값으로 치환하지 않는다. 상세 규칙은 [공간 적용 계약](19-spatial-source-audit.md#서울-25개-구-전환-계약)을 따른다.

- [x] 주간·재해의 지도/후보/API/워커가 같은 공간 버전·해시를 참조하도록 전환한다. OSM 입력·생성기·조회/표시·식별자 결속에 의존하는 경로를 교체하고 사용하지 않는 분기를 정리한다. 과거 원본·수치 재현 사례와 OSM 파생물의 출처·라이선스는 보존하되 현재 서비스의 대체 입력으로 섞지 않는다.
- [x] 서울 25개 구 범위·도엽 접합·동일 후보 면적·표시/클릭/계산 위치·재생성 해시·타일 성능을 검증한다. 데이터 화면에 실제 사용한 데이터명·버전·출처·적용 범위와 가정을 연결한다. 전체 화면/후보 대조와 실제 구 경계 클릭, 로컬 배포 빌드의 빈 캐시 첫 로드·상세 타일 재사용·렌더/복구를 확인했다. [기본 지도 측정 범위](../data/benchmarks/native-browser-load-v1.json)는 단일 로컬 기기다. [121종 입체 표시·도로 후보 추가 검증](../data/benchmarks/native-3d-map-v1.json)은 원본/형상·빌드 검사를 통과했으며 최신 브라우저 깜빡임·FPS 재확인은 남아 있다. 미해결 접합·현장 정확도와 P6의 대상 기기 전체 검증을 통과로 바꾸지 않는다.

완료 기준: 보관 원본만으로 재생성 가능한 공간 카탈로그, 25개 구의 공통 지도/설치 흐름, 모델에 전달되는 동일 형상·면적·출처의 결속, 서비스 경로의 OSM 의존 제거. CRC/해시 통과를 도형 유효성·서울 전역 피복·현장 정확도 통과로 표시하지 않는다. 지형·관망 미확인 영역은 상태를 제공하며, 첫 연결 유역의 수문 검증은 P3에서 수행한다.

## P1 · 평가·설계 구조 통합

- [x] 배치, 시설 규격, 유입면적 배분, 초기 상태, 비용, 평가 경계, 원자료/코드 버전을 하나의 현재 계약으로 정리한다. 필요한 DB·API·프론트·워커를 함께 변경한다. 현재 6종 독립 표면은 [공통 설계 계약](05-data-model.md#입력해시결과)을 기존 결과 JSON·원문/manifest·양쪽 워커·화면에 결속했다. 미연결 집수면/노드·미기록 비용·미산정 LCC는 명시적 상태로 남긴다.
- [x] `공간 객체 → 설치 후보/집수면 → 시설 → 배수 노드/관로 → 방류/지표 격자 → 평가 지점`의 연결과 근거를 저장한다. 강우·토양·피복·초기 상태는 해당 공간 객체/유역과 버전으로 결속한다. 집수면적과 유량의 중복 배분을 차단하며 미연결 시설은 직접 강우 탐색으로 구분한다. 현재 독립 표면과 공개 연구 관망의 [연결 근거·면적 원장](../data/benchmarks/public-flow-graph-v1.json)을 기존 결과/재현 자료에 결속했다. 연구 관망의 원 INP 연결·선언 면적은 보존하며 미확인 좌표계/수직 기준·원형 지도 대응·지표 격자는 미연결 상태다. 현장 유역 연결 완료는 P3에서 별도 검증한다.
- [x] 주간·재해가 같은 시설 계산·물수지·지표 정의를 사용하게 한다. 시간 규칙은 유지한다: 주간은 설치 이후 관측, 재해 실험은 시간축 설치 이후, 제출은 동결 설계를 사건 전체에 적용한다. 공통 연속 엔진과 실제 워커의 설치 초 경계·선행 제외·전체 사건/취소 revision·같은 입력 재생을 대조했다. 주간 연속성의 합성 기상은 시험 전용이다.
- [x] 구형 설계실·점수·리그 규칙 중 남길 기능을 결정하고 사용하지 않는 진입·분기·마이그레이션 호환 코드를 정리한다. 기록 유지 때문에 두 계산 체계를 병행하지 않는다. 현재 Native 연구/기관 API·원 수치 재현 근거는 유지하고 일반 게임의 미사용 설계실 분기·편집 컨트롤러·자동 조회를 제거했다. 이전 공간은 종료 상태와 원문 보관으로 유지한다. [연구 모형 503 조건의 실제 화면 검증](../data/benchmarks/native-shell-separation-v1.json)과 세션 경합 회귀를 따른다.
- [x] 기준안과 설계안의 강우·선행 상태·유역·보고 시각·수치 정책을 동일하게 고정하고, 단위/시각/좌표계/해시를 결과에 묶는다. 현재 독립 표면은 실제 INP 공통 절·동일 평가 창/엔진·원형 입력 해시를 대조하고 단위·비용/코드 근거를 보관한다. [통합 증거](../data/benchmarks/native-design-contract-v1.json)의 연결 유역·결과 캐시 재사용·회원 브라우저 잔여 범위는 별도다.

완료 기준: 같은 설계와 평가 입력의 API·워커·화면 지표 일치, 캐시 유무에 따른 결과 일치, 주간/재해 시간 규칙·권한·중복 제출 회귀 통과. 진행률 표시는 실제 작업 상태만 사용한다.

## P2 · 빗물이용시설 완성

시설 선택에는 **빗물이용시설**을 두고 규격으로 **소형 빗물통 / 빗물이용조**를 선택한다. 현재 이용조의 미완성 경로를 먼저 완성하고 소형 규격을 추가한다. 서로 다른 엔진이나 복제된 비용·점수 로직을 만들지 않는다. 용어를 가르는 보편적인 용량 기준을 임의로 만들지 않는다.

- [ ] `cistern_map_plans`의 `SPATIAL_DRAFT_NOT_INSTALLED` 초안을 실제 설치와 명확히 분리하고, 공개 근거가 충족된 규격만 확정 설치로 전환한다.
- [ ] 지붕 집수면·배관 연결·용량·설치 면적·유출구·넘침 경로를 명시한다. 집수면 중복 배분과 다른 시설로 보낸 유출의 재사용을 차단한다. 공개 연구 관망에는 명시적 집수·일반 배수·비상 배수 연결관의 길이·내경·조도·높이와 접속부 월류를 연결했다. 실제 지도 지붕·홈통·출구 경로의 결속은 남아 있다.
- [ ] 기존 관망 이용조의 유입·저류·수두 기반 배수·월류 계산을 공통 시설 흐름에 연결한다. 총용량이 아닌 현재 여유 용량을 사용하며 가득 차면 넘침이 발생해야 한다. 공개 연구 관망에서는 같은 원 집수구역의 이용조 집수·덮개·다른 LID를 분리하고 현재 저장 공간, 자연배수와 일반 배출 중지/비상 배수 조건을 API·워커·결과 화면에 연결했다. [관망·지표 결합 경로](../data/benchmarks/coupled-cistern-v1.json)에 원 집수 분할·공동 LID 배분·평가 창별 이용조 원장을 연결했다. 합성 유역 검증이며 원형 지도·두 게임 모드의 확정 설치/예산 연결은 남아 있다.
- [ ] 실제 사용 수요 근거가 있을 때만 재이용량을 계산한다. 저장량을 소비/영구 저감으로 간주하거나 비가 오기 전에 자동으로 빈 통으로 초기화하지 않는다. 수요 미확보 시 재이용량은 미산정으로 유지한다. 현재 수리 이용조 결과는 `reuseM3=null`과 수요 미확보 상태를 보관·표시하며 입력 초기 저장량을 보존한다. [관측 선행 이용조·관망·지표 연속 계산](../data/benchmarks/initialized-coupled-cistern-v1.json)은 원 집수 강우를 먼저 결속한 뒤 이용조·공동 LID를 분할하며, 같은 엔진의 사건 시작 저류량·여유 용량과 선행 기간을 제외한 수지를 보존한다. 공개 사용 수요·일반 설치 통합은 잔여 범위다.
- [ ] 규격별 공개 사양·공종·가격 기준일·포함/제외 공사를 연결한다. 현재 2.35m³ 문헌 사례의 부분 견적을 모든 현장/소형 통의 완성 공사비로 사용하지 않는다. [2025년 공개 1.5톤 이용조 규격·공고](../data/manifests/sinyoung-cistern-procurement-2025.json)의 장비 외형과 발주 범위를 지도 초안·저장/복원에 결속했다. 명목 용량과 실제 내부 단면을 구분하며 발주 예산을 실거래 설치비로 전용하지 않는다. 유효 저류 단면·배수/월류 경로·현장 확정 공사비는 미확정이다.
- [ ] 예산 검증·설치 목록·3D 표시·시간축 아이콘·시설별 결과·제출·순위를 연결한다. 재해는 소속 구와 무관하게 모든 구에서 같은 허용 규칙을 적용한다. 지도 초안의 재해 선택/저장은 전 구로 분리하고 주간 소속 구·점유 제한과 모드 전환 상태를 격리했다. 초안은 확정 설치·예산·제출로 전환되지 않는다.
- [ ] 소형 빗물통도 별도 공개 규격과 설치·월류 근거를 확보해 같은 경로로 추가한다. 단순히 용량만 줄인 가짜 규격은 만들지 않는다.

완료 기준: 무강우·빈 통·부분 충전·만수·배수·넘침·재이용 수요 없음/있음·중복 집수·예산 초과를 검증하고 물수지를 보존한다. 현재 미확정 공사비나 설치 조건이 남은 규격을 정상 설치 버튼으로 노출하지 않는다.

## P3 · 연결 유역 한 곳의 실제 게임 흐름

- [ ] 공개 관망의 수평/수직 기준·맨홀/관로 연결·지표/방류 경계와 강우 시점을 확인해 첫 적용 유역을 선정한다. 확보한 서초 공개 연구 관망도 이 조건을 검사하며, 서울시 공식 현장 관망으로 승격하지 않는다. [추가 공개 유역 구분 입력 4종](../data/manifests/mendeley-seocho-heuristic-v1.json)의 136관로·133접합점과 29/7집수구역을 기존 가져오기 경로로 보존했다. 원 계산 시작을 유지한 보고 구간 확장 진단과 원 보고 시각의 값 일치를 확인했으나 내부 비수렴·좌표/수직 기준·관측 원문 결측이 남아 적용 유역으로 선정하지 않았다.
- [ ] P0 공간 카탈로그의 집수면을 기존 SWMM/ANUGA 입력에 연결하고 강우·토양·피복·표고·관저고·시설 운영·경계 수위 각각의 출처와 시점을 검증한다. 맨홀 위치점이나 도로중심선만으로 하수관 연결·관저고·용량을 생성하지 않는다. 행정구가 달라도 같은 유역의 외부 유입·하류 경계를 포함한다.
- [ ] 시설 외부 유입을 검증 가능한 집수면과 경로로만 연결한다. 자료가 없는 지역은 현재 표면 탐색 범위를 명시한다.
- [ ] 기준안/설계안의 유역 출구 유출 총량·첨두, 맨홀 월류량·지속시간, 계산 지표 수심/유속을 연결한다. 같은 시각의 합 유량에서 첨두를 구하며 개별 최대값을 더하지 않는다. 공개 연구 관망의 [지점별 외부 월류 발생 시간](../data/benchmarks/node-flood-duration-v1.json)을 저장·비교·재현에 연결했다. 지표 저류 시간과 구별하며 [관망 전체 발생 시간](../data/benchmarks/network-flood-duration-v1.json)은 동시 월류를 한 번만 누적해 공통 평가 창에서 비교한다. 실제 지도 유역 결속과 지표 수심/유속 연결은 남아 있다.
- [ ] 자연 하천, 과거 침수흔적, 계산 침수를 구분하고 실제 계산 프레임만 해당 시각에 표시한다. 자료 없는 시각/지역의 깊이를 만들어 채우지 않는다.
- [ ] 사람·차량 반응은 계산/기록에 따른 시각적 반응과 피해 평가를 분리한다. 피해 인원·금액을 점수로 쓸 경우 별도 공개 노출자료와 취약도 근거부터 정의한다.
- [ ] 관망·지표 교환 물수지, 역류·만관·건습 전환, 시간/격자 민감도와 독립 참조 대조를 검증한다.

완료 기준: 한 공개 유역에서 지도 설치부터 서버 계산·결과·저장·제출·재현까지 연결되고 실패/미지원 범위가 구분된다. 동일 수준의 근거가 있는 다음 유역으로 확장한다. 공개자료가 부족하면 미지원 범위를 남기되 다른 기능 구현은 계속한다.

## P4 · 성능 지표와 점수

고정된 비율 배점표를 확장 목표로 두지 않는다. 유출 총량·첨두·월류량/지속시간의 실제 계산값과 기준안 대비 개선량을 먼저 제공한다. 동일 조건에서 사전에 정한 주 지표의 개선량으로 경쟁하고 경제성·관리·적합성은 각각의 의미와 근거를 가진 비교 항목으로 둔다. 화면의 달성률이나 등급 상한으로 추가 개선을 같은 점수로 묶지 않는다.

- [x] 먼저 원 지표·단위·기준/설계 차이·증감률·평가 가능 여부를 제공한다. 표면 유출과 관망 유출/월류를 동일 이름으로 혼용하지 않는다. 현재 독립 표면의 평가체적/유출·배수/첨두와 공개 연구 관망의 방류/동시 첨두/월류에 [원 지표 비교 계약](../data/benchmarks/raw-metrics-v1.json)을 연결했다. 미연결 관망·지표, 과거 미수집 지속시간·사용 수요와 수치/경계/구형 덮개 설계의 비교 보류는 원값·null·사유로 구분한다. 실제 연결 유역·새 시설 범위는 P2/P3 잔여 조건을 따른다.
- [ ] 지표별 평가 경계·기간·유효성·방향·0 기준값·음수 효과·수치 허용오차·동점 규칙을 확정한다. 악화된 결과를 0으로 숨기지 않고 원값을 보존한다. 주 지표·비교 집단·동점 순서는 평가 시작 전에 고정한다. 현재 독립 표면은 [조건 동결·정확한 원장 검증](../data/benchmarks/score-comparison-context-v1.json)으로 주간 9자리/제출 18자리 HALF_EVEN·공동 순위·시간 규칙·코드/자료/실행 조건을 결속했다. 연결 유역의 공통 평가점·수치 검증은 P3 잔여 범위다.
- [x] 절대 개선량을 기본으로 비교하고 상대 개선율은 보조 표시한다. 서로 다른 규모/모델/강우의 불공정 비교를 정규화만으로 해결하지 않는다. 보조 정규화가 필요하면 사전에 고정한 기준과 단조 증가 규칙을 사용하고 참가자 최고값이나 임의 만점 절단을 사용하지 않는다. 물리적으로 가능한 최대 저감량은 그대로 인정한다. 현재 두 모드는 원 체적 차이를 유지하며 참가자 기준 환산·비율 순위·만점 절단을 적용하지 않는다. 지역별 강우·설치 길이 차이는 같은 값으로 정규화하지 않고 게임의 관측 결속 규칙과 범위로 공개한다.
- [x] 필수 지표가 없으면 미산정과 사유를 반환한다. 결측을 0점/효과 없음으로 바꾸거나 나머지를 100점으로 재배분하지 않는다. 서로 다른 지표 집합·모델·조건의 기록을 같은 순위에 혼합하지 않는다. 재해는 동결 규칙/계산 집단마다 최고 기록·순위를 분리하고 주간 조건 혼합·미기록은 시설 원 기록을 보존하면서 합산/순위/우승을 보류한다. 실제 0·음수·원장 해상도 내 개선과 미산정은 별도로 검증했다.
- [x] 종합점수는 지표 중복·가중치 민감도·비용/관리 근거를 검토한 뒤 필요성이 확인될 때만 도입한다. 비용·안전·효과를 임의 비율로 합산하지 않는다. 그전에는 현재 체적 차이 순위를 그 이름과 범위로 유지한다. 주간의 관측 확정 범위와 재해의 전체 사건 평가를 명시한다. 현재 정책·API·데이터/결과 화면은 직접 강우 독립 표면의 체적 차이를 유지하며 종합점수/가중치·생애 효과를 생성하지 않는다.
- [x] 안전상 금지 조건은 설치/평가 제약으로 처리한다. 다른 지표의 점수로 구조 하중·지하수·배수 안전 위반을 상쇄하지 않는다. [조건별 판정·차단 검증](../data/benchmarks/site-suitability-v1.json)의 같은 정책을 주간/재해 설치·저장 설계·이용조 초안·계산 워커에 적용한다. 미확인 후보의 탐색 배치를 시공 승인으로 표시하지 않는다.

완료 기준: 같은 입력에 같은 점수, 참가자 증감에 불변, 수치 허용오차를 넘는 주 지표 개선의 순위 반영, 무강우/0 기준값·악화·결측·동점 검증, 서버 계산·화면·랭킹·재현 자료 일치. 점수 확정 전 현재 순위를 임의 환산하지 않는다.

## P5 · 비용·유지관리·현장 적합성

- [ ] 설치비와 LCC를 구분한다. 공통 평가기간·가격 기준연도·할인 가정과 출처를 고정하고 설치·점검/청소·수선·교체 비용을 분리한다. 근거 없는 수명·교체 주기·금액을 생성하지 않는다. 현재 7개 비용 항목·원장/정책 해시와 미산정 상태를 두 모드에 연결했다. 이용조 문헌의 기간/할인 가정으로 부분 현재가치와 감도를 제공하며 현장 공통 기간·가격 기준과 누락 공종 확정은 남아 있다.
- [x] LCC는 `초기 설치비 + 기간별 운영·유지·수선·교체비의 현재가치 − 종료 잔존가치의 현재가치`로 계산하며 해당되는 철거/처분비도 포함 범위를 밝힌다. 잔존가치·교체 시점·할인율·물가 기준의 근거와 결측을 보존한다. 공통 기간/관리 시나리오별 비용 내역과 민감도를 제공하며 기간·할인율을 근거 없이 고정하지 않는다.
- [x] 게임 설치 예산에는 설치 시점 비용을 적용하고 LCC는 별도 생애주기 비교로 제공한다. 장기 예산 경쟁을 추가할 때만 별도 규칙으로 확정한다. 단일 호우의 저감량을 임의로 연간화하거나 하루 효과로 생애 총효과·비용효율을 산정하지 않는다. 주간/재해 설계에 같은 비용 버전·시나리오를 결속한다.
- [x] 현재 이용조의 부분 공종·연간 비용을 전체 설치비로 오인하지 않도록 미산정 항목을 표시한다. 한 시설 비용을 다른 시설의 계수로 복제하지 않는다.
- [ ] 새 시설/관리 지연/정비 이후 등의 관리 상태를 공개 문헌 근거에 따라 시나리오로 제공한다. 현재 신규·막힘 없음 설정과 구분하며, 몇 시간의 사건 재생에 수년간 노후화를 압축하지 않는다. 회원 재해의 선택 투수포장에 공개 Type-A 블록의 새 재료·협잡물 96g·192g 조건을 별도 계산하고 기존 설치/순위와 분리했다. [공개 PICP 청소 전후 측정](../data/manifests/winston-pavement-cleaning-2016.json)의 4개 구역/시기 쌍과 통계·단위 비교를 기존 제원/결과에 연결했다. 다른 재료의 현장 표면 침투속도를 Type-A 투수계수로 전용하지 않으며 서울 현장 사용 연수·완성 포장체 열화·청소 회복/관리 비용의 계산은 미확정이다.
- [x] 토양·경사·지하수·지장물·교통 하중·옥상 구조 하중·방수/배수 조건을 허용/조건부/금지/미확인으로 구분한다. 지도 배치 허용은 실제 시공 승인이 아니다. 후보와 새 계산 결과에 해당 조건별 상태·사유·출처 및 정책 해시를 보관하며 문헌 참조 입력으로 현장 결측을 채우지 않는다.
- [x] 유지관리와 실현성 점수의 근거·판정표를 먼저 정의한다. 공개자료에서 확인 불가능한 항목을 임의 상/중/하로 채우지 않는다. [공개 관리 기준](../data/facilities/maintenance-reference-v1.json)에 LH·EPA의 시설별 점검 항목/주기·참조 쪽과 원문 해시를 결속하고, [문헌만 확보/이상 징후/점검·정비 근거의 판정표](02-scientific-validity.md#유지관리실현성의-근거와-판정표)를 정의했다. 데이터 페이지는 같은 기준과 기존 서버 적합성 정책을 표시한다. 현장 이력·비교 배점의 검증 전 점수·등급은 null이며 이 정의 완료를 현장 상태·회복률·관리 비용 계산 완료로 확대하지 않는다.

완료 기준: 비용 포함 범위·결측·할인 가정·관리 시나리오를 재현하고, 미확인 안전 조건을 확정값으로 표시하지 않는다. LCC 비교 대상의 기간·금액 기준이 같아야 한다.

## P6 · 통합 화면·성능·보안

- [ ] [공통 UX 계약](08-experience.md)에 따라 시설별 현재 상태·효과·근거를 기존 목록/결과에 통합한다. 중복 안내·별도 임시 패널을 늘리지 않는다.
- [ ] 무거운 연결 계산은 서버 비동기 큐에서 실행한다. 같은 입력의 계산 캐시와 지도 시야별 파일 캐시를 분리하고, 카메라 이동/재생 프레임마다 물리 계산을 요청하지 않는다. 공개 관망의 기준/설계 원 계산에도 입력·엔진·코드·실행 환경별 제한 캐시를 연결하며 현재 설계 검증·물수지/입구 월류 판정·소유권·재현 파일 결속을 유지한다. 두 게임 모드의 연결 유역 통합과 전체 흐름 검증은 남아 있다.
- [ ] 실제 대상 기기에서 첫 로드·근접 이동·확대/축소·긴 재생·시설 전환의 시간/메모리/프레임을 측정한다. 타일/객체 예산·취소·GPU 해제·이전 형상 유지와 오류 복구를 확인한다. 도로·교량의 지속 Worker·개별 형상 재사용·캐시 초과 시 전체 재생성 방지를 구현하고 공개 육교 268개·이름 있는 교량 977개 형상과 실제 배포 Worker의 취소/복구를 대조했다. 건물도 개별 형상 재사용과 지속 Worker 취소를 연결하고 [25개 구 1,014,532개 건물 대조](../data/benchmarks/building-mesh-reuse-v1.json)에서 형상·클릭 범위를 보존했다. 평면/3D 레이어를 분리해 진입 파일의 렌더러 의존을 제거하고 도시 자료와 3D 코드를 병렬 취득한다. 도로 투수포장 미리보기·확정 형상이 도로/보도 아래 가려지는 높이와 반투명 표시 순서를 수정하고 원 면적·구멍·상부 교량·얕은 침수의 형상 회귀를 검증했다. [도로 시설 표시 검증](../data/benchmarks/road-placement-display-v1.json)과 [CPU 재사용·진입 파일 측정](../data/benchmarks/native-3d-map-v1.json)은 대상 기기의 화면·FPS 완료 판정과 구분한다.
- [x] 게스트/회원/기관 경계·소유권·CSRF·예산 경합·멱등 제출·작업 만료·결과 해시를 통합 검증한다. 게스트 최종 결과 잠금을 UI만으로 처리하지 않는다. [현재 서버 경계 통합 검증](../data/benchmarks/security-boundaries-v1.json)의 Java 64개·공통 큐 10개·실제 프로세스/결과 입력 8개와 가입 입력 보강 후 집중 3개를 통과했다. 기관 승인·동의 철회·회원 소유권·예산 경합·동시 제출, 공통 워커의 자식 회수·잠금 대기 중 만료 갱신/게시 차단·손상/과대 결과 실패를 확인했다. 현재 서버 경계의 완료이며 미구현 확장 시설/유역·두 모드 전체 브라우저 흐름·대상 기기 성능·공개 배포 검증과 구분한다.

현재 독립 표면의 [회원 실제 브라우저 검증](../data/benchmarks/game-browser-flow-v1.json)은 격리 DB에서 가입 → 소속 구 주간 설치 → 다른 구 재해 설치 → 저장 → 실제 SWMM 계산 → 최종 제출 → 기록 경쟁 → 재접속 복원·재제출·재현 자료 다운로드를 확인했다. 두 제출의 SWMM INP/OUT·시설 결과가 같고 API·DB·재현 자료·순위의 소수 18자리 저장값이 일치했다. 서로 다른 제출 요청 식별자는 별도 계보로 보존한다. 주간 첫 계산은 관측자료 수집 중 `KMA_UNAVAILABLE`로 실패했으며 시설·예산·실패 사유를 보존하고 점수·순위를 생성하지 않았다. 현재 날씨 응답 성공과 시설 계산 입력의 완비를 구분한다. 주간 계산 성공·시설 전체 조합·기관·연결 유역·대상 기기 성능의 완료 증거로 확대하지 않는다.

이후 [관측 수집 복구](../data/benchmarks/kma-transport-retry-v1.json)에서 일시 통신 실패의 제한 재시도와 성공한 축소 구간의 유지, 요청마다 임대 갱신·만료 시 중단을 적용했다. 실제 기상청 성동 421 지점의 1시간 원문 조회·검증과 기존 주간 연속 계산/점수 원장의 격리 DB 회귀를 통과했다. 전자는 일부 실제 관측, 후자의 합성 강우는 시험 전용이며 두 결과를 합쳐 전체 주간 실제 관측 계산 성공으로 표시하지 않는다.

그 뒤 [주간 실제 관측 전체 흐름](../data/benchmarks/game-browser-weekly-v1.json)에서 격리 회원의 성동구 녹화지붕 설치 → 예산 차감 → 7일 선행 관측 수집 → 실제 SWMM 연속 계산 4회 → 개인/구 순위 → 재접속 복원 → 인증 재현 자료 조회를 확인했다. 설치 초부터 33·93·153·213초를 누적했고 마지막 저장 점수 `0.000049229m³`가 원 결과·DB·API·화면과 일치했다. 이전 상태·기여 구간과 선행 입력을 보존하고 141파일 재현 ZIP의 계산/내보내기 해시를 대조했다. 선행 강우 40mm와 평가 구간 0mm를 구별하며 작은 체적 차이를 강우 중 현장 침수 저감의 증거로 해석하지 않는다. 이 실행에서 통신 장애가 발생했다고 단정하지 않으며, 확장 시설·연결 유역·기관·대상 기기 성능은 남은 범위다.

완료 기준: 두 모드의 실제 브라우저 → API → 워커 → 저장/조회 흐름 검증, 핵심 수치 회귀, 실패·재접속·캐시·권한 시험 통과. 기능별 증거를 [검증 기록](12-validation-log.md)에 남기고 이 문서의 체크를 갱신한다. 공개 운영 검증은 [운영 계약](10-operations.md)으로 별도 관리하며 구현을 막는 자료 요청으로 취급하지 않는다.

## 이후 범위와 참고 근거

기관의 다강우 비교·패턴 후보 탐색은 [기관 분석 계약](18-institution-analysis.md), 리그 운영은 [참가 계약](17-league-participation.md), 연구/사업 활용은 [동의 계약](16-utilization-consent.md)을 따른다. 핵심 게임 완성 뒤 필요한 화면을 통합하며 예전 화면 복원을 목표로 삼지 않는다.

- [서울 25개 구 수치지형도 원본 목록·설명서](../data/manifests/vworld-seoul-topography-20260307.json): 프로젝트 내부 입력 경로·해시와 설명서 버전. 레이어/코드 해석은 실제 파일과 대조하며 [공간 적용 계약](19-spatial-source-audit.md#서울-25개-구-전환-계약)을 따른다.
- [EPA SWMM](https://www.epa.gov/water-research/storm-water-management-model-swmm): 시설 물수지·배수 연결의 계산 근거.
- [EPA 도로 유출 녹색인프라 유지관리](https://www.epa.gov/green-infrastructure/operation-and-maintenance-green-infrastructure-receiving-runoff-roads-and): 관리 항목 조사 근거이며 게임 점수표 자체의 인증이 아니다.
- [NIST Handbook 135](https://nvlpubs.nist.gov/nistpubs/hb/2022/NIST.HB.135e2022-upd1.pdf): 생애주기비용 산정 절차 참고. 미국 기준의 금액·할인율을 서울 사업에 그대로 적용하지 않는다.
