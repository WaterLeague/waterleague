## 이번 기능의 사용 범위

공개 관측 강우와 형상, 명시적 수문 가정으로 재현 가능한 후보 배치를 탐색한다. 원화 비용은 타 지역 공개 사업계획 참고치다. 실공사비·침수위험·효과 확정 연구에는 아직 사용할 수 없다.

기준안·배치안 수치 계산, 소유권·기관 격리, 실제 PostgreSQL API→워커→제출→다운로드와 동일 수치 재현 확인. 단위·통합 검사의 성공을 현장 정확성 검증으로 전용하지 않는다.

## 외부 의존성

성수동 실제 배수경계·관망 표고와 단면·지표고·토양 침투·유출 관측, 현장 설치 적합성, 시설 규격과 원가 검토, Oracle 접속·운영 도메인·메일·기관 신원 확인. 관측자료가 확보되지 않으면 공식 모델 활성화 금지.

## Goal 잔여 완료 기준

원기획 전체 대조에서 추가 확인된 기능·검증 부족 항목은 [잔여 범위 점검](18-scope-audit.md)에 기록. 아래 기존 완료 표시는 해당 구현 범위에 한하며 참가 방식·기관 다강우 분석·계산 캐시·3D 품질까지 모두 완료했다는 의미가 아님.

- [x] 기관 리그 초안·공개·불변 규칙·취소·제출·독립 순위·기관 연구 연결
- [x] 리그별 시설 개수·합산 면적 상한·원화 상금·수상 예정 인원·심사 안내 고정
- [x] 과거 실측 강우 3개와 모델 카탈로그·관측소 차이 비교 (과거 좌표 이력·현장 대표성 검증 별도)
- [x] 실제 SWMM CPU 기준안·후보 원장·고정 배치의 네 강우 비교·개인 설계 복사
- [x] 사용자 저장 버전의 다강우 일괄 계산·비교 그룹·결과/재현 파일·설계 복원
- [x] 평가·연구·사업 활용 동의 구분과 기관 검토 기록
- [ ] 공개 지형·피복·배수·토양·유출 자료 조사 결과와 확보/미확보 근거
- [ ] 보정·독립 검증 자료, 전문가 검토, 공식 모델 활성화 판단
- [ ] 배포 구성·비밀 관리·백업 복원·큐 동시성·부하·운영 문서
- [ ] 실제 Oracle 배포·TLS·운영 점검 (접속·도메인 확보 필요)
- [ ] 원기획의 리그 세부 규칙·참가 방식·기관 분석·캐시·3D 품질 잔여 항목

기능별 완료 시 검증·커밋·푸시하며 Goal은 유지한다. 외부 자료·인프라가 필요한 항목은 근거와 필요한 사용자 조치를 남기고, 독립적으로 가능한 구현을 계속한다.
