# 공통 지도·게임 화면 계약

기준일: 2026-10-21. 주간 서울 대항전과 재해 모드의 공통 화면 기준이다. 게임 규칙은 [제품 계약](01-product.md), 구현/캐시 구조는 [아키텍처](04-architecture.md), 실행 증거는 [검증 기록](12-validation-log.md)에 둔다.

## 페이지 주소

| 화면 | 주소 |

| 주간 서울 대항전 | `/weekly` |

각 페이지는 링크·직접 주소·새로고침·뒤로/앞으로 이동으로 접근한다. 주소만으로 계정 권한을 부여하지 않는다. 대회 화면은 기존 공통 카드·폼·드롭다운·표·버튼 스타일을 사용한다. 승인 조직의 개최 폼은 모드·재해 사건·서울 전체/구 선택·시설·기간·이름/정보·상/상금을 받고, 공개 후 상세에서 고정 조건·참가·제출·결과를 제공한다. 결과는 같은 조건별 공동 순위와 계산 대기/보류를 구분한다. 관리자 주간 결과에는 시설별 설치 시각을 표시하고 재해 결과는 전체 사건 제출로 표시한다.

## 화면 구성

- 홈은 사용자가 제공한 서울·수달 여울이·물총새 가람이 이미지로 게임과 기능을 소개한다. 공통 로고는 제공 이미지의 두 줄 `WATER / LEAGUE` 글자만 사용하며 클릭하면 `/`로 이동한다. 홈 메뉴와 게임 시작을 구분하고 첫 방문을 주간 지도에 자동 이동시키지 않는다. ‘게임 시작하기’는 주간 서울 대항전·재해 모드 선택 창을 열며, 두 선택지의 설명·로그인/체험 조건·각 주소를 제공한다. 기본 모달의 키보드 포커스·Escape 닫기·닫기 버튼을 유지한다.
- 홈의 두 게임 모드와 시설 7종은 회전 가능한 3D 소개 모형을 제공한다. 시설 선택·회전 버튼은 키보드로도 사용할 수 있으며, 3D를 지원하지 못해도 설명과 게임 링크를 유지한다. 모형은 이해를 위한 표현으로 실제 관측·침수 계산·시공 치수를 뜻하지 않는다. 화면 밖 모형은 해제한다. 시설 모형은 등장·시설 전환·회전 중에만 다시 그린다. 주간 모드 모형은 현재 한국 시각에서 시작해 24초에 하루가 흐르는 시계를 오른쪽에 표시하며 낮·밤과 강수·비강수를 순환한다. 해의 위치·일출/일몰 표시와 조명 방향은 실제 게임과 같은 서울 태양 고도·방위 계산을 시계에 연결한다. 재해 모형은 기존 도시·구름을 유지하고 비를 계속 내린다. 두 모드의 빗방울은 실제 게임의 GPU 강수 표현을 재사용한다. 미리보기 시각·날씨는 소개용이며 관측·점수·물리 입력과 연결하지 않는다. 캐릭터 이미지·3D 모듈은 필요할 때 불러온다. 섹션은 스크롤에 따라 한 번씩 순차 등장하고 캐릭터는 짧게 인사하며 시설 설명·3D 회전은 부드럽게 전환한다. 캐릭터 인사는 반복하지 않는다. 모드 모형은 재생/일시정지 버튼을 제공하고 화면에 보일 때 최대 초당 30회 갱신하며 화면 밖·숨긴 탭·서버 연결 단절 시 정지한다. 모션 축소 설정에서는 정적으로 표시하고 키보드 포커스 시 등장 지연을 제거한다.
- 게임 모드 바로 아래에 시설 안내를 두고, `/#home-map`에서 침수 기록·공개 기존 시설을 소개한 뒤 `/#home-score` 점수 설명을 둔다. 지도 안내는 보라색 과거 침수 범위의 사건별 선택, 현재 시설 효과 계산과 실시간 수심/유속 미지원, 주황색 기존 시설 종류·검색·공개 제원/이력·출처 확인을 설명한다. 침수 기록은 게임 수면 재질을 적용한 평면 범위를 입체 도시 위에 보여주며 수심을 만들지 않는다. 공개 기존 시설은 게임의 8종 공통 기호를 선택·회전하는 3D를 제공한다. 두 장면은 표시 방식 설명용 모형임을 안내하고 조작 중에만 다시 그린다. 공개 위치 자료를 현재 운영 상태나 재해 당시 존속 확인으로 안내하지 않는다. 기준/설계 평가체적 차이, 유출+배수+종료저류−시작저류 식, 실제 기록과 구분한 숫자 예시, 주간 개인/구 합계·설치 이후 기간·재해 전체 사건 제출·개인 최고 기록·대회 조건·0/음수/미계산·정밀값 동점(1·1·3)·평가 범위를 설명한다. 시설 소개에서는 시설의 역할·설치 위치와 3D 조작만 제공하며 기존 ‘지도에서 표시되는 허용…’ 안내 문구와 ‘지도에서 배치해 보기’ 링크를 제거한다.
- 주간·재해·랭킹·대회와 권한을 확인한 관리자 화면은 연구 모델 조회의 성공을 진입 조건으로 사용하지 않는다. 일반 게임에 구형 설계실 진입을 노출하지 않으며 계정 만료·개별 요청 실패는 공통 알림으로 구분한다. 서버 연결 단절은 아래 복구 화면으로 안내한다.
- 게임 외 화면(홈·랭킹·대회·재해 선택·회원/결과 관리·로그인)은 공통 청록색 강조, 밝은 중성 바탕, 본문 대비와 8px 조작부/12px 패널 모서리를 사용한다. 일반 페이지는 같은 최대 너비·좌우 여백과 제목/설명/행동 헤더를 사용하고 탭은 밑줄, 순위는 표, 입력은 같은 높이로 통일한다. 홈페이지는 캐릭터·서울 이미지·3D를 중심으로 구성하고 반복 카드·장식용 영어·추상적인 권유 문구를 줄인다. 자료 출처·시설 설명·점수 공식은 보존한다. 모바일에서는 상단 메뉴를 별도 가로 행에 두고 표만 내부 스크롤한다. 키보드 포커스·모달 닫기·모션 축소를 유지한다. 일반 화면 스타일은 `shared/ui/site.css`와 `SitePageHeader`에 두며 게임 내부 지도/HUD/시설 조작부의 스타일·점수 계산과 분리한다.
- 첫 상단 바는 날씨/모드 상태, 둘째 줄은 위치·지도 도구 등 개별 부유 조작부다. 둘째 줄 전체를 막는 배경 바와 재해 전용 하단 재생 바는 두지 않는다. 설치 메뉴가 상단 바 너비·정렬을 줄이지 않는다.
- 재해 재선택은 사건명 왼쪽, 재생 버튼·시각·배속은 같은 그룹이다. 배속은 기본 HTML select 대신 공통 드롭다운이며 2·3·5·10배속을 포함한다.
- 재해 선택 카드의 사건별 연녹색·올리브색·베이지색 구분을 유지한다. 날짜·사건 설명·시작 버튼·출처를 제공하며 ‘공개 관측 구간 재생 · 기본 1배속’ 안내는 표시하지 않는다.
- 시작 위치는 서울 전체다. 구 선택 시 이동하고, 지도를 다른 구로 이동하면 위치 드롭다운·날씨도 현재 시야에 맞춘다. 재해 도구에 내 소속 구 제한 탭을 두지 않는다.
- 주간 HUD는 우리 구 순위/총점과 내 설치 수/총점, 재해 HUD는 내 설치 수/현재 점수다. 서울 공유 시설 0곳·시설을 설치할 위치를 찾아보세요·서울 25개 구 상태 조회 등의 중복 안내는 두지 않는다.
- 설치 버튼 오른쪽에 노란색 전체 예산 조작부와 사용 바를 두고, 상세는 호버/포커스로 제공한다. 한 개 이상 설치하면 설치한 시설 보기 버튼과 목록을 별도로 제공하고 설치 메뉴에 중복 목록을 넣지 않는다.
- 재해 제출은 오른쪽 끝의 설치 버튼과 같은 형태에 다른 색/아이콘을 사용한다. 설치 없음·처리 중은 비활성화하며 설명을 제공한다. 게스트는 로그인 후 제출하기다. 별도 설치 이후 효과 계산 버튼과 중복 게스트 안내를 두지 않는다.

## 설치 위치·시설 선택

기본 상태에서도 현재 원형 자료에서 허용된 옥상·지상·도로·보도 후보를 초록색 계열로 표시하고 직접 클릭할 수 있다. 시설 설치 메뉴를 먼저 열 필요가 없다. 시설 선택 시 해당 종류가 가능한 곳은 초록색, 다른 후보는 낮은 불투명도로 유지한다. 선택/드래그 영역은 노란색이며 100% 선택해도 유지한다. 선택 조건과 다른 후보를 누르면 해당 표면의 허용 시설로 전환한다.

설치 창은 공통 닫기 버튼으로 닫을 수 있고, 닫으면 종류 필터·미확정 선택을 해제해 전체 허용 후보 표시로 돌아간다. 시설 선택 해제 전용 버튼은 두지 않는다. 사업 예산에는 사업 한도를 표시하고 남은 잔액은 각 시설 항목에서 확인한다. 시설 버튼의 아이콘·이름·비용·잔액 정렬을 통일한다. 선택만으로 서버 배치를 저장하지 않는다.

주간·재해 후보 창의 설치 동작은 시설·면적·비용 설명 아래에 둔다. 주간 비회원의 ‘로그인하고 우리 구에 설치’와 소속 구 확정/이동 조작도 후보 창 하단에 두며 후보 정보 위에 노출하지 않는다.

미확정 배치는 흐린 미리보기로 표시한다. 허용 면적·예산·종류 검증을 통과한 확인 동작으로 확정하며 취소·Escape는 미리보기만 해제한다. 녹화지붕은 지붕 높이, 지상 시설은 표시 지형에 맞춰 놓고 자산 경계·구멍을 보존한다. 경계선·색·아이콘·목록을 함께 사용해 색만으로 상태를 구분하지 않는다. 빗물이용조는 같은 시설 메뉴에서 건물을 선택하고 크기 버튼/슬라이더로 조절한 뒤 바로 설치한다. 지붕 집수 표시와 건물 외측 지상 탱크·연결관이 함께 나타나며 크기·비용·용량이 연동된다. 별도 지상 선택·수리 설계·계획 저장 화면으로 보내지 않는다. 위치·형상은 탐색 표시이며 현장 적합성·실제 배관을 확인한 값은 아니라는 한계는 근거 상세에 둔다.

도로 투수포장의 미리보기·확정 형상은 도로·보도와 후보 색상보다 위에 표시한다. 반투명 미리보기는 후보 색상 뒤에 그리되 상부 건물·교량의 가림을 유지한다. 계산 침수는 포장 위에서 원 수심 두께를 유지하며 겹침 방지용 표시 간격을 실측 표고·시설 두께·수문 입력으로 사용하지 않는다.

설치 위치 목록은 처음부터 종류별 선택을 제공하고 현재 보고 있는 위치에서 가까운 순으로 갱신한다. 가까운 후보를 눌러도 현 확대 비율이 갑자기 줄지 않는다. 설치·공개 시설 목록 선택은 해당 위치로 이동하며 시설 자체가 보이도록 초점을 잡는다. 공개 시설과 다른 회원/내 시설은 색·아이콘·설명으로 구분하고, 근접 시 설치자·현재 점수를 제공한다.

시간축은 설치 시각에 해당 시설 아이콘을 표시하고 같은 구간에 여러 개면 수를 표시한다. 목록/지도/시간축이 동일 설치를 가리킨다. 되돌리기·다시 실행은 편집을 허용한 설계 흐름에서만 적용하며, 확정 뒤 잠긴 주간 시설을 우회 수정하지 못한다. 서버에 저장한 revision과 클라이언트 미확정 편집은 구분한다.

회원 재해 화면의 선택한 투수포장은 기존 시설 상세에서 공개 실험의 막힘 조건 비교를 요청한다. 새 블록·협잡물 두 조건의 결과는 기존 계산 결과 안에서 펼쳐 보고, 실험 시료 면적·고정 제원·선행 7일과 전체 사건 창·청소 회복 미산정·출처를 표시한다. 현재 시간축 효과·설치비·순위와 합산하지 않으며 조건별 계산 실패는 0 대신 실패로 표시한다.

## 지도 도구·조작

자치구 선택 옆의 ‘내 위치’는 누를 때만 브라우저 위치 권한을 요청한다. 현재 좌표를 지도와 같은 EPSG:5186 지역 좌표로 변환하고 원 자치구 다각형으로 서울 내부 여부를 확인한다. 서울 안이면 주간·재해·대회의 2D/3D 지도 중심을 현재 위치로 이동하고 최대 1,000m 거리까지 확대한다. 서울 밖·권한 거부·조회 실패·시간 초과이면 기존 시야를 유지하고 닫을 수 있는 안내를 제공한다. 조회 중 중복 요청을 막으며 화면을 떠난 뒤 응답은 무시한다. 회원의 소속 구·설치·점수는 변경하지 않는다.

지도 도구 아이콘은 시설 설치 아이콘과 다르게 사용한다. 주간 과거 침수 기록 선택과 공개 시설 스위치는 지도 도구 안에 둔다. 공개 시설이 꺼져 있으면 레이어와 관련 창을 닫고 공개 시설 메뉴를 비활성화한다. 펼친 메뉴의 여백·정렬은 두 모드가 같다.

색상 범례는 초기화 오른쪽의 도움말 버튼을 눌러 펼친다. 그 오른쪽에 소리 켜기/끄기를 두며 기본은 켬이다. 불필요한 범례/도움말을 지도에 항상 펼치지 않는다.

지도 이동은 잡기 커서, 설치 가능 후보는 설치 아이콘, 기존/공개 시설은 탐색 커서다. 지도 이동·드래그 배치·슬라이더는 동작을 유지한다. 일반 화면의 이미지/링크 기본 드래그와 우클릭 메뉴는 차단하되 입력·코드 등 필요한 텍스트 선택/편집은 허용한다. 이 조작 제한은 자료 보호나 보안 통제가 아니다.

## 날씨·수면·도시

유효 무강우는 0mm, 결측/지연은 해당 상태로 표시한다. 같은 시각 유효한 구 수를 N/25로 표시하고 일부 미확인 구는 이름을 제공한다. 관측소 수를 구 수로 대신하지 않는다. 전체/현재 구의 시간·깊이·강도·관측 여부를 두 모드의 같은 디자인으로 표현한다. 강우 0만으로 강수 현상 없음까지 단정하지 않는다.

자연 하천은 청록 계열, 과거 침수흔적은 기록 색상, 계산 침수는 수심/유속 범례를 사용한다. 세 레이어 모두 물 재질을 사용할 수 있지만 흔적 자료에 시간별 깊이/유속을 만들지 않는다. 도로·인도와 겹친 침수는 포장 위에 보여야 하며 교량의 상·하층은 구분한다. 바람은 시각 물결에만 적용하고 실제 계산 유향/유속과 구분한다.

공개 기존 시설은 침수의 보라색과 혼동하지 않도록 짙은 주황색 계열로 표시한다. 2D/3D 시설 기호·영역·묶음 표시·범례에 같은 색 계열을 적용하며, 선택 상태는 공통 노란색을 유지한다. 종류별 기호·이름도 함께 제공한다.

서울 25개 구 원본의 121종 점·선·면 레이어를 모두 표시 경로에 연결한다. 가로수·조명·신호등·소화전·시설물은 공개 위치의 입체 모형, 담장·옹벽·철도·계단·보도 턱은 입체 형상으로 표시한다. 터널·지하도 입구는 열린 문틀, 잔교는 상판·지지대, 승강장 지붕은 얇은 지붕·기둥으로 표시한다. 이 구조물의 미확인 단면과 높이도 표시용 가정이다. 지명은 원본 명칭으로 표시하고, 행정·도곽·하천 경계는 경계선으로 그린다. 축소도는 100m/25m 격자별 원 건물의 대표 경계 상자이며 확대하면 원형을 순차 표시한다. 추가 표시 타일의 경계 분할과 실측되지 않은 모형 제원·교량 높이·접속 형상은 표시용이며 면적·수문 입력을 바꾸지 않는다. 1:5,000 레이어 표시는 원래 축척을 유지하며 설치 후보의 1:1,000 조건을 대신하지 않는다.

태양·낮/밤 조명은 모드의 시각을 따른다. 도로·횡단보도·보행 경로·교량·주차장은 공개 형상과 표시 가정을 구분한다. 주차장은 정차 차량을 표시하고 일반 통과 경로와 분리한다. 현재 지도는 과거 사건의 당시 도시를 복원한 자료가 아니다.

조명·가로등은 수치지형도에 기록된 위치에만 둔다. 도로를 따라 임의 간격으로 기둥·등기구·광원 효과를 생성하지 않는다. 도로·보도 면은 건물 상세 타일 제한과 독립적으로 표시하고, 겹치는 지표면의 깊이를 구분한다. 지상 설치 가능 색상은 서버와 동일한 원형 후보·허용 시설을 사용하며 도로·보도 위에서 표시하고 상부 건물·교량의 가림은 유지한다. 표시 타일을 설치 면적·현장 시공 적합성의 근거로 사용하지 않는다.

교량·육교는 상판·보행로·난간·지지 구조와 접근 경로를 표시하고 원 차로 수가 있는 도로는 차선을 표시한다. 반포대교 아래 잠수교의 표시 도로·보도와 청담대교 하부 전철의 표시 상판·복선은 상층과 분리하고 같은 지형 기준을 사용한다. 원본에 하층 외곽·높이가 없어 원 중심선·교량 외곽으로 제한한 표시 모형이며 실측 하층 형상이 아니다. 교량 원 레코드에 연결된 도로·철도 선형만 상판 높이에 맞추고 평면으로 교차하는 지상 도로는 유지한다. 접속부 측면은 얇은 상판으로 그려 하층을 막는 지면까지의 수직 벽을 만들지 않는다. 공개 자료로 확인한 교량 구조 종류를 반영하되 실측되지 않은 치수·위치는 표시 가정으로 구분한다. 산의 지형과 경사면 건물은 불투명한 면으로 표시하며 축소 배경은 상세 타일 로드 중에도 유지한다.

설치 후보 이름은 확인되는 건물명+옥상, 도로명+도로 또는 지물 종류를 사용하고 같은 구역 내 구별 번호를 붙인다. 확인되는 도로명 주소는 이름 바로 아래 표시한다. 주소가 없으면 추정 주소를 만들지 않는다. 주차장 후보는 별도 필터와 투수포장 선택을 지원하며 기존 후보·건물·교량·수면 등과 중복된 면적을 다시 배분하지 않는다.

게임의 ‘지도 자료·표시 범위’ 펼침 버튼·설명 영역과 2D/3D 사선 피복 레이어를 제거한다. 자료 출처·적용 범위는 홈의 자료와 계산 근거에서 제공한다. 원 도곽 밖의 건물·도로·수면을 임의 생성하지 않으며 지물 로딩 중·조회 실패 상태는 유지한다.

생활인구·공개 장소 속도는 차량/보행자 표시의 참고 입력이며 모든 사람/차량의 관측 위치가 아니다. 2022 사건의 확보 인구, 현재 공개 장소 자료, 참고 프로필, 2010/2011 미확보를 구분한다. 침수 접촉 시 감속·정차·회피/대피·고립 표현은 원 수문 계산과 피해 점수를 바꾸지 않는다.

## 소리·재생

빗소리·침수 물소리·가까운 차/보행자·설치 효과음을 제공한다. 확대/거리와 대상 존재 여부에 따라 음량을 조절하며 무조건 지도 전체에서 같은 음량으로 재생하지 않는다. 브라우저 정책에 따라 첫 사용자 조작 뒤 오디오를 시작한다. 사용자 음소거 선택은 기기에 보존한다.

환경음은 AudioWorklet의 연속 합성으로 짧은 파일 반복 경계의 끊김을 피한다. 재해 일시정지는 환경음도 멈추고 배속은 같은 사건 시계에 맞춰 소리 진행에 반영한다. 숨긴 탭·장면 종료 시 재생/자원을 정리한다. 합성 음향은 실제 현장 소음 관측이 아니다.

## 반응성·접근성·복구

첫 접속과 사용 중 서버 연결이 실패하면 기존 로고·수달 여울이·물총새 가람이를 사용한 공통 오류 화면을 표시한다. 청록 버튼·중성 배경 등 게임 외 공통 디자인을 따르며 내부 오류 문구를 노출하지 않는다. ‘다시 연결’ 버튼과 자동 확인 상태를 제공하고 확인 중 중복 클릭을 막는다. 게임 전체화면에서도 안내가 보이며, 연결이 복구되면 새로고침 없이 이전 주소·화면 상태로 복귀한다. 지도/WebGL 상태는 유지하고 3D 프레임·음향과 재해 재생은 일시정지한다. 복구 후 재해 재생은 사용자가 다시 시작한다. 실패한 설치·제출을 자동 재전송하지 않으며 저장 성공으로 표시하지 않는다. 오류 제목으로 초점을 이동하고 상태 변경을 읽어 주며 모션 축소를 지원한다. 로그인 만료·권한 거부·개별 자료 오류와 서버 연결 단절은 구분한다.

지도 이동·확대·재생·점수 갱신 때문에 건물/도로/시설을 전체 해제하거나 물리 계산을 다시 요청하지 않는다. 새 형상이 준비될 때까지 이전 유효 형상을 유지한다. 시야별 로딩·요청 취소·Worker·상한이 있는 캐시·인스턴싱·GPU 해제로 자원을 관리한다. 상세 구현은 [지도 복구·캐시](04-architecture.md#지도-장애-복구와-캐시)를 따른다.

첫 접속은 기존 지도 준비 화면에서 공개 기본 자료를 읽고, 이동 후 주변 자료 준비 상태를 표시한다. 공개 도시 지도는 최대 256MiB의 전용 기기 캐시와 백그라운드 해석·검증을 사용한다. 캐시를 사용할 수 없는 기기도 네트워크 조회로 계속 동작한다. 기존 표시 범위·건물·도로·지형지물·입자 수를 줄이지 않고 원 자료를 재사용하며, 물리 입력·점수·실시간 관측은 이 공개 지도 캐시에 넣지 않는다.

WebGL 실패 시 설계 상태를 보존하고 재시도·평면도·목록 선택 대안을 제공한다. 키보드 포커스·입력 레이블·비활성 사유·좁은 화면의 넘침을 점검한다. 강제 안내 단계·의미 없는 계산 대기 문구 대신 실제 오류/진행 상태와 가능한 다음 동작을 제시한다. 성능 수치는 실제 기기 측정과 함께 기록하며 타이머 목표를 보장 FPS로 주장하지 않는다.

## 홈 하단 데이터

데이터 메뉴·별도 페이지는 두지 않고 아래 내용을 모두 홈 마지막 콘텐츠 `/#home-data`에 배치한다. 홈의 기능 소개·하단 링크로 바로 이동할 수 있으며 기존 `/data` 방문은 해당 위치로 주소를 교체한다. 해시 이동·직접 접근·뒤로/앞으로 이동을 보존한다.

현재 서울 지도·두 게임 모드의 기상·침수 기록·공개 시설·도시자료·시설 제원/단가·개인 예산과 계산 범위를 제공한다. 초기 성수 연구 모델의 건물 수·예산·3종 단가를 현재 게임 정보로 표시하지 않는다. 출처 링크와 적용 시점/범위를 항목별로 제공하고 슬로건·수식 문구는 사용하지 않는다. 설치비는 현재 공통 비용 자료, 예산은 서버 정책을 사용하며 미조회 값을 임의 금액으로 채우지 않는다.

주간·재해의 비용 근거에는 전체 생애주기비용의 미산정 사유를 함께 표시한다. 공개 관망 이용조는 기존 견적별 상세 안에 문헌 가정의 부분 현재가치·기간·할인율·연차별 비용·민감도를 제공한다. 부분 비용을 전체 설치비로 표시하거나 별도 비용 순위로 사용하지 않는다.

각 자료 카드에는 실제 사용하는 데이터셋·문헌명을 기본 화면에 표시하고 해당 자료의 상세 페이지를 이름에 연결한다. 제공기관명이나 포털 홈 링크만으로 데이터명을 대신하지 않는다. 여러 자료를 쓰는 항목은 개별 이름·식별자와 적용 연도/범위를 나열하며 계산 엔진·설계 문헌은 관측 데이터와 구분한다. 예산과 설치비 근거에도 서버 정책과 원가 기록의 전체 자료명을 표시한다.

현재 서울 25개 구 지도는 ‘2026-03-07 갱신 수치지형도’로 표시하고 데이터셋 상세 페이지를 연결한다. 배포 갱신일과 도엽별 제작연도·촬영연도·취득시각을 구분한다. 1:1,000 도곽 피복·1:5,000만 있는 범위·미피복과 공통 Loam/경사 설계 가정을 표시하며, 90m DSM을 현장 배수 지형으로 설명하지 않는다. 원형 대응·미확인 속성 근거는 [공간 검사](19-spatial-source-audit.md)를 따른다.

시설 설치 메뉴의 아이콘 정의를 건물 선택창·설치 목록·타임라인·2D 지도 기호에서 공유한다. 시설 버튼에는 짧은 용도 설명만 표시하고, 잔액은 사업 예산 바로 아래에 해당 사업의 `remainingKrw`를 한 번 표시한다. 주간 설치와 재해 배치에서 각각 해당 예산 원장을 사용하며 미설정 사업 금액을 생성하지 않는다.

## 경로·게임 전체화면 · 2026-10-21

주요 페이지는 독립 URL과 링크로 이동한다. 기록 경쟁은 랭킹으로 이름을 바꾸고 기관 리그 탭을 제거한다. 대회와 관리자 결과 화면은 기존 색·둥근 조작부·표·폼 스타일을 공유한다. 전체화면 버튼은 게임 내부 시간 조작부 바로 오른쪽에 두고 게임 상단 상태 바·지도·게임 조작부를 포함한 영역만 확대한다. 사이트 로고·주 메뉴·로그인은 전체화면에 포함하지 않는다. ‘사선 영역: 상세 지도 미지원’ 부유 안내 박스·사선 미지원 영역과 ‘지도 자료·표시 범위’ 펼침 영역은 제거한다.


### 원 교량과 지면 사본의 분리·철도 운행 표시 (2026-10-21)

- 한 원 도로·보도를 교량 상판과 지면에 중복 표시하지 않는다. 교량·접속부의 표시 면과 원 도시 수면의 교집합에서 지형지물 도로/보도/철도/교차로/안전지대 지면 사본과 경계선을 절단한다. 표시용 접속 경사로는 수면 안으로 연장하지 않는다. 원 도로 중심선으로 교량 아래에 별도 통행 면을 만들지 않는다. 육상 하부 통과 도로와 원 수면 구멍은 보존한다. 반포·청담의 별도 하층은 기존 출처와 표시 가정을 유지한다.
- 레일은 원 철도 레이어에서 한 번만 생성하고 열차 모형·교량 접속부에서 다시 만들지 않는다. 수면 위 원 교량 면의 레일과 이동체는 같은 상판 기준을 사용한다. 조명·도로분리대·난간·울타리도 수면 위 교량 면에 한 번만 배치한다. 상판으로 뒷받침되지 않는 수면 접속 부분에는 부속물을 생성하지 않는다. 층 속성이 없는 부속물의 상판 배정과 모든 높이는 표시 가정이다.
- 이름이 없는 상판을 평면 교차만으로 다른 방향의 교량에 합치지 않는다. 노들섬 남쪽 한강대교와 노량대교를 분리하고, 노들섬 양쪽 한강대교의 두 차로 방향별 원 끝점 그래프 연결을 확인해 높이 기준을 공유한다. 원 외곽을 메우거나 새 도로를 만들지 않는다.
- 원 보도 면으로 제한한 교량 접속 보도와 접속부 차선을 표시한다. 접속 도로 면이 없는 교량도 원 중심선과 차로 수를 버리지 않는다. 일반 도로는 일관된 원 차로 수가 있을 때만 차선을 표시하며 원 도로 면 밖으로 도색하지 않는다. 차선 생성은 원 도로 중심선 한 곳에서 담당하며 교량 전체의 최대 차로 수로 중복 도색하지 않는다. 차량과 도색은 원 도로별 폭·차로 수를 공유한다. 차선 폭·간격과 원 폭이 없을 때 사용하는 3.25m 차로 폭은 표시 가정이다.
- 지상 지하철·일반철도의 원 선형과 끝점 연결을 따라 표시용 열차가 이동한다. 청담 하층의 투영 선로는 기존 표시 가정으로 구분한다. 원 운행 시각표·실시간 위치·실제 열차 수를 제공하지 않는다. 지도 범례에 표시용 운행임을 명시한다. 노선별 각 방향 최대 1편성·편성당 최대 4객차(화면 전체 최대 128객차), 객차 길이 18m·간격 20m, 지하철 10m/s·철도 12m/s는 표시 제원이다. 기존 재생/정지·시간 탐색·동작 줄이기를 따른다.
- 도로와 열차 표시 자료는 전용 Worker에서 크기·스키마·원 도시 버전·SHA-256을 검증한다. 지면 절단 결과 캐시에는 교량 버전을 포함한다. 화면 표시 변경은 설치 가능 면·수문 계산·관측·피해 통계에 사용하지 않는다.

지면 제외는 원 도시 수면 4,112개 면과 교량 전체의 통행면 소유 범위를 함께 사용한다. 육지·섬·접속 경사로에서도 상판에 표시한 같은 도로·보도·철도 면과 경계·도색·부속물을 지면에 다시 생성하지 않는다. 도로교·철교·보행교의 통행 종류를 구분하고, 원 중심선이 교량을 횡단하는 별도 하부 도로는 원 도로폭과 도로면으로 제한해 보존한다. 지하차도 분류를 고가 상판으로 만들지 않는다.

섬 양쪽의 교량 사이에는 원 도로 끝점 그래프에서 수면을 통과하지 않는 연결 경로가 확인되는 경우만 원 도로면 안에서 접속면을 표시한다. 직진 연결 대신 유턴 선형을 탐욕적으로 선택해 끊기는 것을 방지하며, 섬 위를 단순 통과하는 교량에는 섬으로 내려가는 접속로를 새로 만들지 않는다. 수면 경계의 섬 구멍 자체는 보존한다. 지상 철도·차량·보행 표시도 수면에서 받치는 교량 면이 없는 구간에는 생성하지 않는다. 이 표시 소유권과 높이는 현장 측량이나 실제 통행 가능성 판정이 아니다.

교통 표시 일관성: 도로 면과 별도로 고정 폭 중심선 포장을 중복 생성하지 않는다. 교차로 내부에는 직진 차선 도색을 이어 붙이지 않고 원 도로 면과 교차로 면의 접합을 유지한다. 차량은 표시 차로의 중앙과 우측 통행 방향을 함께 사용하며 양방향 도로에는 두 방향의 이동체를 배치한다. 열차는 원 선로의 평행 관계로 방향을 배정하고 동일 단선 위에 서로 마주 오는 편성을 동시에 만들지 않는다. 운행 속도·방향 배정은 실시간 교통 관측 또는 운행 시각표가 아닌 표시 가정이다.

터널 면·입구 선형은 지상 도로와 구분한다. 원 터널 영역 내부의 도로·차선·이동체를 산이나 지표면 위에 덧그리지 않고, 원 입구에서 연결되는 표시용 통로를 사용한다. 단면과 입구 사이 표고 보간은 표시용이며 실측 터널 표고나 통행 가능성의 근거가 아니다.

서울 자치구 선택 바로 아래에 ‘설치 가능 구역 표시’ 토글을 둔다. 초기값은 꺼짐이며 지상·옥상 후보 색상을 2D와 3D에서 함께 제어한다. 기존 시설, 선택한 위치와 설치 미리보기, 후보 선택과 서버 설치 조건 검증은 유지한다.


같은 원 중심선을 공유하는 서로 다른 교량 그룹의 접속면도 한 번만 그린다. 별도 방향의 입체 교차는 유지한다. 접속 경로가 상대 상판 안으로 연장된 경우 침투 길이를 제외한 실제 상판 간격으로 높이를 보간하며, 같은 이름·통행 종류와 원 도로 연결이 확인된 분리 상판은 높이 기준을 공유한다. 난간·레일 부재의 양옆 모서리는 중심선 높이를 공유해 상판 경계에서 한쪽만 지면으로 꺾이지 않게 한다.


양화대교 남단 하부 횡단부에서는 상부 안전지대와 실제 하부 도로가 같은 평면 위치에 겹친다. 하부 도로 보존 영역을 모든 객체에 일괄 적용하지 않고, 원 레코드별 상부 도로·안전지대 소유 범위를 별도로 절단한다. 상부 보도도 하부 차도 보존 영역과 무관하게 지면 사본을 제거한다. 교량 외곽과 원 난간 사이의 작은 간격은 최대 0.3m의 표시 귀속 범위로 처리하며 원 난간 좌표를 이동하지 않는다. 평면 횡단 난간은 방향을 대조해 하부에 유지한다. 이는 층 속성이 없는 자료에 대한 표시 가정이다.

진입로 끝점이 다른 원 접속 경로의 중간 정점에 정확히 합류하면 해당 지점의 높이를 공유한다. 같은 원 경로에서 상판 끝점이 일치하는 무명 인접 교량도 높이 기준을 공유한다. 평면 교차만으로 다른 층의 도로를 연결하지 않는다.

열차 편성은 전체 원 철도 자료에서 노선별로 배정한 뒤 시야에 있는 편성만 표시한다. 원 선분마다 편성을 새로 생성하지 않으며 같은 노선의 각 방향에는 최대 한 편성만 존재한다. 서로 떨어진 원 선형 사이에 가상 연결선을 만들지 않고, 이전 편성이 완전히 빠져나간 뒤 다음 경로를 표시한다.

설치 가능 구역 조작부는 체크박스 외형을 사용하지 않는 손잡이형 스위치이며 기본 꺼짐·키보드 조작·현재 상태 읽기를 지원한다. 연속·순환 진입로의 합류 높이는 전체 연결 그래프의 고정점을 사용하며 연결 계산 순서에 의존하지 않는다. 도로교 난간은 원 C053 레이어가 생성하며 표시 접속면의 절단 경계에 별도 난간을 생성하지 않는다.
