# 3D·UX 설계

## 시각 방향

도전 선택 → 3D 플레이 → 결과 → 재도전의 전략 게임 흐름. 큰 목표 문구, 실제 관측 이벤트와 원화 예산, 시설 배치에 대한 즉시 피드백. 잉크색 도전 화면과 밝은 도시의 대비, 플레이 중 지도 중심 배치. 상세 계약은 [게임 흐름](30-gameplay-loop.md) 참조.

실제 footprint, 근거 있는 높이와 미확보 표시. PBR 재질·일관된 태양광·접지 그림자·외곽선·시설 단면으로 입체감. 사선 조감·탑뷰·셀 확대, 카메라 범위 제한. 시각화용 형상과 계산 입력 구분.

## 조작·설명

위치 선택 → 시설·면적 → 강우 비교의 3단계 온보딩. 쉬운 설명과 정확한 단위 병기, 기술 상세는 확장 패널. 실측·모델·가정은 색상과 텍스트로 구분.

hover·선택·미리보기·면적·확정·삭제·undo/redo. 제한 이유 구체화, 서버 거부 시 입력 복구. 키보드 셀 목록·버튼·focus·label·오류 연결.

계산 전에는 면적·예산만 표시. 근사 점수를 공식 성과로 표시 금지. 큐·실행·품질거부·실패 구분. 물결은 설명용, 검증된 2D 수리모델 없이 침수깊이 생성 금지. 임의 랭커·효과 수치 금지, 빈 상태 명확히 표시.

## 품질

1080p 일반 노트북 조작 30fps 이상·목표 60fps, 측정 기기·브라우저·맵 규모 기록. DPR 상한·인스턴싱·LOD·지연 로딩·dispose. WebGL 미지원/context loss의 목록·2D 대안. reduced-motion·자동회전 해제, WCAG 2.2 AA 목표의 대비·키보드·탭·그래프 텍스트 대안. 작은 화면 패널 전환, 넓은 기관 비교 화면 제공.
