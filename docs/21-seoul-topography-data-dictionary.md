# 서울 수치지형도 1:1,000 데이터 설명서

현재 WATER LEAGUE에서 사용하는 서울 25개 구 `수치지형도v2.0(1:1000)`의 해석을 위해, 제공된 「전국 연속수치지형도 코드 및 레이어 설명서」에서 **1:1,000에 해당하는 내용과 공통 정의만** 정리한 문서다. 원문 153쪽을 확인했으며 1:5,000·1:25,000 전용 레이어·속성 코드·통합 코드는 제외했다.

아래 레이어·속성·코드 표는 **설명서의 DB 설계 정의**다. 실제 확보한 서울 SHP/DBF에 모든 항목이나 값이 존재한다는 뜻은 아니다. 현재 파일의 구조·좌표계·적용 범위는 [서울 공간 원자료 계약](19-spatial-source-audit.md), 출처와 원본 해시는 [자료 출처](03-data-provenance.md)와 [원본 목록](../data/manifests/vworld-seoul-topography-20260307.json)을 함께 따른다.

## 레이어 명명 규칙

원문 2쪽. 일반 형식은 `N①②_③xxxxxxx`, 현재 대상 축척의 형식은 `N1{공간형태}_{통합코드 8자리}`다.

| 부분 | 1:1,000에서의 의미 |
| --- | --- |
| `N` | 원문 레이어명 접두 문자 |
| `① = 1` | 축척 1/1,000 |
| `② = P` | 점형 |
| `② = L` | 선형 |
| `② = A` | 면형 |
| `③xxxxxxx` | 지형지물 분류 문자와 코드번호로 이루어진 통합코드 8자리 |

| 분류 문자 | 분류 |
| --- | --- |
| `A` | 교통 |
| `B` | 건물 |
| `C` | 시설 |
| `D` | 식생 |
| `E` | 수계 |
| `F` | 지형 |
| `G` | 경계 |
| `H` | 주기 |

예: `N1A_B0010000`은 1:1,000·면형·건물 레이어이고, `N1L_F0010000`은 1:1,000·선형·등고선 레이어다. 레이어명 뒤 8자리와 개별 객체의 `SCLS` 값은 구분한다. 하나의 레이어에 여러 통합 코드가 정의될 수 있다.

## 속성·코드 공통 해석

| 표기 | 해석 |
| --- | --- |
| `항목ID` | 원문 DB 설계의 속성 식별자 |
| `VARCHAR2(n)` | 원문 Oracle DB 설계의 문자열 타입·길이 표기. SHP DBF의 실제 타입·필드 길이와 동일하다고 가정하지 않음 |
| `NUMBER(p,s)` / `NUMBER(p)` | 원문 수치 타입·정밀도 표기. 이 표기만으로 길이·높이·면적의 단위를 확정하지 않음 |
| `PK` | 원문 기본키 지정 |
| `NN` | 원문 Not Null 지정 |
| 빈 `Not Null` 칸 | 원문에 NN 지정 없음. 실제 DBF 값의 유효성 판정과 구분 |
| `참조` | 아래 항목 설명 또는 관련 코드 정의 참조. 설명서에 코드표가 없는 항목은 임의 생성하지 않음 |
| `UFID` | 원문에서 `VARCHAR2(34)`, PK·NN으로 정의한 식별 필드. 실제 원자료의 공백·중복·도엽 분할 여부는 별도 검사 |
| `SCLS` | 해당 지형지물의 통합 표준코드. 자료형은 각 명세의 원문 표기를 따름 |
| `FMTA` | 기본도 제작정보를 참조하는 일련번호. 참조 테이블은 `SL_PRODUCT_INFO` |

**제작정보 공통 설명:** 원문은 “기본도 제작정보를 참조하는 일련번호 (SL_PRODUCT_INFO)”, “각각의 정기/수시 갱신 영역에 포함되는 지형지물 객체에 일련번호 부여”로 설명한다. `SL_PRODUCT_INFO` 자체의 테이블 명세는 이 설명서에 제시되지 않는다. `FMTA`를 제작연도나 최신성 보증으로 바꾸어 해석하지 않는다.

코드표의 `미분류`, `기타`는 원문에서 정의한 값이다. 결측·알 수 없는 코드와 합치거나 0으로 치환하지 않는다. 원문에 축척 구분이 없는 코드표는 공통 정의로 포함하고, 축척 구분이 있으면 1:1,000에 명시된 행만 포함했다. 축척 코드 `SCAL`은 `SCA000`(미분류)과 `SCA001`(1/1,000)만 수록한다.

## 원문 대조 범위

1:1,000 지형지물 104종·레이어 105개, 속성 명세 636행, 공통/1:1,000 코드 정의 802행을 수록했다. 코드 행 수는 레이어·항목별 중복을 포함한 정의 행 수이며 고유 코드 개수가 아니다. 모든 명세의 원문 쪽, 필드 순서·자료형·제약, 다음 쪽에 이어지는 축척별 코드 범위를 대조했다. 이 확인은 문서 전사 범위의 검증이며 서울 SHP의 현장 정확도·피복 완전성·모든 DBF 값의 의미 검증과 구분한다.
