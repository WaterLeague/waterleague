# 시설 입체 표현·배치 미리보기

2026-10-17. 문서 30의 지도 중심 플레이 후속 작업. 지리적 확장과 시설 표현 개선은 별도 범위.

## 현재 지도 범위

성수 약 0.3km 블록을 첫 시험 구역으로 선정한 상태이며 공개자료가 이 지역에만 존재하는 것은 아니다. [환경공간정보서비스](https://aid.mcee.go.kr/api/land.do)는 2024·2025년 전국 세분류 토지피복 레이어를 제공한다. 다른 지역의 원본 취득·이용조건·정합성 검사는 별도 필요하다. 화면 확장만으로 연구 가능한 유역 모델이 되지 않으며 지형·관망·토양·관측 유출의 지역별 검증이 필요하다. 현재 성수도 EXPLORATORY 유지. 취득한 DEM·피복의 편입 조건은 문서 28 기준.

## 표시 계약

- 공개 건물·도로·후보 구역 좌표와 시설 종류·면적·비용·수문 입력은 유지한다. 시설 표면과 낮은 입체 두께·식재는 구분을 위한 도식 표현이며 실제 시공 형상이나 관측 식생이 아니다.
- 시설 위치는 후보 구역 안의 면적 비율 표시다. 사용자가 정한 정확한 시공 위치, 토양층 두께 또는 배수 경로로 해석하지 않는다. 화면에 이 범위를 표시한다.
- 중심점 기준 축소는 오목한 구역 경계를 벗어날 수 있으므로 사용하지 않는다. 단순 링을 삼각 분할한 뒤 동일한 절단선으로 잘라 원래 구역 안에서 목표 비율만큼 표시한다. 목표 비율은 입력 면적/모델 구역 면적이며 투영 도형 면적을 모델 면적 대신 쓰지 않는다.
- 3D와 2D는 같은 표시 도형을 공유한다. 단순 링만 지원하며 비유한 좌표·자기교차·퇴화·범위 밖 면적은 공통 오류 경로로 전달한다. 구멍·다중 외곽선은 지원 계약 확장 없이 수용하지 않는다.
- 빗물정원·옥상녹화·투수포장을 색상과 표면 패턴으로 구분한다. 식재 도식은 경계 안에만 배치하고 개수를 제한한다. 임의의 관측 수목이나 침수 효과를 추가하지 않는다.

## 편집 상태

선택한 시설·면적이 제약을 만족하고 확정 배치와 다를 때만 미확정 미리보기를 표시한다. 편집 구역의 확정 도형 대신 반투명 도형·점선·미확정 설명을 표시하고, 확정 배치 수·예산·점수·저장 이력은 바꾸지 않는다. 배치 버튼을 누른 뒤 확정 상태로 전환한다. 리그/구역 제한과 실제 적용하는 소수 둘째 자리 면적을 미리보기에도 동일하게 적용한다. 잘못된 입력은 미리보기에서 제외한다. 연구 화면에는 미리보기를 전달하지 않는다.

## 검증 기준

실제 13개 구역과 오목한 시험 도형의 포함·면적 비율·결정성·원본 불변·잘못된 입력 거부 검사. 브라우저에서 세 시설, 면적 편집, 미확정/확정 비용 구분, 되돌리기, 2D 전환, 그래픽 연결 복구 확인. 기존 demand 렌더·reduced-motion 유지와 렌더/정지 성능 측정. 계산 모델·랭킹·공개자료 hash 불변 확인.

구현 근거: [Three.js ShapeUtils](https://threejs.org/docs/pages/ShapeUtils.html), [InstancedMesh](https://threejs.org/docs/pages/InstancedMesh.html).

## 검증 결과

- 프런트 70개 검사 통과. 신규 5개는 실제 성수 13개 구역의 0.01 m²/40 m²/최대 면적, 오목한 링·반대 방향·분리된 절단면, 외곽 길이, 결정적 식재 개수/내포, 자기교차·퇴화·비유한 좌표·미소 면적/범위 위반 검사. 타입·프로덕션 빌드·포맷 통과.
- 실제 브라우저에서 G1 빗물정원 60 m², R1 녹화지붕 120 m², G3 투수포장 60 m² 확정. 확정 전에는 예산/배치 수 불변, 확정 뒤 세 시설 비용 71,400,000원 확인. G3 81 m² 입력 시 미리보기 제거·버튼 차단, 70.126 입력 시 표시/적용 면적 70.13 일치. 되돌리기 60 → 다시 실행 70.13 확인.
- 3D/2D 동일 배치·미확정 설명, 입력 50 m²의 미확정 상태에서 계산 버튼의 ‘확정된 배치로 도전’ 표시. DOM 유효 폭 400px에서 가로 넘침 없음. 요청한 브라우저 폭과 실제 CSS 폭은 구분하며 모바일 실기기 검증은 미완료.

## 2026-10-19 설치 후보·선택 표시 통일

설치 메뉴의 열림 상태와 관계없이 검증된 옥상은 상단 면, 지상·주차장·도로·인도 후보는 옅은 면과 경계로 표시한다. 후보는 민트색, 선택 구역은 노란색을 공통 사용한다. 시설 유형 필터는 다른 후보·건물·기존 시설을 제거하지 않고 투명도를 낮추며 공개 시설 건물도 유지한다. 후보 목록의 필터·페이지와 주변 지도 후보 조회를 분리하되 동일 기본 조회는 재사용한다. 흐린 후보도 직접 클릭하여 허용된 시설을 확인할 수 있으며 로그인·소속 구·서버 설치 검증은 유지한다.

선택 표시는 설치 미리보기와 독립된 전체 후보 경계이며 0~100% 면적 변경으로 크기·색상이 바뀌지 않는다. 3D는 선택 면·외곽선을 시설 미리보기 위에, 2D는 시설·강우/침수 레이어 다음에 표시한다. 이 표시는 선택 UI로서 수면 높이·시설 치수·배치 면적·계산 입력을 변경하지 않는다. 선택하지 않은 후보는 지형 깊이 판정을 유지한다.

## 2026-10-19 전체 설치 후보 표시와 닫기 동작 보완

목록의 가까운 200개 조회는 탐색용으로 유지하고 지도 후보 표시는 분리한다. 검증된 v9·v10 원문에서 공개 시설 점유 제외 후 지상 후보 547,476곳을 1km 표시 타일 648개로 생성한다. `site-display-v1`은 시설별 허용 유형 비트와 원 후보 좌표(표시 소수 셋째 자리)만 담으며 설치 요청·면적·물리 입력은 기존 서버 원문을 재조회한다. 모든 타일의 해시와 원문 카탈로그·점유 제외 목록 해시를 매니페스트에 보존한다.

기본 상태에는 옥상·차도·인도·주차장 등 검증된 전체 후보를 민트색으로 표시한다. 유형 선택 시 허용 후보만 민트색이며 나머지는 중립색·낮은 불투명도로 남긴다. 본인 점유·소속 구 제한과 공개 시설 제외는 유지한다. 상세 구역은 메뉴를 열지 않고 직접 선택할 수 있다. 시설 확충·위치 목록·선택 위치 상세의 닫기는 유형·표면 필터·미확정 선택을 함께 해제하고 전체 후보 표시로 복귀한다. 확정 시설과 저장된 설계는 유지한다.

거리 5km 이상의 전체 보기에서는 모든 후보가 포함된 20m 격자 범위의 합집합을 표시하고 내부 구멍을 보존한다. 이는 원거리 가독성용 범위이며 시공 경계·설치 면적이 아니다. 개요의 합쳐진 면을 임의 시설 ID로 선택하지 않으며, 확대하면 동일 화면의 상세 원 후보로 교체한다. 개요 1,617개 다중 구역·6,085,021 bytes. 기본 후보와 선택된 전체 노란 경계는 별도이므로 미리보기 면적 100%에서도 노란 강조가 유지된다.
