# 배치 구역별 공개 피복 정합 검사

2026-10-17. 문서 28의 도엽·시험 블록 품질 검사에서 현재 13개 배치 구역의 정합 검사로 확장한다. 원본 피복 분류와 도형을 물리 침투율·불투수율·설치 적합성으로 치환하지 않는다.

## 입력과 경계

- 등록된 성동083 토지피복 ZIP, 현재 OSM 스냅샷과 기본 성수 모델을 해시로 고정. 파생 지도 hash·OSM 원문 hash·모델 카탈로그 hash 일치 후 검사. 원본 변경·자동 모델 생성 없음.
- 옥상 후보는 `buildingId`로 연결한 OSM WGS84 원형상 사용. 화면용 근거리 투영 좌표를 공식 면적으로 취급하지 않는다. 원문 지오데식 면적·모델 면적·피복 좌표계 면적을 분리한다.
- 지상 후보는 가정된 10×10m 화면 패치이다. 생성기의 근거리 투영식을 역변환해 위치를 대조하며 측량한 지상 경계로 표시하지 않는다. 역변환식·원점·반올림 정밀도·가정 출처 보존.
- 원문 피복 PRJ와 대상지 변환 연산을 그대로 기록. 좌표 epoch·영상/OSM 시점 정합 부족을 정밀도 0으로 숨기지 않는다. 전체 배치 경계와 블록 경계 밖 면적을 각각 보고한다.

## 교차와 판정

원본 유효 도형만 사용한 결과와 `make_valid`의 linework/structure 후보 결과를 나란히 계산한다. 잘못된 도형의 envelope가 구역과 겹치는지, 보정 도형이 실제로 영향을 주는지 구분. 보정 후보를 원본 관측으로 표시하지 않는다.

각 구역에 대해 원문 L3 코드·이름·IMG_DATE, 겹친 면적의 합·합집합·중복·미피복, 피복률, 교차 원도형 식별/해시를 로컬 보고서에 보존한다. 경계에 닿기만 한 도형은 면적 교차에 포함하지 않는다. 분류 간 중첩도 합계의 오류로 감추지 않고 별도 표시한다. 두 보정 방식의 구역 내·분류별 대칭차 기록. 계산상의 피복률·일치는 현장 분류 정확성 또는 2024년 강우 당시 상태의 승인과 별개다.

옥상/지상 후보끼리 겹친 면적도 검사하여 독립 표면의 중복 모델링 위험을 드러낸다. OSM 건물과 토지 이용 분류가 다르다는 사실만으로 어느 원본을 오류로 판정하지 않는다. 분류의 의미·축척·취득 시점이 다를 수 있다.

## 저장과 검증

상세 좌표·속성은 기존 비공개 자료 경로에만 저장, 출력 덮어쓰기·링크 거부. 공개 산출물은 코드·원본/모델/결과 hash·검사 건수와 한계 요약. `modelEligible=false`, `calibrationEligible=false` 유지. 신규 운영 모델은 이용조건·정합·설치 제약·배수 연결 검토 후 별도 버전으로 작성.

검사는 실제 원본 반복 실행의 결정성·원본/모델 불변, 옥상과 가정 패치의 좌표 경로 구분, 중복/결측/경계 접촉, 구역 밖 오류의 비영향, 후보 차이·속성 오류 거부를 포함한다. 원본 피복을 사용하는 로컬 교차 검증과 합성 도형 단위 검증의 범위를 구분한다.
