## 일괄 전달 방식과 완료 추적

사용자가 바로 처리할 수 있는 다운로드는 B01 네 도엽과 동봉 문서다. 시간이 걸릴 수 있는 B03~B08 기관·학교 협력과 C01~C05 운영 접근 준비도 지금부터 같은 목록으로 관리한다. 아직 없는 자료는 `미보유/제공 불가/확인 중`으로 남기면 되며 존재하지 않는 파일을 계속 찾아 달라고 요구하지 않는다.

한 번에 전달할 비밀 제외 요약: `지도 ZIP 저장 경로 / 협력 가능한 학교·기관 유무와 자료 보유 여부 / Oracle SSH 별칭·운영 변경 범위 / 도메인·DNS 담당 / 메일·백업 서비스 준비 상태 / 운영 담당·검토자·시험 참여 가능 여부 / 공개되지 않은 공모전 양식 유무`. 실제 비밀값·명단·기관 개인정보는 공개 이슈/문서에 적지 않는다.

이 문서는 2026-10-17 기준 확인 가능한 전체 의존성 목록이다. 이후 파일 검사에서 범위/정밀도 부족 또는 제공 정책 변경이 발견되면 해당 ID에 구체적인 차이를 기록하고 변경분을 묶어 알린다. 이미 완료한 항목을 처음부터 다시 요구하지 않는다.
