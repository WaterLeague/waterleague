# CPU 탐색 기준안·강우별 결과

2026-10-16. 계약: [0008](decisions/0008-reference-comparison.md). 실제 EPA SWMM 5.2.4 계산 결과. 현장 미검증 EXPLORATORY.

## 고정 탐색·비교

성동 421의 2024-07-18 104mm 창에서만 후보 선택. 10m² 증분으로 추가 원당 평가체적 저감이 큰 배치를 채택하는 결정적 탐욕 탐색. 기존 셀 시설 유형 교체를 탐색하지 않으므로 전역 최적해 아님. 모든 예산의 배치를 확정한 뒤 6월 22일·7월 2일과 같은 날 서울 108에서 계산. 별도 강우 입력의 비교이며 독립 유출 관측 검증 아님.

| 예산 상한 | 배치 비용 | 배치 | 선택 단계 | 후보 요청 수 | 네 강우 점수 최저–최고 |
| --- | ---: | --- | ---: | ---: | --- |
| 30,000,000원 | 29,700,000원 | G1~G3 투수포장 각 50m², G4~G5 각 60m² | 27 | 356 | 3.35363075–3.61596917 |
| 100,000,000원 | 33,000,000원 | G1~G5 투수포장 각 60m² | 30 | 424 | 3.57760484–3.66994221 |
| 300,000,000원 | 33,000,000원 | G1~G5 투수포장 각 60m² | 30 | 424 | 3.57760484–3.66994221 |

실제 고유 후보 424개, 중복 캐시 포함 요청 1,204회. 같은 배치는 한 번 계산한 값을 재사용. 모든 비교의 물수지 오차 절대값 1% 이내. 최저/최고는 선택된 관측 창의 기술 통계로 신뢰구간 아님. 큰 예산에서 미사용액이 남았다는 사실은 현실에서 추가 투자 효과가 없다는 결론이 아니다.

평가체적 = 기간 유출 + 최종 잔여저류 − 초기저류. 점수는 기준안 대비 평가체적 감소율. 다른 강우에서 악화될 경우 음수 보존. 탐색 개선 문턱은 SWMM 보고서의 깊이 반올림·체적 차분 오차를 고려하며 원장에 값 기록.

## 사용·계보

- 기록 경쟁 → CPU 기준안: 세 예산의 선택 단계·면적·비용·강우별 점수·평가체적·종료 저류·수지 오차 표시
- 현재 선택한 호환 모델의 새 개인 설계로 배치 복사, 이후 별도 저장·계산·공개 제출
- 사람 순위나 회원 기록에 CPU 결과를 자동 삽입하지 않음
- `GET /api/v1/references`: 보고서와 원문 해시. `/source`, `/ledger`: 보고서·후보 원장 다운로드
- `data/derived/cpu-reference.json`, `cpu-search-ledger.json`: 배포용 근거. 서버 리소스 원문과 바이트 일치
- 보고서에 탐색 알고리즘·생성기·엔진 빌더·엔진 바이너리·입력 모델·후보 원장·각 결과/manifest의 해시 및 계산 환경 기록
- 전체 엔진 파일은 로컬 `data/private/references/<id>/` 보존. 재현에 필요한 모델·알고리즘·빌더는 저장소 포함, 원문 강우 수집 키 불필요

```bash
# 새 기준안 생성: 동일 소스 식별자 폴더가 존재하면 덮어쓰기 거부
simulation/.venv/bin/python scripts/build_references.py
# 기존 원장을 다시 탐색해 후보 선택·비용·해시 검증
simulation/.venv/bin/python scripts/verify_references.py
# 3개 배치 × 4개 강우의 기준안·배치안·민감도 실제 재계산
simulation/.venv/bin/python scripts/verify_references.py --rerun
```

## 확인한 동작

원장 424개 재생으로 세 예산의 모든 선택 단계와 중단 사유 일치. 실제 엔진으로 12개 비교의 수치·점수·민감도 일치. CI에서도 실행. 다른 플랫폼은 바이너리 해시 차이를 허용하지만 모델·빌더·알고리즘 계보와 수치 비교는 필수.

실제 브라우저에서 1억 원 상한 배치를 성동 55mm 개인 설계로 복사→저장→PostgreSQL 큐→워커 계산. 점수 3.64142094와 기준/배치 모든 보고 지표가 CPU 자료와 동일. 사람 순위 미제출. 데스크톱·390px 화면 배치와 전체 문서 가로 넘침 없음 확인.

일반 사용자의 저장 버전을 여러 강우로 묶어 실행·비교하는 기능은 별도 구현 중이며, 이 기준안 화면 완료만으로 다강우 비교 전체 완료로 표시하지 않음.
