# 저장 버전의 다강우 비교 그룹

2026-10-16 · 구현 계약. [0008](decisions/0008-reference-comparison.md)의 사용자 비교 구체화.

## API·보관

- `POST /api/v1/comparisons`: `sourceVersionId`, 등록 모델 해시 `modelHashes` 2~3개, UUID `requestKey`. 현재 편집 배치가 아니라 저장된 불변 버전을 서버에서 읽음
- `GET /api/v1/comparisons`: 본인 그룹 최근 50개 요약
- `GET /api/v1/comparisons/{id}`: 본인 원본 버전·각 복사 버전/설계 ID·계산 작업과 상태. 다른 회원은 404
- 원본 설계명·생성 시각·요청 조건 해시·원본 버전·작업 연결 보존. 모델 해시 순서는 정렬하여 멱등 판정
- 각 대상에 새로운 개인 설계·불변 버전·작업 생성. 원본 버전과 기존 결과 수정 금지. 복사 이벤트에 비교 그룹·원본 버전 ID 기록
- 기관 동의·리그 제출·일반 순위 제출 자동 생성 금지

## 입력 일치·동시성

시설 셀/면적·단가·원화·예산·최대 시설 수·수문 매개변수·시설 제원·엔진·생성기·점수 규칙 일치 필요. 강우만 달라지는 등록 모델에 한정. 계산 가능 상태·배치 비용 재검증.

계정 잠금→멱등 조회→소유권·호환성 검증→공용 큐 입장 잠금→개인 활성 3개/전체 500개 한도 검사→전체 생성 순서. 기존 작업을 포함한 여유가 부족하면 429, 그룹·버전·작업 모두 생성하지 않음. 하나라도 저장/큐 등록에 실패하면 전체 트랜잭션 롤백. 대상 작업 수만큼 기존 `run` 시간당 요청 제한 차감. 재전송은 같은 키를 유지하며 다른 입력을 같은 키로 재사용하면 409.

## 화면·해석

로그인한 회원이 저장 버전을 선택해 비교 생성. 편집 내용이 아직 저장되지 않았으면 저장 버전을 비교한다는 문구와 버전 번호 표시. 비교 도중 이동해도 작업 유지. 각 행에 대기/계산/실패/성공 구분, 성공한 결과만으로 그룹 전체 성공 표시 금지. 완료 결과는 강우별 점수·평가체적·저류·물수지, 각 작업의 재현 ZIP과 개인 설계 열기 제공. 통합 순위·현장 적용 등급 생성 금지.

브라우저·실제 PostgreSQL 워커 검사와 소유권·중복 요청·부분 실패 롤백·호환성·동시 큐 한도 회귀 검사 완료 전 구현 완료로 표시하지 않음.
