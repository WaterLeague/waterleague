# 첫 플레이 안내·배치 제한 피드백

2026-10-17. 문서 08·30의 지식 없이 참여하는 흐름 보완. 특정 시설·구역·면적을 정답으로 유도하거나 자동 배치하지 않는다.

## 동작 계약

- 플레이에 접을 수 있는 3단계 안내 제공: 구역 선택 → 시설·면적 확정 → 같은 강우 계산·비교. 안내는 현재 선택·확정 배치·미확정 편집·계산 상태에서 파생하며 가짜 진행률·보상·완료 이력을 만들지 않는다.
- 선택/확정/되돌리기/삭제/새 설계에 따라 단계 갱신. 계산 중에는 실제 상태 표시, 저장된 결과는 현재 배치와 일치할 때만 완료 안내. 새 강우/계정/설계의 결과를 이전 완료로 표시하지 않는다.
- 도움 버튼은 기존 구역 목록·면적 입력·계산 버튼으로 이동. 안내를 닫아도 배치 보존, 헤더에서 재열기. 기본 버튼·키보드 초점·목록 Escape 복귀 유지. 안내 상태는 현재 화면 메모리만 사용.
- 비회원에게 계산 전 로그인 필요를 알리고 배치는 유지. 시설 없는 기준안 계산도 허용하며 버튼 문구에서 구분. 저장·계산·순위 제출은 기존 명시적 조작으로 실행.
- 유효성 판정을 game 서비스로 모아 미리보기·배치 가능 여부·제한 설명에 동일한 소수 둘째 자리 면적 적용. 입력 허용 최소값은 서버와 같은 0.01 m². 범위를 벗어난 면적·금지 시설·개수·합계 면적·예산 초과를 구체적으로 표시하고 입력에 설명 연결.
- 기존 시설 교체의 비용·개수·면적은 해당 구역의 이전 배치를 제외한 뒤 계산. 미확정 비용·확정 총비용 구분. 비유한 입력을 원화 금액으로 표시하지 않는다. 배치 검사와 별개인 서버 권한·제약 검증은 유지.
- 시설 설명·점수 해석은 계산 범위에 맞게 유지. 배치 과정에서 예상 효과·순위·가상 물 흐름 추가 없음. 지도·원본·모델·평가 규칙 변경 없음.
- 구역 선택 전 편집 패널은 3단계 안내를 반복하는 대신 허용 시설의 역할을 짧게 설명한다. 효과 수치나 추천 순위는 제공하지 않는다.

## 검증 범위

기존 배치 교체/삭제/되돌리기, 0.01 m²·소수 반올림 경계, 비유한 입력, 구역/기관 시설 제한, 구역 수·합계 면적·예산 상한의 이유와 미리보기 일치 검사. 브라우저의 첫 선택→면적 편집→확정→로그인 안내, 단계 회귀·접기/다시 열기·키보드 이동·2D·좁은 화면 확인. 실제 초보자 사용성 조사를 대신한다고 표현하지 않는다.

## 검증 결과

- 실제 성수 모델을 사용하는 제약 검사 6개 추가, 프런트 전체 76개·타입·빌드·포맷 통과. 시설 허용·최소/최대 면적·반올림·교체 비용/개수/면적·합계 면적·예산 초과 검사.
- 비회원 브라우저에서 구역 목록→면적 초점, 81 m² 상한 거부·0 면적 거부·0.01 m² 확정, 계산 버튼 초점→Enter→로그인 창 확인. 안내 이동만으로 계산 실행 없음, 로그인 창 취소 후 배치 보존.
- undo/redo의 미확정/확정 안내 전환, 접기/재열기와 초점 복귀·예산 보존. R1 1,500 m²와 기존 G1 0.01 m²에서 90,005,600원 예산 초과 설명·미리보기 제거·배치 차단 확인. 40.126→40.13 m² 확정과 총 10,439,400원 일치.
- 2D에서 키보드로 R2 선택 후 면적 입력 초점과 단계 갱신. 실제 CSS 폭 400/1,600에서 가로 넘침 없음. 요청한 viewport와 실제 CSS 크기는 별도 기록. 새 설계로 시험 배치·되돌리기 기록 정리 후 첫 단계 복귀.
- DB 저장·계산·공개 순위 제출 없는 화면 검증. 이번 변경으로 새 서버 계산 흐름·실제 초보자 조사·모바일 실기기 품질을 검증한 것으로 처리하지 않음.
