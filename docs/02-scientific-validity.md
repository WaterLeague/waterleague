# 연구 적합성·모델 검증

기준일: 2026-10-21. 아래 수치·자료 경계는 현재 과학적 계약이며, 날짜가 붙은 상세는 해당 계산 버전의 적용 범위다. 신규 종합평가와 배포 전 구조 통합은 [구현 목표](09-delivery.md)에 둔다. 과거 시험 성공은 [검증 이력](12-validation-log.md)이고 현장 검증 완료 선언이 아니다.

## 서초 계산 지형의 파생 계약

2026-10-21: `NGII_CONTOUR_SPOT_CONFORMING_TIN_V1`은 보관된 2026-03-07 배포 수치지형도의 1:1,000 등고선 `등고수치`와 표고점 `수치`를 사용한다. 도로 대조 위치 가정의 유역 범위 주변 500m에서 조회한 원 레코드 전체를 보존한다. 같은 좌표·높이는 출처를 합치고 같은 좌표의 다른 높이는 거부한다. 무스냅 Delaunay 삼각망에 포함되지 않은 원 등고선 변을 이분하여 같은 높이의 파생점을 추가하고, 모든 세분 선분이 삼각망 변으로 보존될 때만 입력을 만든다. 원 선분·분할 비율과 파생점 구분을 보존한다. 16회/20만 점의 자원 한계를 넘거나 원 점이 유실되면 실패하며 무제약 보간으로 대체하지 않는다. 볼록껍질 밖 외삽·결측 메우기·함몰 제거·관망 높이 맞춤을 하지 않는다. 원 등고선 선분 중점 잔차와 표고점을 제외한 별도 삼각망의 표고점 잔차를 보존한다. 이것은 측량 정확도 인증이 아닌 보간 지지 검사다.

[국토지리정보원 공공측량 작업규정의 표고점 미터 표기](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2000000085686)와 [2026년 수치표고모형 규정 제43조](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000272806&chrClsCd=010201)를 단위 해석의 제품군 근거로 보존한다. 전자는 과거 규정이며 현행 준수 인증에 사용하지 않는다. 해당 배포 파일의 수직 기준 메타데이터는 미확인이므로 미터 해석은 `PRODUCT_FAMILY_INFERRED`, 절대 기준고 검증은 false다. 일반적인 국가 높이 기준을 근거로 이 파일과 연구 관망의 기준고가 같다고 확정하지 않는다.

10m/20m 계산 격자는 같은 보간 지형을 표본화한 수치 해상도이며 원 관측 간격·정확도가 아니다. 격자 원점·셀 중심·높이·보간 지지 삼각형·원 레코드/코드 해시를 보존한다. 유역 주변 100m의 계산 창은 실제 분수계가 아니며, 별도 명시한 외곽 경계·조도·건조 초기 상태로 수치 입력을 검증한다. 원 관망의 절점 바닥/깊이와 지형의 차이를 전수 기록하고 방류구를 지표 유입구로 간주하지 않는다. 실제 관망과의 양방향 결합·주간/재해 게임 순위 편입은 경계·강우 소유 면적·수두 기준의 별도 결속 뒤 진행한다.

삼각망 연산은 고정된 [Shapely의 무스냅 Delaunay 연산](https://shapely.readthedocs.io/en/2.2.0/reference/shapely.delaunay_triangles.html)을 사용한다. 점 추가로 선형 제약을 보존하는 conforming triangulation의 구분은 [JTS 문서](https://locationtech.github.io/jts/javadoc/org/locationtech/jts/triangulate/ConformingDelaunayTriangulationBuilder.html)를 참고하되 JTS 구현을 실행했다고 표시하지 않는다. 현재 구현은 필요한 변의 이분 분할과 모든 변·원 점·면 피복 검사를 명시적으로 수행한다. 2026-10-21 검증에서 원 42,497점과 파생 831점으로 원 선분 41,317개의 중점 잔차 최댓값 약 4.39×10⁻⁹m를 얻었다. 표고점 제외 대조의 RMSE 약 2.400m는 별도로 보존한다. 등고선 보존과 미측정 지점 정확도는 서로 다른 검사다.

서초 AWS 401의 2022-08-08 18:00~19:00 KST 관측을 같은 3,030,000m² 창에 적용한 다섯 조건에서 강우 입력은 10,605m³이며 수치 물수지 검사를 통과했다. 전달 경계의 순유입은 20m/1초에서 약 289.843m³, 10m/1초에서 약 438.060m³로, 관측 외부 유입이 아니라 경계조건이 계산한 값이다. 차단 경계와의 차이도 보존하며 전달 경계를 유출 전용으로 설명하지 않는다. 20m/1초와 0.5초의 최종 수심 최대 차이 약 0.003847m, 20m와 10m의 면적 평균 대응 수심 최대 차이 약 0.545166m를 기록한다. 수치 통과는 공간 수렴·현장 검증·운영 침수 예측 인증이 아니다. [원 지표와 재현 근거](../data/benchmarks/seocho-terrain-v1.json).

## 원칙

실제 지역 데이터 사용과 실제 현상 예측 정확도를 구분한다. SWMM 사용·낮은 물수지 오차·높은 게임 점수만으로 현실 적합성 입증 불가. 목적·입력·검증 범위·불확실성·재현 근거를 결과에 포함한다.

[EPA 모델링 QA/G-5M](https://www.epa.gov/quality/guidance-quality-assurance-project-plans-modeling-epa-qag-5m)과 [모델 QA 항목](https://www.epa.gov/quality/design-and-implementation-new-tools-quality-assurance-modeling)을 참고해 프로젝트별 입력 품질, 보정·독립 검증, 지표·검토 책임을 사전 정의한다. EPA 승인이나 법적 인증을 의미하지 않는다.

## 검증 등급

| 상태 | 최소 근거 | 허용 범위 |
| --- | --- | --- |
| `DRAFT` | 자료·모델 미완성 | 내부 제작, 공식 계산 불가 |
| `EXPLORATORY` | 출처·가정 기록, 실행·수치 검사 | 가정 아래 교육·탐색, 비공식 |
| `BENCHMARKED` | 참조 사례·독립 실행 대조·목적 적합성 검토 | 동일 모델 내 연구 비교·모델 랭킹 |
| `SITE_VALIDATED` | 부지 관측 보정·독립 검증·오차 승인 | 승인된 공간·변수·강우 범위의 현장 연구 |

모델 랭킹은 `BENCHMARKED` 이상만 허용하며 현장 효과 검증과 구분한다. 승인에는 검토자·날짜·근거 해시·목적·검증 변수·범위·한계 필수. 철회 시 신규 공식 사용 중지, 과거 결과에는 당시 등급과 현재 철회 상태 표시. 높은 등급도 다른 강우·시설·배수경계로 자동 확장하지 않는다.

위 등급 게이트는 공식 연구 평가용 모델 랭킹에 적용한다. 새 서울 공동 게임 순위는 `EXPLORATORY` 관측 입력 계산의 합산으로 별도 표시하며 공식 모델 승인·현장 성과 순위로 전용하지 않는다. 관측 또는 계산이 빠진 종료 주의 우승 확정 금지.

2026-10-19 화면 정정: 별도 강우 그래프·선택·정보 카드를 제거해도 계산에 사용한 기상 원본·시각·공간 배정·해시와 재현 묶음은 유지. 계산 결과가 없는 유량 차트에 강우 깊이를 대신 표시하지 않음. 화면 구성 변경으로 입력·물리 설정·평가 구간·과거 점수를 변경하지 않음.

## 입력 분류

`OBSERVED` 관측값, `PUBLIC_GEODATA` 공개 공간자료, `DERIVED` 원자료·처리 코드의 파생값, `CALIBRATED` 보정 근거가 있는 매개변수, `ASSUMED` 근거·범위·민감도 대상 가정. 시각화용 건물 높이·물결·나무와 수문 입력 분리.

## 대상지·시간해상도

건물·피복·DEM 외에 배수구·관거·방류구·분수계·토양·지하수·관측 유출 확보 가능성 평가. 지도의 사각형이 실제 배수경계를 자르면 외부 유입·유출 조건 추가. 최종 서울 부지는 검증 자료 가용성에 따라 선정.

관측소 거리·고도차·강우 공간 대표성 명시. 도시 소유역 반응시간보다 긴 시간강우로 정밀 첨두유량 주장 금지. 시간자료만 확보한 초기 단계는 총량 중심 탐색. 공식 첨두 평가 전 적합한 분자료 또는 해상도 민감도·검증 근거 확보. 시간강우의 균등 분할은 새로운 관측자료가 아니다.

## 설치 제약

| 시설 | 확인 조건 |
| --- | --- |
| 빗물정원 | 유입 면적·고도·토양 투수성·지하수 이격·넘침·지장물 |
| 투수포장 | 포장·교통하중·기층·침투·암거·경사·막힘·유지관리 |
| 녹화지붕 | 지붕 경계·면적·경사·구조 하중·방수·배수·소유권 |

현장 적합성 `ELIGIBLE/CONDITIONAL/PROHIBITED/UNKNOWN` 기록. 게임 배치 허용과 현장 시공 승인 분리. 같은 유입면적의 시설 간 중복 할당 금지.

`SITE_SUITABILITY_V1`은 지상에 토양·경사·지하수·지하 지장물·교통 하중·배수, 옥상에 경사·구조 하중·방수·배수 조건을 적용한다. 원 후보의 조건별 판정에는 사유·공개 출처 URL/해시·참조 위치가 필요하며 결측은 `UNKNOWN`이다. 문헌 참조 경사·토양·표시 높이로 현장 조건을 채우지 않는다. 어느 항목이든 `PROHIBITED`면 배치·계산을 차단하고, 명시한 안전 조건의 충족이 미확인인 `CONDITIONAL`도 근거를 갱신하기 전에는 보류한다. 그 외 미확인은 지도 탐색만 허용하며 모든 상태의 `constructionApproved`는 false다. 조건별 근거가 모두 허용이어야 `ELIGIBLE`이며 기존 집계의 금지·조건부는 세부 결측으로 지우지 않는다. 이 정책은 임의 점수·실현성 등급을 산정하지 않는다.

기존 연구 모델의 수치 생성기와 원문 해시는 재현을 위해 보존한다. 연구 작업은 캐시 조회·새 계산 전에 배치 검증 계층에서 현재 안전 조건을 검사하며, 실행·배치 검사 코드와 현장 적합성 코드/정책 해시를 캐시 식별자에 결속한다. 주간·재해 연속 계산은 해당 입력 계층에서 같은 안전 조건을 검사한다.

### 유지관리·실현성의 근거와 판정표

[공개 관리 기준](../data/facilities/maintenance-reference-v1.json)은 LH 2022 지침의 시설별 점검 항목·주기와 EPA 2016 생물저류 관리 지침을 출처·원문 해시·쪽에 결속한다. 현재 시설 6종과 빗물이용시설 참고 행을 구분한다. 점검 주기는 문헌의 권고이지 해당 위치의 점검 이행·시설 수명·법적 의무가 아니다. 수치 모델의 단면·노후화·수리계수·정비 비용을 이 표로 바꾸지 않는다.

| 확보 근거 | 판단 가능한 범위 | 점수·등급 |
| --- | --- | --- |
| 관리 문헌만 확보 | 점검 참고 항목·권고 주기 제공. 현장 상태 미확인 | 미산정 |
| 같은 시설·위치·시점의 이상 징후 기록 | 막힘·손상·정체 등의 원인 조사·조치 필요성 검토 | 징후를 감점·성능 저하율로 환산하지 않음 |
| 점검·정비 전후 기록과 방법·시점 확보 | 같은 조건의 원 측정값 비교 | 검증된 배점·등급 경계가 없으면 미산정 |

관리 평가에는 시설/규격/위치, 기록의 출처·버전, 점검·보수 시각과 평가 기간, 측정 방법·단위·결측, 관리 주체·접근, 공종·가격 시점이 명시된 비용 근거가 필요하다. 가중치·등급 경계·불확실성·결측 처리의 별도 검증 전까지 `score`·`grade`는 null이다. 공개 지침의 점검 주기를 과거 관리 지연이나 미래 청소 효과로 바꾸지 않는다. EPA의 강우 48시간 후 물고임은 추가 조사 신호이며 서울 시설의 자동 불합격·침투율·효과계수로 전용하지 않는다.

실현성은 위 `SITE_SUITABILITY_V1`의 조건별 공개 근거와 금지 → 조건부 → 미확인 → 허용 우선순위를 따른다. 금지·조건부는 탐색 배치/계산을 차단하고, 미확인·허용은 탐색만 허용한다. 모든 상태에서 시공 승인은 false이며 물리 성능 점수로 안전 제약을 상쇄하지 않는다. 데이터 페이지는 서버 정책의 우선순위·탐색 허용 목록을 직접 읽어 판정표를 표시한다. 관리 참고 표로 위치별 현장 상태·관리 점수·실현성 등급을 새로 생성하지 않는다.

## 모델 연결

`cellId → footprint → subcatchmentId → inflow allocation → LID_CONTROLS/LID_USAGE`.

시설은 검토된 물리 단면·재료 버전에 연결. 사용자는 허용 배치·면적을 선택, 침투율·효과계수 임의 수정 불가. 소유역·불투수·LID 면적의 중복 집계 금지. [SWMM 5.2 공식 매뉴얼](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=P10145M6.TXT) 기준으로 변환하고 엔진 패치·빌드 해시 고정.

## 평가 경계·단위

- 강우 `mm`: 구간 깊이·집계간격·시각 규약 보존, 강도 `mm/h`와 구분.
- UTC 저장, 원본 KST와 SWMM 입력 변환 기록.
- API 면적 `m²`, SWMM 소유역 `ha`; 10,000 변환 명시.
- 유량 `m³/s`, 체적 `m³`, 길이 `m`, 수직 기준 별도 저장.
- 기준·전략 동일 평가지점·기간, 지정 방류구 시계열 적분·엔진 집계 교차 확인.
- 첨두는 같은 시각의 유량 합 시계열의 최댓값. 개별 최댓값 합산 금지.
- 선행강우·토양수분·저류·증발산·hotstart 고정.
- 강우 종료 뒤 고정 배수기간 포함. 시설별 종료시각 변경 금지.
- 잔여저류·침투·증발·지연방류 분리. 임시 저장을 영구 저감으로 단정 금지.

2026-10-17 연속 계산 변경: 공동 설치는 설치 후 첫 완전한 분 구간부터 관측 강우를 연속 입력한다. 같은 실행 안에서 표면·포장·토양·저류층 상태를 적분하며 주 경계에서 초기화하지 않는다. 재실행은 보존한 계산 입력 전체를 같은 엔진으로 재생한다. SWMM 일반 hotstart는 LID 내부 상태를 저장하지 않으므로 LID 연속 계산의 재시작 수단으로 사용하지 않는다. 기존 연구 모델·빌더는 변경하지 않고 별도 버전으로 구현한다.

공동 계산의 분별 상태는 EPA 5.2.4 원본에 추가한 읽기 전용 관측 함수로 가져온다. 물리 수식·시간 적분·매개변수 갱신에는 개입하지 않는다. 누적 강우·침투·증발·유출·배수·현재 저류량과 LID 층별 상태를 엔진 내부 값에서 SI 단위로 변환한다. 원본 리비전·관측 함수·바이너리·입력·결과 해시를 보존하며, 기존 공식 바이너리의 RPT/OUT과 동일 입력 대조로 관측 함수의 비개입을 확인한다.

관측 기온·습도·풍속·기압은 기존 AWS 응답의 원단위로 연결한다. 이 값만으로 관측 토양수분·증발산·관망 유량을 만들어내지 않는다. 증발산은 지원하는 기상 입력이 갖춰진 계산식과 별도 파생 근거가 있을 때만 시변 입력으로 사용한다. 실제 지형 경사·토양·관망 미확보 위치의 설계 매개변수와 설치 시 초기 수분은 미확인 가정으로 남기고, 고정 효과율이나 관측값으로 표시하지 않는다.

공동 설치의 증발산 입력은 KMA 서울 108 ASOS 시간 일사량과 동일 지점 AWS 60개 분 관측의 기온·습도·1분 평균 풍속·현지기압 평균을 사용한다. 지점정보의 좌표·고도·풍속계 높이를 조회 구간 양 끝에서 확인하고 [FAO-56 시간별 식 53](https://www.fao.org/4/x0490e/x0490e08.htm)으로 기준 잔디 증발산을 계산한다. 풍속은 관측 높이에서 2m로 변환. 야간 단파복사는 천문학적 0으로 분류하고, 구름비는 이전 일몰 2~3시간 전 실제 일사로 파생한다. 주간 일사·필수 분 기상·야간 구름비 결측 시 새 계산 게시 중단. 미래 관측을 사용하지 않도록 완료 시간의 파생률을 다음 시간에 유지하고 mm/h를 SWMM mm/day로 변환한다. 이 값은 시설별 관측 증발산이 아니며 지점 공간 대표성·표면별 보정은 미검증이다. 실제 증발량은 엔진의 수분 상태로 제한된다. 계산에 사용한 원본·파생률·공식 코드·출처 해시 보존, 최신 날씨 응답 캐시로 사용 금지. 기존 계산 구간의 증발 조건은 그대로 보존하고 신규 구간부터 적용.

과거 재해는 보관한 기상 입력만 사용한다. 2022·2010 사건은 같은 시간별 방식. 2011-07-27 서울 AWS는 일부 분 기상이 결측이므로 ASOS 일 최저·최고기온·평균 수증기압·풍속·현지기압·일사합으로 FAO-56 일 산정식 6 적용. 일 기준 증발산을 해당 일에 균등 적용하며 일중 변화를 복원한 것으로 표시하지 않는다. 당일 전체 확정 자료를 쓰므로 실시간 모드의 대체 입력으로 사용 금지. 재해별 시간 해상도·선택 이유·원본·계산식 해시를 재현 묶음에 포함한다.

연속 강우 정규화는 같은 날의 연속 일 누적 차분을 기본으로 한다. 00:00·00:01 초기화 경계는 직전 14분의 유효 분량과 해당 시각 15분 이동누적의 차이로 복원하고, 가능한 60분 이동누적과 0.1mm 이내 일치 검사. 직전 구간·누적값 결측, 음수 차분, 이동누적 충돌은 계산 거부. 임의 보간·결측 0 치환 없음. 계산 시각은 UTC 고정, 엔진 종료 날짜의 내림 연산으로 마지막 1초가 잘리는 문제는 입력 종료를 1초 여유 있게 잡고 관측 종료 분에서 정확히 `swmm_step`을 중단해 방지. 해당 여유 구간은 평가에 포함하지 않음.

기상 원문·파생 파일의 SHA-256은 바이트 단위로 검사한다. FAO-56 원문 재계산의 부동소수점 비교만 `64 × max(ulp(원값), ulp(재계산값), ulp(1))` 이내를 허용한다. macOS/libm과 Linux/libm의 삼각함수·뺄셈 마지막 자리 차이를 위한 한도이며 강우·원문 해시·시각·문자열·목록 길이·정수에는 적용하지 않는다. 원 저장값을 계산 입력으로 유지하고 비교 구현의 해시도 재현 자료에 보존한다.

## 검증 절차

1. 원자료: 누락·중복·품질코드·단위·CRS·날짜경계·총강우 검사.
2. 기하·배수: 면적·중첩·피복·출구·유입 경로 검사.
3. 수치: 오류·비유한 값·물수지·시간간격 민감도·안정성 검사.
4. 회귀: 시설 0개·무강우·단일 시설·동일 입력·면적 경계 사례.
5. 참조: 공식 예제/공개 연구 사례, API와 별도 SWMM 실행 경로 대조. 같은 엔진의 API/CLI 일치는 다른 수문모형의 독립 검증과 구분. [EPA 참조 진단](20-epa-reference-validation.md)의 인쇄 충돌·단위 차이는 검토 필요 상태이며 현재 모델의 등급 승격 근거로 단독 사용 불가.
6. 보정: 해당 부지 유량·수위 관측, 계측 오차·경계조건 반영.
7. 독립 검증: 보정에 쓰지 않은 이벤트·기간, 계절·강도 범위 확인.
8. 민감도·불확실성: 토양·피복·시설 투수성·배수 연결·강우 오차 앙상블.
9. 전문가 목적 적합성 검토 후 승인 버전 공개.

내부 수치 게이트 초안: 유출·해당 라우팅 연속오차 각각 절댓값 1% 이하, 초과 격리. 프로젝트 정책 제안이며 EPA의 보편 인증 기준 아님. 라우팅 없는 모델은 근거 있는 `NOT_APPLICABLE`, 누락값의 0% 치환 금지. 수치 통과와 현실 검증 분리.

현장 지표: 총량 상대오차, 첨두 크기·시각 오차, RMSE, 적합한 경우 NSE/KGE, 잔차 패턴. 계측 정확도·표본수·이용 목적에 맞는 합격값을 결과 확인 전에 정의. 보편 임계값 임의 지정 금지.

## 현재 게임 평가와 확장 지표

### 공개 관망·지형의 명시적 교환 가정

`PUBLISHED_SURFACE_CONNECTION_EXPLORATION_V1`은 원 관망·위치 자료·계산 지형·강우 면적 분할을 보존한 별도 파생 계산이다. 원 관저고·최대 깊이·관로·강우·추정 외부 유입을 보존하고, 각 원 접합 절점에 가정한 원형 바닥 오리피스와 지표 수두 경계를 추가한다. 원 절점의 지상 월류 손실을 교환 통로로 보낼 수 있도록 추가 허용 수두를 명시한다. 이는 압력 한계의 실측값이나 밀폐 뚜껑의 확인이 아니며, 이 한계에서도 원 SWMM 월류가 생기면 계산은 실패한다. [EPA SWMM 5.2](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=P10145M6.TXT)의 `Ysur`와 바닥 오리피스 수리식을 사용한다.

관망과 지형의 공통 높이 기준은 미검증 가정으로 명시하며 기존 `absoluteVerticalReferenceVerified=false`를 바꾸지 않는다. 교환 지점은 공개 절점이 포함된 삼각형 한 개이며 경계 위에서는 인덱스가 작은 쪽을 사용한다. 교환 문턱은 원 뚜껑 높이와 해당 격자 평균 바닥 높이 중 큰 값이다. 평균 바닥이 더 높으면 그 차이를 격자 표현에 따른 문턱 상승으로 기록하며 원 지형 또는 관망 높이를 보정하지 않는다. 건조 지표가 높은 수두만으로 존재하지 않는 물을 관망에 공급하는 것을 막는다. 원 위치·격자·높이·문턱·개구부와 파생 관망은 원 요청에서 다시 생성해 대조한다.

개구부 크기·방류계수·추가 허용 수두·지표 높이 오프셋·외곽 경계·교환 간격은 모두 명시적 시나리오 입력이다. [2021년 결합 모형 논문 §2.5](https://www.mdpi.com/2073-4441/13/15/2028)의 오리피스 계수 0.6–0.62를 참고하되 미확인 서울 빗물받이의 계수로 인증하지 않는다. 폐쇄 외곽 경계는 교환 물수지 진단용이며 실제 분수계가 아니다. 원 강우의 시간대·관측소 미확인과 추정 외부 유입을 유지하며 관측 재난 복원·현재 관측 강우·운영 점수와 구분한다. 수치 검증 이후에도 경계·높이·개구부와 해상도의 민감도를 확인해야 한다.

[격자형 유입구의 가압 실험](https://www.mdpi.com/2306-5338/8/4/162)은 해당 형상/흐름의 방류계수 0.14–0.41을 보고한다. 개방 오리피스 0.62를 모든 빗물받이에 공통 적용할 근거가 아니며, 현재 0.6m 등가 직경도 원 관망에 없는 시나리오 가정이다. [2026-10-15의 진주 1D–2D 수치 정밀도 연구](https://www.mdpi.com/2073-4441/18/20/2555)는 장시간 교환량·국소 수심 차이 확인의 최신 근거로 보존하되 해당 GPU 성능이나 지역 계수를 전용하지 않는다. [열람 범위·출처·가정 목록](../data/manifests/published-surface-connection-reference-v1.json)을 구분하며 미확인 수두 기준 입력은 평가에서 현장 검증 또는 당시 재난 복원 등급으로 승격할 수 없다.

지표 교환 체적의 장시간 누적은 부호 변화와 작은 증분의 소실을 줄이는 보정 합산을 사용한다. 관망 절점별 원 누적량은 변경하지 않고 결합 대조에는 `math.fsum`을 적용한다. 각 실제 지표 적용량·건조 가용량·원 엔진 물수지 검사와 교환 상쇄 절대 허용오차 10⁻⁸m³는 유지한다. 이 계산상의 개선을 초기 상태 또는 관망 원 모형의 물수지 오차 보정으로 해석하지 않는다.

### 관망·지표 강우의 경계 격자 분할

`GEOMETRIC_RAINFALL_PARTITION_V1`은 원 집수구역 다각형과 삼각형의 교차 면적을 계산한다. 격자별 직접 강우율은 관측 강도 × 미피복 면적/격자 면적이며 관망에는 원 SWMM 선언 집수면적과 강우를 보존한다. 원 다각형의 겹침·격자 밖 영역·잘못된 형상은 거부하고 중심점 선택·경계 확장·면적 정규화로 대체하지 않는다. 교차 면적·남은 면적·부동소수 면적 잔차·원 형상/격자/선언 면적 해시를 보관한다. 원 SWMM 선언 면적과 도형 면적이 다르면 그 차이와 강우 체적 차이를 별도 원장으로 표시하며, 같은 물리 면적을 정확히 표현했다고 주장하지 않는다. 원 면적은 [EPA SWMM 5.2 매뉴얼](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=P10145M6.TXT)의 집수구역 `Area`, 지도 경계는 `POLYGONS`의 구별을 따른다.

부분 지표 영역은 한 삼각형의 수심·운동량을 공유하는 면적 평균 근사다. 강우는 고정 [ANUGA 4.0.1 원 구현](https://raw.githubusercontent.com/anuga-community/anuga_core/7d701dc2bebc3ba2a7904e3e118115c8d172f89d/anuga/operators/rate_operators.py)의 격자별 `Rate_operator`에 적용한다. 토양 침투 면적과 지표 잠재 증발도 같은 남은 면적 비율을 사용하며, 침투 상태에는 면적 평균으로 줄이기 전 국소 강우 강도를 전달한다. 토양 제원의 투수 비율은 남은 지표 면적 내부의 명시적 비율이다. 전체 격자에서 만든 공간 토양 배정은 부분 격자의 남은 도형을 다시 교차하기 전에는 자동 재사용하지 않는다. 지표 저류지 설계도 관망과 나눈 격자를 전용 지표 부지로 사용할 수 없다. 동일 격자의 강우를 여러 번 줄이거나 관망 소유 토양/증발을 중복 생성하지 않는다. 새 소유권 입력은 원 집수 형상에서 재생해 실제 지표 입력·결과와 대조한다. 기존 전체 격자 소유 정책과 과거 산출물은 보존한다.

서초 연구 관망의 지도 연결은 [도로 대조 위치 가정](15-sewer-observations.md#근거-기반-파생-위치-계약)을 사용한다. EPSG:5181→5186 수평 변환은 원 절점·관로·집수 연결과 선언 길이를 유지하며 원 INP의 강우·기저 유입·높이·수리 제원·평가 창을 변경하지 않는다. 3D의 지형 높이 위 도형은 선택 표시이며 관저고 또는 계산 지형이 아니다. 제출의 위치 가정 원문/해시는 결과·재현 묶음에 고정하고, 원 좌표계 미확인·수직 기준 미확인·현장 미검증을 유지한다. 이 연구 모형의 지도 선택과 수치 통과를 주간/재해 점수 또는 실제 피해 감소 검증으로 승격하지 않는다.

현재 주간·재해 게임 순위는 기준안과 설계안의 회계상 배출량 차이(m³)다. 회계상 배출량은 `surfaceRunoff + lidDrainage + finalStorage − initialStorage`로 정의하며 음수 효과를 보존한다. 연결 유역의 유출·월류/피해량과 표면 시설의 체적 차이를 구분한다. 계산이 없거나 실패한 경우 0점으로 대체하지 않는다.

현재 독립 표면의 순위 정책은 `ABSOLUTE_ACCOUNTED_VOLUME_RANKING_V1`이다. 주간 누적값은 소수 9자리, 전체 사건 제출 합계는 소수 18자리에서 HALF_EVEN으로 고정하고 같은 저장값은 공동 순위(1·1·3)로 처리한다. 이는 저장·비교 해상도이며 엔진 정확도·물수지 오차·현장 유의성의 인증이 아니다. 원 부동소수 지표와 물수지 잔차는 별도로 보존한다. 동점 표시 순서는 주간 개인 UUID, 구 이름/ID, 제출 시각/ID로 사전 고정하며 참가자 수·최고값·비율에 따라 점수나 상한을 바꾸지 않는다.

정책 원문은 계산 코드·공통 공간/관측 결속·참조 조건·예산 입력의 해시를 포함한다. 재해 API는 제출 규칙에 정책 해시를 동결하고 워커는 계산 전에 검증한 엔진 바이너리·Python·OS/아키텍처·공간 라이브러리와 규칙을 `scoreContext`로 동결한다. 주간도 시간 규칙과 공통 자료 정책을 같은 방식으로 결속한다. 지역별 관측·설치 이후 평가 길이가 같다는 뜻은 아니며 주간은 정해진 관측 결속 규칙 아래의 게임 기여 비교다. 재해는 전체 사건·25개 구의 강우 모델 맵을 같은 규칙에 고정한다. 다른 코드/조건의 재해 기록은 별도 집단으로 비교하고 주간에 서로 다른 조건 또는 조건 미기록 점수가 섞이면 원 시설 기록을 보존하면서 합산·순위·우승을 보류한다. 기존 주간 접두 구간의 조건 변경은 재게시를 거부하며 과거 기록에 현재 조건을 소급 부여하지 않는다.

유출·첨두의 상대 변화율은 각각 `(Vbase−Vdesign)/Vbase`, `(Qbase−Qdesign)/Qbase`이며 기준값 0·결측·비유한 값은 정상 비율로 계산하지 않는다. 서로 다른 시각의 시설별 최대 유량 합을 유역 첨두로 사용하지 않는다. 100점 종합 배점은 현재 적용 규칙이 아니며 [평가 확장 계획](09-delivery.md#p4--성능-지표와-점수)에서 같은 조건의 절대 개선량·0 기준값·결측·수치 허용오차·동점 처리를 확정한 뒤 적용한다. 초기의 70/30 제안은 현재 게임 요구사항에서 제외한다.

확장 평가의 주 지표는 사전에 정하고 수치 허용오차를 넘는 개선을 임의 만점으로 절단하지 않는다. 상대 개선율·정규화·비용효율은 서로 다른 모델/강우/평가 범위의 결과를 비교 가능하게 만드는 증거가 아니다. LCC는 공통 평가기간·가격/할인 기준·비용 포함 범위를 가진 별도 비용 비교이며 단일 호우의 효과를 생애 효과로 환산하지 않는다. 현재 할인 현금흐름 계산은 초기 설치·운전·점검/청소·수선·교체·철거/처분·잔존가치를 분리하고 미확정 공종을 0원으로 치환하지 않는다. 설치 예산·점수에는 합산하지 않는다. [계산 정책](../backend/src/main/resources/facilities/life-cycle-method-v1.json)의 NIST 절차를 적용하며 미국 가격·할인율은 전용하지 않는다. 이용조의 40년·실질 0.89%는 2018년 문헌 사례의 분석 가정이고 현장 수명·현재 사업 할인율이 아니다. 가격 기준연도·규격/공사 범위·교체/처분비·잔존가치가 미확정이므로 세 견적의 부분 현재가치만 제공하며 전체 LCC·경제성 순위는 미산정이다.

기존 연구 모델의 고정 점수는 해당 모델 원문의 규칙으로 재현하며 현재 게임 점수나 현장 성능으로 일반화하지 않는다. 예산/설치비는 KRW, LCC·경제성 검증은 별도다. 순위 차이는 통계적 유의성을 뜻하지 않는다.

### 표면 유출의 중심시각 지연

새 독립 표면 결과는 같은 평가 창에서 `q=표면 유출률+시설 배수율`, `V=Σ(q·Δt)`, `M=Σ(q·Δt·(구간 중간시각−평가 시작))`, `중심시각=M/V`를 계산한다. 지연은 설계 중심시각−기준 중심시각이며 양수는 늦어짐, 음수는 빨라짐이다. 엔진의 내부 구간 평균 유량을 사용하며 선행 기간·설치 전 구간·화면의 분별 표본을 적분에 섞지 않는다. [Lönnqvist 외, Journal of Hydrology 646 (2025) 132325, 표 2](https://doi.org/10.1016/j.jhydrol.2024.132325)의 대조 지붕 대비 중심시각 정의를 따른다. [서지·열람 경로](../data/manifests/lonnqvist-runoff-timing-2025.json)를 보존하며 논문의 현장 효과량을 서울 시설의 계수로 전용하지 않는다.

`runoffComparison` v3는 원 1차 모멘트·중심시각·비교 상태·지연 초를 보관한다. 양쪽 실제 배출량이 양수이고 음의 내부 유량 성분이 없을 때만 비교한다. 무유출은 중심시각/지연 null, 허용오차 이내 음의 유량도 원값을 보존하고 시간 비교는 보류한다. 이전 결과에 없는 중심시각은 분별 표본으로 소급 생성하지 않는다. 같은 최대 유량이 반복되면 첨두 시각은 기존 첫 발생 구간을 유지한다.

이 값은 공통 창 안에서 이미 배출된 물의 시간 분포 차이다. 종료 저류가 남으면 창 이후 배출이 누락되며, 서로 다른 배출 체적과 초기 상태의 영향도 포함한다. 개별 물 입자의 체류시간·연결 유역 침수 개선·항상 좋은 방향의 효과로 단정하지 않는다. 체적 점수에 더하거나 시설별 지연을 합산하지 않고 기존 유출 비교에 별도 표시한다.

## 공개 투수 블록 막힘 조건 비교

회원 재해 계산의 선택 투수포장에 [2025년 한국수자원학회 논문](https://jkwra.or.kr/articles/xml/N8x4/) 표 7–9의 Type-A 블록 조건을 별도로 적용한다. [원본 목록](../data/manifests/kwra-pavement-clogging-2025.json)과 `pavement-maintenance-v1.json`의 원문·카탈로그 해시를 요청/결과/재현 묶음에 보존한다. 원 실험값(*) 중 협잡물 0·96·192g의 3.49·2.12·1.40mm/s만 12,564·7,632·5,040mm/h로 환산하고 보정값(**)·회귀식(***)·보간값은 사용하지 않는다. 협잡물 투입량은 블록 4장, 0.16m² 시료 기준이며 설치 면적의 오염량이나 현장 사용 연수로 환산하지 않는다.

포장층은 세 조건 모두 표 7의 두께 60mm·초기 공극률 20%로 고정한다. 본문에 공극률로 적힌 7.84는 같은 표의 휨강도 값과 일치하므로 불일치를 기록하고 표의 명시된 열을 사용한다. 막힘 후 공극률은 측정값이 없어 동일 공극률 가정을 표시한다. 원 논문의 투수값은 유량/시료 면적의 산정값이며 수두 경사를 확인한 현장 재료 투수계수로 인증하지 않는다. 기존 EPA 기층·지반 조건은 유지하는 재료 투수 민감도이며 완성 포장체의 성능 검증이 아니다.

동일 원형 후보·강우·증발산에서 각 조건을 선행 7일부터 사건 전체 종료까지 고정해 계산한다. 자동 노후화·청소 계수는 적용하지 않는다. 선행 기간을 점수에서 제외하며 시작 저류·유출/배수·침투·1분 평균 첨두·평가체적 감소와 새 블록 대비 부호 있는 차이를 보관한다. 조건 실패는 미완료/차이 null로 남기고 0이나 성공 결과로 대체하지 않는다. 기존 설치의 제원·시간축 효과·비용·순위는 변경하지 않는다. 동일 재료의 청소 후 회복값·관리 비용은 미확보로 유지하며 P5의 청소/관리 시나리오 전체 완료를 뜻하지 않는다.

기존 투수포장 제원·막힘 비교에는 [Winston 외 2016년 현장 청소 연구](https://repository.library.noaa.gov/view/noaa/57786)의 PICP 전후 측정 비교를 제공한다. [원본·파생 목록](../data/manifests/winston-pavement-cleaning-2016.json)의 표 3 중 Piney Wood의 유입 경계 근접/이격 구역과 Willoughby Hills의 2014/2015년을 각각의 쌍으로 유지한다. 중앙값·평균·최소/최대·표준편차·시험 횟수·원문 p값을 보존하고 mm/min→mm/h는 속도 통계에만 60을 곱한다. 청소 전 중앙값 대비 부호 있는 변화는 신설 대비 회복률이 아니다. 감소·비유의 사례를 숨기지 않으며 시험 횟수를 독립 현장 수로 해석하지 않는다. 이 자료의 현장 표면 침투속도를 Type-A 재료 투수계수·서울 후보의 수리 입력으로 치환하지 않는다. 동일 지점의 신설 상태·현장 비용이 없으므로 회복률·비용효율·게임 점수에 연결하지 않는다.

## 공동 설치 면적·유입 조건 변경

신규 공동 설치는 공개 후보 도형의 면적에서 0.01m² 미만을 버린 값을 기하학적 최대 면적으로 사용한다. 기존 옥상 60%·지상 80% 비율은 근거 없는 설계 제한이므로 신규 배치에 적용하지 않는다. 건축물 footprint는 실제 유효 지붕 면적·구조안전·피난 동선 확인 자료가 아니며, 이 상한은 도형 밖 면적 배치를 차단하는 계산 경계다. 현장 시공 승인 상태는 계속 UNKNOWN이다.

공개자료로 배수 연결이 확인되지 않은 신규 후보에서는 시설 바깥 불투수면 유출을 전부 시설로 보낸다는 기존 100% 유입 가정을 제거한다. 신규 물리 버전은 시설 자체에 내리는 강우만 입력하고 주변 표면의 유출은 별도로 계산한다. 주변 집수면적이 확인되기 전 임의 집수 효과를 가산하지 않는다. 기존 설치·저장 결과의 면적 및 유입 조건은 입력 버전으로 보존한다.

SI API의 체적 반올림 상수 0.02832와 정확한 ft³→m³ 변환 구분, 원본 저장곡선의 반올림은 임의 보정하지 않음. 엔진 종료 날짜 내림으로 평가 기간이 짧아지면 거부하고, 여유 종료가 있는 입력은 실제 평가 종료를 별도 고정.

관망 수치 판정 v2는 완전한 평가 구간·유출/라우팅 수지 오차 1% 이내와 모든 내부 DYNWAVE 단계의 수렴을 함께 요구. 고정 EPA 바이너리의 `TotalStepCount`·`NonConvergeCount`를 읽기 전용으로 수집, 보고서의 소수 둘째 자리 백분율을 성공 판정에 사용하지 않음. 비수렴이 한 단계라도 있으면 `ROUTING_NONCONVERGED` 실패로 보존하고 결합 계산·원 지표의 성공 승격 차단. 비수렴은 전체 평가/선행 실행에 적용하며 선행 구간을 점수에서 제외한다고 수치 실패까지 제외하지 않음. 과거 판정 결과·바이너리·재현 코드 보존. 단일 저장조/관로의 수지 실패를 실제 관경·경사·저류량 변경이나 허용치 완화로 감추지 않음.

EPA `massbal_getFlowError`는 입출 체적 차이가 1ft³(0.028316846592m³) 미만이면 `TINY`를 반환. 작은 시설의 원 체적 잔차가 상대적으로 커도 보고값은 거의 0이 될 수 있으므로 유입·유출·초기/최종 저류의 부호를 보존한 별도 수지로 판정. 절대 잔차 한도는 `max(10⁻⁸m³, 총 유입 체적의 1%)`, 유입이 없으면 총 유출/저류 체적 기준. 원 잔차·축약 없는 백분율·EPA 보고값 모두 보존. 이 절대 허용치는 부동소수 오차 기준이며 EPA의 1ft³ 축약을 계승하지 않음. 조기 결합 실패에도 마지막 관망 상태와 내부 비수렴 횟수 보존.

관망 결과는 엔진 초기화 후 실제 적용된 압력 해법(EXTRAN/SLOT)·최대/최소 시간 간격·Courant 계수·최소 수치 절점 면적·수위 수렴 허용치·반복 한도를 읽기 전용으로 보존. INP에 명시한 값과 생략한 항목을 구분하며 최소 수치 면적을 실제 시설 면적으로 표시하지 않음. 압력 해법은 시나리오 입력으로 고정하며 실패 후 다른 해법으로 자동 재시도해 같은 실행/순위로 대체하지 않음. 공식 SLOT의 가상 슬롯도 수치 근사이며 실제 관로 체적으로 해석하지 않음. 같은 제원의 시간·격자·교환 간격 및 초기 상태 민감도 확인이 필요하며, 건조 시작 사례의 통과를 임의 젖은 초기 상태나 서울 현장 재현의 성공으로 확대하지 않음.

관망 산출물 해시는 `swmm_close`의 보고서 종료 기록과 파일 닫기가 끝난 뒤 확정. 종료 전 해시가 들어간 이전 결과는 원본 그대로 보존하고 엄격한 결과 리더에서 무결성 통과로 취급하지 않음. 상위 실행 묶음의 사후 해시가 일치하더라도 내부 결과 파일의 해시 일치를 별도로 확인.

공개 연구 INP의 원형 재실행은 별도 `NATIVE_DURATION_DIAGNOSTIC`에서만 EPA 날짜 차의 초 단위 내림을 그대로 사용하고 선언 기간과 실제 계산 기간의 차이를 보존. 최대 1초 수준의 원 엔진 내림을 허용하되 게임의 명시적 평가·관측 결합에는 적용하지 않음. 표시 프레임 간격을 맞추기 위해 원 내부 단계를 자르지 않으며, `run`의 모든 내부 단계 수렴/체적 적분을 유지하고 프레임에 필요한 전체 상태만 읽음. 원본과 출력 경로만 바꾼 실행본의 이진 결과 일치를 별도 확인. 연구 자료의 좌표계/기준고/시점/외부 유입 계보가 없거나 원 입력 비수렴이 남으면 현장 검증·경쟁 등급 승격 금지([서초 공개 연구 모형](15-sewer-observations.md)).

ANUGA의 공식 4.0.1 소스·태그 커밋·실행 휠·라이선스·의존성 잠금 해시를 보존. 명시된 반시계 삼각 격자·표고·조도·초기 수심·전체 외곽 경계·좌표/수직 기준만 입력하며 누락된 경계를 임의 벽으로 채우지 않음. `DE0`, CPU 계산, 한 스레드와 입력별 최대 시간 간격 기록. CFL은 계속 적용하고, 건조 격자의 강우가 긴 단계 끝에 일괄 투입되지 않도록 최대 시간 간격을 필수화. 격자별 강우 소유권에 따라 관망 소유 영역의 2D 직접 강우를 거부. 수심·유속·체적·외곽 유입·강우 원장·SWW 보존. 격자 생성에 비상업용 Triangle을 사용하지 않고 해당 의존성 제외. macOS의 OpenMP 중복 로드 충돌은 별도 `spawn` 프로세스에서 엔진별 상태를 유지하여 회피하며 비안전 중복 허용 환경값 사용 금지. 자식 계산에 DB/API 비밀 환경 전달 없음.

신규 지표 입력 schemaVersion 2는 공식 `use_inscribed_circle=True`를 고정하여 삼각형 면적·둘레의 내접원 반경 `2A/P`로 CFL 시간 간격을 산정. 이전 schemaVersion 1의 중심→변 중점 거리 방식은 원본 실행 재현용으로 보존. 격자 형상·강우·시설·조도 변경 없이 수치 반경만 구분하며 실제 적용 반경 범위·CFL·최대 시간 간격·엔진 설정을 결과에 기록. 실패한 실행을 자동 재계산으로 교체하지 않음. 근거: [ANUGA 4.0.1 공식 격자 반경 구현](https://github.com/anuga-community/anuga_core/blob/4.0.1/anuga/abstract_2d_finite_volumes/general_mesh.py).

schemaVersion 2는 매 내부 단계의 강우·경계 체적 갱신 후 원 수지와 상태를 읽기 전용으로 검사. 수심/운동량 비유한값·허용 범위 밖 음수 수심·1%/10⁻⁸m³ 초과 원 수지는 즉시 실패, 마지막 내부 시각·체적·누적 최대 잔차·단계 수·실제 시간 간격 범위를 파일로 보존. 화면/강우 출력 경계 사이에 발생한 실패가 마지막 작은 잔차로 감춰지지 않도록 함. 지표 수치 설정과 검사기 소스 해시를 비교 엔진 식별자에 포함하고, 결과 리더에서 개별 엔진·결합 결과·품질 원본 및 완료 시각 일치 검사. 수치 판정을 통과해도 현장 검증 또는 운영 순위 사용 승인을 뜻하지 않음.

개별 엔진의 공개 사례·해석 검증과 아래 결합 수치 검증을 분리. 2D 지표 침투와 관측 기상 기반의 가용 지표수 제한 증발은 연결했으나 공개 서울 연결 관망·침수흔적 대조·토양/식물/지하수 전체 증발산은 미완료이므로 현재 강우·지표 흐름 시험을 완성된 도시 물수지 또는 운영 순위로 전용하지 않음. EPA 사례의 원본 바이너리 출력 일치는 같은 엔진의 비개입 대조이며 독립 현장 검증이 아님. 참조 사례 자체의 수치 실패도 보존.

### 관망·지표 체적 교환 v1

지표 침투 연결 계약: EPA 5.2.4 원본 Green–Ampt 함수를 별도 OpenMP 미사용 라이브러리로 실행하며 계산식을 재작성하지 않음. 명시한 투수 면적비·포화투수계수·흡입수두·초기 수분 부족률·회복계수·근거를 요구하고, 모든 지표 소유 삼각형을 투수 영역 또는 명시적 불투수 영역으로 분류. 자료가 없는 영역을 자동 불투수 처리하지 않음. 관망 소유 삼각형에는 지표 침투를 추가하지 않아 SWMM 손실과 중복 차감 차단. 부분 투수 삼각형은 같은 지표 수심을 공유하는 면적비 근사로 표시. 각 내부 단계에서 흐름→직접 강우→침투 순서로 계산하며 방금 투입한 강우와 기존 고인 물을 분리해 EPA 함수에 전달. 실제 가용수량보다 큰 손실은 실패 처리하고, 물 제거에 비례해 수평 운동량 제거. 총 강우·누적 침투·순 소스·관망 교환 체적을 별도 보존. EPA 수분 회복 상태는 경험식 상태이며 현장 함수율이나 실제 증발산량으로 해석하지 않음. 초기 부족률은 명시된 시드이며 관측 초기 수분을 주장하지 않고 선행 강우 연속 계산·민감도 비교가 필요. 이 단계는 지표 제어체적에서 지하로 나간 물만 계산하며 토양층·지하수·증발산 전체 수지는 별도 연결 대상.

지표 증발 입력 계약: 보관 ASOS/AWS 원문·관측소 메타자료와 고정 계산 코드를 대조하여 FAO-56 기준 잔디 증발산을 재산정. 원문 또는 파생률 불일치·기간 누락은 실패 처리. 이를 지표 고인 물의 잠재 손실률로 적용하는 것은 보정되지 않은 표면 전용 가정이며 수면·포장·식생의 실측 증발량으로 표시하지 않음. 시간별 값은 직전 완료 시간의 다음 시간 유지, 2011 일 자료는 과거 일중 균등 적용으로 구분. 전체 계산 창의 연속 구간을 요구하며 외삽·마지막 값 무한 유지 금지. 각 내부 단계는 흐름→강우→침투→가용 지표수 제한 증발 순서의 명시적 분할이며 시간 세분 비교가 필요. 관망 소유 삼각형에 지표 손실 추가 금지. 잠재 증발 체적·실제 제거 체적·수분 부족으로 충족하지 못한 체적·강우·침투를 분리하고 물 제거에 비례해 수평 운동량 제거. 지표가 마르면 실제 제거량은 0. 지표에서 빠지는 체적만 계산하며 식물 뿌리·토양 수분·지하수 증발을 생성하지 않음. 원 지표 평가는 실제 지표 깊이 변화만 사용하며 잠재량을 효과로 중복 보상하지 않음. 근거: [FAO-56 기준 증발산 정의](https://www.fao.org/4/x0490e/x0490e04.htm), [EPA 표면 가용수량에 따른 증발 제한](https://github.com/USEPA/Stormwater-Management-Model/blob/v5.2.4/src/solver/subcatch.c).

공개 DEM 입력 경로: 원본 압축/래스터 해시·GDAL 원문 WKT·격자 변환·행/열 창·NoData·원시 높이 보존. 격자 중심을 꼭짓점으로 연결하며 보간으로 해상도를 높이거나 외삽·결측 채움·함몰 제거를 수행하지 않음. 수평 좌표는 원본 투영에서 평행 이동만 적용, 높이는 원본 값을 유지. 단위/수직 기준 근거와 조도·초기 수심·외곽 경계의 근거를 별도 필수 입력으로 둠. 제품군 성과 목록은 개별 파일의 제작 시점·기준고 확인을 대체하지 않음. 기준고 미확인 지형의 상대 높이 탐색은 명시한 단위 해석을 가정으로 기록하고 관망 결합·경쟁·현장 침수 판정에서 제외. 사각 격자 창의 경계는 실제 배수 경계로 취급하지 않음.

시간별 경계수위 입력은 UTC 시작/종료·관측 단위·수직 기준·관측 간격 한도·원문 해시를 고정. 관측 사이 선형 보간은 계산값이며 외삽·누락 값의 자동 연결·마지막 수위 무한 유지는 금지. 경계 운동량 0은 정수 저수지 근사로 명시하고 관측 유속으로 표시하지 않음. WAMIS 시간자료의 관측소 눈금 수위와 절대 표고를 구분하며 현재 영점표고를 과거 사건에 소급 적용하지 않음. 해당 시점의 영점표고와 지형 기준고 일치가 확인되지 않은 수위는 상대 기준의 수치 진단에만 사용. 지표 내부 단계에서 시각에 맞는 경계수위를 평가하고 관측 절점에서 단계를 나누며, 관망 결합 시 같은 UTC 시작과 전체 기간을 요구. 근거: [ANUGA 4.0.1 시간 경계 구현](https://github.com/anuga-community/anuga_core/blob/4.0.1/anuga/abstract_2d_finite_volumes/generic_boundary_conditions.py), [WAMIS 청담대교 시자료](https://www.wamis.go.kr/wkw/wl_hrdata.do?code=1018662&name=Seoul).

관망 외부 방류구의 관측 수위는 SWMM 원본 `TIMESERIES` 경계로 연결. 입력 표고는 관저고 위 수심이 아닌 같은 수직 기준의 수면고이며 CMS/CFS 길이 단위 변환만 수행. 관측 시각을 UTC 날짜·시간으로 기록하고 전체 평가 창의 자료 유효성·결측·기준고를 시작 전에 검사. EPA의 시계열 끝값 연장을 관측으로 이용하지 않도록 실행 종료를 관측 창으로 제한. 관저고·역류방지 플랩·재유입 대상은 원본대로 유지하고 원본/변환 INP·변환 근거를 함께 보존. 해당 방류구의 실행 중 수동 수위 덮어쓰기와 지표 교환 포트의 중복 경계 지정 금지. SWMM의 방류구 수심은 연결 관로의 정상/한계 수심 제약도 받으므로 관측 하천 수위와 노드 수두가 항상 같다고 가정하지 않음. 근거: [EPA 5.2.4 방류구 구현](https://github.com/USEPA/Stormwater-Management-Model/blob/v5.2.4/src/solver/node.c), [공식 시간 보간 구현](https://github.com/USEPA/Stormwater-Management-Model/blob/v5.2.4/src/solver/table.c).

원 지표 집계 확장: 평가 시작/끝·외부 방류구·침수 노출 삼각형·젖음 판별 수심·근거를 실행 전에 고정. 정상 하천/저류지 제외 영역을 명시하지 않으면 침수 원 지표를 생성하지 않음. 선택 방류구의 같은 시각 유량 합에서 첨두를 구하고 역류 체적/첨두는 별도로 보존. 내부 교환 방류구는 평가 출구로 지정 불가. 선행 구간은 상태 계산에 유지하되 원 지표에서는 제외.

집계는 SWMM 내부 라우팅 단계와 ANUGA DE0 내부 단계에서 읽기만 수행. 방향별 체적과 깊이×면적×시간은 인접 계산 상태의 선형 보간·사다리꼴 적분이며 평가 경계에 걸친 단계도 해당 구간만 포함. 수심 최고값과 젖은 면적 최고값은 내부 단계 끝점에서 관측한 최댓값으로 표시. 표시 프레임에서 재적분하거나 개별 출구 첨두를 합산하지 않음. 교환의 순간 수심 변화는 0시간 상태 갱신으로 처리하며 인공적인 지속시간을 더하지 않음. 출력 프레임·집계 유무가 물리 상태를 바꾸지 않아야 함. 수치 실패의 원 지표는 진단값으로 보존하고 경쟁 이용 가능으로 승격하지 않음. 새 점수·총점·현장 검증 등급은 별도 고정 정책과 근거가 충족되기 전 보류.

`network-exchange-swmm` 별도 빌드에서 기존 EPA 5.2.4 식·이전 관망/LID 바이너리를 보존. 수평 `BOTTOM` 오리피스의 EPA 위어/오리피스 전환·잠김·역류 식을 사용하며 제원·방류계수·유입부 높이를 입력 원본에서 읽는다. 연결 관망 절점→수평 유입부→지표 교환 전용 방류구 구조, 방류구 하나당 연결 하나와 같은 기준고 요구. 역류방지판·개방률 제어·다른 유입/유출이 섞인 교환 포트는 현재 어댑터에서 거부. 일반 관망의 펌프·제어는 유지. 좌표계·수직 기준 불일치, 중첩 지표 영역, 영역보다 큰 개구부, 지표 아래로 뒤집힌 유입부 기준고 거부.

공식 구현 근거: [EPA 5.2.4 유입부 수리식](https://github.com/USEPA/Stormwater-Management-Model/blob/v5.2.4/src/solver/link.c), [ANUGA 4.0.1 체적·운동량 소스 연산](https://github.com/anuga-community/anuga_core/blob/4.0.1/anuga/structures/inlet_operator.py). ANUGA 기본 연산의 부족 체적 절삭을 그대로 사용하지 않고 양쪽 원장의 같은 체적을 요구하는 별도 교환 연산 적용.

명시적 분할 순서: 단계 시작의 지표 수두로 관망 전진 → EPA 반시간 적분의 방향별 누적 체적 차이 읽기 → 같은 순 체적을 지표에 적용 → 2D 흐름 전진. 지표 수두는 유입부 높이 위 가용 체적/영역 면적이며 격자 내 수위 차를 평균하는 근사로 기록. 유입은 수평 운동량을 추가하지 않고 인출은 기존 운동량을 수심 비율로 줄임. 두 방향의 총 교환량·단계 전/후 수두·가용 체적·지표 적용량·반올림 차이 보존. 교환은 전체 외부 유입/유출에서 제외하여 내부 이동으로 상쇄.

자유 유출 상한과 직전 역류량의 큰 값으로 지표 가용량 25% 이내 교환 간격을 정함. 이는 수치 간격 제한이며 실제 개방률·재료 계수를 조작하지 않음. 정수 밀리초 관망 설정과 최소 1ms 지원, 더 짧은 간격이 필요하면 실패 처리. 지표 초과 인출·연결되지 않은 노드의 월류 발생·누적량 역전·시간 불일치·수지 위반은 실패로 보존하고 음수 수심을 잘라 물을 만들어내지 않음. 단계 적용 전 원장과 마지막 양쪽 상태를 실패 파일에 남김.

관망 소유 강우 격자는 소유 유역 이름·면적과 일치해야 하고 2D 직접 강우를 받지 않음. 외부 유입/강우의 변경 시각은 물리 단계 경계로 반영. 현재 전체 수지의 범위는 관망 라우팅+지표 흐름이며 유역 토양·증발산·오염 물질까지 합친 수지는 아님. 전체 수지 1%·엔진별 게이트와 교환 상쇄 검사를 함께 적용하고 실패 사례를 제외하지 않음. 상대 오차만으로 작은 체적 잔차를 감추지 않도록 원 단위 잔차도 보존.

관측 지표 강우 입력: 저장된 AWS 원문·매니페스트·파생 깊이의 해시를 확인하고 원문을 다시 정규화하여 분별 깊이와 기간·관측소·합계 일치 요구. 명시한 UTC 계산 창 전체가 실제 연속 관측으로 덮여야 하며 분 중간 자르기·창 밖 무강우·보간·미승인 품질 허용 없음. 지표 격자마다 하나의 관측소와 공간 배정 근거를 고정하고 관망 소유 격자는 미배정. 분 깊이→시간당 강도 환산은 그 분 내부의 균일 강도 가정으로 기록. 같은 강도가 이어지는 구간만 합치되 끝 시각은 계산 창으로 제한. 실제 지표 강우 체적을 격자 면적×관측 깊이 적분과 대조하며 강우 자료·공간 배정·소스 코드를 재현 묶음에 보존. 관측 강우의 도입은 지형·관망·경계 조건의 현장 검증이나 당시 재해 복원 등급을 올리지 않음.

프레임 저장 주기는 물리 시간 간격을 제한하지 않으며 요청 시각 이후 첫 계산 상태의 실제 시간을 저장. 중심 상태를 바꾸지 않고 표시용 꼭짓점을 재구성. 교환 단계 RPC에는 체적/유입부 상태만 보내고 전체 관망·SWW는 출력 프레임에서 보존. 재현 묶음에는 양쪽 입력/출력·교환 원장·실패·코드/엔진 해시 포함. 명시적 분할·영역 평균 수두의 시간/격자 민감도는 적용 유역별 확인 대상. 수치 사례 통과를 서울 현장 보정·전체 게임 물리 완성으로 표시하지 않음.

지도용 원 계산 프레임은 선택한 출력 시각의 ANUGA 중심 수심·x/y 운동량을 Float64 little-endian으로 별도 보관. SWW 표시용 꼭짓점 값에서 수심을 역산하거나 인접 격자의 수심을 합성하지 않음. 격자 원형·중심 표고·면적·좌표계·수직 기준·입력/파일 해시와 실제 출력 시각을 연결. 시간 보간 없이 요청 이전의 마지막 저장 시각과 경과 차이를 반환하고 범위 밖 외삽 금지. 8 ULP 이내의 시계 반올림은 같은 시각으로 대응하되 원 요청/저장 시각과 조정량 보존. 유속은 수심 >10⁻⁶m에서 운동량/수심, 그 이하는 표시 유속 0으로 두되 원 수심·운동량 보존. 표시 프레임에서 첨두·침수 지속시간·점수를 재계산하지 않음. 출력 개수/바이트 한도 초과는 명시적 실패로 보존하며 물리 간격이나 격자를 몰래 축소하지 않음. 입력·수치 판정·해시가 확인된 결과만 읽고 수치 통과를 현장 검증/공개 게시 승인으로 취급하지 않음.

2026-10-18 공개 기존 시설 편입 경계: 공개 위치/정격 제원 조회와 물리 계산 입력을 분리. 공간 ZIP의 점 자료·삭제 플래그와 강서구의 호기별 m³/min·유수지 m³는 원문 그대로 보존. 현재 운전량·양정-유량 곡선·유입/출구 연결·제어 수위·당시 존재 증거가 없으므로 무한 출구나 상수 양수량으로 계산하지 않음. 파일 수정일·자료 기준일을 준공일로 치환하지 않고, 재해 당시 시설 목록과 현재 공개 참고 레이어를 구분.

광진구 설비 이력의 설치·증설은 연 단위 근거. 사건보다 뒤에 설치한 설비는 당시 자산에서 제외, 사건 뒤 증설한 설비의 현재 제원을 과거에 전용하지 않음. 같은 연도는 정확한 날짜 미확인으로 보류하고, 설치 연도가 앞서도 당시 존속·운전까지 확정하지 않음. 사건 날짜는 서버 사건 카탈로그에서 결정. 원문의 `kW(HP)` 혼합 표기는 단위 확인 없이 환산하거나 양수량으로 대체하지 않음. 원본·행 번호·구/명칭 검토 대응표·파생 해시와 사건별 판정 보존. 현재 9개 설비 묶음 모두 참고 이력이며 `simulationIncluded=false` 유지.

## 초기 상태·선행 기간 민감도 비교

지표 침투의 선행 관측 연결은 원문 재정규화한 강우와 이전 완료 일의 관측 기상 기반 증발산을 같은 ANUGA/EPA 실행 앞부분에 입력. 지정한 7/14/28일 이전의 수심·수분 부족률은 명시적 시드로 유지. 평가 시작 경계에서 EPA 침투 상태와 지표 수심·저류·누적 원장을 읽기만 하며 엔진 재초기화나 최종 수분값만의 이식 없음. 평가 구간은 시작 누적량을 차감하고 시작 저류량을 포함한 별도 물수지로 집계. 선행 강우의 구간 평균·품질 경고는 보존하고 평가 강우의 엄격한 원문 판정을 완화하지 않음. 기간 비교는 동일 재료 매개변수와 시드에서 수행하며, Green–Ampt의 초기 최대 수분 부족 매개변수를 바꾼 실행을 동일 토양의 건습 상태 비교라고 표시하지 않음. 이 연결은 경험식 토양 회복·지표 가용수량 제한 증발이며 뿌리/지하수 전체 수분 모형이나 현장 함수율 관측으로 승격하지 않음.

현재 경쟁 입력의 선행 7일·시들음점/빈 저류층 정책은 유지. 연구 비교에서는 같은 실제 평가 강우·기상·도형·제원을 고정하고 선행 7/14/28일과 SWMM InitSat 0/100%를 별도 실행. 0은 식재토 시들음점, 100은 공극률 및 저류·배수매트 포화 상태이며 둘 다 관측 초기 수분이 아닌 경계 시나리오. 평가 시작의 토양수분·총저류·층별 수심과 평가 유출/배수/증발/침투·기여의 범위, 시드별 기간 차이를 보존. 비교 구간의 선행 효과는 평가에서 제외. 임의 보편 임계값으로 수렴 인증하지 않으며 실패 조건도 보존. 일부 사건·시설의 작은 차이를 서울 전체 완전 수렴으로 확대 해석하지 않음. 참고: EPA SWMM 5.2 사용자 매뉴얼 [LID_USAGE] InitSat 정의.

선행 비교의 원문 수집은 조회 허용 여부와 관계없이 보관 응답의 해시·겹치는 관측·전체 시간창을 먼저 검사. 완전한 보관 강우는 요청 구간 분할이 달라도 재사용, 실제 분 구간 미확보이고 새 조회가 명시된 경우에만 보완 조회. 원문 변조·중첩 불일치를 새 응답으로 덮어쓰지 않음. 28일 비교에는 7/14/28일 모두 포함하며 경쟁 초기화 정책을 자동 변경하지 않음. 별도 재현 묶음은 원 계산 매니페스트·출력을 보존하고 실행 당시 코드·시설 제원·EPA 원본 소스·관측 빌드 바이너리·의존성 잠금을 함께 저장. 현재 파일과 당시 기록의 일치를 확인한 뒤 포장하며, 재생은 묶음 내부의 코드·엔진을 사용. 다른 플랫폼의 이진 일치를 주장하지 않고 별도 수치 비교 필요.

신규 후보 v6의 빗물정원은 공개 토성군에서 추정한 원지반 투수계수를 EPA의 하부 침투 경계에 명시적으로 연결. SWMM 5.2.4는 RG STORAGE 입력이 없으면 storage.kSat=0으로 초기화하므로 `RG STORAGE 0 0 Ksat 0`으로 하부 침투율만 지정. 두께·공극 체적 0 유지, 가상의 쇄석층·추가 저류 용량 생성 없음. 토성 미확보 후보는 기존 설계 투수계수의 가정임을 보존. 차수막 없는 설계 조건이며 실제 부지의 차수막·지하수·매설물·다짐 확인을 뜻하지 않음. 후보별 적용률·출처 수준·방법을 입력과 계산 결과에 보존. v5 이하의 원문·점수·기존 계산 입력은 소급 변경하지 않고, 원지반 침투 미연결 결과는 해당 한계를 표시.


## 연결 지하 저류조

연결 지하 저류조 설계는 원 관망 해시에 결속한 별도 파생 입력으로 생성. 원 관망과 같은 높이 기준의 바닥고·깊이-수면적 표·초기 수심·덮개/차수 조건·유입구/배수구/비상 배수구의 치수·유량계수·역류방지판 근거를 필수로 사용. 현재 컴파일 범위는 명시적 설계이며 현장 확인·설치 승인·경쟁 자격을 부여하지 않음. 깊이-수면적 표의 구간 적분으로 용량 계산, 최상단까지 표를 제공하고 임의 외삽 금지. 기존 내부 절점으로만 연결하고 배수 대상은 기존 방류구까지 연결된 하류 절점이어야 함. 원 관로 삭제·임의 외부 출구·무한 배수 생성 금지.

하류 수위에 따른 역류를 EPA SIDE 오리피스 식으로 계산하고 역류방지판은 명시한 경우에만 적용. 국부 개구부 모델이므로 긴 접속관 마찰·침전·막힘을 포함한 것으로 표시하지 않음. 추가 압력 수두와 저장 용량 구분, 배수 용량 초과로 발생한 미연결 절점 월류는 결합 실패로 보존. 지표의 토지/강우 소유권은 변경하지 않는 지하·덮개·차수 설계 범위이며 개방 저류지는 직접 강우/증발/침투의 면적 소유권 연결 후 별도 확장. 근거: [EPA SWMM 5.2 매뉴얼](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=P10145M6.TXT) 3.2.6·B.6·C.20·STORAGE/ORIFICES 입력 정의, 고정 5.2.4 소스의 저장 체적·오리피스·절점 수지.

저류조는 선행 관측 초기화 전에 관망에 연결하고 같은 엔진 상태를 평가까지 유지. 시작/종료 절점의 유입·유출 누적량과 저장량으로 전체/평가 구간 수지를 분리. 절점 유출 누적량의 월류는 다시 차감하지 않으며 관망 전체 수지에 포함된 저류조 체적·흐름을 추가 합산하지 않음. 원 요청·컴파일 INP·실제 실행 INP의 시설 행·네이티브 상태·요약을 연구 리더에서 대조. 수지·수렴 실패를 성공 효과로 승격하지 않고 이전 실행 원본·코드 보존.

## 개방 저류지의 지표 설계

개방 저류지 설계는 원 모형 해시에 결속한 지표 절토 격자로 계산. 원본 높이/격자·관측·경계·유역 강우 면적을 보존하고 선택한 지표 소유 격자 내부의 설계 높이·재료만 별도 파생. 격자 경계 높이는 유지하여 범위 밖 지형을 함께 바꾸지 않으며 초기 물이 있는 영역의 공사 중 상태 변경은 거부. 직접 강우·침투·가용수 증발은 ANUGA의 같은 지표 원장에서 한 번만 계산. 추가 SWMM 저류 노드로 용량을 중복 생성하지 않음. 명시한 바닥 배수구는 기존 내부 관망 절점과 양방향 교환, 둑 월류는 연결된 주변 격자의 흐름으로 계산. 정상 저류지 영역은 비교 전에 고정한 침수 노출 영역과 분리하며 실행 도중 지표를 유리하게 변경하지 않음. 원 지형과 설계 지형·절토량·최저 경계고 기준 저장량·선행/평가 경계의 지표 저장 상태 보존. 부분 영역의 저장량을 유역 수지에 다시 더하거나 경계 흐름을 별도 계측한 것처럼 표시하지 않음. 설계 지형은 현장 DEM·실제 시설 준공 상태가 아니며 기존 수평 유입부의 영역 평균 수두 근사와 격자 해상도 한계 유지.

입력은 현재 격자에 정합한 절토 높이·연속된 내부 영역·차수/투수 재료·조도·유효 배수구 제원을 요구. 주소점의 임의 버퍼·설계 높이 외삽·유역 외곽을 저류지 둑으로 사용·원 관망의 무한 외부 배수구 생성 금지. 최소 경계고 기준 용량은 격자 중심 수심의 이산 적분으로 표시하고 부지의 실측 용량으로 승격하지 않음. 바닥 침투·증발은 기존 지표 물성/기상 모형의 한계 유지. 근거: [ANUGA 4.0.1](https://github.com/anuga-community/anuga_core/releases/tag/4.0.1)의 고정 지표 계산, [EPA SWMM 5.2](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=P10145M6.TXT)의 오리피스와 DYNWAVE 연결.

저류지 설계 v2는 위 이산 저장량과 별도로 원 꼭짓점 사이 선형 지형의 수위–잠긴 평면적–체적을 제공. 수평 수면이 삼각형을 자르는 부분을 높이 구간별로 적분하며 마른 경사면 전체를 젖은 면적으로 세지 않음. 바닥부터 최저 경계고까지 최대 33개 수위의 값을 각각 계산하며 표 사이 선형 보간을 정확한 용량 함수로 사용하지 않음. 모든 낮은 영역에 같은 수위를 놓는 기하 적분이므로 독립 함몰의 채움 순서·수리 연결·실제 저류지 부지·시공 가능 용량의 증거는 아님. 기존 ANUGA의 중심 저장량·물수지·수심·효과는 유지하고 적분 차이는 별도 표시. v1 입력/메타데이터 재현 유지. 기하 범위 참고: [TIN과 기준면 사이 체적](https://doc.esri.com/en/arcgis-pro/latest/tool-reference/3d-analyst/tin-polygon-volume.html); 구현은 삼각형의 선형 높이에 대한 독립 구간 적분이며 Esri 도구 실행 결과가 아님.

개방 저류지와 지하 저류조의 동시 설계는 같은 원 모형·원 관망에 결속한 두 설계를 각각 검증한 뒤 추가 절점/곡선/오리피스 행만 합성. 원본 해시를 파생 관망 해시로 바꿔 검증을 우회하지 않음. 연결 대상은 원 관망의 내부 절점으로 한정하며 다른 신규 시설을 원래 존재한 절점처럼 참조하지 않음. 같은 관망 수두·지표 흐름에서 상호작용을 계산하고 개별 실행의 효과 합으로 대체하지 않음. 지하 저장은 관망 수지에, 개방 저류는 기존 지표 수지에 각각 한 번만 포함. 원본·개별 파생·합성 INP·합성 코드/해시/추가 행을 보존하며 결과 읽기에서 실제 실행 입력과 대조. 선행 초기화와 LID 설계는 합성 관망에 이어서 적용하고 평가 전 상태를 유지. 현장 입지·지하 공간 중첩·공사비 검증이나 운영 설치 자격의 증거는 아님.

## 관망·지표의 연속 선행 초기화

관망·시설·지표의 관측 선행 초기화는 동일한 두 엔진을 평가 종료까지 유지하는 연속 실행으로 연결. 시설 수분만 복사하거나 평가 시작에 관망/지표를 다시 생성하지 않음. 강우·기상·경계는 선행 전체 기간을 충족해야 하며 외부 유입 시각을 자동 이동하지 않음. 평가 경계의 시설·관망 누적량, 지표 수심/속도·침투 상태·교환 누적량을 보존하고 경계 전 기여를 차감. 시설/라우팅/지표 및 결합 수지의 범위를 구분하며 하나라도 실패하면 효과 계산을 진단 실패로 유지. 연구 재현 리더는 원 요청·파생 입력·평가 경계·최종 상태·원 지표를 함께 대조. 실제 서울 좌표/기준고·관망·지형 연결 요건은 초기화 구현 여부와 별도로 적용.

연결 초기화 비교는 공통 원문 참조로 7/14/28일과 생물저류·침투 트렌치·빗물이용조 묶음의 InitSat 0/100%를 분리. 포화율 입력이 적용되지 않는 식생수로는 0 고정 및 비영 입력 거부. 기간에 따른 시작 시각·시설 시드·명시한 교환 시간 간격 이외의 지형·재료·연결·평가 입력 변경은 비교 거부. 관망/지표의 시작 수량·토양 매개변수는 고정하므로 이를 전체 토양/관망의 건습 시드 비교로 표시하지 않음. 실행 실패·수치 실패를 비교 결과에서 삭제하거나 0 효과로 바꾸지 않고 해당 차이를 보류. 평가 시작 시설 수분·저류, 관망/지표 저류, 평가 원 지표와 수지 잔차를 함께 보존. 같은 조건 재생과 시간 간격 비교를 별도 표시하며 보편 수렴 임계값이나 운영 7일 정책을 자동 발행하지 않음.

선택한 `BOUNDED_DRY_TAIL_ROUNDOFF_V1` 수치 정책에서만 건조 유입부의 직전 유량 반시간 적분 꼬리를 1ms 간격으로 종료. 현재 자유 유입 상한이 0이고 예상 꼬리가 10⁻⁹m³ 이하일 때만 적용. 실제 부족량도 교환당 10⁻⁹m³·전체 실행 10⁻⁸m³를 넘으면 실패. 부족분을 관측 강우나 외부 수원으로 생성하지 않고 요청/실제 교환 체적 차이·수지 잔차로 보존. 기존 정책의 건조 실패와 입력/코드 보존, 시설 제원·침투율·초기 수분 변경 없음. 이 수치 허용은 물리적인 가용 수량 부족을 허용하는 규칙이 아님.

지표 교환 종료 시각은 관망의 정수 밀리초 시계에서 산정. 현재 지표 시각이 밀리초 경계에서 기존 시계 일치 허용치 10⁻⁸초를 벗어나면 거부하고, 범위 안의 반복 덧셈 잔차는 다음 절대 밀리초 목표로 누적하지 않음. 관측 기상 종료를 늘리거나 외삽을 허용하는 변경이 아니며 기존 시각 실패·코드와 새 실행 근거를 각각 보존.

## 격자 내 토양 면적 분할

지표 침투 v2는 같은 삼각형 안의 여러 토양을 독립 EPA 상태로 계산하며 삼각형 수심을 공유하는 면적 분할 근사로 표시. 각 투수 부분의 면적비와 명시적 불투수 부분의 합은 1이어야 하며 허용 오차 10⁻¹²는 부동소수 면적 연산에만 적용. 누락 면적의 자동 불투수 처리·면적비 정규화·토양 매개변수 평균 금지. 침투량은 부분 면적별로 계산한 뒤 삼각형별로 합산하여 물과 운동량을 한 번만 제거. 부분별 상태·침투량과 삼각형별 합계 보존. 기존 v1 입력과 결과 의미 유지.

공간 배정은 원본 DEM 삼각형과 공개 토양/토지피복 폴리곤의 실제 교차 면적으로 수행. 원본 구멍과 다중 도형 유지, 경계 접촉 면적 0 제외. 같은 분류라도 겹친 원본은 임의 우선순위로 선택하지 않고 중복 영역 보존. 오류 도형의 영향 범위·미피복·자료 시점·좌표 변환 정확도 미확인을 별도로 기록. 토지 이용 분류를 관측 투수율로 치환하지 않으며, 공간 교차 결과만으로 침투 입력을 활성화하지 않음. 전체 면적의 물리 분류 근거가 없는 경우 미해결 원인을 반환하고 불완전한 격자/유역을 잘라 계산하지 않음.


## 공개 도시생태현황도의 표면 구성 입력

서울시 도시생태현황도 2025/2020/2010 원본을 판년도별로 보관. 블록의 건폐율·불투포장율·투수포장율·녹지율·기타비율·불투토포비 원값과 원본 고유번호/행 순번을 보존. 합계 100과 건폐율+불투포장율=불투토포비를 10⁻⁷%의 수치 허용 오차로 대조하며 누락·범위 초과·불일치 값을 정규화하지 않음. 토양포장 범례와 숫자값의 모순도 원문 그대로 표시. 비율은 블록의 조사/영상 기반 속성이며 각 DEM 삼각형 안에서 같은 비율을 적용하는 것은 공간 균질 배정 근사. 실제 포장 위치의 측량 결과로 표시하지 않음.

투수포장 면적을 자연 토양 Green–Ampt 영역으로 자동 전용하지 않음. 녹지·나지와 투수포장을 별도 면적 구성으로 보존하고, 포장층 제원 없이는 투수포장 물리 입력을 완료로 표시하지 않음. 2025 최종보고서의 111~112쪽 속성 정의와 264쪽 주석 66(일부 투수포장의 면적 미산정·불투수 면적 과대평가 가능), 267쪽 주석 67(건설현장의 기타비율) 반영. 2020/2010의 동일 필드도 2025 작성 방식과 동일한 현장 조사였다고 단정하지 않음. 판년도만으로 사건 당일 유효성을 확정하지 않으며 현재 지형+과거 속성 비교는 별도 탐색 등급 유지.

생물저류 직접 강우 설계 v2: 지상 후보 전체가 공개 토성 도형에 포함되어 양수 원지반 투수계수 추정값이 있는 경우만 BC 허용. EPA 표 6-2·6-3의 식재토·저류층 설계값은 관측값이 아니며, 원지반·시설 식재토 제원을 분리. 하부배수관·외부 집수 유입 없이 표면 월류·식재토 침투·쇄석 저류·원지반 침투·증발을 계산. 차수막·지하수·다짐·지장물은 미확인 조건이며 해당 조건을 실제 시공 적합성으로 해석하지 않음. 선행 실제 강우·기상 7일을 같은 상태로 이어 계산하고 선행 효과는 평가에서 제외. v1 제원·v6 후보와 기존 저장 계산을 소급 변경하지 않음. 생물저류 원가 v3는 공개 식생체류지 참고 단가와 시설 상세 규격의 불일치를 명시하고 전체 현장비는 미확정 유지.

회원 저류조 설계는 원 관망·수치 파생 해시에 연결된 내부 관로만 선택하며 두 절점의 바닥/상단고 안에 모든 원형 개구부가 들어가는지 서버와 워커가 검사. 저장 용량은 깊이-수면적 적분, 자체 강우/증발/침투는 덮개·차수 조건으로 0. 유입·방류 방향은 수두와 플랩 조건으로 결정하고 임의 제거 유량을 사용하지 않음. 저류조 월류·수지 실패 시 전체 비교를 실패로 유지하며 기존 관망 월류 총량을 지표 수심으로 대체하지 않음. LID와 저류조의 추가 입력을 같은 관망에서 실행하고 기존 강우·관로·외부 유입 불변.

회원 관로 개량은 원 공개 INP의 CONDUITS/XSECTIONS 행 및 전체 원본 해시와 대조. [EPA 5.2.4 관로 입력](https://github.com/USEPA/Stormwater-Management-Model/blob/v5.2.4/src/solver/link.c)의 단면·병렬 관 개수·Manning 조도를 DYNWAVE 엔진에 전달하며 임의 유량 제거/저감 계수 금지. 원 연결 절점·길이·유입/유출 오프셋·초기/최대 유량·국부 손실·강우·외부 유입·하류 경계 불변. 저류조 추가와 관로 개량의 파생 순서/각 해시 보존, 동일 원 관로의 중복 변경 거부. 수치 실패를 효과 0으로 치환하거나 관경 확대의 하류 악화를 숨기지 않음.

관로 내부 높이의 한계는 원 접속 절점의 최대 깊이에서 해당 관저고 오프셋을 뺀 값의 최솟값으로 계산. 깊이 없는 외부 방류구에 임의 지표고를 부여하지 않으며 알려진 내부 절점만 사용. 이 한계는 공개 연구 모형 내부의 연결 정합 조건이며 현장 매설·도로 폭·시공 허가의 증거가 아님.

회원 빗물이용조 견적 비교는 보관 JKSWE 2018 표 9의 2.35m³ 단위 견적 A·B·C를 별도 비용 스냅샷으로 연결. 설계 용량이 2.35m³의 정수배일 때만 같은 총용량의 견적 묶음을 비교하며, 개수·상세 치수·배수구·펌프의 물리적 동일성을 주장하지 않음. 비정수 용량은 금액 외삽 없이 미산정. 표의 총액·자재 소계·공종별 미기재·차액을 보존하고 연간 비용 가정은 물리 전력량과 구분. 기존 면적 단가 부분합에 자동 합산하거나 현재 서울 총공사비·예산 차감으로 사용하지 않음. 요청 시 카탈로그 해시와 서버 산정값을 고정하고 워커가 설계 용량·원문·금액을 재검증, 미요청 과거 기록 보존.

회원 관망 결과의 절점 월류도는 같은 실행의 내부 라우팅 단계에서 읽기 전용 사다리꼴 적분한 `floodingM3` 사용. 5분 표시 프레임·최종 순간 유량·보고서 반올림 통계를 누적 체적으로 대체하지 않음. 시작 0초부터 원 엔진 종료 시각까지 전체 절점 합계와 관망 월류 총량 대조, 원본 관망도 해시·절점 유형·비교 기간 결속. 추가 저류조 절점도 전체 합계에 포함하되 실제 위치가 없으므로 지도에 좌표 생성 금지. 기준/설계의 절점별 부호 있는 변화와 원 체적을 보존하며 수치 실패 시 개선·악화 표시 보류. 색상은 지점별 누적 월류량이며 지표 침수 깊이·범위 아님. 기준·설계 절대량의 색상 상한은 동일하게 사용. 기존 결과는 절점 자료를 소급 생성하지 않고 원 기록 유지.

### 공개 펌프 곡선·압력관 계산 · 2026-10-18

KSB 제조사 `1580.5/13-EN`(2024-04-16) 14쪽 `K4200358s/2`의 Amacan PA4 500-270, 50Hz·1450rpm·날개각 17° 곡선 적용. [공개 원문](https://www.lenntech.com/Data-sheets/KSB-AmaCan-P-50-Hz-EN-L.pdf)은 `data/private/facility-reference-20261018/`에 보관하고 원문 해시 `359a742139ec004925f7190fcce8f7e0914206443e97fb05bf1cd07e8864a647` 고정. 전체 PDF 재배포 권한을 가정하지 않으며 공개 저장소에는 수치 추출과 출처만 보존. `scripts/prepare_pump_curve.py`로 벡터 경로와 축 기준을 읽어 `data/derived/pump-curves/ksb-pa4-500-270-1450-17-v1.json` 생성. 양정·NPSHr·축동력 세 곡선의 공통 공개 범위 안에서 700~1000m³/h를 10m³/h 간격으로 사용. 이 범위를 제품의 전체 운전 범위나 서울 펌프 성능으로 일반화하지 않음. 60Hz 변환·상사법칙 확장 없음. 선 두께에 따른 약 ±0.0264m 양정 판독 폭과 표본 보간 차이 최대 0.001475m 별도 보존. 제조사 제작 공차나 현장 불확실성의 대체값 아님.

`connected_pumps.py`는 새 펌프→토출 접속 절점→유한 길이 FORCE_MAIN→원 관망 내부 수신 절점으로 연결. 기존 원 관로·강우·외부 유입 유지. 원 관망에 FORCE_MAIN이 없을 때만 미사용 H-W 옵션을 D-W로 변경하며 기존 H-W 압력관이 있으면 거부. 역류방지판·관경·절대조도·국부손실·허용 압력수두는 명시적 설계 입력. 부분 충만 등가 Manning n은 EPA forcmain.c의 완전 난류 변환으로 산정하며 임의 계수를 추가하지 않음. D-W 엔진은 20°C 동점성 상수를 사용하므로 실시간 수온 반영으로 주장하지 않음. 제조사 양정 기준은 모터 위 0.5m의 기준면이며 해당 지점까지의 라이저 손실 포함. 기준면 이후 접속관·입구/출구 손실과 흡입부 조건은 현장 검증되지 않은 설계임을 표시.

별도 `pump-network-swmm` 빌드는 기존 바이너리를 보존하고 내부 단계의 수위차·유량·기동/정지·가동 시간·이송량·필요흡입수두·축동력만 관측. 이송량은 내부 체적이며 외부 유출 감소로 합산하지 않음. 축동력 P(Q)를 단계 끝값으로 시간 적분하며 전력 효율·전기요금을 가정하지 않음. 성능곡선 범위 밖의 EPA 끝점 유량 유지가 성공 효과로 들어가지 않도록 범위 이탈 시간을 별도 기록하고 실행 실패 처리. 토출 접속부의 허용 압력수두 초과 월류도 실패 처리. NPSHa·최소 잠김이 없으므로 캐비테이션 판정은 `NOT_EVALUATED`, 순위·현장 안전성·당시 재현 승격 없음.

`run_pump_design`은 원 입력·설계·변환·곡선·INP/RPT/OUT·엔진/소스·계산 코드·물수지·외부 출구 지표·펌프 운전 원장을 함께 보관. 보관 `replay.py --output 새폴더`로 같은 플랫폼의 바이너리 OUT·펌프 원장·외부 출구 지표를 대조. 비용은 미확정이며 0원이나 예산 사용으로 대체하지 않음. 회원 API/공통 설계 화면은 아래 계약으로 연결. 실제 자산의 기동 수위·펌프 모델 대응은 잔여 구현 범위.


회원 펌프 요청은 원 관망·공개 곡선 해시·공통 시설 식별자에 결속. 공개 원 내부 절점과 같은 요청의 지하 저류조만 흡입점으로 허용하고 토출점은 원 관망의 연결된 하류 내부 절점으로 제한. 원본→저류조→관로 개량→펌프→LID 순서의 파생을 보존하며 원본 해시를 파생 해시로 치환하여 검증을 우회하지 않음. 기준안에는 신규 시설을 넣지 않고 같은 펌프 관측용 바이너리로 비교. 추가 토출 절점은 물수지·월류 합에 포함하되 좌표를 만들지 않음.

재현 묶음에 펌프 곡선·원 요청·파생 단계·네이티브 관측 코드/빌드·운전 원장을 포함하고 재생 시 같은 13개 운전 누적값·OUT·출구 지표·절점 월류를 대조. 클라이언트는 중복/누락된 펌프, 다른 설계의 기록, 토출 월류/운전 범위와 판정 불일치를 정상 결과로 표시하지 않음. 실패 원장과 축에너지 산정 보류를 그대로 표시. 공사비·최소 잠김·NPSHa·실제 자산 대응·서울 지도 설치 미확보는 계속 유지.

펌프·지표 결합 계약: 공개 곡선 기반 펌프를 저류·LID·양방향 지표 교환과 같은 SWMM 상태에 연결. 펌프 이송은 관망 내부 이동으로만 기록하고 지표·유역 외부 유입/유출에 다시 더하지 않음. 선행 운전과 평가 구간 운전은 별도 네이티브 관측 메모리로 분리하며 평가 시작에 계속 운전 중인 펌프를 신규 기동으로 세지 않음. 토출 지점의 관망 수위와 실제 지표 교환 수두로 역압·월류·재유입 계산. 연결되지 않은 토출부 월류·공개 성능 범위 이탈은 실패 보존. 원본/시설 합성/펌프 파생/초기화/실행 입력과 원장·코드·곡선 해시를 연구 리더에서 대조. 새 결합 빌드만 추가하고 기존 독립 펌프·관망·LID 바이너리와 보관 결과 유지.

평가 시작/종료는 결합 시계의 명시적 경계로 추가하며 이를 가로지르는 내부 단계를 비례 배분하지 않음. 평가 시작 전 마지막 유량·운전 상태만 평가 관측기에 넘기고 체적·에너지·기동 누적량은 넘기지 않음. 평가 종료 뒤에도 전체 수리 계산은 계속. 새 관측기를 제거한 빌드와 OUT·지표 지표가 같아야 하며 표시 간격과 계산 간격을 구분. 연구 리더는 원 곡선 파일 해시, 펌프/압력관/곡선의 실제 입력 행, D-W 옵션, 전체/평가 운전 시간·범위 판정·토출부 월류와 최종 절점 기록을 대조. 실패를 재해석한 성공 결과 거부.

`data/benchmarks/coupled-pumps-v1.json`은 공개 제조사 곡선과 합성 관망/지표의 수치 증거. 기본 사례의 이송 8.002366m³ 중 지표 월류 1.785935m³·재유입 1.709279m³, 교환 상쇄 잔차 1.89×10⁻¹⁵m³. 전체 결합 수지 잔차는 별도로 −0.384867m³이며 현장 정확도 또는 오차 없는 보존으로 표시하지 않음. 7일 실제 선행 강우/기상·4종 LID·지하 저류·개방 저류·펌프를 함께 계산한 사례는 0.25초 라우팅에서 비수렴 10회·곡선 범위 이탈 0.75초로 실패. 0.05/0.01초에서도 미연결 토출부 월류로 실패하여 간격 축소에 따른 수렴을 주장하지 않음. 실패한 전체 계산을 평가 물수지 통과만으로 승격하지 않으며, 초기 상태·실패·원본/코드/바이너리와 독립 재생을 보존. 실제 서울 자산·지형·좌표 정합과 안정한 결합 설계 검증은 잔여 범위.

결합 수치 설정 파생 계약: 원 관망·시설·강우·지형과 별도로 명시한 `networkNumericalProfile`만 적용. 기존 `network_variant`의 SURCHARGE_METHOD·ROUTING_STEP·MINIMUM_STEP·MAX_TRIALS 허용 목록을 재사용하고 물리 입력 해시 동일성 검사. 시설 합성 뒤, 선행 초기화 전에 적용하여 전체 계산에서 동일 설정 유지. EXTRAN↔SLOT은 압력 계산 근사의 변경으로 표시하며 원 실행과 설정·소스·파생 입력을 보존. 기본값 자동 변경·실패 허용치 완화·통과 설정의 운영 자동 발행 금지.

결합 수치 설정은 물리 입력 해시를 유지하는 4개 옵션만 파생. `MIN_SURFAREA`와 수렴 오차 완화는 이 프로필에서 허용하지 않음. 절점 면적 민감도 시험은 원 합성 입력을 별도 버전으로 생성하고 `NUMERICAL_AREA_NOT_SITE_GEOMETRY`로 표시. 원 0.01m²와 EPA 공식 기본 12.566ft²(1.16744024544m²), 그 절반을 분리. 이 기본값은 현장 맨홀 제원의 확보가 아닌 수두 갱신용 최소 수치 면적. 근거: [EPA SWMM 5.2 매뉴얼 §8.1.4](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=P10145M6.TXT), 고정 EPA `dynwave.c`의 DEFAULT_SURFAREA.

관측 선행 7일·평가 21,540초의 같은 합성 시설 묶음에서 SLOT·공식 기본 절점 면적은 0.05/0.025초 모두 비수렴·성능곡선 이탈 0. 외부 유출 차이 0.00102573m³·펌프 이송 차이 0.0393982m³. 0.05초 실행의 결합 수지 잔차 0.704791m³는 별도 보존. 반면 절점 면적 절반과 원 0.01m²는 반복 횟수 40→200 또는 시간 간격 축소에도 일부 비수렴이 남아 실패. 작은 지표 차이만으로 실패를 통과시키거나 전체 수치 설정의 수렴으로 확대하지 않음. `data/benchmarks/coupled-numerics-v1.json`에 정상/실패 10개 실행과 기준을 보존.

독립 재생은 외부에서 고정한 매니페스트 해시·개별 파일 해시·경로/심볼릭 링크를 확인한 뒤, 목록에 포함된 코드·바이너리·공개 입력만 새 임시 작업 공간으로 복사해 실행. 원 보관 경로에 추가된 미검증 모듈/바이트코드를 가져오지 않음. 정상과 실패의 OUT·평가 경계 상태·저류/시설/펌프 원장·물수지·지표를 함께 대조하며 실패의 재생 일치를 물리 통과로 표시하지 않음. 명령은 `scripts/replay_coupled_bundle.py --bundle 묶음 --manifest-sha256 고정해시 --case 상대실행경로 --output 새경로`. 같은 플랫폼의 네이티브 이진 재생이며 현장 정확도 판정과 별개.

빗물받이 확장 계약: 기존 공개/명시적 설계 관망의 STREET·개수로에 EPA 5.2.4의 HEC-22 격자 유입부를 연결. 길이·폭·격자 유형·수량·막힘·국부 침하·경사부/저점 배치를 입력으로 보존하고 원 지형·관로·집수 연결을 임의 생성하지 않음. 포착과 하수관 월류의 지표 반환은 EPA 내부 단계 값을 각각 보존하며 내부 이송을 외부 배수·침수 저감으로 중복 합산하지 않음. EPA의 하수관 월류 배분은 2D 지표–관망 수두 결합과 구분. 빗물받이 제원/공식 수식의 수치 검증과 서울 실제 설치·가격·현장 효과 검증을 분리. 원 관망에 도로/개수로가 없으면 이 설계 요청을 거부.

빗물받이 관측 원장은 EPA `inlet_findCapturedFlows`가 실제 적용한 단계별 포착/반환 유량×시간을 보존. 포착 절점 월류는 EPA 자체 외부 손실 집계에서 제외되므로 별도 관측 빌드에서도 지점별 외부 월류 합계에서 제외하고 내부 반환량으로 제공. 수리식·상태·시간 간격 변경 없음. 원형 수평 오리피스의 2D 결합과 별도 엔진이며 임의 포착 효율로 대체하지 않음. 짧은 건조 시작 도로/개수로 6진단은 물수지 실패 유지, 원 엔진 OUT 일치 및 역류 독립 재생은 재현성 근거만으로 사용. `data/benchmarks/connected-inlets-v1.json`과 공개 코드 원본 `data/manifests/epa-inlet-model-v1.json` 보존.

관망 공간 세분 계약: 원 관로의 총길이·단면·조도·양 끝 절점/관저고를 유지한 계산 구간 분할만 별도 입력으로 허용. 중간 절점은 수치 연결점이며 신규 맨홀/실측 자산 또는 추가 저류 시설로 표시하지 않음. 최소 수치 절점 면적은 현장 면적과 분리해 명시·기록, 원 설정/과거 실패 유지. 수두 허용치와 물수지 승인 기준은 자동 완화하지 않음. 끝 구간에 원 관로 ID를 유지하여 기존 빗물받이의 하류 위치 보존. 지원하지 않는 오프셋·손실/제어·초기 수심·단면은 추정 변환하지 않고 거부. 계산 절점의 월류가 생기면 실제 배수 경로가 없으므로 결과 개방 거부.

폐관 중간 연결점의 허용 수두는 원 끝 절점의 최대 허용 수두를 사용하며 실제 맨홀·압력 한계의 관측값으로 취급하지 않음. 원 관로 ID의 출력은 분할 후 마지막 구간의 출력으로 범위가 바뀌므로 전체 관로 지표로 오인하지 않도록 메타데이터 보존. `MIN_SURFAREA`는 기존 절점에도 적용되는 전역 수치 설정이며 분할점만의 물리 면적 아님. 초기 수심·관로 유량·오프셋·곡선 경계수위·손실·제어·중간 형상이 있는 입력은 현재 세분 경로에서 거부.

`data/benchmarks/refined-inlets-v1.json`: 50m 구간 16분할·최소 수치 면적 0.0001m²·SLOT·0.01초·최대 반복 200회·원 수두 허용치 10⁻⁶m의 명시적 합성 시험. 경사부 수지 잔차 0.00207008m³(0.0347609%)·비수렴 0, 도로 잔차 0.00127121m³·비수렴 0. 0.005초 경사부도 통과하며 포착량 차이 0.0000932876m³. 여러 수치 설정을 함께 바꾼 결과이며 개선의 단일 원인을 확정하지 않음. 32분할은 비수렴 6회, 막힘/저점 각각 1회, 역류는 잔차 −0.368784606m³로 실패. 시설 수지 실패·외부 출구 지표 미완료도 세분 실행의 실패 사유에 포함하며 관망 수지만으로 승격하지 않음. 독립 재생에 `--kind refined-inlet-network` 추가: 원 입력·설계·세분 요청·수치 프로필·변환 내역·원 결과의 결속을 검증하고 같은 보관 코드로 다시 컴파일. 입력·OUT·내부 포착/반환·수지·계산 절점 월류·실패 사유를 대조. 정상/역류 실패/계산 절점 월류 실패의 세 사례 재생 일치, 기존 빗물받이 묶음의 재생 호환 유지.

지표 흐름 방향 표시 계약: 원 Float64 수심·운동량 파일은 변경하지 않고, 원 투영 좌표에서 EPSG:5186 지도 좌표로 변환하는 국소 미분행렬을 각 격자 중심에 별도 보관. ±0.5m 중앙차분과 ±0.25m 차분의 상대 차이 10⁻⁶ 이하·유한성·비특이성 검사, 좌표축 x/y 순서·변환 경로·코드 해시 보존. 원 운동량/수심의 속력은 그대로 유지하고 지도 방향만 정규화한 단위 벡터로 반환. 마른 격자·정지 상태·방향 없는 이전 기록은 화살표를 만들지 않음. 원 격자·시각·해시/권한 결속 유지, 렌더링용 격자 선택과 화살표 길이는 계산·총점에 영향 없음. 주간/재해 및 2D/3D는 동일 방향 자료·공통 생성 함수 사용. 수면 표고가 아닌 지표에 올린 계산값 표시이며 실제 침수 관측으로 승격하지 않음.

관망 재생 계약: 완료 보고서에 고정된 원 초기 상태·기록 프레임의 해시를 검증한 뒤 본인에게만 필요한 시각의 수위·수심·저류·월류 유량·관로 유량을 제공. 같은 요청 시각에 기준안/설계안 각각의 직전 원 기록을 선택하고 실제 기록 시각·지연을 표시. 보간·마지막 기록 뒤 외삽·표시 프레임으로 첨두 재산정 금지. 원본 좌표 관망도에서 유량 부호에 따른 방향을 표시하고 좌표 없는 추가 시설은 수치 목록으로 제공. 수치 실패 기록은 진단 표시로 유지하며 성공/효과로 승격하지 않음. 읽기 전후 회원 상태·소유권 재확인, DB 해시와 입력·결과 결속, 파일 크기·프레임/객체 수 제한과 변경/심볼릭 링크 거부. 기존 24시간 외부 유입을 선행 기간이나 다른 재해 날짜로 자동 이동하지 않음.

공개 DEM 배수 경로 계약: 원 타일 전체의 8이웃에서 고도차/실제 투영 거리의 최대 하향 경로만 추출. 함몰·평탄부·경사 동률·결측 이웃·타일 외곽은 미해결 종점으로 보존하고 원 높이 채움/절삭·외부 배수구·임의 수량 배분 생성 금지. 전체 유효 픽셀의 기여 수를 각 미해결 종점까지 정수 누적하여 면적 분할 보존. 경사 동률의 상대 수치 허용치 10⁻¹²는 선택 거부 기준이며 물리 보정값 아님. 같은 고도라도 수두·관망에 따른 역류/월류가 가능한 2D 수리 계산과 구분. [Esri D8 최대 하향 경사 설명](https://doc.arcgis.com/en/arcgis-online/analyze/how-flow-direction-works.htm)을 경로 정의 근거로 사용하며 해당 도구의 함몰 채움·동률 해소 구현을 복제한 것으로 표시하지 않음.

기존 13×13 원본 창과 전체 타일의 높이 완전 일치 확인 후 창 외부에서 유입되는 알려진 경로·기여 픽셀·면적을 산출. 원 픽셀 면적과 중심 간 삼각 격자 면적은 다른 공간 범위로 명시. 미해결 경로를 제외한 면적을 완전한 실제 집수면적으로 확대하지 않고 결과를 반사벽/자유 방류 경계에 자동 적용하지 않음. 성동 2025 DEM 79,380픽셀에서 기존 창으로 들어오는 경로 11개·외부 기여 29픽셀(234,900m²)·창 내부 미해결 함몰 12개 확인. 따라서 기존 사각 창을 닫힌 실제 유역으로 취급할 근거가 없으며 강우만 추가한 해당 탐색 결과의 실제 침수 개방은 계속 보류. 근거 `data/benchmarks/dem-drainage-v1.json`.

선택 표면 첨두 계약 `NATIVE_RUNOFF_STEP_SURFACE_PLUS_DRAIN_V1`: 고정 EPA 5.2.4의 매 유출 계산 단계에서 `Subcatch.newRunoff`와 `lid_getDrainFlow(CURRENT)`를 같은 시각에 합산. 현재 단일 표면의 고정 1초/이전 10초 간격 전체를 관측하고 누락·평가 창 불일치 거부. 첨두는 해당 계산 구간 평균률의 최댓값이며 발생 시각은 구간 끝; 최초 동률 시각 보존. 1분 출력값 보간이나 개별 첨두 합산 금지. 선행 구간을 제외한 유량 적분과 누적 표면 유출+배수의 차이를 원문 보존하며 허용차 max(10⁻⁸m³, 유출량×10⁻⁷) 초과 거부. 기존 상태 검증과 같은 −10⁻⁹m³/s 범위 내 부동소수 오차는 0으로 보정하지 않고 적분·최소 성분률에 보존. 수지 잔차와 초기/최종 저류·순저류·평가체적을 함께 표시. 동일 INP·엔진·분별 상태/점수를 유지하는 읽기 전용 집계이며 하수관/하천 첨두·현장 저감 검증으로 승격하지 않음.

관망 이용조 분할 v1: 덮개형 LID 이용조의 원 입력·결과는 보존하고, 별도 명시적 설계에서 전면 불투수 집수면을 이용조 유입과 원 출구 우회 면적으로 분할. 총 강우 면적·조도·요지저류·폭/면적 비를 유지하고 덮개 강우는 우회 면적에 포함. 저장 절점에는 직접 강우·증발·침투를 중복 투입하지 않음. 실제 수두차를 사용하는 배수구/비상구와 역류방지판을 DYNWAVE에 연결. 집수 면적과 덮개 면적의 중복, 혼합 불투수율·상류 집수 유입·기존 LID 등 단순 분할로 상태를 보존할 수 없는 입력 거부. 저장 한도 초과·절점 월류·물수지/수렴 실패는 실패 유지. 집수 경계·지붕·홈통 실측, 홈통 수리와 지붕 재유입, 이용 수요, 당시 초기 상태·현장 비용은 별도 미확보 범위이며 운영 지도·순위의 자동 승격 금지.

회원 관망 이용조는 기존 원 집수·절점 행과 두 카탈로그 해시를 서버·워커에서 다시 대조하고, 시설이 추가된 입력에 원본 출처를 결속한 뒤 수두 배수 입력 생성. 최초 v1은 전면 불투수 원 구역 S9와 다른 LID를 같은 집수구역에 두지 않는 조건이며, 혼합 표면·공동 집수는 아래 v2/v3 계약을 따른다. 새 이용조·기존 LID 기록을 별도 필드로 보존하고 이전 입력·점수 재해석 없음. 단면적×깊이의 공개 견적 비교와 수리 입력은 독립, 서버가 확정한 용량·견적 수량을 워커와 표시 계층에서 교차 검증. 저장 원장 없는 성공 결과·다른 용량·월류를 숨긴 성공 결과의 화면 표시 거부.

식생수로 지도 설계: EPA Volume III §6.5.7/Table 6-7의 단면 범위 안에서 선택한 상부 폭 2m, 바닥 폭 0.75m, 깊이 0.25m, 측면 2.5:1, Manning n=0.15, 식생 체적비 0.1 적용. LID_USAGE 폭은 집수 유출 폭이 아닌 수로 상부 폭이며 길이는 설치 면적/2. 원지반 침투는 공개 토성군의 기존 Green–Ampt 문헌 추정값 사용. 지역 DEM 경사는 수로 종단 실측값이 아니며 0.5~3% 범위 후보만 선별. 부지 안 직선 배치의 기하 한도는 전체 시공 가능 면적이나 최적 방향이 아님. 외부 유입·관망 연결 생성 없음. 2022 사업계획의 폭 1.5/2m 혼합 총길이 1,271m와 설치비 114,390,000원으로 길이 단가 산출, 표 머리와 행 단위 모순 및 실제 단면·현재 가격 미확인 보존.


혼합 집수 이용조 설계 v2: 원 불투수율이 0~100% 사이이고 표면 간 유출 전환 없는 `OUTLET` 구역에서만 적용. 원 투수면을 같은 ID·면적·폭·조도·요지저류·침투 입력으로 유지하고, 불투수면을 집수/우회 두 표면으로 분할. SWMM 5.2.4 `subcatch_validate`의 유출 계수는 원 폭/각 표면 면적이므로 집수 폭은 원 폭×집수 면적/원 불투수 면적, 우회 불투수 폭도 같은 비율로 산정. 전체 면적 비율로 폭을 줄여 기존 투수면의 배수 속도를 바꾸지 않음. 집수+덮개는 원 불투수 면적 이하로 제한하고 덮개 강우는 기존 절점으로 우회. 지하수·상류 유입·기존 LID·적설·수질 등 분할에 추가 상태 이전이 필요한 조건은 계속 거부. v1 전면 불투수 입력은 그대로 재현. 이 분할은 공개 연구 입력의 수문 상태를 보존하는 설계이며 실제 지붕이나 홈통의 공간 확인을 뜻하지 않음. 근거: [EPA 5.2.4 subcatch.c](https://github.com/USEPA/Stormwater-Management-Model/blob/v5.2.4/src/solver/subcatch.c)의 `subcatch_validate`·`subcatch_readSubareaParams`.

공동 집수 이용조 설계 v3: 같은 원 집수구역에 다른 LID를 함께 설계하면 원 불투수면을 이용조 집수·덮개 강우 우회·나머지 면적으로 분리한다. 원 투수면은 유지하고 각 불투수 분할의 폭/면적 비를 보존한다. LID를 뺀 잔여 표면의 유출 계수도 유지하도록 그 유효 면적에 비례한 폭을 사용하고 변환 전후 해시·폭·면적을 보관한다. 다른 시설은 덮개와 이용조 집수를 제외한 나머지 불투수면에서만 설치 면적·처리 유입을 배분하며 시설 배수/표면 유출은 원 관망 절점으로 보낸다. 덮개 강우·이용조에 보낸 유출·다른 시설의 배수를 재포집하지 않는다. 서버와 워커는 `이용조 집수 + 덮개 + 다른 시설 면적 + 처리 집수 ≤ 원 불투수면적`을 함께 검사하고 원 설계 집수 ID와 파생 실행 ID의 대응을 보존한다. 단독 이용조의 v1/v2 원 입력은 재작성하지 않는다. 비용·현장 연결·일반 게임 설치 가능성은 별도 검증 범위다.

CMS 저류 용량은 선언한 곡선 적분 `capacityM3`와 내부 ft³를 정확한 SI로 읽은 `nativeCapacityM3`를 구분한다. EPA 5.2.4의 [저류 곡선 변환](https://github.com/USEPA/Stormwater-Management-Model/blob/v5.2.4/src/solver/node.c)은 [VOLUME 상수 0.02832](https://github.com/USEPA/Stormwater-Management-Model/blob/v5.2.4/src/solver/swmm5.c)를 사용하므로, 후자는 선언 체적×0.028316846592/0.02832다. 엔진·INP를 보정해 두 값을 임의로 맞추지 않는다. 시작/종료 여유 공간은 계산 용량에서 해당 시각의 실제 엔진 저류량을 뺀 값이며 초과분을 0으로 숨기지 않는다. 사용 수요가 없는 이용조는 `reuseM3=null`, `NOT_CALCULATED_NO_USE_DEMAND`로 반환하고 저장량·관망 배수를 소비량으로 표시하지 않는다. 새 용량 근거가 없는 과거 결과는 재작성하지 않는다. v3 공동 집수에는 덮개 강우의 별도 우회가 없는 구형 RB LID를 추가하지 않는다.

관망 이용조의 일반 배출 중지 설계는 `CLOSED_NO_WITHDRAWAL`로 명시한다. 일반 배수 링크를 생성하지 않고 비상구의 원 수두·역류 조건은 유지하며, 초기 저장수를 비가 오기 전에 자동으로 비우지 않는다. 누락된 배수구를 이 조건으로 추정하지 않고 배출 중지와 일반 배수구의 동시 입력을 거부한다. 배출 조건을 계산 원장에 보관하고 화면의 설계 조건과 대조한다. 실제 펌프 운전·사용 수요·강우예보 제어의 구현으로 표시하지 않는다. [마곡 공개 설계자료](../data/manifests/magok-cistern-procurement-2025.json)의 325톤 규격 체적·273m³ 계획 용량, 단일 펌프 사양점과 운전 설명은 구분해 보관하며 실제 유효 단면·펌프 곡선·사용 수요·설치 단가로 자동 변환하지 않는다.

집수 연결관 설계는 선택한 `inletPipe`의 실제 입력 길이·내경·Manning 조도·양 끝 관저고·입구 월류 깊이를 [EPA SWMM 5.2의 JUNCTIONS/CONDUITS/XSECTIONS](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=P10145M6.TXT)에 전달한다. 집수 분할의 유출을 입구 절점으로 보내고 원형 관의 마찰·저장·수두·역류를 같은 DYNWAVE에서 계산한다. 관은 양 절점의 바닥/상단 안에 들어가야 하며 하향 관저고 차는 입력 길이 이하로 제한한다. 실제 홈통 측량값을 자동 생성하지 않는다. 입구 초기 수심·추가 압력고·지표 저류 면적·국부 손실계수는 0, 역류 방지 장치는 없는 명시적 설계 범위다. 입구 월류를 전체 관망 월류에 보존하고 지표 연결 없는 월류는 효과 비교를 보류한다. 관 내부 저장량을 이용조 용량·재이용량이나 별도 저감량으로 다시 합산하지 않는다. 연결관을 선택하지 않은 설계는 종전 측방 직접 유입이며 홈통 용량 미모형화 상태를 유지한다. 실제 지붕 재유입·막힘·현장 위치/비용의 검증은 남아 있다.
