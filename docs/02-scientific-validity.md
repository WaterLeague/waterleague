# 연구 적합성·모델 검증

## 원칙

실제 지역 데이터 사용과 실제 현상 예측 정확도를 구분한다. SWMM 사용·낮은 물수지 오차·높은 게임 점수만으로 현실 적합성 입증 불가. 목적·입력·검증 범위·불확실성·재현 근거를 결과에 포함한다.

[EPA 모델링 QA/G-5M](https://www.epa.gov/quality/guidance-quality-assurance-project-plans-modeling-epa-qag-5m)과 [모델 QA 항목](https://www.epa.gov/quality/design-and-implementation-new-tools-quality-assurance-modeling)을 참고해 프로젝트별 입력 품질, 보정·독립 검증, 지표·검토 책임을 사전 정의한다. EPA 승인이나 법적 인증을 의미하지 않는다.

## 검증 등급

| 상태 | 최소 근거 | 허용 범위 |
| --- | --- | --- |
| `DRAFT` | 자료·모델 미완성 | 내부 제작, 공식 계산 불가 |
| `EXPLORATORY` | 출처·가정 기록, 실행·수치 검사 | 가정 아래 교육·탐색, 비공식 |
| `BENCHMARKED` | 참조 사례·독립 실행 대조·목적 적합성 검토 | 동일 모델 내 연구 비교·모델 랭킹 |
| `SITE_VALIDATED` | 부지 관측 보정·독립 검증·오차 승인 | 승인된 공간·변수·강우 범위의 현장 연구 |

모델 랭킹은 `BENCHMARKED` 이상만 허용하며 현장 효과 검증과 구분한다. 승인에는 검토자·날짜·근거 해시·목적·검증 변수·범위·한계 필수. 철회 시 신규 공식 사용 중지, 과거 결과에는 당시 등급과 현재 철회 상태 표시. 높은 등급도 다른 강우·시설·배수경계로 자동 확장하지 않는다.

위 등급 게이트는 공식 연구 평가용 모델 랭킹에 적용한다. 새 서울 공동 게임 순위는 `EXPLORATORY` 관측 입력 계산의 합산으로 별도 표시하며 공식 모델 승인·현장 성과 순위로 전용하지 않는다. 관측 또는 계산이 빠진 종료 주의 우승 확정 금지.

## 입력 분류

`OBSERVED` 관측값, `PUBLIC_GEODATA` 공개 공간자료, `DERIVED` 원자료·처리 코드의 파생값, `CALIBRATED` 보정 근거가 있는 매개변수, `ASSUMED` 근거·범위·민감도 대상 가정. 시각화용 건물 높이·물결·나무와 수문 입력 분리.

## 대상지·시간해상도

건물·피복·DEM 외에 배수구·관거·방류구·분수계·토양·지하수·관측 유출 확보 가능성 평가. 지도의 사각형이 실제 배수경계를 자르면 외부 유입·유출 조건 추가. 최종 서울 부지는 검증 자료 가용성에 따라 선정.

관측소 거리·고도차·강우 공간 대표성 명시. 도시 소유역 반응시간보다 긴 시간강우로 정밀 첨두유량 주장 금지. 시간자료만 확보한 초기 단계는 총량 중심 탐색. 공식 첨두 평가 전 적합한 분자료 또는 해상도 민감도·검증 근거 확보. 시간강우의 균등 분할은 새로운 관측자료가 아니다.

## 설치 제약

| 시설 | 확인 조건 |
| --- | --- |
| 빗물정원 | 유입 면적·고도·토양 투수성·지하수 이격·넘침·지장물 |
| 투수포장 | 포장·교통하중·기층·침투·암거·경사·막힘·유지관리 |
| 녹화지붕 | 지붕 경계·면적·경사·구조 하중·방수·배수·소유권 |

현장 적합성 `ELIGIBLE/CONDITIONAL/PROHIBITED/UNKNOWN` 기록. 게임 배치 허용과 현장 시공 승인 분리. 같은 유입면적의 시설 간 중복 할당 금지.

## 모델 연결

`cellId → footprint → subcatchmentId → inflow allocation → LID_CONTROLS/LID_USAGE`.

시설은 검토된 물리 단면·재료 버전에 연결. 사용자는 허용 배치·면적을 선택, 침투율·효과계수 임의 수정 불가. 소유역·불투수·LID 면적의 중복 집계 금지. [SWMM 5.2 공식 매뉴얼](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=P10145M6.TXT) 기준으로 변환하고 엔진 패치·빌드 해시 고정.

## 평가 경계·단위

- 강우 `mm`: 구간 깊이·집계간격·시각 규약 보존, 강도 `mm/h`와 구분.
- UTC 저장, 원본 KST와 SWMM 입력 변환 기록.
- API 면적 `m²`, SWMM 소유역 `ha`; 10,000 변환 명시.
- 유량 `m³/s`, 체적 `m³`, 길이 `m`, 수직 기준 별도 저장.
- 기준·전략 동일 평가지점·기간, 지정 방류구 시계열 적분·엔진 집계 교차 확인.
- 첨두는 같은 시각의 유량 합 시계열의 최댓값. 개별 최댓값 합산 금지.
- 선행강우·토양수분·저류·증발산·hotstart 고정.
- 강우 종료 뒤 고정 배수기간 포함. 시설별 종료시각 변경 금지.
- 잔여저류·침투·증발·지연방류 분리. 임시 저장을 영구 저감으로 단정 금지.

2026-10-17 연속 계산 변경: 공동 설치는 설치 후 첫 완전한 분 구간부터 관측 강우를 연속 입력한다. 같은 실행 안에서 표면·포장·토양·저류층 상태를 적분하며 주 경계에서 초기화하지 않는다. 재실행은 보존한 계산 입력 전체를 같은 엔진으로 재생한다. SWMM 일반 hotstart는 LID 내부 상태를 저장하지 않으므로 LID 연속 계산의 재시작 수단으로 사용하지 않는다. 기존 연구 모델·빌더는 변경하지 않고 별도 버전으로 구현한다.

공동 계산의 분별 상태는 EPA 5.2.4 원본에 추가한 읽기 전용 관측 함수로 가져온다. 물리 수식·시간 적분·매개변수 갱신에는 개입하지 않는다. 누적 강우·침투·증발·유출·배수·현재 저류량과 LID 층별 상태를 엔진 내부 값에서 SI 단위로 변환한다. 원본 리비전·관측 함수·바이너리·입력·결과 해시를 보존하며, 기존 공식 바이너리의 RPT/OUT과 동일 입력 대조로 관측 함수의 비개입을 확인한다.

관측 기온·습도·풍속·기압은 기존 AWS 응답의 원단위로 연결한다. 이 값만으로 관측 토양수분·증발산·관망 유량을 만들어내지 않는다. 증발산은 지원하는 기상 입력이 갖춰진 계산식과 별도 파생 근거가 있을 때만 시변 입력으로 사용한다. 실제 지형 경사·토양·관망 미확보 위치의 설계 매개변수와 설치 시 초기 수분은 미확인 가정으로 남기고, 고정 효과율이나 관측값으로 표시하지 않는다.

공동 설치의 증발산 입력은 KMA 서울 108 ASOS 시간 일사량과 동일 지점 AWS 60개 분 관측의 기온·습도·1분 평균 풍속·현지기압 평균을 사용한다. 지점정보의 좌표·고도·풍속계 높이를 조회 구간 양 끝에서 확인하고 [FAO-56 시간별 식 53](https://www.fao.org/4/x0490e/x0490e08.htm)으로 기준 잔디 증발산을 계산한다. 풍속은 관측 높이에서 2m로 변환. 야간 단파복사는 천문학적 0으로 분류하고, 구름비는 이전 일몰 2~3시간 전 실제 일사로 파생한다. 주간 일사·필수 분 기상·야간 구름비 결측 시 새 계산 게시 중단. 미래 관측을 사용하지 않도록 완료 시간의 파생률을 다음 시간에 유지하고 mm/h를 SWMM mm/day로 변환한다. 이 값은 시설별 관측 증발산이 아니며 지점 공간 대표성·표면별 보정은 미검증이다. 실제 증발량은 엔진의 수분 상태로 제한된다. 계산에 사용한 원본·파생률·공식 코드·출처 해시 보존, 최신 날씨 응답 캐시로 사용 금지. 기존 계산 구간의 증발 조건은 그대로 보존하고 신규 구간부터 적용.

과거 재해는 보관한 기상 입력만 사용한다. 2022·2010 사건은 같은 시간별 방식. 2011-07-27 서울 AWS는 일부 분 기상이 결측이므로 ASOS 일 최저·최고기온·평균 수증기압·풍속·현지기압·일사합으로 FAO-56 일 산정식 6 적용. 일 기준 증발산을 해당 일에 균등 적용하며 일중 변화를 복원한 것으로 표시하지 않는다. 당일 전체 확정 자료를 쓰므로 실시간 모드의 대체 입력으로 사용 금지. 재해별 시간 해상도·선택 이유·원본·계산식 해시를 재현 묶음에 포함한다.

연속 강우 정규화는 같은 날의 연속 일 누적 차분을 기본으로 한다. 00:00·00:01 초기화 경계는 직전 14분의 유효 분량과 해당 시각 15분 이동누적의 차이로 복원하고, 가능한 60분 이동누적과 0.1mm 이내 일치 검사. 직전 구간·누적값 결측, 음수 차분, 이동누적 충돌은 계산 거부. 임의 보간·결측 0 치환 없음. 계산 시각은 UTC 고정, 엔진 종료 날짜의 내림 연산으로 마지막 1초가 잘리는 문제는 입력 종료를 1초 여유 있게 잡고 관측 종료 분에서 정확히 `swmm_step`을 중단해 방지. 해당 여유 구간은 평가에 포함하지 않음.

## 검증 절차

1. 원자료: 누락·중복·품질코드·단위·CRS·날짜경계·총강우 검사.
2. 기하·배수: 면적·중첩·피복·출구·유입 경로 검사.
3. 수치: 오류·비유한 값·물수지·시간간격 민감도·안정성 검사.
4. 회귀: 시설 0개·무강우·단일 시설·동일 입력·면적 경계 사례.
5. 참조: 공식 예제/공개 연구 사례, API와 별도 SWMM 실행 경로 대조. 같은 엔진의 API/CLI 일치는 다른 수문모형의 독립 검증과 구분. [EPA 참조 진단](32-epa-reference-validation.md)의 인쇄 충돌·단위 차이는 검토 필요 상태이며 현재 모델의 등급 승격 근거로 단독 사용 불가.
6. 보정: 해당 부지 유량·수위 관측, 계측 오차·경계조건 반영.
7. 독립 검증: 보정에 쓰지 않은 이벤트·기간, 계절·강도 범위 확인.
8. 민감도·불확실성: 토양·피복·시설 투수성·배수 연결·강우 오차 앙상블.
9. 전문가 목적 적합성 검토 후 승인 버전 공개.

내부 수치 게이트 초안: 유출·해당 라우팅 연속오차 각각 절댓값 1% 이하, 초과 격리. 프로젝트 정책 제안이며 EPA의 보편 인증 기준 아님. 라우팅 없는 모델은 근거 있는 `NOT_APPLICABLE`, 누락값의 0% 치환 금지. 수치 통과와 현실 검증 분리.

현장 지표: 총량 상대오차, 첨두 크기·시각 오차, RMSE, 적합한 경우 NSE/KGE, 잔차 패턴. 계측 정확도·표본수·이용 목적에 맞는 합격값을 결과 확인 전에 정의. 보편 임계값 임의 지정 금지.

## 점수

`Rv=(Vbase−Vstrategy)/Vbase`, `Rp=(Qbase−Qstrategy)/Qbase`.

초기 규칙 후보 `100×(0.7Rv+0.3Rp)`. 첨두 검증 미충족 미션은 별도 규칙의 `100×Rv`. 음수 개선율 보존. 0 또는 사전 최소 검출값 미만 분모, NaN·무한대·결측은 공식 점수 거부. 가중치·분모 기준·평가지점·수치 정책 버전 고정.

반올림 전 고정 정밀도로 순위 계산, 화면 두 자리 표시. 같은 점수는 동점, 표시 순서만 제출시각·ID 사용. 점수 차이를 통계적 유의차로 해석하지 않는다. 연구 화면에는 성능 범위·순위 역전·Pareto 비교 제공. 예산과 시설 비용은 원(KRW) 단위. 출처 미확보 단가는 가정으로 표시하고 실제 공사비·경제성 검증으로 해석 금지.

## 재현 묶음

manifest, 출처·이용조건, 원본 또는 재취득 참조, 정규화 강우, 기준·전략 INP, 셀 GeoJSON, 시설·초기상태, RPT/OUT·시계열, 검증 보고서, 불확실성 설정·결과, 코드 커밋·엔진 빌드·이미지 digest, OS/아키텍처·시드, SHA-256 목록.

같은 빌드의 결정론과 다른 아키텍처의 수치 허용오차를 구분해 검증. seed만으로 재현을 보장하지 않는다. 연구 재사용 동의·범위를 export에 포함.

## 공동 설치 면적·유입 조건 변경

신규 공동 설치는 공개 후보 도형의 면적에서 0.01m² 미만을 버린 값을 기하학적 최대 면적으로 사용한다. 기존 옥상 60%·지상 80% 비율은 근거 없는 설계 제한이므로 신규 배치에 적용하지 않는다. 건축물 footprint는 실제 유효 지붕 면적·구조안전·피난 동선 확인 자료가 아니며, 이 상한은 도형 밖 면적 배치를 차단하는 계산 경계다. 현장 시공 승인 상태는 계속 UNKNOWN이다.

INP에 명시한 값과 생략한 항목을 구분하며 최소 수치 면적을 실제 시설 면적으로 표시하지 않음. 압력 해법은 시나리오 입력으로 고정하며 실패 후 다른 해법으로 자동 재시도해 같은 실행/순위로 대체하지 않음. 공식 SLOT의 가상 슬롯도 수치 근사이며 실제 관로 체적으로 해석하지 않음. 같은 제원의 시간·격자·교환 간격 및 초기 상태 민감도 확인이 필요하며, 건조 시작 사례의 통과를 임의 젖은 초기 상태나 서울 현장 재현의 성공으로 확대하지 않음.

ANUGA의 공식 4.0.1 소스·태그 커밋·실행 휠·라이선스·의존성 잠금 해시를 보존. 명시된 반시계 삼각 격자·표고·조도·초기 수심·전체 외곽 경계·좌표/수직 기준만 입력하며 누락된 경계를 임의 벽으로 채우지 않음. `DE0`, CPU 계산, 한 스레드와 입력별 최대 시간 간격 기록. CFL은 계속 적용하고, 건조 격자의 강우가 긴 단계 끝에 일괄 투입되지 않도록 최대 시간 간격을 필수화. 격자별 강우 소유권에 따라 관망 소유 영역의 2D 직접 강우를 거부. 수심·유속·체적·외곽 유입·강우 원장·SWW 보존. 격자 생성에 비상업용 Triangle을 사용하지 않고 해당 의존성 제외. macOS의 OpenMP 중복 로드 충돌은 별도 `spawn` 프로세스에서 엔진별 상태를 유지하여 회피하며 비안전 중복 허용 환경값 사용 금지. 자식 계산에 DB/API 비밀 환경 전달 없음.

### 관망·지표 체적 교환 v1

원 지표 집계 확장: 평가 시작/끝·외부 방류구·침수 노출 삼각형·젖음 판별 수심·근거를 실행 전에 고정. 정상 하천/저류지 제외 영역을 명시하지 않으면 침수 원 지표를 생성하지 않음. 선택 방류구의 같은 시각 유량 합에서 첨두를 구하고 역류 체적/첨두는 별도로 보존. 내부 교환 방류구는 평가 출구로 지정 불가. 선행 구간은 상태 계산에 유지하되 원 지표에서는 제외.

집계는 SWMM 내부 라우팅 단계와 ANUGA DE0 내부 단계에서 읽기만 수행. 방향별 체적과 깊이×면적×시간은 인접 계산 상태의 선형 보간·사다리꼴 적분이며 평가 경계에 걸친 단계도 해당 구간만 포함. 수심 최고값과 젖은 면적 최고값은 내부 단계 끝점에서 관측한 최댓값으로 표시. 표시 프레임에서 재적분하거나 개별 출구 첨두를 합산하지 않음. 교환의 순간 수심 변화는 0시간 상태 갱신으로 처리하며 인공적인 지속시간을 더하지 않음. 출력 프레임·집계 유무가 물리 상태를 바꾸지 않아야 함. 수치 실패의 원 지표는 진단값으로 보존하고 경쟁 이용 가능으로 승격하지 않음. 새 점수·총점·현장 검증 등급은 별도 고정 정책과 근거가 충족되기 전 보류.

`network-exchange-swmm` 별도 빌드에서 기존 EPA 5.2.4 식·이전 관망/LID 바이너리를 보존. 수평 `BOTTOM` 오리피스의 EPA 위어/오리피스 전환·잠김·역류 식을 사용하며 제원·방류계수·유입부 높이를 입력 원본에서 읽는다. 연결 관망 절점→수평 유입부→지표 교환 전용 방류구 구조, 방류구 하나당 연결 하나와 같은 기준고 요구. 역류방지판·개방률 제어·다른 유입/유출이 섞인 교환 포트는 현재 어댑터에서 거부. 일반 관망의 펌프·제어는 유지. 좌표계·수직 기준 불일치, 중첩 지표 영역, 영역보다 큰 개구부, 지표 아래로 뒤집힌 유입부 기준고 거부.

공식 구현 근거: [EPA 5.2.4 유입부 수리식](https://github.com/USEPA/Stormwater-Management-Model/blob/v5.2.4/src/solver/link.c), [ANUGA 4.0.1 체적·운동량 소스 연산](https://github.com/anuga-community/anuga_core/blob/4.0.1/anuga/structures/inlet_operator.py). ANUGA 기본 연산의 부족 체적 절삭을 그대로 사용하지 않고 양쪽 원장의 같은 체적을 요구하는 별도 교환 연산 적용.

명시적 분할 순서: 단계 시작의 지표 수두로 관망 전진 → EPA 반시간 적분의 방향별 누적 체적 차이 읽기 → 같은 순 체적을 지표에 적용 → 2D 흐름 전진. 지표 수두는 유입부 높이 위 가용 체적/영역 면적이며 격자 내 수위 차를 평균하는 근사로 기록. 유입은 수평 운동량을 추가하지 않고 인출은 기존 운동량을 수심 비율로 줄임. 두 방향의 총 교환량·단계 전/후 수두·가용 체적·지표 적용량·반올림 차이 보존. 교환은 전체 외부 유입/유출에서 제외하여 내부 이동으로 상쇄.

자유 유출 상한과 직전 역류량의 큰 값으로 지표 가용량 25% 이내 교환 간격을 정함. 이는 수치 간격 제한이며 실제 개방률·재료 계수를 조작하지 않음. 정수 밀리초 관망 설정과 최소 1ms 지원, 더 짧은 간격이 필요하면 실패 처리. 지표 초과 인출·연결되지 않은 노드의 월류 발생·누적량 역전·시간 불일치·수지 위반은 실패로 보존하고 음수 수심을 잘라 물을 만들어내지 않음. 단계 적용 전 원장과 마지막 양쪽 상태를 실패 파일에 남김.

관망 소유 강우 격자는 소유 유역 이름·면적과 일치해야 하고 2D 직접 강우를 받지 않음. 외부 유입/강우의 변경 시각은 물리 단계 경계로 반영. 현재 전체 수지의 범위는 관망 라우팅+지표 흐름이며 유역 토양·증발산·오염 물질까지 합친 수지는 아님. 전체 수지 1%·엔진별 게이트와 교환 상쇄 검사를 함께 적용하고 실패 사례를 제외하지 않음. 상대 오차만으로 작은 체적 잔차를 감추지 않도록 원 단위 잔차도 보존.

프레임 저장 주기는 물리 시간 간격을 제한하지 않으며 요청 시각 이후 첫 계산 상태의 실제 시간을 저장. 중심 상태를 바꾸지 않고 표시용 꼭짓점을 재구성. 교환 단계 RPC에는 체적/유입부 상태만 보내고 전체 관망·SWW는 출력 프레임에서 보존. 재현 묶음에는 양쪽 입력/출력·교환 원장·실패·코드/엔진 해시 포함. 명시적 분할·영역 평균 수두의 시간/격자 민감도는 적용 유역별 확인 대상. 수치 사례 통과를 서울 현장 보정·전체 게임 물리 완성으로 표시하지 않음.

2026-10-18 공개 기존 시설 편입 경계: 공개 위치/정격 제원 조회와 물리 계산 입력을 분리. 공간 ZIP의 점 자료·삭제 플래그와 강서구의 호기별 m³/min·유수지 m³는 원문 그대로 보존. 현재 운전량·양정-유량 곡선·유입/출구 연결·제어 수위·당시 존재 증거가 없으므로 무한 출구나 상수 양수량으로 계산하지 않음. 파일 수정일·자료 기준일을 준공일로 치환하지 않고, 재해 당시 시설 목록과 현재 공개 참고 레이어를 구분.

## 초기 상태·선행 기간 민감도 비교

현재 경쟁 입력의 선행 7일·시들음점/빈 저류층 정책은 유지. 연구 비교에서는 같은 실제 평가 강우·기상·도형·제원을 고정하고 선행 7/14/28일과 SWMM InitSat 0/100%를 별도 실행. 0은 식재토 시들음점, 100은 공극률 및 저류·배수매트 포화 상태이며 둘 다 관측 초기 수분이 아닌 경계 시나리오. 평가 시작의 토양수분·총저류·층별 수심과 평가 유출/배수/증발/침투·기여의 범위, 시드별 기간 차이를 보존. 비교 구간의 선행 효과는 평가에서 제외. 임의 보편 임계값으로 수렴 인증하지 않으며 실패 조건도 보존. 일부 사건·시설의 작은 차이를 서울 전체 완전 수렴으로 확대 해석하지 않음. 참고: EPA SWMM 5.2 사용자 매뉴얼 [LID_USAGE] InitSat 정의.

신규 후보 v6의 빗물정원은 공개 토성군에서 추정한 원지반 투수계수를 EPA의 하부 침투 경계에 명시적으로 연결. SWMM 5.2.4는 RG STORAGE 입력이 없으면 storage.kSat=0으로 초기화하므로 `RG STORAGE 0 0 Ksat 0`으로 하부 침투율만 지정. 두께·공극 체적 0 유지, 가상의 쇄석층·추가 저류 용량 생성 없음. 토성 미확보 후보는 기존 설계 투수계수의 가정임을 보존. 차수막 없는 설계 조건이며 실제 부지의 차수막·지하수·매설물·다짐 확인을 뜻하지 않음. 후보별 적용률·출처 수준·방법을 입력과 계산 결과에 보존. v5 이하의 원문·점수·기존 계산 입력은 소급 변경하지 않고, 원지반 침투 미연결 결과는 해당 한계를 표시.
