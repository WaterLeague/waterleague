# 연구 적합성·모델 검증

## 원칙

실제 지역 데이터 사용과 실제 현상 예측 정확도를 구분한다. SWMM 사용·낮은 물수지 오차·높은 게임 점수만으로 현실 적합성 입증 불가. 목적·입력·검증 범위·불확실성·재현 근거를 결과에 포함한다.

[EPA 모델링 QA/G-5M](https://www.epa.gov/quality/guidance-quality-assurance-project-plans-modeling-epa-qag-5m)과 [모델 QA 항목](https://www.epa.gov/quality/design-and-implementation-new-tools-quality-assurance-modeling)을 참고해 프로젝트별 입력 품질, 보정·독립 검증, 지표·검토 책임을 사전 정의한다. EPA 승인이나 법적 인증을 의미하지 않는다.

## 검증 등급

| 상태 | 최소 근거 | 허용 범위 |
| --- | --- | --- |
| `DRAFT` | 자료·모델 미완성 | 내부 제작, 공식 계산 불가 |
| `EXPLORATORY` | 출처·가정 기록, 실행·수치 검사 | 가정 아래 교육·탐색, 비공식 |
| `BENCHMARKED` | 참조 사례·독립 실행 대조·목적 적합성 검토 | 동일 모델 내 연구 비교·모델 랭킹 |
| `SITE_VALIDATED` | 부지 관측 보정·독립 검증·오차 승인 | 승인된 공간·변수·강우 범위의 현장 연구 |

모델 랭킹은 `BENCHMARKED` 이상만 허용하며 현장 효과 검증과 구분한다. 승인에는 검토자·날짜·근거 해시·목적·검증 변수·범위·한계 필수. 철회 시 신규 공식 사용 중지, 과거 결과에는 당시 등급과 현재 철회 상태 표시. 높은 등급도 다른 강우·시설·배수경계로 자동 확장하지 않는다.

위 등급 게이트는 공식 연구 평가용 모델 랭킹에 적용한다. 새 서울 공동 게임 순위는 `EXPLORATORY` 관측 입력 계산의 합산으로 별도 표시하며 공식 모델 승인·현장 성과 순위로 전용하지 않는다. 관측 또는 계산이 빠진 종료 주의 우승 확정 금지.

## 입력 분류

`OBSERVED` 관측값, `PUBLIC_GEODATA` 공개 공간자료, `DERIVED` 원자료·처리 코드의 파생값, `CALIBRATED` 보정 근거가 있는 매개변수, `ASSUMED` 근거·범위·민감도 대상 가정. 시각화용 건물 높이·물결·나무와 수문 입력 분리.

## 대상지·시간해상도

건물·피복·DEM 외에 배수구·관거·방류구·분수계·토양·지하수·관측 유출 확보 가능성 평가. 지도의 사각형이 실제 배수경계를 자르면 외부 유입·유출 조건 추가. 최종 서울 부지는 검증 자료 가용성에 따라 선정.

관측소 거리·고도차·강우 공간 대표성 명시. 도시 소유역 반응시간보다 긴 시간강우로 정밀 첨두유량 주장 금지. 시간자료만 확보한 초기 단계는 총량 중심 탐색. 공식 첨두 평가 전 적합한 분자료 또는 해상도 민감도·검증 근거 확보. 시간강우의 균등 분할은 새로운 관측자료가 아니다.

## 설치 제약

| 시설 | 확인 조건 |
| --- | --- |
| 빗물정원 | 유입 면적·고도·토양 투수성·지하수 이격·넘침·지장물 |
| 투수포장 | 포장·교통하중·기층·침투·암거·경사·막힘·유지관리 |
| 녹화지붕 | 지붕 경계·면적·경사·구조 하중·방수·배수·소유권 |

현장 적합성 `ELIGIBLE/CONDITIONAL/PROHIBITED/UNKNOWN` 기록. 게임 배치 허용과 현장 시공 승인 분리. 같은 유입면적의 시설 간 중복 할당 금지.

## 모델 연결

`cellId → footprint → subcatchmentId → inflow allocation → LID_CONTROLS/LID_USAGE`.

시설은 검토된 물리 단면·재료 버전에 연결. 사용자는 허용 배치·면적을 선택, 침투율·효과계수 임의 수정 불가. 소유역·불투수·LID 면적의 중복 집계 금지. [SWMM 5.2 공식 매뉴얼](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=P10145M6.TXT) 기준으로 변환하고 엔진 패치·빌드 해시 고정.

## 평가 경계·단위

- 강우 `mm`: 구간 깊이·집계간격·시각 규약 보존, 강도 `mm/h`와 구분.
- UTC 저장, 원본 KST와 SWMM 입력 변환 기록.
- API 면적 `m²`, SWMM 소유역 `ha`; 10,000 변환 명시.
- 유량 `m³/s`, 체적 `m³`, 길이 `m`, 수직 기준 별도 저장.
- 기준·전략 동일 평가지점·기간, 지정 방류구 시계열 적분·엔진 집계 교차 확인.
- 첨두는 같은 시각의 유량 합 시계열의 최댓값. 개별 최댓값 합산 금지.
- 선행강우·토양수분·저류·증발산·hotstart 고정.
- 강우 종료 뒤 고정 배수기간 포함. 시설별 종료시각 변경 금지.
- 잔여저류·침투·증발·지연방류 분리. 임시 저장을 영구 저감으로 단정 금지.

2026-10-17 연속 계산 변경: 공동 설치는 설치 후 첫 완전한 분 구간부터 관측 강우를 연속 입력한다. 같은 실행 안에서 표면·포장·토양·저류층 상태를 적분하며 주 경계에서 초기화하지 않는다. 재실행은 보존한 계산 입력 전체를 같은 엔진으로 재생한다. SWMM 일반 hotstart는 LID 내부 상태를 저장하지 않으므로 LID 연속 계산의 재시작 수단으로 사용하지 않는다. 기존 연구 모델·빌더는 변경하지 않고 별도 버전으로 구현한다.

공동 계산의 분별 상태는 EPA 5.2.4 원본에 추가한 읽기 전용 관측 함수로 가져온다. 물리 수식·시간 적분·매개변수 갱신에는 개입하지 않는다. 누적 강우·침투·증발·유출·배수·현재 저류량과 LID 층별 상태를 엔진 내부 값에서 SI 단위로 변환한다. 원본 리비전·관측 함수·바이너리·입력·결과 해시를 보존하며, 기존 공식 바이너리의 RPT/OUT과 동일 입력 대조로 관측 함수의 비개입을 확인한다.

관측 기온·습도·풍속·기압은 기존 AWS 응답의 원단위로 연결한다. 이 값만으로 관측 토양수분·증발산·관망 유량을 만들어내지 않는다. 증발산은 지원하는 기상 입력이 갖춰진 계산식과 별도 파생 근거가 있을 때만 시변 입력으로 사용한다. 실제 지형 경사·토양·관망 미확보 위치의 설계 매개변수와 설치 시 초기 수분은 미확인 가정으로 남기고, 고정 효과율이나 관측값으로 표시하지 않는다.

공동 설치의 증발산 입력은 KMA 서울 108 ASOS 시간 일사량과 동일 지점 AWS 60개 분 관측의 기온·습도·1분 평균 풍속·현지기압 평균을 사용한다. 지점정보의 좌표·고도·풍속계 높이를 조회 구간 양 끝에서 확인하고 [FAO-56 시간별 식 53](https://www.fao.org/4/x0490e/x0490e08.htm)으로 기준 잔디 증발산을 계산한다. 풍속은 관측 높이에서 2m로 변환. 야간 단파복사는 천문학적 0으로 분류하고, 구름비는 이전 일몰 2~3시간 전 실제 일사로 파생한다. 주간 일사·필수 분 기상·야간 구름비 결측 시 새 계산 게시 중단. 미래 관측을 사용하지 않도록 완료 시간의 파생률을 다음 시간에 유지하고 mm/h를 SWMM mm/day로 변환한다. 이 값은 시설별 관측 증발산이 아니며 지점 공간 대표성·표면별 보정은 미검증이다. 실제 증발량은 엔진의 수분 상태로 제한된다. 계산에 사용한 원본·파생률·공식 코드·출처 해시 보존, 최신 날씨 응답 캐시로 사용 금지. 기존 계산 구간의 증발 조건은 그대로 보존하고 신규 구간부터 적용.

과거 재해는 보관한 기상 입력만 사용한다. 2022·2010 사건은 같은 시간별 방식. 2011-07-27 서울 AWS는 일부 분 기상이 결측이므로 ASOS 일 최저·최고기온·평균 수증기압·풍속·현지기압·일사합으로 FAO-56 일 산정식 6 적용. 일 기준 증발산을 해당 일에 균등 적용하며 일중 변화를 복원한 것으로 표시하지 않는다. 당일 전체 확정 자료를 쓰므로 실시간 모드의 대체 입력으로 사용 금지. 재해별 시간 해상도·선택 이유·원본·계산식 해시를 재현 묶음에 포함한다.

연속 강우 정규화는 같은 날의 연속 일 누적 차분을 기본으로 한다. 00:00·00:01 초기화 경계는 직전 14분의 유효 분량과 해당 시각 15분 이동누적의 차이로 복원하고, 가능한 60분 이동누적과 0.1mm 이내 일치 검사. 직전 구간·누적값 결측, 음수 차분, 이동누적 충돌은 계산 거부. 임의 보간·결측 0 치환 없음. 계산 시각은 UTC 고정, 엔진 종료 날짜의 내림 연산으로 마지막 1초가 잘리는 문제는 입력 종료를 1초 여유 있게 잡고 관측 종료 분에서 정확히 `swmm_step`을 중단해 방지. 해당 여유 구간은 평가에 포함하지 않음.

## 검증 절차

1. 원자료: 누락·중복·품질코드·단위·CRS·날짜경계·총강우 검사.
2. 기하·배수: 면적·중첩·피복·출구·유입 경로 검사.
3. 수치: 오류·비유한 값·물수지·시간간격 민감도·안정성 검사.
4. 회귀: 시설 0개·무강우·단일 시설·동일 입력·면적 경계 사례.
5. 참조: 공식 예제/공개 연구 사례, API와 별도 SWMM 실행 경로 대조. 같은 엔진의 API/CLI 일치는 다른 수문모형의 독립 검증과 구분. [EPA 참조 진단](32-epa-reference-validation.md)의 인쇄 충돌·단위 차이는 검토 필요 상태이며 현재 모델의 등급 승격 근거로 단독 사용 불가.
6. 보정: 해당 부지 유량·수위 관측, 계측 오차·경계조건 반영.
7. 독립 검증: 보정에 쓰지 않은 이벤트·기간, 계절·강도 범위 확인.
8. 민감도·불확실성: 토양·피복·시설 투수성·배수 연결·강우 오차 앙상블.
9. 전문가 목적 적합성 검토 후 승인 버전 공개.

내부 수치 게이트 초안: 유출·해당 라우팅 연속오차 각각 절댓값 1% 이하, 초과 격리. 프로젝트 정책 제안이며 EPA의 보편 인증 기준 아님. 라우팅 없는 모델은 근거 있는 `NOT_APPLICABLE`, 누락값의 0% 치환 금지. 수치 통과와 현실 검증 분리.

현장 지표: 총량 상대오차, 첨두 크기·시각 오차, RMSE, 적합한 경우 NSE/KGE, 잔차 패턴. 계측 정확도·표본수·이용 목적에 맞는 합격값을 결과 확인 전에 정의. 보편 임계값 임의 지정 금지.

## 점수

`Rv=(Vbase−Vstrategy)/Vbase`, `Rp=(Qbase−Qstrategy)/Qbase`.

초기 규칙 후보 `100×(0.7Rv+0.3Rp)`. 첨두 검증 미충족 미션은 별도 규칙의 `100×Rv`. 음수 개선율 보존. 0 또는 사전 최소 검출값 미만 분모, NaN·무한대·결측은 공식 점수 거부. 가중치·분모 기준·평가지점·수치 정책 버전 고정.

반올림 전 고정 정밀도로 순위 계산, 화면 두 자리 표시. 같은 점수는 동점, 표시 순서만 제출시각·ID 사용. 점수 차이를 통계적 유의차로 해석하지 않는다. 연구 화면에는 성능 범위·순위 역전·Pareto 비교 제공. 예산과 시설 비용은 원(KRW) 단위. 출처 미확보 단가는 가정으로 표시하고 실제 공사비·경제성 검증으로 해석 금지.

## 재현 묶음

manifest, 출처·이용조건, 원본 또는 재취득 참조, 정규화 강우, 기준·전략 INP, 셀 GeoJSON, 시설·초기상태, RPT/OUT·시계열, 검증 보고서, 불확실성 설정·결과, 코드 커밋·엔진 빌드·이미지 digest, OS/아키텍처·시드, SHA-256 목록.

같은 빌드의 결정론과 다른 아키텍처의 수치 허용오차를 구분해 검증. seed만으로 재현을 보장하지 않는다. 연구 재사용 동의·범위를 export에 포함.

## 공동 설치 면적·유입 조건 변경

신규 공동 설치는 공개 후보 도형의 면적에서 0.01m² 미만을 버린 값을 기하학적 최대 면적으로 사용한다. 기존 옥상 60%·지상 80% 비율은 근거 없는 설계 제한이므로 신규 배치에 적용하지 않는다. 건축물 footprint는 실제 유효 지붕 면적·구조안전·피난 동선 확인 자료가 아니며, 이 상한은 도형 밖 면적 배치를 차단하는 계산 경계다. 현장 시공 승인 상태는 계속 UNKNOWN이다.

공동 귀속 v1은 회원의 고정 시설 묶음을 하나의 참여자로 취급하고, 정렬된 참여자 목록에서 SHA-256 카운터 난수·거절 표본·Fisher–Yates 순열을 생성. 같은 순열에서 원 지표 변화량·효과 점수·총점 각각의 한계 기여를 계산. 10진 입력을 유리수로 처리해 각 순열과 평균의 개인 합계·소속 구 합계·전체 효과가 정확히 일치하도록 보존하며 표시용 실수는 순위 원값으로 사용하지 않음. 구별 표본 오차는 같은 순열의 소속 회원 기여를 먼저 합산해 공분산을 포함. 표준오차는 표본 평균의 오차 추정이며 현장 정확도·보장된 신뢰구간이 아님; 1개 표본은 추정 불가. 유역 조합 캐시는 비교 프로필·회원/시설 스냅샷·조합의 해시와 결과 해시를 검사. 실패한 조합을 건너뛰거나 미완성 순열을 평균에 포함하지 않음. 연산 한도 도달·중간 실패 시 완료 순열만 진단 추정으로 보존하고 결과 게시 보류. 현재 새 귀속 모듈의 결과는 진단 등급이며 운영 순위 자동 게시 불가. 근거: [Shapley 원 논문](https://www.rand.org/pubs/papers/P295.html), [순열 표본 추정 연구](https://arxiv.org/abs/2104.12199v2).

연결 시설 설계 v1은 생물저류시설·침투 트렌치·식생수로·빗물이용조의 EPA LID 단면을 기존 관망 집수구역에 배치. 시설 면적과 대체 불투수 면적을 분리하고 남은 불투수 집수면적 내에서만 유입을 배분하며, 표면 월류·하부 배수는 기존 집수구역 출구로 연결. 원본 강우·유입·관로·경계·계산 설정과 기존 세 시설 입력은 유지. 식생수로는 사다리꼴 단면과 종단 경사를 사용하고 원본 집수구역의 침투법을 계승. 이용조 배수는 구경·유량계수·수두의 오리피스 식으로 변환하며 관망 방류를 재이용 수요 충족으로 계산하지 않음. 덮개가 있는 이용조의 직접 강우 제외, 지하수/역압에 의한 LID 배수 제약 부재, 새 시설의 초기 포화도·입지·설계 선택은 명시적 한계로 보존. 문헌 범위 내 설계는 현장 제원·관측이 아니며 비용·입지·관망 연결의 공개 근거가 갖춰지기 전 운영 설치·순위로 승격하지 않음.

이용조 원가 v1: [한국물환경학회 2018년 논문](https://journal.cricit.kr/jkswe/XmlViewer/f253405)의 2.35m³ 단위 견적 세 건·표 9 공종별 금액을 버전 카탈로그로 연결. 2018년은 발표 연도이며 견적 기준 연도·부가세·세부 규격은 미확인. 견적의 물통/배관/펌프/Log/기타와 자재 소계·총액을 보존하고, 미기재 항목은 null·소계와 총액의 차이는 미분류 차액으로 유지. 임의 용량에 m³당 비례 가격 적용 금지. 같은 용량의 개별 시설 수량만 견적 수량과 연결하며, 큰 단일 저장조를 작은 설비 여러 개로 가격 환산하지 않음. 비용 정보 추가·업체 변경은 SWMM INP를 변경하지 않음.

연결 시설의 지표 결합 입력은 `connectedFacilityDesign`과 외부 출구·노출 영역·평가 창을 명시한 원 지표 규칙을 함께 요구. 원 관망 입력을 보존하고 설계 컴파일 결과를 별도 INP로 실행. 시설별 수분·저류·침투·월류·배수와 관망/지표 교환·외부 출구·침수 노출을 같은 실행에 보관. 기존 엔진을 덮어쓰지 않는 별도 관측 빌드를 사용하며 시설 수지 실패는 결합 결과와 원 지표 성공 판정을 차단.

시설 수지는 EPA 유출 계산 시각의 내부 진단이며 관망 라우팅 시각과 다를 수 있음. 두 시각과 초기/최종 상태를 함께 보존하고 원 지표 평가 창의 시설별 효과로 표시하지 않음. 시설 배수·표면 유출은 관망의 유출 유입에 이미 포함되므로 관망/지표 수지에 재가산하지 않음. 시설 수지를 더한 전체 토양/식생/지하수 물수지로 주장하거나 지표 역압을 LID 하부 배수에 적용한 것으로 해석하지 않음. 덮개 강우 경로·수치 시드·문헌 설계의 한계도 유지.

물리 단면과 견적은 용량만 대조된 상태이며 실제 자재·관경·배수·펌프·시공 조건의 일치를 뜻하지 않음. 초기 견적 소계와 문헌 가정의 연간 전기/모니터링/보수·인건비/청소비를 분리. 세 업체의 견적 범위는 통계적 신뢰구간이 아님. 현장 추가 공사·세금·가격 시점·다른 미산정 시설이 남아 있으면 전체 설치비는 null, 알려진 부분합과 미산정 시설 ID를 별도 보존. 본문에서 제외한 추가 공사비를 실제 0원으로 간주하거나 보조율을 차감하지 않음. 신규 설계 원가 해시·수량·원문·카탈로그·계산 코드와 물리 입력을 같은 재현 묶음에 보존. 현재 운영 단가·지출 원장·사건 당시 가격의 대체 근거로 사용하지 않음.

공개 연구 INP의 원형 재실행은 별도 `NATIVE_DURATION_DIAGNOSTIC`에서만 EPA 날짜 차의 초 단위 내림을 그대로 사용하고 선언 기간과 실제 계산 기간의 차이를 보존. 최대 1초 수준의 원 엔진 내림을 허용하되 게임의 명시적 평가·관측 결합에는 적용하지 않음. 표시 프레임 간격을 맞추기 위해 원 내부 단계를 자르지 않으며, `run`의 모든 내부 단계 수렴/체적 적분을 유지하고 프레임에 필요한 전체 상태만 읽음. 원본과 출력 경로만 바꾼 실행본의 이진 결과 일치를 별도 확인. 연구 자료의 좌표계/기준고/시점/외부 유입 계보가 없거나 원 입력 비수렴이 남으면 현장 검증·경쟁 등급 승격 금지([서초 공개 연구 모형](16-sewer-observations.md)).

ANUGA의 공식 4.0.1 소스·태그 커밋·실행 휠·라이선스·의존성 잠금 해시를 보존. 명시된 반시계 삼각 격자·표고·조도·초기 수심·전체 외곽 경계·좌표/수직 기준만 입력하며 누락된 경계를 임의 벽으로 채우지 않음. `DE0`, CPU 계산, 한 스레드와 입력별 최대 시간 간격 기록. CFL은 계속 적용하고, 건조 격자의 강우가 긴 단계 끝에 일괄 투입되지 않도록 최대 시간 간격을 필수화. 격자별 강우 소유권에 따라 관망 소유 영역의 2D 직접 강우를 거부. 수심·유속·체적·외곽 유입·강우 원장·SWW 보존. 격자 생성에 비상업용 Triangle을 사용하지 않고 해당 의존성 제외. macOS의 OpenMP 중복 로드 충돌은 별도 `spawn` 프로세스에서 엔진별 상태를 유지하여 회피하며 비안전 중복 허용 환경값 사용 금지. 자식 계산에 DB/API 비밀 환경 전달 없음.

신규 지표 입력 schemaVersion 2는 공식 `use_inscribed_circle=True`를 고정하여 삼각형 면적·둘레의 내접원 반경 `2A/P`로 CFL 시간 간격을 산정. 이전 schemaVersion 1의 중심→변 중점 거리 방식은 원본 실행 재현용으로 보존. 격자 형상·강우·시설·조도 변경 없이 수치 반경만 구분하며 실제 적용 반경 범위·CFL·최대 시간 간격·엔진 설정을 결과에 기록. 실패한 실행을 자동 재계산으로 교체하지 않음. 근거: [ANUGA 4.0.1 공식 격자 반경 구현](https://github.com/anuga-community/anuga_core/blob/4.0.1/anuga/abstract_2d_finite_volumes/general_mesh.py).

schemaVersion 2는 매 내부 단계의 강우·경계 체적 갱신 후 원 수지와 상태를 읽기 전용으로 검사. 수심/운동량 비유한값·허용 범위 밖 음수 수심·1%/10⁻⁸m³ 초과 원 수지는 즉시 실패, 마지막 내부 시각·체적·누적 최대 잔차·단계 수·실제 시간 간격 범위를 파일로 보존. 화면/강우 출력 경계 사이에 발생한 실패가 마지막 작은 잔차로 감춰지지 않도록 함. 지표 수치 설정과 검사기 소스 해시를 비교 엔진 식별자에 포함하고, 결과 리더에서 개별 엔진·결합 결과·품질 원본 및 완료 시각 일치 검사. 수치 판정을 통과해도 현장 검증 또는 운영 순위 사용 승인을 뜻하지 않음.

개별 엔진의 공개 사례·해석 검증과 아래 결합 수치 검증을 분리. 2D 지표 침투와 관측 기상 기반의 가용 지표수 제한 증발은 연결했으나 공개 서울 연결 관망·침수흔적 대조·토양/식물/지하수 전체 증발산은 미완료이므로 현재 강우·지표 흐름 시험을 완성된 도시 물수지 또는 운영 순위로 전용하지 않음. EPA 사례의 원본 바이너리 출력 일치는 같은 엔진의 비개입 대조이며 독립 현장 검증이 아님. 참조 사례 자체의 수치 실패도 보존.

### 관망·지표 체적 교환 v1

지표 침투 연결 계약: EPA 5.2.4 원본 Green–Ampt 함수를 별도 OpenMP 미사용 라이브러리로 실행하며 계산식을 재작성하지 않음. 명시한 투수 면적비·포화투수계수·흡입수두·초기 수분 부족률·회복계수·근거를 요구하고, 모든 지표 소유 삼각형을 투수 영역 또는 명시적 불투수 영역으로 분류. 자료가 없는 영역을 자동 불투수 처리하지 않음. 관망 소유 삼각형에는 지표 침투를 추가하지 않아 SWMM 손실과 중복 차감 차단. 부분 투수 삼각형은 같은 지표 수심을 공유하는 면적비 근사로 표시. 각 내부 단계에서 흐름→직접 강우→침투 순서로 계산하며 방금 투입한 강우와 기존 고인 물을 분리해 EPA 함수에 전달. 실제 가용수량보다 큰 손실은 실패 처리하고, 물 제거에 비례해 수평 운동량 제거. 총 강우·누적 침투·순 소스·관망 교환 체적을 별도 보존. EPA 수분 회복 상태는 경험식 상태이며 현장 함수율이나 실제 증발산량으로 해석하지 않음. 초기 부족률은 명시된 시드이며 관측 초기 수분을 주장하지 않고 선행 강우 연속 계산·민감도 비교가 필요. 이 단계는 지표 제어체적에서 지하로 나간 물만 계산하며 토양층·지하수·증발산 전체 수지는 별도 연결 대상.

지표 증발 입력 계약: 보관 ASOS/AWS 원문·관측소 메타자료와 고정 계산 코드를 대조하여 FAO-56 기준 잔디 증발산을 재산정. 원문 또는 파생률 불일치·기간 누락은 실패 처리. 이를 지표 고인 물의 잠재 손실률로 적용하는 것은 보정되지 않은 표면 전용 가정이며 수면·포장·식생의 실측 증발량으로 표시하지 않음. 시간별 값은 직전 완료 시간의 다음 시간 유지, 2011 일 자료는 과거 일중 균등 적용으로 구분. 전체 계산 창의 연속 구간을 요구하며 외삽·마지막 값 무한 유지 금지. 각 내부 단계는 흐름→강우→침투→가용 지표수 제한 증발 순서의 명시적 분할이며 시간 세분 비교가 필요. 관망 소유 삼각형에 지표 손실 추가 금지. 잠재 증발 체적·실제 제거 체적·수분 부족으로 충족하지 못한 체적·강우·침투를 분리하고 물 제거에 비례해 수평 운동량 제거. 지표가 마르면 실제 제거량은 0. 지표에서 빠지는 체적만 계산하며 식물 뿌리·토양 수분·지하수 증발을 생성하지 않음. 원 지표 평가는 실제 지표 깊이 변화만 사용하며 잠재량을 효과로 중복 보상하지 않음. 근거: [FAO-56 기준 증발산 정의](https://www.fao.org/4/x0490e/x0490e04.htm), [EPA 표면 가용수량에 따른 증발 제한](https://github.com/USEPA/Stormwater-Management-Model/blob/v5.2.4/src/solver/subcatch.c).

공개 DEM 입력 경로: 원본 압축/래스터 해시·GDAL 원문 WKT·격자 변환·행/열 창·NoData·원시 높이 보존. 격자 중심을 꼭짓점으로 연결하며 보간으로 해상도를 높이거나 외삽·결측 채움·함몰 제거를 수행하지 않음. 수평 좌표는 원본 투영에서 평행 이동만 적용, 높이는 원본 값을 유지. 단위/수직 기준 근거와 조도·초기 수심·외곽 경계의 근거를 별도 필수 입력으로 둠. 제품군 성과 목록은 개별 파일의 제작 시점·기준고 확인을 대체하지 않음. 기준고 미확인 지형의 상대 높이 탐색은 명시한 단위 해석을 가정으로 기록하고 관망 결합·경쟁·현장 침수 판정에서 제외. 사각 격자 창의 경계는 실제 배수 경계로 취급하지 않음.

시간별 경계수위 입력은 UTC 시작/종료·관측 단위·수직 기준·관측 간격 한도·원문 해시를 고정. 관측 사이 선형 보간은 계산값이며 외삽·누락 값의 자동 연결·마지막 수위 무한 유지는 금지. 경계 운동량 0은 정수 저수지 근사로 명시하고 관측 유속으로 표시하지 않음. WAMIS 시간자료의 관측소 눈금 수위와 절대 표고를 구분하며 현재 영점표고를 과거 사건에 소급 적용하지 않음. 해당 시점의 영점표고와 지형 기준고 일치가 확인되지 않은 수위는 상대 기준의 수치 진단에만 사용. 지표 내부 단계에서 시각에 맞는 경계수위를 평가하고 관측 절점에서 단계를 나누며, 관망 결합 시 같은 UTC 시작과 전체 기간을 요구. 근거: [ANUGA 4.0.1 시간 경계 구현](https://github.com/anuga-community/anuga_core/blob/4.0.1/anuga/abstract_2d_finite_volumes/generic_boundary_conditions.py), [WAMIS 청담대교 시자료](https://www.wamis.go.kr/wkw/wl_hrdata.do?code=1018662&name=Seoul).

관망 외부 방류구의 관측 수위는 SWMM 원본 `TIMESERIES` 경계로 연결. 입력 표고는 관저고 위 수심이 아닌 같은 수직 기준의 수면고이며 CMS/CFS 길이 단위 변환만 수행. 관측 시각을 UTC 날짜·시간으로 기록하고 전체 평가 창의 자료 유효성·결측·기준고를 시작 전에 검사. EPA의 시계열 끝값 연장을 관측으로 이용하지 않도록 실행 종료를 관측 창으로 제한. 관저고·역류방지 플랩·재유입 대상은 원본대로 유지하고 원본/변환 INP·변환 근거를 함께 보존. 해당 방류구의 실행 중 수동 수위 덮어쓰기와 지표 교환 포트의 중복 경계 지정 금지. SWMM의 방류구 수심은 연결 관로의 정상/한계 수심 제약도 받으므로 관측 하천 수위와 노드 수두가 항상 같다고 가정하지 않음. 근거: [EPA 5.2.4 방류구 구현](https://github.com/USEPA/Stormwater-Management-Model/blob/v5.2.4/src/solver/node.c), [공식 시간 보간 구현](https://github.com/USEPA/Stormwater-Management-Model/blob/v5.2.4/src/solver/table.c).

원 지표 집계 확장: 평가 시작/끝·외부 방류구·침수 노출 삼각형·젖음 판별 수심·근거를 실행 전에 고정. 정상 하천/저류지 제외 영역을 명시하지 않으면 침수 원 지표를 생성하지 않음. 선택 방류구의 같은 시각 유량 합에서 첨두를 구하고 역류 체적/첨두는 별도로 보존. 내부 교환 방류구는 평가 출구로 지정 불가. 선행 구간은 상태 계산에 유지하되 원 지표에서는 제외.

집계는 SWMM 내부 라우팅 단계와 ANUGA DE0 내부 단계에서 읽기만 수행. 방향별 체적과 깊이×면적×시간은 인접 계산 상태의 선형 보간·사다리꼴 적분이며 평가 경계에 걸친 단계도 해당 구간만 포함. 수심 최고값과 젖은 면적 최고값은 내부 단계 끝점에서 관측한 최댓값으로 표시. 표시 프레임에서 재적분하거나 개별 출구 첨두를 합산하지 않음. 교환의 순간 수심 변화는 0시간 상태 갱신으로 처리하며 인공적인 지속시간을 더하지 않음. 출력 프레임·집계 유무가 물리 상태를 바꾸지 않아야 함. 수치 실패의 원 지표는 진단값으로 보존하고 경쟁 이용 가능으로 승격하지 않음. 새 점수·총점·현장 검증 등급은 별도 고정 정책과 근거가 충족되기 전 보류.

`network-exchange-swmm` 별도 빌드에서 기존 EPA 5.2.4 식·이전 관망/LID 바이너리를 보존. 수평 `BOTTOM` 오리피스의 EPA 위어/오리피스 전환·잠김·역류 식을 사용하며 제원·방류계수·유입부 높이를 입력 원본에서 읽는다. 연결 관망 절점→수평 유입부→지표 교환 전용 방류구 구조, 방류구 하나당 연결 하나와 같은 기준고 요구. 역류방지판·개방률 제어·다른 유입/유출이 섞인 교환 포트는 현재 어댑터에서 거부. 일반 관망의 펌프·제어는 유지. 좌표계·수직 기준 불일치, 중첩 지표 영역, 영역보다 큰 개구부, 지표 아래로 뒤집힌 유입부 기준고 거부.

공식 구현 근거: [EPA 5.2.4 유입부 수리식](https://github.com/USEPA/Stormwater-Management-Model/blob/v5.2.4/src/solver/link.c), [ANUGA 4.0.1 체적·운동량 소스 연산](https://github.com/anuga-community/anuga_core/blob/4.0.1/anuga/structures/inlet_operator.py). ANUGA 기본 연산의 부족 체적 절삭을 그대로 사용하지 않고 양쪽 원장의 같은 체적을 요구하는 별도 교환 연산 적용.

명시적 분할 순서: 단계 시작의 지표 수두로 관망 전진 → EPA 반시간 적분의 방향별 누적 체적 차이 읽기 → 같은 순 체적을 지표에 적용 → 2D 흐름 전진. 지표 수두는 유입부 높이 위 가용 체적/영역 면적이며 격자 내 수위 차를 평균하는 근사로 기록. 유입은 수평 운동량을 추가하지 않고 인출은 기존 운동량을 수심 비율로 줄임. 두 방향의 총 교환량·단계 전/후 수두·가용 체적·지표 적용량·반올림 차이 보존. 교환은 전체 외부 유입/유출에서 제외하여 내부 이동으로 상쇄.

자유 유출 상한과 직전 역류량의 큰 값으로 지표 가용량 25% 이내 교환 간격을 정함. 이는 수치 간격 제한이며 실제 개방률·재료 계수를 조작하지 않음. 정수 밀리초 관망 설정과 최소 1ms 지원, 더 짧은 간격이 필요하면 실패 처리. 지표 초과 인출·연결되지 않은 노드의 월류 발생·누적량 역전·시간 불일치·수지 위반은 실패로 보존하고 음수 수심을 잘라 물을 만들어내지 않음. 단계 적용 전 원장과 마지막 양쪽 상태를 실패 파일에 남김.

관망 소유 강우 격자는 소유 유역 이름·면적과 일치해야 하고 2D 직접 강우를 받지 않음. 외부 유입/강우의 변경 시각은 물리 단계 경계로 반영. 현재 전체 수지의 범위는 관망 라우팅+지표 흐름이며 유역 토양·증발산·오염 물질까지 합친 수지는 아님. 전체 수지 1%·엔진별 게이트와 교환 상쇄 검사를 함께 적용하고 실패 사례를 제외하지 않음. 상대 오차만으로 작은 체적 잔차를 감추지 않도록 원 단위 잔차도 보존.

관측 지표 강우 입력: 저장된 AWS 원문·매니페스트·파생 깊이의 해시를 확인하고 원문을 다시 정규화하여 분별 깊이와 기간·관측소·합계 일치 요구. 명시한 UTC 계산 창 전체가 실제 연속 관측으로 덮여야 하며 분 중간 자르기·창 밖 무강우·보간·미승인 품질 허용 없음. 지표 격자마다 하나의 관측소와 공간 배정 근거를 고정하고 관망 소유 격자는 미배정. 분 깊이→시간당 강도 환산은 그 분 내부의 균일 강도 가정으로 기록. 같은 강도가 이어지는 구간만 합치되 끝 시각은 계산 창으로 제한. 실제 지표 강우 체적을 격자 면적×관측 깊이 적분과 대조하며 강우 자료·공간 배정·소스 코드를 재현 묶음에 보존. 관측 강우의 도입은 지형·관망·경계 조건의 현장 검증이나 당시 재해 복원 등급을 올리지 않음.

프레임 저장 주기는 물리 시간 간격을 제한하지 않으며 요청 시각 이후 첫 계산 상태의 실제 시간을 저장. 중심 상태를 바꾸지 않고 표시용 꼭짓점을 재구성. 교환 단계 RPC에는 체적/유입부 상태만 보내고 전체 관망·SWW는 출력 프레임에서 보존. 재현 묶음에는 양쪽 입력/출력·교환 원장·실패·코드/엔진 해시 포함. 명시적 분할·영역 평균 수두의 시간/격자 민감도는 적용 유역별 확인 대상. 수치 사례 통과를 서울 현장 보정·전체 게임 물리 완성으로 표시하지 않음.

지도용 원 계산 프레임은 선택한 출력 시각의 ANUGA 중심 수심·x/y 운동량을 Float64 little-endian으로 별도 보관. SWW 표시용 꼭짓점 값에서 수심을 역산하거나 인접 격자의 수심을 합성하지 않음. 격자 원형·중심 표고·면적·좌표계·수직 기준·입력/파일 해시와 실제 출력 시각을 연결. 시간 보간 없이 요청 이전의 마지막 저장 시각과 경과 차이를 반환하고 범위 밖 외삽 금지. 8 ULP 이내의 시계 반올림은 같은 시각으로 대응하되 원 요청/저장 시각과 조정량 보존. 유속은 수심 >10⁻⁶m에서 운동량/수심, 그 이하는 표시 유속 0으로 두되 원 수심·운동량 보존. 표시 프레임에서 첨두·침수 지속시간·점수를 재계산하지 않음. 출력 개수/바이트 한도 초과는 명시적 실패로 보존하며 물리 간격이나 격자를 몰래 축소하지 않음. 입력·수치 판정·해시가 확인된 결과만 읽고 수치 통과를 현장 검증/공개 게시 승인으로 취급하지 않음.

2026-10-18 공개 기존 시설 편입 경계: 공개 위치/정격 제원 조회와 물리 계산 입력을 분리. 공간 ZIP의 점 자료·삭제 플래그와 강서구의 호기별 m³/min·유수지 m³는 원문 그대로 보존. 현재 운전량·양정-유량 곡선·유입/출구 연결·제어 수위·당시 존재 증거가 없으므로 무한 출구나 상수 양수량으로 계산하지 않음. 파일 수정일·자료 기준일을 준공일로 치환하지 않고, 재해 당시 시설 목록과 현재 공개 참고 레이어를 구분.

광진구 설비 이력의 설치·증설은 연 단위 근거. 사건보다 뒤에 설치한 설비는 당시 자산에서 제외, 사건 뒤 증설한 설비의 현재 제원을 과거에 전용하지 않음. 같은 연도는 정확한 날짜 미확인으로 보류하고, 설치 연도가 앞서도 당시 존속·운전까지 확정하지 않음. 사건 날짜는 서버 사건 카탈로그에서 결정. 원문의 `kW(HP)` 혼합 표기는 단위 확인 없이 환산하거나 양수량으로 대체하지 않음. 원본·행 번호·구/명칭 검토 대응표·파생 해시와 사건별 판정 보존. 현재 9개 설비 묶음 모두 참고 이력이며 `simulationIncluded=false` 유지.

## 초기 상태·선행 기간 민감도 비교

지표 침투의 선행 관측 연결은 원문 재정규화한 강우와 이전 완료 일의 관측 기상 기반 증발산을 같은 ANUGA/EPA 실행 앞부분에 입력. 지정한 7/14/28일 이전의 수심·수분 부족률은 명시적 시드로 유지. 평가 시작 경계에서 EPA 침투 상태와 지표 수심·저류·누적 원장을 읽기만 하며 엔진 재초기화나 최종 수분값만의 이식 없음. 평가 구간은 시작 누적량을 차감하고 시작 저류량을 포함한 별도 물수지로 집계. 선행 강우의 구간 평균·품질 경고는 보존하고 평가 강우의 엄격한 원문 판정을 완화하지 않음. 기간 비교는 동일 재료 매개변수와 시드에서 수행하며, Green–Ampt의 초기 최대 수분 부족 매개변수를 바꾼 실행을 동일 토양의 건습 상태 비교라고 표시하지 않음. 이 연결은 경험식 토양 회복·지표 가용수량 제한 증발이며 뿌리/지하수 전체 수분 모형이나 현장 함수율 관측으로 승격하지 않음.

현재 경쟁 입력의 선행 7일·시들음점/빈 저류층 정책은 유지. 연구 비교에서는 같은 실제 평가 강우·기상·도형·제원을 고정하고 선행 7/14/28일과 SWMM InitSat 0/100%를 별도 실행. 0은 식재토 시들음점, 100은 공극률 및 저류·배수매트 포화 상태이며 둘 다 관측 초기 수분이 아닌 경계 시나리오. 평가 시작의 토양수분·총저류·층별 수심과 평가 유출/배수/증발/침투·기여의 범위, 시드별 기간 차이를 보존. 비교 구간의 선행 효과는 평가에서 제외. 임의 보편 임계값으로 수렴 인증하지 않으며 실패 조건도 보존. 일부 사건·시설의 작은 차이를 서울 전체 완전 수렴으로 확대 해석하지 않음. 참고: EPA SWMM 5.2 사용자 매뉴얼 [LID_USAGE] InitSat 정의.

신규 후보 v6의 빗물정원은 공개 토성군에서 추정한 원지반 투수계수를 EPA의 하부 침투 경계에 명시적으로 연결. SWMM 5.2.4는 RG STORAGE 입력이 없으면 storage.kSat=0으로 초기화하므로 `RG STORAGE 0 0 Ksat 0`으로 하부 침투율만 지정. 두께·공극 체적 0 유지, 가상의 쇄석층·추가 저류 용량 생성 없음. 토성 미확보 후보는 기존 설계 투수계수의 가정임을 보존. 차수막 없는 설계 조건이며 실제 부지의 차수막·지하수·매설물·다짐 확인을 뜻하지 않음. 후보별 적용률·출처 수준·방법을 입력과 계산 결과에 보존. v5 이하의 원문·점수·기존 계산 입력은 소급 변경하지 않고, 원지반 침투 미연결 결과는 해당 한계를 표시.


## 격자 내 토양 면적 분할

지표 침투 v2는 같은 삼각형 안의 여러 토양을 독립 EPA 상태로 계산하며 삼각형 수심을 공유하는 면적 분할 근사로 표시. 각 투수 부분의 면적비와 명시적 불투수 부분의 합은 1이어야 하며 허용 오차 10⁻¹²는 부동소수 면적 연산에만 적용. 누락 면적의 자동 불투수 처리·면적비 정규화·토양 매개변수 평균 금지. 침투량은 부분 면적별로 계산한 뒤 삼각형별로 합산하여 물과 운동량을 한 번만 제거. 부분별 상태·침투량과 삼각형별 합계 보존. 기존 v1 입력과 결과 의미 유지.

공간 배정은 원본 DEM 삼각형과 공개 토양/토지피복 폴리곤의 실제 교차 면적으로 수행. 원본 구멍과 다중 도형 유지, 경계 접촉 면적 0 제외. 같은 분류라도 겹친 원본은 임의 우선순위로 선택하지 않고 중복 영역 보존. 오류 도형의 영향 범위·미피복·자료 시점·좌표 변환 정확도 미확인을 별도로 기록. 토지 이용 분류를 관측 투수율로 치환하지 않으며, 공간 교차 결과만으로 침투 입력을 활성화하지 않음. 전체 면적의 물리 분류 근거가 없는 경우 미해결 원인을 반환하고 불완전한 격자/유역을 잘라 계산하지 않음.


## 공개 도시생태현황도의 표면 구성 입력

서울시 도시생태현황도 2025/2020/2010 원본을 판년도별로 보관. 블록의 건폐율·불투포장율·투수포장율·녹지율·기타비율·불투토포비 원값과 원본 고유번호/행 순번을 보존. 합계 100과 건폐율+불투포장율=불투토포비를 10⁻⁷%의 수치 허용 오차로 대조하며 누락·범위 초과·불일치 값을 정규화하지 않음. 토양포장 범례와 숫자값의 모순도 원문 그대로 표시. 비율은 블록의 조사/영상 기반 속성이며 각 DEM 삼각형 안에서 같은 비율을 적용하는 것은 공간 균질 배정 근사. 실제 포장 위치의 측량 결과로 표시하지 않음.

투수포장 면적을 자연 토양 Green–Ampt 영역으로 자동 전용하지 않음. 녹지·나지와 투수포장을 별도 면적 구성으로 보존하고, 포장층 제원 없이는 투수포장 물리 입력을 완료로 표시하지 않음. 2025 최종보고서의 111~112쪽 속성 정의와 264쪽 주석 66(일부 투수포장의 면적 미산정·불투수 면적 과대평가 가능), 267쪽 주석 67(건설현장의 기타비율) 반영. 2020/2010의 동일 필드도 2025 작성 방식과 동일한 현장 조사였다고 단정하지 않음. 판년도만으로 사건 당일 유효성을 확정하지 않으며 현재 지형+과거 속성 비교는 별도 탐색 등급 유지.
