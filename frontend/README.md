# WATER LEAGUE 설계실

React·TypeScript·R3F/Three.js. 계정·자료·게임·연구 도메인과 공통 API·예외 처리. DTO 검증→매퍼→엔티티, 컨트롤러 상태→서비스·저장소→뷰 구조.

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm dev
```

[로컬 설계실](http://127.0.0.1:5173/)에서 실제 건물 경계, 시설 3종 배치·면적·원화 예산·되돌리기·저장·계산·탐색 순위·공유 동의·기관 이력·재현 묶음 제공. `/api`는 127.0.0.1:8080 API로 프록시. 결과 계산은 Python 워커 별도 실행 필요.

표고 평탄화·일부 건물 높이·도로 폭·지상 실험 단위·시설 형상은 가정. 빗물정원 색상은 배치 표시이며 침수깊이가 아니다. 강우 그래프는 관측 분당 깊이, 결과 그래프는 SWMM 보고시각 보간 유량. 원화 단가 출처와 서울 현장 전용 전 가정은 데이터 화면에서 확인.

3D 번들 지연 로딩, 지도 외 목록으로 구역 선택, WebGL 오류 경계, 작은 화면 로그인·설계·데이터 접근. 토큰 localStorage 저장 없음. 실제 기기별 FPS·전체 WCAG 감사·WebGL context loss 검사는 별도 운영 검증 대상.
